## 讲解

点一个画一个：所有 (x, y) 工作记录连起来就是这条直线。

函数图像 = 一台机器全部工作记录的画像。

```interaction
{
  "type": "plot-points",
  "params": {
    "fn": "2*x + 1",
    "xMin": -2,
    "xMax": 2,
    "step": 0.5,
    "autoPlay": true,
    "speed": 800
  }
}
```

null
