# 白队前端经验沉淀（通用版 · 可复用数学及其他学科）

> 来源：2026-10-10 英语·词根词缀工具 v13–v18 实战。项目约束：纯静态 HTML/CSS/JS，零依赖（无 CDN、无外部字体），全相对路径，GitHub Pages + `file://` 双兼容。
> 本文档只谈**跨学科通用**的前端经验；学科特有检查（如英语词素高亮）见 `docs/white-checklist.md`（英语专用版）。

## 一、一屏布局的约束与技巧

核心铁律：**整页无滚动**（`html,body{height:100%;overflow:hidden}`），所有内容塞进一屏。

1. **纵向空间预算先行**：动手写 CSS 前，先给每个区域定死预算——header（flex:none）/ hero 区（flex:none）/ 主交互区（flex:1）/ 说明区（flex:none, 固定高度）。预算一经定死，后续只允许压缩、不允许膨胀。
2. **`flex:1` 只给主交互区**：拨盘/画布/练习区这类核心组件独占 `flex:1`；说明文字、按钮条一律 `flex:none`。
3. **动态内容区必须固定高度**：凡是内容行数会变的区域（如词义说明、公式推导步骤、提示文字），**禁止用 `min-height` 让它自然撑高**——它会挤压上面的 `flex:1` 区。做法：按"全库最大行数"定死 `height` + `overflow:hidden`。英语页教训：`.dial-mean` 从 `min-height:2.2em` 改为 `height:5em`（容纳 2 行词义），切换词根时拨轮位置纹丝不动。
4. **新增数据后回查预算**：数据扩容（加词根、加公式、加题型）后，必须程序化检查"最大行数"是否突破预算，突破则先调预算再上线，而不是让用户发现错位。
5. **用 `dvh` 不用 `vh`**：移动端浏览器地址栏伸缩会导致 `100vh` 跳动，一律 `height:100dvh`。
6. **横向零溢出**：`white-space:nowrap` 的长文本（如长单词、长公式）必须配 `overflow:hidden;text-overflow:ellipsis`，三端都要测。

## 二、选择器组件设计经验（拨盘 → 通用滚轮选择器）

英语页的双拨盘本质是一个**纵向滚轮选择器**，可直接复用给：数学公式选择器、符号面板、题型切换、章节导航。

1. **结构**：外层 `.wheel-wrap`（`flex:1` 占位）+ 内层 `.wheel`（`overflow-y:auto`）+ 上下 `.wheel-pad` 垫片。垫片高度 =（容器高 − 行高）/2，保证选中项永远居中对齐高亮框；容器尺寸变化时用 `ResizeObserver` 重算。
2. **选中判定防抖**：`scroll` 事件只做 `requestAnimationFrame` 节流 + 140ms settle 防抖，停止滚动后才 `Math.round(scrollTop/itemH)` 落定。狂拨 30 次无错乱、无重复触发。
3. **视觉透视**：离选中项越远越小（scale）、越透明（opacity）、越模糊（blur），约显示 7 项。选中项用高亮框（浅蓝框）而非仅靠颜色，色弱可辨。
4. **三种操作都要通**：触摸滚动、点击直达（`click` 委托到 `.wheel-item`）、键盘方向键（`tabindex` + keydown）。无障碍 `role="listbox/option"` + `aria-selected`。
5. **数据量上限实测**：250 项 → 约 260 个 DOM 节点，浏览器无压力；滚动 59–60fps（headless 软件渲染），堆内存零增长。**通用红线：单个选择器 ≤500 项**，超出则必须加搜索过滤（英语页抽屉搜索 250 项全量遍历 <5ms）。
6. **初始选中必须静默**：`setItems` 后的首次 `go(0)` 不播音效、不播动画、不震动，否则打开页面就"咔哒"一声。

## 三、音效与触觉反馈的实现模式

1. **Web Audio 现场合成，不放音频文件**：短促"卡塔"声用 `OscillatorNode`（triangle 波，2400Hz→1200Hz，0.04 秒衰减到静音，增益 0.04）即可，零外部文件、零加载延迟、零仓库体积。英语页曾为此删掉 7.8MB 的 MP3 目录——**新学科一律不引入音频文件**，全部合成。
2. **AudioContext 懒创建 + resume**：首次交互时再 `new AudioContext()`，`state==='suspended'` 时 `resume()`；全程 try/catch，失败静默。
3. **音效只在"落定"时响一次**：滚动过程中不响，settle 选中后响一声；去重 300ms 内相同事件。
4. **震动**：`navigator.vibrate(8)`（8 毫秒微弱震动），try/catch 包裹，桌面端 `navigator.vibrate` 不存在则自动跳过。**震动与音效同一次事件触发**，保持一致。
5. **卡入动画**：CSS `@keyframes`（scale 1.1 → 1.26 → 1.22，0.18s ease-out），JS 侧 `classList.remove` + 强制重排（`void el.offsetWidth`）+ `add` 重启动画。动画时长 <200ms，不阻塞交互。
6. **提供关闭预期**：音效/震动虽默认开启，但后续学科若用户反馈打扰，应在设置里加开关（英语页暂未加，记为待办）。

## 五、降级策略（零依赖项目的生命线）

1. **数据文件缺失可运行**：`data/*.js` 用 `window.XXX || []` 兜底；缺失时显示空态提示（"没有找到"/"暂无收词"），不白屏、不报错。实测：`phon.js` 缺失 → 单词正常显示，音标行自动隐藏。
2. **localStorage 禁用可运行**：所有读写包 try/catch，禁用时回退内存默认值，切换功能不受影响。
3. **`file://` 双击可运行**：不用 `fetch` 加载数据（改用 `<script>` 标签引入 `.js` 数据文件）；不用 ES Module（用 IIFE + `var`）；全相对路径。
4. **字体降级**：特殊符号字体（如 IPA 用 Charis SIL）按 `"Charis SIL", Georgia, serif` 顺序写，缺失时自动回退，实测显示正常。
5. **浏览器特性检测**：`ResizeObserver`、`speechSynthesis`、`navigator.vibrate`、`AudioContext` 用前先 `in` 检测，不支持就静默跳过对应功能。

## 七、与红/蓝队的协作接口（白队视角）

1. **红队交付 → 白队要查**：红队改数据（如补变体、拆词根）后，白队必须重跑"全库扫描"（如词素可见性、最大行数），因为数据变化会打破 UI 假设。本项目实例：补 11 个音变变体后，词素匹配失败从 12 降为 0。
2. **蓝队交付 → 白队要查**：蓝队加功能后，白队按"三端 + 降级 + 性能"三件套验收，不只看功能通不通。
3. **问题归档格式**：`版本：现象 → 根因 → 修复`，写入 `docs/white-checklist.md`（学科专用）底部"历史问题归档"，防止复发。本项目已归档 v15/v16/v17 三个布局类问题。
4. **用户截图优先于自动化**：用户随手截的图（如"词义被挡住"）定位速度远超自动化脚本——白队的 Playwright 检查负责"确认修复"，用户的眼睛负责"发现问题"。

## 八、绘图几何断言（2026-10-14 几何绘图事故沉淀）

> 背景：用户目检发现几何模块"角位置不对、延长线虚线不共线"。白队对 340 页逐页程序化审计（`tools/geom-audit-20261014.mjs`，逻辑坐标 0–100、y 向上），定位渲染器 R1/R2/R3 三处根因 + 约 60 页数据修正。以下条目**全部可程序化断言**，且**适用所有学科**（物理受力图、化学分子式配图、地理示意底图、生物结构图凡有几何图形处一律套用），不只几何。

1. **角弧圆心 = 顶点**：`arc` 的圆心坐标必须落在所标角的顶点上（容差 0.75 逻辑单位）。事故：R1 渲染器把弧画偏了顶点，看起来"角位置不对"。断言时按顶点 id 反查，不许按"看起来在附近"放行。
2. **弧端点方向落在两边上**：弧起止方向角必须分别落在角两边的方向角容差内（容差 3°）。事故：弧方向错导致弧横跨到角外面。端点不许只查"在圆上"，必须查"在边上"。
3. **弧 sweep 与内角一致（防优弧错画）**：弧扫过的角度必须等于标注的内角度数（容差 2.5°），且 sweep 方向与内角开口方向一致。事故：g10-u1-l5-p1 把 90° 转角画成了 270° 优弧。断言必须显式比较 `|sweep − 内角|`，不许默认"画出来是个弧就行"。
4. **延长线虚线与实线共线且从端点起接**：虚线延长段的方向角与被延长实线段的方向角偏差 ≤2°，且虚线起点 = 实线端点（容差 0.75）。事故：R2 渲染器延长线不共线。两个条件缺一不可——只共线不接端点、只接端点不共线，都算 FAIL。
5. **延长线断言不许做帧级掩盖**：同一帧里有多条延长线时，每条线独立断言、独立报告；**不许"同帧有一条好线就压住坏线"**。事故复盘发现早期审计逻辑里"一好遮百丑"的掩盖写法，漏掉了真坏线。实现上：循环内 `fail` 只追加不 `break`，报告精确到元素 id。
6. **装饰弧也要做方向核查**：非教学主体的装饰弧（如步骤高亮弧 `ARC_HL`）同样跑"圆心=顶点、端点在边上"断言；程序化对不上的（如跨步沿用的 A/B 点）标记 `ARC_HL_UNVERIFIED` 转人工目检，**不许静默跳过**。本次 5 处跨步沿用点全部经人眼截图复核通过。
7. **直角标记真 90° 且不浮空**：直角标记的两条短边必须分别平行于角的两边（偏差 ≤2°），标记角点 = 角顶点（容差 0.75）。"看起来像个小方块"不算，必须验平行 + 验落点。
8. **圆上点到圆心距离 = 半径**：凡标注"在圆上"的点，`|dist(点,圆心) − 半径| ≤ 1.5`。近圆（≤4）只给 warn 不给 fail，但必须出现在报告里供人眼看。
9. **标注度数与图形一致**：图上文字标注的度数（如"50°"）必须与程序化量出的实际几何度数一致（容差 2.5°）。文字和图形是两套数据源， mismatch 说明至少一边错了。
10. **审计工具自身的坐标系必须与被测对象一致**：本次 `dirOf` 事故——审计函数在屏幕系（y 向下）里算方向，却拿去和数学系（y 向上）的数据比较，造成误报/漏报。铁律：断言工具的坐标约定必须写在报告 `meta.coordinateNote` 里，且所有方向比较先统一到同一坐标系再比。非均匀缩放的渲染链（如 angle-protractor 的 X/Y 缩放不一致）必须单独声明并证明自洽，否则结论无效。

- **执行位置**：数据入库前（蓝队写完数据 → 白队跑审计 → 0 FAIL 才合入），不许"先上线后补查"。
- **报告格式**：`{page, frame, type, severity, element, measured, expected}`，warn 必须带"人工确认"动作项，不许只有 fail 才有人看。

## 九、物理位图断言（2026-10-15 物理审计修复沉淀）

> 背景：用户亲检物理后投诉四类问题（①交互位图不准确 ②交互不直观 ③目录未收起 ④学习页划不出目录）。白队随后对 356 页做全量位图程序化审计（终验 640 断言 0 FAIL）+ 目录抽屉专项 12 项（含 CDP 真实触摸）。以下条目**供化学/地理/生物直接复用**：先有真值口径 + 位图断言脚本，再谈上线。

1. **口径引用方式**：每条断言必须引用专家队真值口径的编号（如 `physics-truth-criteria.md` 的 PHY-O13 像距公式一致），断言格式固定为"编号 断言名 — 判定条件 — 容差/例外"。口径未覆盖的一律标 WARN 转人工确认（口径 §8），**不许自创口径放行**，不许"看起来对"就 PASS。
2. **坐标声明**：所有几何断言先写 `coordinateNote`（物理：逻辑坐标 0–100、y 向上；渲染映射 `svg_y = 100 − y_logic`；角度一律 `atan2(dy,dx)` 换算）。审计工具自身的坐标系必须与被测对象一致（见第八节第 10 条 `dirOf` 事故）；非均匀缩放的渲染链必须单独声明并证明自洽，否则结论无效。
3. **初值帧策略**：审计基线 = params 初值渲染的第一帧（口径 §0.2）；交互后状态做**行为一致性抽查**（滑块拖到边界值、拖拽到两终态、读数跟着变不变），**不许只验默认位形**。动画逐帧、拖拽中间态未覆盖的，必须在报告"未覆盖项"里如实声明，不许用"抽查"二字含糊带过。
4. **FAIL/WARN 分级**：`FAIL` = 物理关系画错，必须修；`WARN` = 教学故意示意/可接受近似（如近似条件已写进学生文案），须在报告中列出并转人工确认。报告格式 `{page, frame, type, severity, element, measured, expected}`；warn 必须带"人工确认"动作项，不许只有 fail 才有人看。
5. **断言脚本位置**：审计脚本与证据沉淀在仓库外工作区 `~/workspace/phy-audit/`（行为脚本 `behavior*.mjs`、复验脚本 `taskA-reverify.mjs`/`taskB-regression.mjs`/`drawer-rerun.mjs`、截图 `shots/`、真值口径 `physics-truth-criteria.md`、审计报告 `audit-report.md`）。化学/地理/生物建同名工作区（`~/workspace/chem-audit/` 等）复用同一套脚本骨架。
6. **补修复验铁律（2026-10-15 R2 追加）**：修复队的自述不可采信，必须独立实测。本次两条教训：① 修复队称"浅色沿用 body 白底不受影响"，白队实测浅色抽屉背景为透明（`rgba(0,0,0,0)`，页面内容透出）——**补修必须深浅两色独立断言**，修一色验两色；② 抽屉专项旧脚本的"滑块保持"项 fixture 选错页（p05.1.1/1 是 force-drag，全文档零 range 滑块），**测试 fixture 的有效性本身要先断言**（断言前先验 fixture 存在），否则假 PASS/假 FAIL 全是噪音。

### 上线 QA 漏检自查（为什么 80 项断言 + 试点 225 项没拦住四类投诉）

先说覆盖了什么（不抹功）：约 80 项断言覆盖一屏布局、44px 行高、翻页流程/hash、深色、file://；试点闸门 225 项覆盖试点三页。验证的是 **"页面活着、布局没崩、流程能走"** ——存在性/布局级。

再说漏了什么（不含糊、不甩锅，四类投诉一一对应）：

- **① 交互位图不准确 → 位图物理真值断言缺失**。断言只查"组件渲染出来了"，没查"图画得对不对"（三条特殊光线是否真过焦点、像距公式算出的 v 是否与图上像点位置一致、徽章性质与 u/f 区间是否矛盾）。"渲染器构造正确"是一个**未经独立换算验证的假设**——白队信了蓝队的构造逻辑，没有拿独立公式重算一遍去对质。
- **② 交互不直观 → 只验默认位形，未拖动验证**。滑块停在初值、拖拽停在起点，没有"真的拖一下"看读数/位图跟不跟、跟得对不对。直观性是黄队的事后审计补上的，上线 QA 里根本没有这一项。
- **③ 目录未收起 → 目录只验了浏览器视图，没进学习视图查入口**。QA 的页面清单里有章节浏览器（目录在那儿好好的），但**学习视图里根本没有目录入口**——"收起"无从谈起。漏的不是"目录好不好用"，漏的是"学习页有没有目录"这一整行检查项。
- **④ 学习页划不出目录 → 零手势测试**。全仓无 swipe 处理，QA 却没有任何触摸手势测试（CDP 真实触摸事件是事后才引入的）。手势是否生效全靠读代码脑补，而代码里根本就没有手势处理。

根因一句话：**白队 QA 断言的粒度停在"存在性/布局级"，没下沉到"正确性/行为级"**。这是白队断言设计的问题，不怪蓝队代码、不怪黄队——用户（robbin）的眼睛替白队查了这次漏。以后说"完成"之前，先按他的眼光把图自审一遍。

新规（已生效）：位图正确性沉淀为程序断言，列为后续学科上线门槛——化学/地理/生物开工前必须先有专家队真值口径 + 白队位图断言脚本，0 FAIL 才许上线，不许"先上线后补查"。

## 十一、视觉提案 P-01~P-05 落地断言（2026-10-16 主观观感提案实现沉淀）

1. **受力图内容自适应 bounds（P-01）**：Konva 受力类画布按内容实测包围盒自适应 bounds，
   不许固定大 bounds 留白。断言：初始状态内容包围盒面积 / 画布面积 ≥35%；
   拖拽全范围（各力 min..max、角度任意）内容不被裁剪；**可见内容**边缘距画布边 ≥8px；
   `eng-hitarea` 命中区（不可见触控设施）不计入内容比、不裁剪即可（≥0px）。
   修法口径：grow-only（只放大不缩小，中心固定，无缩放跳变）+ 增长迭代至收敛
   （setBounds 后 scale 变化，一次增长不够，循环 3 次）；
   装饰性地面线收缩到内容范围，不许用固定长线撑大 bounds。事故：p12 三页固定
   bounds 0..100，300px 画布中有效内容约 130px（面积比约 19%）。
2. **力标签零碰撞 + 避让算法（P-02）**：受影响页全部文字外接框两两零相交（含图标、
   箭头杆按 6px 膨胀计入）。断言：headless 渲染后遍历 `stage.find('Text')` 取
   `getClientRect()`，两两相交面积 >0.5px² 即 FAIL；**标签盒与他箭头杆线段距离 <6px
   即 FAIL**（自身箭头尖端锚定 + halo 是正确做法，除外——可执行口径：标签/箭头节点均
   带 `data-force` 标识，测量时排除与标签同 `data-force` 的箭头线段）。
   修法口径：候选位评分（零碰撞优先、位移最小次之；6px 门禁只针对他杆，自身杆不计
   罚分、仅用于 halo 触发判定）+ 紧贴时小底衬（halo，描边取画布底色）；
   **共线构型专项**：合力尖端落在他杆上时（如 p12.2.4 N=15N、角度 80°–100°），

   断言：80°/85°/90°/95°/100° 五态 F合 标签与他杆距离 ≥6px、零相交；
   **零长箭头**：mag≈0（<0.05）时隐藏力标签（合力已用同样阈值），断言：该态下标签
   不可见且文字零相交。
   事故：p12.1.4 `N` 标签与 🔒 重叠、p12.1.3 `F合` 标签压箭头杆；
   复验打回（2026-10-16）：p12.2.4 共线态 F合 标签盒被 N 杆穿过（d=0，6 候选位
   偏移量级不够）、f1=0 时 F₁ 标签与"木块"交叠 34.55px²，均已按本条口径返工。
3. **"下面还有" pill 嵌入流内（P-03）**：提示 pill 不许绝对定位悬浮覆盖内容。
   黄队口径：**嵌入流内**（zone 下方文档流占位；"可滚且未到底才显示"逻辑保留），
   不选"仅首屏提示一次"。断言：pill 显示状态下，对 zone 内各滚动位置截图，
   内容区文字/图注被 pill 遮挡面积 =0（程序化：pill 盒与内容盒零相交）。

   不许只改试点页。事故：1366 下 pill 压住杠杆页 O 标签区、弹簧页读数行。
4. **宽屏入口版式（P-04）**：≥820px 视口入口壳放宽到 980（与数学 `.m-main` 对齐；
