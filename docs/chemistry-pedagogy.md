## 一、设计总纲：六条铁律 + 化学专属三条

### 1.1 沿用几何六条铁律（化学转述版）

1. **一页一概念**：一屏只讲透一个核心概念。宁可多一页，不可一页塞两个概念。化学课常犯"一页讲完化学式书写又讲化合价"——拆开。
2. **先动手，后结论**：交互动画在前，文字解释在后。学生先亲眼看到"铁钉放进硫酸铜溶液变红"，再看文字"这就是置换反应"。**交互区没有 exploreTip（动手提示）= 不合格**。
3. **图言永不分离**：每个化学结论旁边必须有对应的实验现象图/微观粒子动画；**每个化学定义必须配一个"反例"**（"不是××的东西"）：每个规律的适用条件，本质上就是一组反例。只给方程式不给现象 = 不合格。
4. **跃升必有台阶**：每个难度跃升点必须设计中间脚手架（见第三章），不许"显然""易得"式跳跃。**化学里最危险的跳跃是"符号跳跃"**：从现象直接跳到化学方程式，中间缺了"微观粒子在干什么"。
5. **密度上限**：每页 ≤ 3 个信息块（标题区 / 交互区 / 点拨区），≤ 2 个例子，文字总量 ≤ 150 字（讲解页 ≤ 300 字，见第四章）。
6. **（化学转述）宏观—微观—符号三重表征切换**：化学的灵魂是"同一件事，三种讲法"。凡是可调参的交互，必须同时给出三重表征：**宏观**（看到了什么现象）、**微观**（粒子在干什么）、**符号**（怎么写）。表征切换时必须明示"现在切换到哪一重"——对应几何"变化中找不变"，化学版叫**读数徽章 + 粒子计数徽章**：实时显示带规范符号的读数（如 `溶液质量分数 = 10%`、粒子计数 `Na⁺ : Cl⁻ = 1:1`），徽章文字写清楚"微观在发生什么"。

### 1.2 化学专属三条（黄队新增）

7. **三重表征切换**：**每个抽象概念必须"宏观现象 → 微观粒子动画 → 化学符号"三步走，缺一不可**。教学顺序永远是：先看到现象（宏观）→ 再看粒子在干什么（微观）→ 最后学怎么写（符号）。不许从现象直接跳到符号——跳过去的那一步，就是学生"背方程式"的开始。例如 cm05.1.2 化学方程式：先看 C 在 O₂ 中燃烧的现象，再看碳原子、氧分子"拆开重组"的粒子动画，最后才写 C + O₂ → CO₂。
8. **实验先行**：**无实验不定——凡涉及实验现象的结论，必先有一页"动手/观察页"，学生亲手"看"到现象后才下结论**。燃烧、酸碱变色、沉淀生成、气体放出——凡是"现象说了算"的结论，定义页之前必须有一页观察页。**安全操作必须在实验页开头以"安全徽章"呈现**（⚠ + 一句话，常驻不随交互消失），例如点燃 H₂ 前验纯、稀释浓硫酸酸入水、有毒气体尾气处理。虚拟实验可以"试错"，但每一页都要让学生清楚"现实中哪一步绝不能试"。
9. **符号慢读**：**化学符号（化学式、方程式、离子符号）第一次出现必须"慢读"：逐字读出意义（宏观 + 微观），不许跳读**。H₂O 第一次出现：宏观读"水这种物质"，微观读"一个水分子由两个氢原子和一个氧原子构成"——两遍都读完，才算"认识"了这个符号。慢读用蓝队 Y8 `slow-read` 组件实现（点一句亮一重表征）。

## 二、每页结构规范（沿用物理三块式，化学微调）

### 2.1 页面结构

```
┌─────────────────────────────┐
│ 标题区（一句话概念）    │ ← ≤ 20 字，flex none
├─────────────────────────────┤
│ │
│ 交互区（主角，占 60%）  │ ← flex 1：虚拟实验/粒子动画在这里
│ 读数徽章（小标签）    │ ← ★化学版：带规范符号的实时读数
│ 状态徽章（状态文字）  │    如 溶液质量分数 = 10%；Na⁺ : Cl⁻ = 1:1
│ 安全徽章（⚠ 一句话）  │ ← 涉及危险操作时常驻顶部
├─────────────────────────────┤
│ 点拨区（≤ 60 字 + 下一步） │ ← flex none，"这就是××"式点题
└─────────────────────────────┘
```

**化学微调说明**：

- **读数徽章**：交互区角落的小标签，随交互实时更新。**所有数值读数走 MathML、化学符号规范、单位与数值同行**（`溶液质量分数 = 10%`，不许裸文本 "10%"；粒子计数 `Na⁺ : Cl⁻ = 1:1`，不许裸文本 "Na+:Cl-=1:1"）。读数徽章是第六条铁律的落地——学生即使不看文字，也能从徽章里读出"微观在发生什么"。例如 cm05.1.1 质量守恒页：徽章"反应前原子总数 = …，反应后原子总数 = …"；cm09.2.1 配制溶液页：徽章"溶质质量分数 = …%"。
- **状态徽章（状态文字）**：化学特有——很多化学状态不能只靠图形读出来，必须配文字。溶液（"饱和 ✓"/"不饱和"）、反应（"进行中"/"平衡 ✓"）、现象（"变浑浊"/"产生气泡 ↑"/"颜色变红"）。**状态永远双编码：图形 + 文字，不只靠颜色**。
- **安全徽章**：涉及点燃可燃性气体、加热、浓酸/浓碱、有毒气体的页，交互区顶部固定一条安全提示条（⚠ + 一句话），常驻不随交互消失。话术见第九章。
- **虚拟/现实分界线标注**：虚拟实验页角落常驻小字"虚拟实验：现实中须××（如验纯/通风橱/戴护目镜）"，不误导"现实中也能这么玩"。
- **三重表征切换器**：同一交互配"宏观 / 微观 / 符号"三视图切换按钮（蓝队 Y6 `tri-rep`），切换时页面顶部小字明示"现在是微观视角：你在看粒子在干什么"。这是第七条铁律的组件落地。

### 2.2 四类页面的分工（化学四步走：看 → 玩 → 懂 → 练）

| 页类型 | 作用 | 结构 | 占比 |
|---|---|---|---|
| **观察页** | 看：动手/观察页，亲眼看到现象（实验先行，铁律 8） | 三块式 + 安全徽章 + exploreTip | 约 15% |
| **交互实验页** | 玩：调参探究，亲手改变条件看结果 | 三块式 + 读数徽章 + exploreTip | 约 30%（130 课每课 1 页起） |
| **演示/慢放页** | 看：微观粒子动画慢放、思想实验（如原子结构演化史） | 步骤条 + 画布（复用 slow-replay 范式，≤ 5 步） | 约 10% |
| **讲解页** | 懂：交互页之后 1–2 页完整讲解，三重表征对齐 + 反例 | 见第四章 | 约 35% |
| **习题页** | 练：每章末，答案折叠；**每章必有一道"生活中的化学"题 + 一道定量计算题** | 见第五章 | 约 10% |

**顺序铁律**：同一概念内，顺序必须是 **观察页 → 交互实验页 → 演示/慢放页（如有） → 讲解页 →（章末）习题页**。不许先给方程式再让学生玩——方程式是学生自己"玩出来"之后，黄队用文字帮他"说出来"。**特别地，符号页的顺序永远是：现象 → 微观 → 符号 → 条件/反例**（第七、九条铁律）。

### 2.3 讲解页与交互实验页的衔接语规范

- 讲解页开头第一句必须是"认旧友"："还记得吗？你第 X 页看到铁钉表面变红时，溶液颜色变浅了。"（沿用几何"认旧友"标注规范）
- 交互页的 exploreTip（≤ 40 字）只说"动手做什么"，不说结论。结论永远在点拨区，由学生"看到"之后黄队点题。
- **"先猜后验"**：鼓励每类交互实验页配一个"猜一猜"小条——学生先点选预测（"把锌片放进硫酸铜溶液，会发生什么？"），再动手验证。**不判对错**，只记录（给后续学习报告留接口）。此为黄队新增教学动作需求（蓝队 Y1 `guess-verify`，沿用物理增补流程）。

## 三、难度跃升脚手架（12 个化学特有卡点）

> 每个脚手架 = 卡点描述 → 2–3 页分步脚手架 → 点拨话术。课号全部取自 `docs/chemistry-curriculum.md` v1.1。

### 跃升 1：宏观 → 微观（"看不见的粒子"第一次升级）

- **卡点**：学生学了多年"东西"，第一次被要求相信"看不见的粒子"。要么当神话听，要么追问"那你咋知道它存在"——直接讲"分子三性"会被当成背诵。
- **脚手架**（cm03.1.1 分子与原子（上），3 页）：
  1. 观察页：品红扩散 / 氨气扩散虚拟实验（温度可调）。"红色自己散开了——谁推的它？"
  2. 交互页：三重表征切换器（Y6）——宏观（品红散开）→ 微观（品红分子/水分子永不停息运动动画）。"你看不到分子，但你能看到'被分子推着走'的品红——**看不见的东西，可以通过它'推'的东西来证明。**"
  3. 讲解页：分子三性（运动/间隔/质量体积小）。口诀："**分子三性：动、隔、小。**"
- **点拨话术**："从今天起，化学有两双眼睛：一双看现象（宏观），一双看粒子（微观)。**看不见的粒子，干着看得见的事。**"

### 跃升 2：物理变化 → 化学变化（"分子种类变了"判据）

- **卡点**："发光发热 = 化学变化"的直觉根深蒂固（电灯发光发热偏偏是物理变化）。学生靠"现象清单"背诵判据，一换题就错。
- **脚手架**（cm01.1.1 物质的变化和性质，3 页；红线辨析③立靶）：
  1. 交互页：水沸腾 vs 水电解对比动画（微观粒子视角）。"左边水分子还是水分子（只是散开了），右边水分子'散架'成了氢分子和氧分子——**分子种类变没变？**"
  2. 交互页：判据闯关——电灯发光、铁锅生锈、冰化水、饭变馊，拖进"分子变了 / 没变"两个筐。"发光发热的电灯，分子没变，是物理变化。"
  3. 讲解页：红线辨析③立靶页。"判据只有一个：分子种类变没变。"
- **点拨话术**："**别看热不热闹，看分子变没变。**发光发热只是'热闹'，分子种类变了才是化学变化。"

### 跃升 3：元素 → 原子（宏观种类 vs 微观粒子）

- **卡点**：全书最绕的一对词。"水由氢氧元素组成"和"水分子由氢氧原子构成"在学生嘴里是同一句话——但在化学里分管两重表征，串了就是错句。
- **脚手架**（cm03.2.2 元素，3 页；红线辨析④立靶）：
  1. 交互页：元素周期表交互地图——点一个元素，看"质子数相同的一类原子"。"元素是原子的'姓氏'：质子数相同的原子同'姓'，算同一元素；质子数一改等于'改姓'，就是另一种元素。"
  2. 交互页：错句医院——"水由氢氧原子组成""水分子由氢氧元素构成"，学生当"医生"改错句。"**元素讲种类（宏观），原子讲个数（微观）——串了就是错句。**"
  3. 讲解页：红线辨析④立靶。固定句式卡："水由氢、氧两种元素组成"（宏观）vs "一个水分子由两个氢原子和一个氧原子构成"（微观）。
- **点拨话术**："**元素是'哪一类'（宏观），原子是'哪一个/几个'（微观）。说'组成'用元素，说'构成'用原子。**"

### 跃升 4：下标 vs 系数（配平第一大错）

- **卡点**：学生看到 H₂ + O₂ → H₂O 左边 2 个氧、右边 1 个氧，第一反应是去改 H₂O 的下标。改下标 = 改物质种类 = 全书第一大错（curriculum 审计清单第 1 条）。
- **脚手架**（cm04.2.1 立靶 2 页 + cm05.1.2 回填 1 页；红线辨析①）：
  1. 交互页：H₂O 四层含义慢读（Y8 slow-read）——点"2"，高亮"一个水分子里有两个氢原子"。"**下标是物质的'身份证号'：改了它，水就变成了双氧水（H₂O₂）——另一种物质。**"
  2. 交互页：配平第一课——只允许拖"系数"滑块（Y9 balance-check），点下标弹警告"⚠ 这是身份证号，不能改！"。
  3. 回填页（cm05.1.2）：配平闯关（H₂ + O₂ → H₂O、Fe₂O₃ + CO），红线辨析①回填。
- **点拨话术**："**下标是身份证，系数是人数。配平只能加人（调系数），不能改身份证（改下标）。**"

### 跃升 5：化学式"慢读"

- **卡点**：化学式对初学者是一串"天书"。直接讲"化学式的意义"会变成背诵四句话，学生"读"化学式像读乱码。
- **脚手架**（cm00.1.4 预告 1 页 + cm04.2.1 严格 2 页）：
  1. 交互页：水 → H₂O 的符号之旅（三重表征切换演示）。"一杯水（宏观）→ 一群水分子（微观）→ H₂O（符号）——符号是三重表征的'压缩包'，是'有损压缩'：解压能拿回种类和数量，拿不回形状（H₂O 是折线形还是直线形，符号里看不出来，得去翻微观那一重）。"
  2. 交互页：H₂O 四层含义点读——点一句亮一重表征（Y8 slow-read）。"H₂O 慢读：宏观读'水'、微观读'一个水分子由两个氢原子和一个氧原子构成'——**每次读，都读两遍：宏观一遍，微观一遍。**"
  3. 讲解页：慢读规范卡（固定版式，全书每次新符号复用）。
- **点拨话术**："**化学符号不许跳读。第一次见它，就慢读两遍：它是什么东西（宏观），它里面有什么粒子（微观）。**"

### 跃升 6：质量守恒的"称一称"

- **卡点**：镁条烧完"变轻了"、敞口烧杯"少了"——生活经验直接对抗定律。学生把"天平读数"当成"质量守恒"本身，开放体系一出现就"证伪"了定律。
- **脚手架**（cm05.1.1 质量守恒定律，3 页）：
  1. 交互页：虚拟天平三组实验对比（红磷燃烧密闭/敞口、铁钉 + 硫酸铜、碳酸钠 + 盐酸密闭）。"敞口的那组'轻了'——少的不是质量，是**跑掉的气体**。"
  2. 交互页：微观解释——反应前后原子"数一数"（粒子计数徽章：反应前 H×4、O×2；反应后 H×4、O×2）。"**原子没少一个，只是换了'队形'。**"
  3. 讲解页：定律表述 + "参加反应的各物质"划重点。
- **点拨话术**："**称的是'参加反应的'，不是'烧杯里剩下的'。气体跑了，天平会'说谎'——把跑掉的算上，质量一点没少。**"

### 跃升 7：物质的量（"一打"类比，mol 是"数"不是"量"）

- **卡点**："物质的量"四个字自带误导——学生以为是"物质的多少"（质量/体积）。mol 被当成"质量单位"，阿伏加德罗常数被当成"6.02×10²³"（丢单位）。
- **脚手架**（cm13.1.1 物质的量（上），3 页）：
  1. 交互页："数"1 mol 粒子——6.02×10²³ 有多大（数量级震撼：从地球数到月球）。"**mol 是'数'的单位，不是'称'的单位——就像'一打'是 12 个，'1 mol'是 6.02×10²³ 个。但'一打'是生活约定 12 个；'1 mol'是国际单位制定的'一堆'——6.02×10²³ 个，'一堆有多大'跟 12 克碳-12 挂钩（本课讲清），不能止于'一打'。**"
  2. 交互页：n = N/N_A 换算闯关——"一堆"与"个数"互推。"n 是'多少堆'，N 是'多少个'。"
  3. 讲解页：首句先注"**一打 = 12 个**（如一打鸡蛋）"，再出 mol 类比；阿伏加德罗常数单位 6.02×10²³ mol⁻¹（**单位不能丢**！审计清单第 7 条）。
- **点拨话术**："**mol 是'数'出来的，不是'称'出来的。看到 mol，先问'多少个粒子'，别问'多重'。**"

### 跃升 8：氧化还原"升失氧、降得还"

- **卡点**：化合价升降、得失电子、氧化/还原、氧化剂/还原剂——八个词互相咬，方向一反全错。初中"得氧失氧"版与高中"电子转移"版打架，学生不知道哪个是本质。
- **脚手架**（cm12.2.1 氧化还原反应（上），3 页）：
  1. 交互页：CuO + H₂ 微观电子转移动画——电子从 H 流向 Cu（粒子/电子流向可视化）。"**电子搬家了：从 H 家搬到 Cu 家。电子画成小球是示意——我们只关心它'从谁家搬到谁家'（转移方向），它真实的样子（电子云）cm20 再讲。**"
  2. 交互页："升失氧、降得还"四位一体拼图——化合价升高 → 失电子 → 被氧化 → 做还原剂，四块拼对才过关。"**一句话里四个身份，方向必须一致——升，就全是'升'那一边。**"
  3. 讲解页：初中版 vs 高中版对照（得氧失氧 vs 电子转移）——"电子版是本质"。
- **点拨话术**："**记住'升失氧、降得还'，再记住它是'电子搬家'的四个名字：价升了，电子丢了，被氧化了，它就是还原剂。**"

### 跃升 9：动态平衡（v正 = v逆 ≠ 0，"可逆不是静止"）

- **卡点**：全书级观念转折（curriculum 审计清单第 9 条）。学生把"平衡"理解成"停了"——天平平衡了就不动了，化学平衡也"不动了"。
- **脚手架**（cm16.1.2 化学平衡（上），3 页）：
  1. 交互页：动态平衡微观动画——N₂ + 3H₂ ⇌ 2NH₃，正逆反应同时进行，分子不停"拆"和"装"。"**两边都在跑，只是跑得一样快——浓度才不动。**"
  2. 交互页：v–t 图像——v正/v逆两条线交于一点后"手拉手"水平走。"**交点之后，v正 = v逆 ≠ 0——'相等'不等于'零'。**"
  3. 讲解页：平衡特征五字（逆/等/动/定/变）+ "动态"划重点。
- **点拨话术**："**化学平衡是'收支平衡'，不是'关门大吉'。v正 = v逆，但都不等于零——可逆不是静止，是'一样快'。'收支平衡'是说进出一样快（v正 = v逆），账面（浓度）才不动——但钱（分子）一直在进出，不是'关门大吉'。**"

### 跃升 10：pH 的对数本质（每差 1 差 10 倍）

- **卡点**：pH = 3 比 pH = 4"酸一点"，学生以为是"多一点"——其实是 10 倍。线性直觉对抗对数标尺，这是全书最漂亮的数学呼应锚点之一。
- **脚手架**（cm10.2.3 pH 与溶液酸碱度，3 页；自带"对数直观版"一页）：
  1. 交互页：pH 标尺——拖动 pH，c(H⁺) 以 10 倍跳动（0.1 → 0.01 → 0.001）。"**pH 每差 1，酸度差 10 倍——pH 是'数量级'的尺子，不是'厘米'的尺子。**"
  2. 讲解页：自带"对数直观版"一页（不讲 log 定义，只讲"10 倍一格"；预告：学完代数 8.2 后回填 pH = −lg c(H⁺)，cm19.1.2 兑现）。
  3. 交互页：生活 pH 谱——胃液 / 雨水 / 肥皂水 / 漂白水，点一点看 pH 和 c(H⁺)。
- **点拨话术**："**pH 差 1，差 10 倍；差 2，差 100 倍。pH 是'压缩'过的尺子——小小一步，浓度大跳。**"

### 跃升 11：离子方程式"四留三拆"

- **卡点**：拆写规则是"条件清单"（强酸强碱可溶性盐拆，弱电解质/沉淀/气体/氧化物留），学生要么全拆，要么全留。初中最痛的点：Ba(OH)₂ + H₂SO₄ 写成了 Ba²⁺ + SO₄²⁻。
- **脚手架**（cm12.1.3 离子反应（下），3 页）：
  1. 交互页：离子方程式四步（写/拆/删/查）分步书写——Ba(OH)₂ + H₂SO₄ 全流程。"**先写全，再决定谁'留'谁'拆'。**"
  2. 交互页："四留三拆"闯关——强酸/强碱/可溶性盐拖进"拆"筐，弱电解质/沉淀/气体/氧化物拖进"留"筐。"**能真正拆开的才拆：CH₃COOH、CaCO₃、CO₂ 都'留'化学式。**"
  3. 讲解页：双守恒检查卡（原子守恒 + 电荷守恒）。
- **点拨话术**："**'四留三拆'：弱酸弱碱沉淀气体氧化物，留化学式；强酸强碱可溶性盐，拆成离子。写完查两遍：原子守恒、电荷守恒。**"

### 跃升 12：有机"同分异构"（分子式相同、结构不同）

- **卡点**："同一个分子式，怎么会是两种物质？"——学生第一次遇到"清单相同、拼法不同"。碳骨架"拼装"没有空间想象，直接讲定义会变成背诵。
- **脚手架**（cm17.1.2 烷烃，3 页）：
  1. 交互页：丁烷同分异构体搭建——碳骨架拼装（正丁烷 / 异丁烷拖拽拼）。"**四个碳、十个氢，拼法不同，就是两种物质——分子式是'原料清单'，结构是'拼装图纸'。**"
  2. 交互页：性质对比——正丁烷 vs 异丁烷沸点不同。"原料一样，拼法不同，脾气不同——这就是'结构决定性质'的第一课。"
  3. 讲解页：同分异构定义 + 三类型预告（cm21.1.1 回填：碳链/位置/官能团异构）。
- **点拨话术**："**分子式相同、结构不同，就是'同分异构'。记住：清单一样，拼法不同——拼法决定脾气。**"

## 四、讲解页规范（沿用物理六段式，化学微调）

### 4.1 为什么必须有讲解页

光有交互，学生"玩得很开心，但说不清学到了什么"。化学比物理更需要讲解页——因为化学的结论是**三重表征对齐**的（现象 + 粒子 + 符号），学生必须能用嘴说出来"看到了什么现象、粒子在干什么、符号怎么写"。

### 4.2 讲解页结构（六段式，一页一屏，文字上限 300 字）

```
1. 现象钩子（交互页最精彩的那一帧定格）+ 一句话：
   "还记得吗？你把锌片放进硫酸铜溶液时，锌片表面变红了。"
2. 动手/观察回顾（≤ 60 字）：你亲手做了什么、看到了什么现象。
3. 微观解释（≤ 80 字）：粒子在干什么，配粒子动画关键帧图。
   "微观上：锌原子把电子给了铜离子，铜离子变成铜原子贴在锌片上。"
4. 符号表达（MathML）：化学式/方程式慢读 + 适用条件一句话。
   "符号上：Zn + CuSO₄ = ZnSO₄ + Cu（等号！条件：金属活动性 Zn > Cu）"
5. 点拨（≤ 60 字）："这就是置换反应——一种单质把另一种单质从化合物里'换'出来。"
6. 下一步：预告下一页 / 回填链接（"下一页我们数一数：原子守恒吗？"）
```

### 4.3 讲解页写作四不许（化学版）

1. 不许"显然""易知""可想而知"——要么写出来，要么写"这一步我们第 X 页玩过"。
2. 不许跳三重表征——抽象结论必须走完"宏观 → 微观 → 符号"，缺一重即不合格。只给方程式不给粒子动画 = 不合格。
3. 不许编造生活例子——生活例子必须来自第六章例子库（化学专家队确认过边界的）；自创例子先入库、经化学专家队确认边界后再用。
4. 不许超纲术语——本课没讲的术语不许提前用（如 cm05 不许出现"物质的量"、cm10 不许出现"电离平衡"、cm16 不许出现"平衡常数 K"）；必须用时加"预告"标注并配"直观版"一页。

### 4.4 术语"认旧友"标注规范

新术语第一次出现时，格式：**术语**（就是你第 X 页 + 动作/现象）。例如：
- **置换反应**（就是第 X 页你看到锌片表面变红、溶液变浅的那个反应）
- **催化剂**（就是第 X 页加了 MnO₂ 后双氧水冒泡变快、MnO₂ 自己没变少的那个东西）
- **饱和溶液**（就是第 X 页你再加蔗糖也化不开的那杯糖水）

## 五、习题页规范（每章末，答案折叠，必有一道生活题 + 一道计算题）

> 化学必须做题——"会玩"不等于"会写"：化学符号规范、配平、纯量法、条件判断必须通过做题固化。

### 5.1 梯度结构（固定 5 档，每章 5–8 道）

| 档 | 数量 | 题型 | 例子 |
|---|---|---|---|
| ① 认现象 | 1–2 道 | 看图/看描述判断：宏观现象 → 微观解释 → 符号表达对齐 | "铁锅生锈了，分子种类变了吗？这是物理变化还是化学变化？"（认出判据） |
| ② 符号书写 | 1–2 道 | 化学式/方程式/离子符号书写与慢读，**规范**（一大二小、电荷位置、↑↓、等号） | "写出实验室制 CO₂ 的化学方程式并配平"（不配平不得分） |
| ③ 定量直用 | 1–2 道 | 一步计算：相对分子质量、元素质量分数、溶质质量分数、简单方程式计算（**纯量法**） | "49g KClO₃ 完全分解生成 O₂ 多少克？"（必须先配平再列式） |
| ④ 条件判断 | 1–2 道 | 给一个似是而非的情境，判断反应能不能发生/公式能不能用 | "Cu + 稀 H₂SO₄ 能放出 H₂ 吗？为什么？"（考金属活动性顺序边界） |
| ⑤ 生活中的化学 + 小综合 | 1–2 道（**每章强制 1 道生活题**） | 生活情境综合题，2–3 步：认现象 → 选原理 → 符号表达/计算 | "84 消毒液为什么不能和洁厕灵混用？写出反应的化学方程式并解释"（安全 + 符号） |

**每章末习题强制要求**：必有一道"生活中的化学"题（第⑤档）+ 一道定量计算题（第③档或⑤档）。定量题必须覆盖"纯量法"与"先配平后计算"两条规范。

### 5.2 答案折叠规范

1. **三级折叠**：思路提示 →→ 关键步骤 →→ 完整答案。学生先看提示，实在不会再看步骤，最后对答案。
2. 思路提示 ≤ 30 字，只指方向不给过程："先问：方程式配平了吗？代入的是纯量吗？"
3. **配平/计算类习题要求步骤展示**：关键步骤级展示"设/写/找/列/解/答"六步（蓝队 Y12 `stoich-steps` 接口预留：分步填空、学生填一步核对一步）。
4. 完整答案末尾附**守恒检查**（质量守恒 / 电子守恒 / 电荷守恒，视题型）+ **条件检查**（"××条件满足 ✓"）。
5. 每道题尾标注"用到的原理：××（第 X 页）"，形成回链。

### 5.3 手机做题特殊规范

### cm00.1 化学初见（cm00.1.1–1.4）

- **怎么讲**：全章是"招生广告"——让学生觉得化学好玩、敢进实验室。策略：**现象拼图 + 走完一次探究 + 安全闯关 + 符号之旅**。cm00.1.4 的 H₂O 是全书第一个"慢读"对象（跃升 5 预告）。
- **主生活例子**：① 铁生锈、饭变馊、烟花、化肥拖进五个筐（组成/结构/性质/转化/应用）；② 蜡烛燃烧三证据（罩住熄灭/罩壁水雾/罩壁白糊）；③ 安全闯关：扇闻法、灯帽盖灭。
- **误区纠正**："化学=污染/有毒"→"化学是研究物质的科学，污染是应用出了问题——学化学恰恰是为了用好物质"；"符号只是缩写"→"符号是'压缩包'：H₂O 里藏着种类和数量两种信息"。
- **自学路径**：先玩 cm00.1.1 现象拼图 → cm00.1.2 走完蜡烛探究全流程 → cm00.1.3 安全闯关（扇闻/盖灭亲手试）→ cm00.1.4 水→H₂O 符号之旅（慢读两遍）。

### cm01.1 变化、性质与探究（cm01.1.1–1.5）

- **怎么讲**：**跃升 2（物理/化学变化判据）**是本单元灵魂，红线辨析③立靶。策略：**对比动画 + 判据闯关**。cm01.1.2/cm01.1.3 是两个经典探究，必须走完变量控制全流程。
- **主生活例子**：① 水沸腾 vs 水电解（分子变没变）；② 电灯发光发热（物理变化！）；③ 量筒读数（俯视/仰视）、酒精灯（灯帽盖灭）。
- **误区纠正**："发光发热一定是化学变化"→见跃升 2 点拨话术（"别看热不热闹，看分子变没变"）；"用嘴吹灭酒精灯没事"→"**安全红线**：必须用灯帽盖灭——嘴吹会把火吹进灯壶"；"俯视读数无所谓"→"俯视偏大、仰视偏小——视线要水平"。
- **自学路径**：先玩跃升 2 的三页脚手架（cm01.1.1）→ cm01.1.2 蜡烛探究（变量可调：罩杯大小/火焰部位取样）→ cm01.1.3 三瓶气体三检验配对 → cm01.1.4 量筒读数交互 → cm01.1.5 酒精灯虚拟操作（⚠ 灯帽盖灭）。

### cm02.1 空气与氧气（cm02.1.1–1.5）

- **怎么讲**：空气组成（体积分数！）+ 氧气性质/制法 + 催化剂"一变二不变"。策略：**磷燃烧测体积分数虚拟实验 + 铁丝燃烧（安全规范）+ 制氧全流程**。催化剂是 cm16/cm18 的长线伏笔，这里只记"一变二不变"八字。
- **主生活例子**：① 磷燃烧：水面上升约 1/5；② 铁丝在氧气中燃烧（火星四射）；③ 双氧水消毒（H₂O₂ 的生活版）；④ 霓虹灯（稀有气体）。
- **误区纠正**："空气中 O₂ 占 1/5 是质量分数"→"**体积分数**！——空气是气体，论体积不论质量"；"MnO₂ 是反应物"→"MnO₂ 是催化剂：**一变（改变化学反应速率）二不变（质量、化学性质不变）**，可以回收"；"铁在空气中点燃能燃烧"→"空气中只发红，**纯氧中**才剧烈燃烧——浓度是条件"；"白烟=水蒸气"→"白烟是 P₂O₅ 固体小颗粒（烟），水蒸气是雾——烟 vs 雾"。
- **自学路径**：先玩 cm02.1.1 磷燃烧虚拟实验 → cm02.1.2 铁丝燃烧（⚠ 瓶底放水防炸裂）→ cm02.1.3 制氧全流程（气密性→装药→收集→验满）→ cm02.1.4 液态空气分馏动画（物理变化！红线辨析③）。

### cm03.1 分子与原子（cm03.1.1–1.2）

- **怎么讲**：全书世界观地基。策略见**跃升 1**。cm03.1.2 的水电解粒子动画是"化学变化微观本质"的第一次完整亮相——分子破裂、原子重组，8 个字刻进脑子。
- **主生活例子**：① 品红扩散（温度可调）；② 水电解微观动画（H₂O → H₂ + O₂）；③ 墙内开花墙外香（扩散的生活版）。
- **误区纠正**："分子静止不动"→"分子**永不停息**地运动，温度越高越剧烈——品红在热水里散得更快"；"化学变化中原子消失了"→"原子**种类、数目、质量**都不变——变的只是'队形'（分子种类）"。
- **自学路径**：先玩跃升 1 的三页脚手架（cm03.1.1）→ cm03.1.2 水电解粒子动画（慢放：H₂O 破裂→H、O 原子→重组为 H₂、O₂）→ "数一数"：反应前后原子种类/数目/质量对照表。

### cm03.2 原子的结构·元素·离子（cm03.2.1–2.4）

- **怎么讲**：**跃升 3（元素 vs 原子）**是本单元灵魂，红线辨析④立靶。策略：**拖拽质子数看元素改变 + 错句医院 + NaCl 电子转移动画**。cm03.2.3 的离子是"带电的原子"，得失电子一次讲清。
- **主生活例子**：① 元素周期表交互地图；② 食盐 NaCl 形成（Na−e⁻→Na⁺，Cl+e⁻→Cl⁻）；③ 地壳/人体元素丰度榜。

### cm04.1 水与净化（cm04.1.1–1.2）

- **怎么讲**：过滤"三靠"规范 + 电解水证明水的组成（宏观→微观→符号完整三步走）。策略：**虚拟过滤（规范动作）+ 电解水微观动画**。cm04.1.2 是红线辨析④的回填点（"水由氢、氧元素组成"）。

### cm10.2 碱与中和（cm10.2.1–2.3）

## 八、颜色编码约定（沿用几何全局 + 化学增补）

### 8.1 沿用几何全局约定

- **已知量**：蓝色（`--chem-known`）——题给质量、浓度、已知化学式等题给条件。
- **待求量**：朱红（`--chem-target`）——待求质量、待求化学式等，加粗 + 文字标签双编码。
- **辅助线**：灰虚线（`--chem-track`）——双线桥、电子转移箭头、作图辅助线。
- **当前步骤高亮**：黄闪（`--chem-highlight`），配深色字。

### 8.2 化学增补：粒子颜色编码（全书强制，不许串）

| 粒子/元素 | 颜色 | 语义变量 | 说明 |
|---|---|---|---|
| H（氢） | 白 | `--chem-h` | 配深色描边（白底可辨） |
| C（碳） | 深灰 | `--chem-c` | 金刚石/石墨/CO₂ 通用 |
| O（氧） | 红 | `--chem-o` | |
| N（氮） | 蓝 | `--chem-n` | |
| Na（钠） | 黄 | `--chem-na` | |
| Cl（氯） | 绿 | `--chem-cl` | |
| Fe（铁） | 棕 | `--chem-fe` | |
| Cu（铜） | 橙红 | `--chem-cu` | 区别于铁 |
| 电子 e⁻ | 紫色小点 + "e⁻"标签 | `--chem-electron` | 电子转移可视化专用 |
| 阳离子 | 原色 + "+"标签 | — | 如 Na⁺：黄色 + "+" |
| 阴离子 | 原色 + "−"标签 | — | 如 Cl⁻：绿色 + "−" |

**铁律**：
1. 粒子颜色全书固定：氧永远是红，学生翻到哪一章都不用重新认。颜色之外的双编码：每个粒子 = 颜色 + 元素符号标签。
2. **宏观/微观/符号三分区**：同一页出现三重表征时，分区底色固定——宏观区浅黄、微观区浅蓝、符号区浅绿（`--chem-macro/micro/symbol`），切换时分区高亮。全书统一。
3. 状态双编码：沉淀（↓ + 文字"沉淀"）、气体（↑ + 文字"气体"）、颜色变化（色块 + 文字描述），绝不只靠颜色。
4. 化学键：共用电子对用紫色小点对表示；电子转移用紫色箭头 + "e⁻"标签（灰度截图下仍能凭"箭头 + 标签"读出转移方向）。

### 8.3 颜色之外的编码（双编码清单）

- 化学式下标 vs 系数：下标小字下沉 + 系数大字在前，双编码不只靠位置（Y8 slow-read 点读时分别高亮）。
- 饱和/不饱和、平衡/未平衡：文字徽章（"饱和 ✓"/"平衡 ✓"），绝不只靠颜色。
- 酸/碱/中性：指示剂颜色 + pH 数值 + 文字三编码。

### 9.2 安全教学三原则

1. **虚拟与现实分界线**：每个安全徽章必须包含"虚拟/现实"对比句式——"虚拟实验里××，现实中××"。不许只写"注意安全"这种空话。
2. **先说"怎么做才对"，再说"错了会怎样"**：安全话术以正确操作为第一句（"先验纯后点燃"），后果为第二句。只吓唬不给方法 = 不合格。
3. **理想化声明**：每个虚拟实验注明理想化之处（如 cm02.1.2 铁丝燃烧注明"现实中瓶底放水防炸裂"、cm06.2.3 CO 实验注明"现实中必须在通风橱中"）——这是 curriculum 附录 A6 的要求，也是科学诚实。

## 十一、风险点（黄队自查）

1. **"人话"滑向"错误直觉"**：如"电子搬家"可能被理解为实心小球。→ 对策：每句人话配术语第二句 + 三重表征对齐；全部经化学专家队"翻译"确认（10.4 清单）。
2. **三重表征信息过载**：一页同时给宏观/微观/符号，学生看不过来。→ 对策：默认只显示一重，Y6 切换器让学生自己切；讲解页六段式固定顺序，不许三重同屏堆叠。
3. **下标 vs 系数预防针的节奏**：cm04.2.1→cm05.1.2 间隔短，但 cm13/cm18 计算中仍会复发。→ 对策：Y9 配平闯关在 cm05.1.3、cm13.1.3、cm18.2.4 三次复用"认旧友"回看（"还记得身份证号吗？"）。
4. **初中到高中两次"升级"陡峭**：cm12 离子反应/氧化还原、cm13 物质的量是两个陡坡。→ 对策：两个陡坡各配完整跃升脚手架（跃升 11、跃升 7/8），不许"一页讲完离子方程式"。
5. **安全页的"说教感"**：安全徽章太多会变成唠叨，学生直接无视。→ 对策：安全话术永远配"虚拟/现实"对比 + 一个真实后果（一句话），不说空话；闯关制（Y13）代替说教。
6. **虚拟实验替代真实体验的边界**：天平、量筒、pH 试纸——虚拟读数再真，也替代不了手感。→ 对策：Y10 仪表读数练习器页尾统一加一句"有条件的话，找真实的××试一次"；不强制，只邀请。
7. **页数口径**：专家队按 130 课×约 2.72 页/课估算 353 页；黄队策略（跃升脚手架 12×3 页、慢读页、三重表征切换）可能推高部分课页数，生产中以白队 QA 为准微调。
