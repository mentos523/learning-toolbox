## 七大铁律

### ① 试点闸门前置——不过闸门，不许批量

来源：语法试点拦下 `.g-zone` 静默裁剪 3 项严重（讲解页核心组件整块不可达）；
物理试点拦下填空判分 bug（`kg/m³` 被判错）、空壳撑屏、深色对比度 3 项。

- [ ] 试点课做全套页 + 试点涉及的全部交互组件，骨架与试点一次做完
- [ ] 白队用本机 headless Chromium 跑三视口（PC 1366×768 / 平板 820×1180 / 手机 390×844）闸门断言
- [ ] 闸门必含：布局断言（一屏、无横向溢出、可点 ≥44px）+ **学科真值断言抽验**（化学：配平/读数/装置正确性，见附表 B）+ 全部组件真交互实操（拖/点/滑实测，不是只看默认位形）
- [ ] 闸门 FAIL → 只修骨架/引擎层，不许逐页打补丁后批量；新白队独立重验全 PASS 才放行
- [ ] 化学试点课：`cm05.1.2`（化学方程式上："改下标配平"全书第一大错教学流 + C3 下标陷阱 + 跃升 4）

### ② 真值断言先于生产——口径立完再写课

来源：物理 21 个渲染器 bug（透镜成像箭头画反、波频率硬编码、加热粒子不加速）
全部漏到上线后，事后补断言才抓出来；白队 QA 当时信了蓝队的构造逻辑，
没有拿独立公式重算一遍——"渲染器构造正确"是未经验证的假设。

- [ ] 专家队在批量生产前立完《真值断言口径》（化学：方程式配平与条件、化合价与化学式、pH/浓度计算、曲线图读数与数据源、实验装置图正确性、微观示意图与三重表征一致性、周期表与原子结构数据、安全规范），编号成文（`CHEM-XX`），断言格式 `编号 断言名 — 判定条件 — 容差/例外`
- [ ] 断言工具先声明坐标系（white-team-lessons §8 第 10 条 `dirOf` 事故：审计工具坐标系必须与被测对象一致，`meta.coordinateNote` 留痕）
- [ ] 审计基线 = params 初值第一帧；交互后状态做行为一致性抽查（边界值/两终态），不许只验默认位形；未覆盖项在报告中如实声明
- [ ] 化学真值口径工作区：`~/workspace/chem-audit/`（物理审计曾因运行时重启清空 `/tmp` 丢过口径文件——**不许用 /tmp 存口径与证据**）
- [ ] 口径未覆盖的一律标 WARN 转人工确认，不许自创口径放行、不许"看起来对"就 PASS
- [ ] 门禁脚本 `tools/qa-chemistry-truth.mjs`（源自化学深审新白队独立断言，转正）：`node tools/qa-chemistry-truth.mjs`，FAIL>0 非零退出；含 S1 测量口径断言；R03/R09 启发式已按深审人工复核结论收紧，剩余 WARN 桶（R05-复核/AX01-复核）仍需人工复核

### ③ 组件真交互验证前置——每个组件试点期就实际拖/点验完

来源：物理 14 个"假交互"（页面看着有交互、实际组件空壳或策略断裂）拖到
黄队试讲才暴露，17 课返工换装；上线 QA 只验默认位形、从未拖动验证。

- [ ] 化学组件清单（C1–C10、Y1–Y4、Y6、Y10、Y12、Y13；Y7/Y8/Y9/Y11 为复用/合并归档）每类在试点期必须实际操作验证：拖拽到边界与终态、读数跟随变化、判分逻辑用对/错输入各走一遍
- [ ] 判分类组件必须含" canonical 答案回退必红验证"（物理 R2 教训：`kg/m³` 判错）
- [ ] 随机出题组件：以当题真值为准断言，不许拿上一题真值比（物理口径 PHY-R01）

### ④ 导航标配——目录抽屉双开 + 页码持久化，骨架期直接带上

来源：物理上线后用户投诉"目录没收起、学习页划不出目录"——全仓根本没有
swipe 处理，抽屉不存在，事后补实现 + hash 升级 + 两轮复验才过关。

- [ ] 化学骨架期直接实现目录抽屉，复用物理已验证定案：顶栏「目录」按钮 + 左缘划出手势**双开**（只靠手势孩子发现不了）；点遮罩/左划/按钮再点/Esc **关闭**
- [ ] 学习页目录默认收起；打开抽屉不挤压主内容（fixed 覆盖层）；一屏不变量保持
- [ ] hash 升级为 `#课号/页码`、每课页码持久化、重进恢复；旧 hash 兼容；localStorage 键与既有学科隔离（`ltb-chm-*`）
- [ ] 白队用 CDP 真实触摸事件验划出/划回 + 按钮路径双验；抽屉深/浅色**独立**断言（物理教训：修一色验两色——修复队自称"浅色不受影响"，实测浅色抽屉透明）
- [ ] 测试 fixture 的有效性本身先断言（物理教训：旧脚本用无滑块页面测"滑块保持"，假 PASS）

### ⑤ 文案即脚本 + 近似/理想化/适用条件当页显性化

### ⑥ 图由数据驱动、数据源可追溯，图文分歧以文案真值为准改图
