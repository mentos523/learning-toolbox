# 英语 · 语法课程体系（英语专家队设计 v1.0）

## 修订记录

### v1.0（2026-10-14）

英语专家队首版设计（对标物理/化学课程体系 v1.1 结构与编号口径）：

1. **全书 20 章**（gr00–gr19）：初中七年级起步 → 高中选择性必修终点，对齐现行人教版教材（初中 Go for it! 七上–九全、高中必修一/二/三、选择性必修一/二/三）与中考/高考语法考查体系。
2. **全书级红线定为"条件—反例双保险"**：每条语法规则必配"适用条件卡"（什么时候成立）+ 至少一个反例（什么时候不成立）；每章必设至少一条"中式英语纠偏"。
3. **语法审计清单 v1.0**（13 条，见下）：在红队清单（词源、翻译、词性、归属、音标）基础上新增 8 条语法专项。
4. **专设构词法桥章 gr11**：前缀/后缀/复合词/词性转换，与讲词根板块（253 词根 / 1777 词）双向呼应——前缀与词根呼应既有词条，后缀词性转换由本章新建，两板互相链接。
5. **体量**：125 课 / 约 334 页（约 2.67 页/课），与物理（127 课 / 约 344 页）相当。

> **英语专家队定位**：类比数学绿队（数学家）与物理/化学专家队的学科专家队，专职抓英语根本错误——语义不对等（把中文直译当英文）、规则泛化无边界（不讲适用条件）、术语与现行教材打架、中式英语放行、例句不自然（母语者不会这么说）。对本课程体系的**英语严谨性负全责**：每一课的规则表述、术语、适用条件与例外、例句合法性，都经过下面的语法审计清单逐项核验。黄队（教学）需求不妥协——凡黄队要求的生活化、趣味化表达，英语专家队负责把它"翻译"成英语上站得住的说法，而不是删掉趣味。
>
> **分工（英语专家队 ↔ 红队）**：英语专家队负责**建体系**（本文件）；红队负责**内容审计**（按红队清单 + 本文件语法审计清单第 7–13 条），两队对抗合作。铁律：**改英语部分红队必须回来**——本次只建体系（例句只给定"方向"，不给成品例句），红队审计由后续专人执行，送审清单见 `docs/english-design-review.md`。出现"人话版被判埋错误直觉 vs 不改讲不下去"僵局时，按用户 2026-10-14 已定案口径 **"先直觉后严格"** 分层（直觉页 + 严格页），红队负责给出边界句。
>
> **范围**：初中七年级起步（零语法起点，不假设小学英语语法基础）→ 高中选择性必修终点，对齐人教版 Go for it!（七上–九全）、高中英语必修一/二/三、选择性必修一/二/三的语法体系，以及中考/高考语法考查口径。
>
> 设计原则：
> 1. **汉语对照先行**：每条英语规则，先讲"汉语是怎么说的"，再讲"英语为什么不一样"——中国孩子学语法的最大障碍是汉语没有的形态（时态、冠词、单复数），对照是脚手架不是目的。
> 2. **规则必有身份证**：每条规则配适用条件卡；条件不是"注意事项小字"，是规则的"身份证"——没有身份证的规则不许上场。
> 3. **例句方向不代替例句**：本文件只给定例句"方向"（场景/句型/词汇难度），成品例句由生产队撰写、红队逐条审计例句自然度与语域。
> 4. **中式英语专治**：每章至少一条中式英语纠偏；高频中式结构全书级清单（见附录 A），在相关各课反复出现、互相印证。
> 5. **与讲词根板块双向呼应**：前缀/词根呼应讲词根既有词条（`un-`/`re-`/`dis-`/`pre-`/`in-`/`ex-` 等均已收录，R3 审计通过）；后缀词性转换由 gr11 新建，两板互相链接、术语一致。
>
> 难度标记：★入门 ★★基础 ★★★进阶 ★★★★高阶
> 课时：40–60 分钟/课（不含习题页时间）
> 口径：课 = 教学单元；页 = 一屏页面（参考几何生产实际；语法讲解课含 1 交互页 + 1–2 讲解页，平均约 2.65 页/课）
>
> 章编号用 `gr00`–`gr19`（与代数 `ch00`–`ch12`、几何 `g00`–`g13`、物理 `p00`–`p17`、化学 `cm00`–`cm21`、地理 `dg00`–`dg15`、生物 `b00`–`b25` 区分；**注意**：`gr` 与几何 `g` 前缀不同，无冲突）。数据文件拟为 `modules/english/data/grNN.js`，经 `assets/js/registry.js` 注册为英语模块的子卡（`slug: "english-grammar"`，与"讲词根"子卡并列，进英语先选子卡，旧链接与学习数据兼容）。
>
> **呼应标签图例**：**预告** = 语法先讲、他处后回填；**奠基** = 前置已讲；**直观版** = 已配单页；**呼应讲词根** = 链接讲词根板块既有词条（词根 id）。

## 语法审计清单（英语专家队抓错清单 v1.0）

本清单是英语专家队每课必查的红线，任一条违反即打回重写：

**沿用红队清单（1–5）**：

1. **词源**：凡涉词源说法的表述须有词源词典依据（沿用 `docs/red-team-lessons.md` 跨语源混同教训；构词法章重点查）。
2. **翻译**：中文释义准确、适合初中生；规则的人话版翻译不许偷换概念。
3. **词性**：词性标注 `n./v./adj./adv.` 等与讲词根板块口径一致；例句中每个词的词性可判定。
4. **归属**：例句/规则的"归属"有依据——不把方言、过时用法当通用规则教；不确定的宁可不收。
5. **音标**：凡出现单词注音一律 IPA（与讲词根 phon.js 口径一致）；重音符号 ˈ/ˌ 不可省略。

**语法专项新增（6–13）**：

6. **时态体系一致性**：全书时态命名统一（"现在完成时"，不许"现在完成式"）；时态数量口径统一（中学主线 8 时态 + 高中拓展，不许一会儿 8 个一会儿 16 个）；时间状语与时态搭配表全书一致。
7. **例句自然度与语域**：每条例句须通过"母语者替换测试"（能想象英语母语者在真实场景说这句话吗）；标注语域（口语/书面）；不许为凑语法点编造母语者不会说的怪句。
8. **拼写口径统一**：全书美式拼写（color/behavior/center），首次出现附英式异体（如 colour）；直接引文保留原拼写并注明。
9. **中式英语纠偏**：每课设中式英语误区栏；高频中式结构进全书级清单（附录 A），不许放行。
10. **语法术语与现行教材一致**：以人教版（Go for it! + 高中必修/选必）术语为准；别名只在"也叫"括号中出现一次（如"宾语从句（也叫名词性从句的一种）"不许反过来）。
11. **规则必注适用条件与例外**：每条规则配"身份证"（适用条件）+ 至少一个反例；不许"无条件规则"（如"although 不能和 but 连用"须注明是单句内）。
12. **汉语对照的边界**：汉语对照只用于"定位差异"，不许把汉语语序/逻辑硬套成英语规则（如"汉语先说时间所以英语也先说"类表述禁止）。
13. **考纲口径一致**：标注中考/高考考点的课，其考点表述须与近 5 年真题口径一致（题型、设错方式），不许自创"考点"。

## 附录 A：全书级中式英语高频清单（英语专家队维护）

生产队撰写例句/讲解时，以下结构出现即须配纠偏（审计清单第 9 条）：

1. 双谓语（I like him is kind.）
2. although…but / because…so 连用
3. There have（there be 误作 there have）
4. 不及物动词被动化（was happened / was died）
5. 漏三单 -s / 漏 be（He go / He running）
6. 宾语从句倒装（where did he go）
7. 关系代词残留 it（The book that I bought it）
8. 悬垂分词（Walking along…, a car…）
9. mustn't 表"不必"；"play the basketball"
10. 主将从现违反（If it will rain）
11. used to 三兄弟混用；enjoy to do
12. "我很" very much 位置（I very much like it. ✗ → I like it very much.）
