## 五、管线级建议（供用户拍板是否立为门禁）

审计撞见的**跨学科共性问题**说明是生产管线缺口，建议立为后续生产/审计门禁：
1. **"首现即定义"门禁**：新术语/符号首次出现必须配定义或指向定义课（程序化可检）。
2. **跨学科引用诚实门禁**：mathlink/`#r=` 等"奠基/呼应"标签必须经目标存在性校验；渲染必须可跳转（纯文本引用视为缺陷）。
3. **"预告必有回音"门禁**："以后再说/下章讲"类承诺必须登记，兑现页回链，未兑现视为缺陷。
4. **练习页完整性门禁**：quiz 页题目数 >0；两页课必须书面确认设计意图。
5. **标号体系统一**：跨模块引用统一用"代数 ch06"式课号，禁用"6.1"式简称。
