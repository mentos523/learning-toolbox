# 红队审计经验沉淀（英语·词根词缀模块）

> 沉淀时间：2026-10-10
> 审计范围：R2-P0 / R2-P1 / R2-P2 / R3 四轮扩词（120 词根/374 词 → 253 词根/1777 词）
> 审计方法：词源核验 + 词频验证（wordfreq）+ 随机抽查 + 超大词根全量核查

---

## 一、高频问题类型与真实案例

### 1. 跨语源混同（同形异源）

同一拼形在不同语源下含义完全不同，混在一个词条里会误导学习者。

**案例：**
- `opt-`：希腊语"眼"（optical/optics） vs 拉丁语"选"（option/adopt/optimal）→ **拆分为两个词条**（R2-P0 M2）
- `sol-`：拉丁语"日"（solar） vs "独"（solo/solitary/solitude）→ **拆分**（R2-P0 M3）
- `host-`：拉丁 hospes"主人"（host/hostess） vs hostis"敌"（hostile/hostility）→ **拆分**（R2-P2 蓝队自查通过）
- `nom-`：拉丁 nomen"名" vs 希腊 nomos"法"→ **拆分**（R2-P1 蓝队自查通过）
- `fil-`：拉丁 filum"线"（filament） vs filius"子"（affiliate）→ **拆分**（R2-P2 蓝队自查通过）

**修复模式**：拆分为独立词条（如 `opt`/`optc`），各自的 `m` 只保留单一语源义，单词的 `mi` 全部归零。

**反例警示**：`hosp-` 与 `host-` 曾被蓝队拆分，红队复核发现两者皆源自拉丁语 hospes（同一词根的语音演变），**不应拆分**，已合并回 `v:["hosp","host"]`（R2-P2 M1）。拆分标准是"不同语源"，不是"含义有别"。

### 2. 词素不可见（拼写中找不到词根）

单词拼写经过音变/拼写演变后，词根词形在单词中不可见，拨盘标红失效或误导。

**案例：**
- `language` ∈ lingu-：古法语演变，拼写中根本不含 "lingu" → **删除**（R2-P0 M1）
- `decay` ∈ cad-：实际词素是 "cay"（古法语 decair < 拉丁 decadere 音变）→ **变体追加 "cay"**（R2-P1 M1）
- `domain` ∈ domin-：→ 补变体 `"doma"`；`flourish` ∈ flor- → 补 `"flour"`；`government/govern` ∈ gubern- → 补 `"govern"`；`neural` ∈ nerv- → 补 `"neur"`（希腊 neuron vs 拉丁 nervus 同源）（R2-P2 M2–M6）
- 12 个词素不可见词补音变变体：number(+number)、course(+cour)、center(+center)、voice(+voic)、peace(+peac)、content(+tent)、letter(+lett)、reign(+reig)、promise(+mis)、destroy(+stroy)、exist(+ist)（v16 后数据补丁，全库匹配失败降为 0）

**修复模式**：优先补合法音变变体（需确认是真实音变，非硬凑）；若词素完全不可还原（如 language），删除该词。

**程序化兜底**：全库扫描每个单词的变体是否在拼写中出现，失败数必须为 0（已纳入白队检查清单）。

### 3. 假阳性收词（拼写巧合非真词源）

单词拼写恰好以词根字母开头，但词源无关。

**案例：**
- `exotic` ∈ ex-：词素是 exo-（外），不是 ex- → **删除**（R3 M1）
- `consul` ∈ co-："con-" 不可分离，是词根本身（拉丁 consul）→ **删除**（R3 M2）
- `deadline/decade/decor` ∈ de-：非拉丁 de- 前缀 → **删除**（R3 蓝队自查）
- `delicious/delicate/device/demure` 的 "de-"：拼写巧合非真前缀（R3 专项核查，已标注待处理）
- `tactics` ∈ tact-：希腊 taktikos"排列"，非 tangere"触" → **删除**（R2-P0 蓝队自查）
- `mutual` ∈ mut-：应为 mutuus 非 mutare → **排除**（R2-P1 蓝队自查）
- `long` ∈ long-：英语 long 系日耳曼语，非拉丁 longus，假同源 → **排除**（R2-P1 蓝队自查通过）
- `commendable` ∈ mend-：实为 mandare"命令"，非 mendum"修" → **排除**（R2-P2 蓝队自查通过）
- `cruise`：词素不可见 → **排除**（R2-P1）
- `dele`：不是英语单词，是拉丁语校对符号 → **删除**（R3 S1，唯一严重问题）

**修复模式**：删除/排除。判断标准：查词源词典确认词素归属，不确定的宁可删除。

### 4. mi 错配（多义词根指派错误）

多义词根的 `m` 数组有多个义项，单词的 `mi` 序号指错。

**案例：**
- `refine` ∈ fin-（["终","界"]）：mi=1（界）→ 应为 0（终，"使完美"）（R2-P0 M4）
- `devote/delay/delight/depict/defy` ∈ de-（["向下","除去"]）：de- 在此是**加强义**（completely），不是"除去"，5 词 mi=1 → 统一改为 0（R3 M4）
- `detour` ∈ de-：de- 是"偏离"义，既非"向下"也非"除去" → **删除**（R3 M6，mi 无法准确归属时宁可删除）

**修复模式**：mi 改为正确序号；若词根义项无法覆盖该词的实际用法，删除该词（不要为保留而硬套）。

### 5. 双收录不一致

同一单词被两个词根收录时，词性/中文/mi 两处不一致。

**案例：**
- `promise`：pro- 下 `v./n.`"承诺；许诺" vs mit- 下不一致 → **统一**（v12 审计 M1）
- `progress`：pro- 下 `n./v.`"进步；进展" vs gress- 下不一致 → **统一**（v12 审计 M2）
- `antibiotic`：anti- 下 `n./adj.` vs bio- 下 `n.` → **统一为 `n./adj.`**（R2-P2 M7）
- `submarine`：sub- 下 `n.`"潜水艇" vs mar- 下 `n./adj.`"潜水艇；水下的" → **统一为后者**（R2-P2 M8）

**修复模式**：以信息更全的一处为准，另一处对齐。程序化检查：同一单词在多处的 `[词性, 中文]` 必须完全一致。

### 6. 生僻词混入

违背"去生僻"原则，低频词混入常用词库。

**案例（R3 M5，24 个极生僻词删除）：**
- 词频 < 1e-07：foreordain、demount、deice、midmost、defog、maltreat、deodorize、manacle、desalinate、despoil、deplane、destine、circumscribe、forenoon、deniable、foreleg
- 词频 < 5e-07：biped、delimit、backfill、depute、midriff、deputation、derangement、defile
- 兼生僻：transpire（spir-，词频 2.29e-07，"呼吸→发生"对教学无价值）（R3 M3）

**修复模式**：wordfreq 词频 < 1e-06 直接删除；1e-06 ~ 2e-06 的偏难/学术词由人工复核去留。

**教训**：R3 蓝队为冲 3000 词目标放宽了标准，红队用词频硬指标拦回 30+ 词。**数量目标永远不能压倒"去生僻"原则**，这是用户拍板的铁律。

### 7. 词根归属牵强（词源成立但教学无价值）

词源上说得通，但词根义对理解单词毫无帮助，初中生学了反而困惑。

**案例：**
- `conjure/contemplate` ∈ co-："共同"义对理解"变魔术/沉思"无帮助 → **删除**（R3 M7/M8）
- `cover/consider` ∈ co-：词源成立但帮助弱 → **接受**（R3 L1/L2，不删除但不再新增同类）

**修复模式**：删除，或接受现状但不再收同类。判断标准：问"这个词根义能帮初中生猜出词义吗？"不能则删。

## 二、未来审计检查清单（按优先级）

### P0（必须查，不通过不许上线）
1. [] 全库词素可见性扫描：变体必须在单词拼写中出现，失败数为 0
2. [] 跨语源混同：新增词根是否同形异源？是则拆分
3. [] 假阳性：新增单词的词素归属是否有词源依据？抽查超大词根（de-/co-/ex-）全量
4. [] 生僻词：wordfreq < 1e-06 的词必须删除
5. [] 双收录一致性：同一单词多处 `[词性, 中文]` 完全一致

### P1（应该查）
6. [] mi 指派：多义词根的每个单词 mi 是否正确？重点查加强义/引申义
7. [] 词根归属教学价值："词根义能帮初中生猜出词义吗？"
8. [] 变体完备性：实际使用的音变是否都已登记？（参考 cad-/cay 先例）
9. [] 翻译准确性：抽查 50 词，中文是否准确、适合初中生

### P2（抽查）
10. [] 词性标注：双词性是否补全（如 report/interview/request 的 n./v.）
11. [] 排序：是否按词频降序（词根内、词根间）

## 三、可迁移性标注

| 问题类型 | 英语特有 | 可迁移到其他学科 | 说明 |
|---|---|---|---|
| 跨语源混同 | ✅ | ❌ | 拉丁/希腊语源特有；数学/物理的符号体系无此问题 |
| 词素不可见 | ✅ | ❌ | 拼写演变特有 |
| 假阳性收词 | ✅ | ⚠️ | 思路可迁移：任何"按特征归类"都需核验归属依据（如数学按题型归类时的错归） |
| mi 错配 | ✅ | ⚠️ | 思路可迁移：多标签数据的标签指派准确性检查 |
| 双收录不一致 | ❌ | ✅ | 通用：同一实体在多处出现时信息必须一致（如数学公式在不同章节的表述） |
| 生僻词混入 | ❌ | ✅ | 通用：用客观频度指标（词频/考频）卡质量红线，数量目标不压倒质量原则 |
| 归属牵强 | ❌ | ✅ | 通用："这个知识点能帮学生理解吗？"是跨学科的内容筛选标准 |

**核心可迁移经验（给后续学科）：**
1. **客观指标卡红线**：英语用 wordfreq 词频，数学可用考纲频次/教材出现率——先定指标，再谈数量。
2. **双收录一致性程序化检查**：任何"一对多"的数据结构都要做交叉一致性校验。
3. **"宁缺毋滥"优先于数量目标**：R3 为冲 3000 放宽标准被红队拦回，证明目标数字不能凌驾于质量铁律。
4. **审计发现的问题要沉淀为程序化检查**：词素可见性从人工抽查变为全库扫描脚本，一劳永逸。
