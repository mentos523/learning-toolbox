## 一、设计总纲：六条铁律 + 生物专属三条

### 1.1 沿用几何六条铁律（生物转述版）

1. **一页一概念**：一屏只讲透一个核心概念。宁可多一页，不可一页塞两个概念。生物课常犯"一页讲完光反应又讲暗反应"——拆开（b14.1.2、b14.1.3 各自独立成课已有此意，页内更要守住）。
2. **先动手，后结论**：交互动画在前，文字解释在后。学生先亲手调出"遮光一半的叶片只有一半变蓝"，再看文字"这就是对照"。**交互区没有 exploreTip（动手提示）= 不合格**。
3. **图言永不分离**：每个生物结论旁边必须有对应的实验现象图 / 结构模式图 / 过程动画；**每个生物定义必须配一个"反例"**（"不是××的东西"）：每个规律的适用条件，本质上就是一组反例。只给文字不给图 = 不合格——生物是"看结构、做实验"的学科，无图的讲解页直接判不合格。
4. **跃升必有台阶**：每个难度跃升点必须设计中间脚手架（见第三章），不许"显然""易得"式跳跃。**生物里最危险的跳跃有两种**："结构跳跃"（从结构名称直接跳到功能，中间缺了"这个结构凭什么适合这个功能"）和"术语跳跃"（从现象直接跳到"等位基因分离"这类术语，中间缺了"到底发生了什么"）。
5. **密度上限**：每页 ≤ 3 个信息块（标题区 / 交互区 / 点拨区），≤ 2 个例子，文字总量 ≤ 150 字（讲解页 ≤ 300 字，见 2.5）。
6. **（生物转述）层次—结构—功能三问**：生物的灵魂是"它在哪个层次、长什么样、适合干什么"。凡是讲生命现象的交互，必须能回答三问：**层次**（细胞/组织/器官/个体/种群/生态系统——审计清单第 10 条的概念边界）、**结构**（长什么样）、**功能**（适合干什么——红线辨析①的日常化）。对应几何"变化中找不变"，生物版叫**读数徽章 + 实验三问徽章**：实时显示带规范单位的读数（如 `放大倍数 = 40×`、`能量传递效率 = 10%–20%`），徽章文字写清楚"这一页在回答三问中的哪一问"；实验页常驻"为什么设对照 / 为什么只变一个量 / 为什么要重复"三问。

### 1.2 生物专属三条（黄队新增）

7. **结构—功能对问（形配其用日常化）**：**每讲一个结构，必须配一页"对问页"**：左边结构特征，右边"它适合干什么"，学生亲手连线。教学顺序永远是：**看结构 → 猜功能 → 对答案 → 说出"相适应"的道理**。例如 b05.1.3 小肠：先看三级放大（皱襞→绒毛），再猜"为什么这么皱"，最后点题"面积大、吸收多"。**只许说"相适应"，不许说"结构决定一切"**（红线辨析①）。
8. **实验三问（为什么这样设计）**：**每个实验页必须回答三问**：为什么设对照组（没有参照物，不知道变没变）、为什么只变一个量（多了就不知道是谁的功劳）、为什么要重复（一次可能是巧合）。三问以常驻徽章呈现，学生做实验前先读三问。curriculum 每课实验栏已标"对照/单一变量/重复"三原则落点，黄队的任务是把三原则讲出"为什么"——**讲不出"为什么"的实验页 = 不合格**。
9. **科学克制（人体/疾病/基因/疫苗/伦理）**：**只讲生物学事实与现行规范 / 参考范围，不做价值审判、不制造焦虑、不做诊疗暗示**。遗传病课讲概率不讲命运（"携带致病基因≠注定发病"）；疫苗讲机制不讲恐吓（"降低重症风险，不是 100% 不得"）；体检指标讲参考范围不讲"你超标了"（"一次测量不能诊断"）；基因编辑/转基因只讲科学事实与现行安全管理规范。**类比必配边界句，模式图必声明"非实物"**（审计清单第 7 条）。

## 二、每页结构规范（沿用物理三块式，生物微调）

### 2.1 页面结构

```
┌─────────────────────────────┐
│ 标题区（一句话概念）   │ ← ≤ 20 字，flex none
├─────────────────────────────┤
│ │
│ 交互区（主角，占 60%） │ ← flex 1：虚拟实验/结构拼搭/过程动画在这里
│ 读数徽章（小标签）   │ ← ★生物版：带规范单位的实时读数
│ 状态徽章（现象文字） │    如 放大倍数 = 40×；能量传递效率 = 10%–20%
│ 实验三问徽章（常驻） │ ← ★生物新增：为什么设对照/为什么只变一个量/为什么要重复
│ 安全徽章（⚠ 一句话） │ ← 口腔上皮取样/酒精灯/盐酸解离等，常驻不随交互消失
│ 模式图声明（小字）   │ ← ★生物新增："模式图，非等比/非实物"，常驻角落
├─────────────────────────────┤
│ 点拨区（≤ 60 字 + 下一步） │ ← flex none，"这就是××"式点题
└─────────────────────────────┘
```

**生物微调说明**：

- **读数徽章**：交互区角落的小标签，随交互实时更新。**所有数值读数走 MathML、单位与数值同行**（`放大倍数 = 40×`，不许裸文本 "40倍"；`能量传递效率 = 10%–20%`，不许裸文本 "10%-20%"；体检指标 `空腹血糖参考范围 3.9–6.1 mmol/L`，不许裸文本 "3.9-6.1"）。读数徽章是第六条铁律的落地——学生即使不看文字，也能从徽章里读出"层次/结构/功能"信息。例如 b17.1.2 分离比模拟页：徽章"高茎 : 矮茎 = …（n = …次）"；b24.3.2 能量流动页：徽章"本级获得 = 上一级的 …%"。
- **状态徽章（现象文字）**：生物特有——很多实验现象不能只靠图形读出来，必须配文字。碘液检验（"变蓝 ✓" / "不变蓝"）、石灰水（"变浑浊"）、发酵（"产生气泡 ↑"）。**状态永远双编码：图形 + 文字，不只靠颜色**（色盲双编码）。
- **实验三问徽章**：实验页常驻三问（"为什么设对照？/ 为什么只变一个量？/ 为什么要重复？"），点开展开一句话答案。这是第八条铁律的组件落地。
- **安全徽章**：涉及口腔上皮取样（一次性消毒牙签）、酒精灯（灯帽盖灭）、盐酸解离、野生菌（不采食）的页，交互区顶部固定一条安全提示条（⚠ + 一句话），常驻不随交互消失。
- **模式图声明**：凡结构示意图（细胞器模式图、细胞膜流动镶嵌模型、DNA 双螺旋球棍模型、生殖系统结构图）角落常驻小字"**模式图：非等比、非实物**"；凡显微/电镜照片注明"**实物图**"（审计清单第 7 条）。
- **虚拟/现实分界线标注**：虚拟实验页角落常驻小字"虚拟实验：现实中须××（如先对光后观察/酒精灯用灯帽盖灭）"，不误导"现实中也能这么玩"。
- **"先猜后验"**：鼓励每类交互实验页配一个"猜一猜"小条——学生先点选预测（"遮光一半的叶片，滴碘液后哪一半变蓝？"），再动手验证。**不判对错**，只记录（复用物理 Y1 `guess-verify`）。

### 2.2 四类页面的分工（生物四步走：看 → 玩 → 懂 → 练）

| 页类型 | 作用 | 结构 | 占比 |
|---|---|---|---|
| **观察页** | 看：结构观察 / 现象观察页，亲眼看到（显微镜操作、装片观察、实验现象） | 三块式 + 安全徽章 + 模式图声明 + exploreTip | 约 20% |
| **交互实验/拼搭页** | 玩：调参探究 + 结构拼搭，亲手改变条件看结果 | 三块式 + 读数徽章 + 实验三问徽章 + exploreTip | 约 30%（129 课每课 1 页起） |
| **过程演示页** | 看：长过程动画慢放（分泌蛋白旅程、转录翻译流水线、免疫流程），步骤条 + 画布（复用 slow-replay 范式，≤ 5 步） | 步骤条 + 画布 | 约 10% |
| **讲解页** | 懂：交互页之后 1–2 页完整讲解，层次—结构—功能对齐 + 反例 | 见 2.5 | 约 30% |
| **习题页** | 练：每章末，答案折叠；**每章必有一道"生活中的生物"题 + 一道实验设计题** | 见 2.6 | 约 10% |

**顺序铁律**：同一概念内，顺序必须是 **观察页 → 交互实验/拼搭页 → 过程演示页（如有） → 讲解页 →（章末）习题页**。不许先给术语再让学生玩——术语是学生自己"玩出来"之后，黄队用文字帮他"说出来"。**特别地，结构页的顺序永远是：看结构 → 猜功能 → 对答案 → 反例/边界**（第七条铁律）。

### 2.3 讲解页与交互页的衔接语规范

- 讲解页开头第一句必须是"认旧友"："还记得吗？你第 X 页把水位…/你第 X 页看到碘液变蓝的那一半叶片……"（沿用几何"认旧友"标注规范）。
- 交互页的 exploreTip（≤ 40 字）只说"动手做什么"（"拖一拖：把细胞器放到它该待的位置"），不说结论。结论永远在点拨区，由学生"看到"之后黄队点题。

### 2.4 每页自查清单（生物版）

- [ ] 一屏能看完，不滚动（手机 390px 为准）
- [ ] 主交互是"动手改变点什么"（拖/调/点选/拼搭），不是纯播放
- [ ] 读数徽章走 MathML、单位与数值同行；写清楚了"这一页在回答三问中的哪一问"（层次/结构/功能）
- [ ] 点拨区 ≤ 60 字，最后一句是"这就是××"式点题（结构名/规律名/观念句）
- [ ] 结构页顺序：看结构 → 猜功能 → 对答案 → 反例/边界；每个定义配了反例
- [ ] 实验页有实验三问徽章（三问一点就展开一句话答案）；对照/单一变量/重复三原则可指认
- [ ] 术语规范：呼吸≠呼吸作用、基因型≠表现型、DNA≠基因，一次用对（审计清单第 1 条抽查）

## 三、难度跃升脚手架（12 个生物特有卡点）

> 每个脚手架 = 卡点描述 → 分步脚手架（**立靶页 → 脚手架 → 严格化 → 回填链**）→ 点拨话术。课号全部取自 `docs/biology-curriculum.md` v1.1。

### 跃升 1：显微镜"东西反着动"（成倒像 + 视野反向）

- **卡点**：显微镜下看到的是倒像，且玻片移动方向与视野中物像移动方向相反。学生"物像偏哪、玻片往哪移"全凭猜，一考就反。
- **脚手架**（b01.1.1，3 页）：
  1. 立靶页：显微镜虚拟操作（Y25 `microscope-sim`）——走完"取放 → 对光 → 安放 → 观察"全流程。"显微镜里看到的是'倒像'：上下颠倒、左右相反，就像把玻片转了 180°。"
  2. 脚手架："偏哪移哪"闯关——视野中物像偏左上，玻片往哪移？"向左上移（因为成倒像，物像动的方向和玻片反着）"。污点三步排查：转动目镜（污点动→在目镜）→ 移动装片（污点动→在装片）→ 转动物镜（在物镜）。
  3. 严格化 → 回填链：放大倍数 = 目镜 × 物镜（ch00 乘法，**奠基**）；回填 b01.1.2（"低倍找到、移到中央，再转高倍"——装片制作规范动作）。
- **点拨话术**："显微镜里看到的是'倒像'——上下颠倒、左右相反。**记住'偏哪移哪'：物像偏左上，玻片就往左上移。**（生物队裁决 T9⚠️：口诀限操作页使用；严格页必配"旋转 180°"图示，B2/W-B4 已落实）"

### 跃升 2：形配其用——结构与功能相适应（红线辨析①立靶）

- **卡点**："结构与功能相适应"背成口号，不会用；易倒置为"结构决定一切"（功能需求同样塑造结构）。这是全书使用频率最高的观念，必须一次立准。
- **脚手架**（b05.1.3，3 页；**红线辨析①立靶**）：
  1. 立靶页：小肠内表面三级放大交互（皱襞 → 绒毛 → 微绒毛）——"为什么小肠这么长、这么皱？猜一猜它适合干什么。"
  2. 脚手架：特征 ↔ 功能配对闯关——长（5–6 米）/ 皱襞 / 绒毛 / 壁薄 / 毛细血管网，拖到"面积大 → 吸收多""壁薄 → 易进入血液"两个功能筐。
  3. 严格化 → 回填链：表述定型——"**结构与功能相适应**，不说'结构决定一切'"；回填 b06.1.1（肺泡壁薄/毛细血管网）、b09.2.1（鱼鳃丝密布毛细血管）、b11.1.3（蛋白质结构多样性 → 功能多样性）、b12.1.3（线粒体内膜嵴多 / 叶绿体基粒多）。
- **点拨话术**："看到任何结构，先问'这个结构适合干什么'——小肠的皱襞和绒毛，都是为了'多吸收'。**记住：结构为功能服务，叫'形配其用'；但别倒过来说'结构决定一切'。**"

### 跃升 3：呼吸 ≠ 呼吸作用（一字之差，全书最高频混淆）

- **卡点**："呼吸"（肺通气）与"呼吸作用"（细胞内氧化分解）一字之差，全书混用重灾区（审计清单第 1 条）。"跑步后喘气是呼吸作用加快"是典型错句。
- **脚手架**（b03.1.3，3 页）：
  1. 立靶页：两个动画并排——左边人跑步喘气（呼吸：肺通气），右边萌发种子使澄清石灰水变浑浊、温度计上升（呼吸作用：分解有机物、释放能量）。
  2. 脚手架：术语医院——"跑步后喘气是呼吸作用加快""植物晚上不进行呼吸作用了"，学生当"医生"改错句。"喘气看得见（呼吸），呼吸作用看不见（细胞里的事）——植物不喘气，但时刻都在呼吸作用。"
  3. 严格化 → 回填链：b15.1.1 回填（有氧呼吸三阶段——"细胞内的事，时刻进行"）；b06.1.1 回填（呼吸是呼吸运动，呼吸作用是氧化分解）。
- **点拨话术**："**呼吸是你'喘气'的动作（肺通气）；呼吸作用是细胞里'烧'有机物放能量的过程。**植物不喘气，但时刻都在呼吸作用。（生物队裁决 T8✅："烧"可用；边界句"呼吸作用是缓慢氧化，不是有火苗的烧"确认保留）"

### 跃升 4：实验三原则——为什么设对照 / 为什么只变一个量 / 为什么要重复

- **卡点**：对照组被当成"摆设"，"为什么设对照"答不上来；变量控制靠背诵，换个实验就不会设。这是全书实验的地基，b03.1.1 是第一个完整探究实验，三原则在此定型。
- **脚手架**（b03.1.1，3 页）：
  1. 立靶页：绿叶实验虚拟全流程（Y26 `experiment-3q` 首立）——暗处理 → 一半遮光 → 光照 → 酒精脱色 → 碘液检验。"遮光一半、见光一半，为什么这么麻烦？"
  2. 脚手架：三问闯关——"为什么一半遮光一半见光？"（对照：没有参照物，不知道变没变）/"为什么只让'光'这一个条件不同？"（单一变量：多了就不知道是谁的功劳）/"为什么多片叶子重复？"（重复：一次可能是巧合）。
  3. 严格化 → 回填链：三问成为全书实验页固定"实验三问"徽章；回填 b05.1.2（唾液淀粉酶：唾液 vs 清水）、b11.1.5（有机物鉴定：清水/已知样对照）、b12.1.5（质壁分离：自身前后对照）、b23.1.1（温特实验：琼脂块 A/B/C/D 对照组）。
- **点拨话术**："做实验先问三句话：**对照组是'参照物'（没它不知道变没变）；一次只变一个量（多了就不知道是谁的功劳）；多做几次（一次可能是巧合）。**这三问，全书每个实验都要过一遍。（生物队裁决 T10⚠️："参照物"可用；边界句：此处的"参照物"指"比较的基准"，不是物理运动学中的参照系）"

### 跃升 5：酶"锁钥"与降低活化能

- **卡点**："酶提供能量"的顽固直觉；高温 vs 低温对酶的影响混为一谈（"高温抑制"说错——高温是破坏，不可恢复）。
- **脚手架**（b13.1.1–1.2，3 页）：
  1. 立靶页：过氧化氢分解三组对照虚拟实验（无催化剂 / 无机催化剂 / 酶）——"酶没多给能量，只是把'门槛'（活化能）降低了。"
  2. 脚手架：温度/pH 双滑块（Y33 `enzyme-lab`）——"锁（酶）配钥匙（底物）：一把锁只开一把钥匙（专一性）；高温把锁'烫变形'回不来，低温只是'冻住'，回温能恢复。"
  3. 严格化 → 回填链：专一性回填 b05.1.2（"唾液只初步消化淀粉——专一性早就见过"）；回填 b13.1.3（ATP"能量货币"的边界：货币流通不是金库囤积）。
- **点拨话术**："**酶不提供能量，它只'降低门槛'（活化能）。记住两句：高温烫坏锁（不可恢复），低温冻住锁（可恢复）；一把锁只开一把钥匙（专一性）。**（生物队裁决 T3⚠️："锁钥"可用；边界句"结合时会微调（诱导契合）"已在 B10 落实）"

### 跃升 6：细胞膜流动镶嵌模型（分层点 b12.1.2）

- **卡点**："静态三明治"直觉根深蒂固；磷脂/蛋白质排布记不住、记混。
- **脚手架**（b12.1.2，3 页；**分层落实**）：
  1. 立靶页（直觉版）：磷脂三明治拖拽动画——"两层磷脂当'面包片'，拖一拖，看它们会'流动'。"
  2. 脚手架（直觉版）：荧光标记小鼠—人细胞融合实验——"两种颜色的膜蛋白混到一起了——膜在流动！"
  3. 严格页（边界明示）：蛋白质镶嵌/贯穿/覆盖三种方式 + 选择透过性；模式图声明（"模式图，非等比、非实物"）。→ 回填链：b12.1.5（物质进出细胞：载体 + 能量）。
- **点拨话术**："细胞膜不是'静止的三明治'，是'流动的'——磷脂分子会动，蛋白质有的镶着、有的穿着。**直觉版记住'流动'两个字；蛋白质怎么排、为什么选择透过，严格版在下一页。**（生物队裁决 T1⚠️："流动的三明治"可用；边界句："三明治"只讲"两层磷脂夹心"的排布样子，不讲"静止"——膜是流动的，严格页见蛋白质三种排布方式与融合实验证据）"

### 跃升 7：有丝分裂染色体"复制—均分"（分层点 b16.1.1）

- **卡点**："分裂后染色体减半"的顽固直觉；间期/前/中/后/末五个术语一次全给会噎住。
- **脚手架**（b16.1.1，3 页；**分层落实**）：
  1. 立靶页（直觉版）：染色体行为动画（Y34 `mitosis-stage`）——复制 → 排队 → 分开 → 进两个细胞。"先复印、再平分。"
  2. 脚手架（直觉版）："数一数"——分裂前后染色体数目对照表（数目不变！因为间期已复制）。
  3. 严格页（边界明示）：间期/前/中/后/末术语 + 动植物区别（纺锤体来源/细胞板）。→ 回填链：b16.1.4（减数分裂对比——"减数是'减半'，有丝是'平分'"）。
- **点拨话术**："有丝分裂就四个字：**先复印、再平分**——间期先把染色体复印一份，分裂时平均分给两个细胞，所以数目不变。时期名字（前中后末）是严格版，先看懂'平分'这个动作。（生物队裁决 T2⚠️："先复印、再平分"可用；边界句："复印"指染色体数目复制（DNA 复制的直觉版，半保留机制见 b19.1.2）；"平分"指染色体平均分配）"

### 跃升 8：分离定律与 3:1 概率直觉（分层点 b17.1.1）

- **卡点**：3:1 被当成"每次杂交的精确结果"；"假说—演绎法"四个字抽象，学生背不下来更用不出来。
- **脚手架**（b17.1.1–1.2，3 页；**分层落实**）：
  1. 立靶页（直觉版）：豌豆杂交故事——高茎 × 矮茎 → 全高 → 自交出现 3:1。"奇怪的比例：矮茎去哪了？又从哪冒出来的？"
  2. 脚手架（直觉版）：分离比模拟器（Y28 `punnett-lab`）——次数滑块 10 次 vs 1000 次。"次数越多越接近 3:1——这是**统计规律**，不是每次恰好。"
  3. 严格页（边界明示）："假说—演绎"四步（观察 → 假说 → 演绎 → 实验验证）+ 分离定律实质（等位基因随同源染色体分离）。→ 回填链：b17.1.3（自由组合 9:3:3:1）、b17.1.4（适用条件自查）、b18.1.3（系谱判读概率回填）。
- **点拨话术**："**3:1 不是'每次恰好'，是'大量统计的结果'**——抛 10 次硬币不一定 5 正 5 反，抛 10000 次才接近。孟德尔的高明在于'假说—演绎'：先大胆假设（成对的遗传因子会分离），再算出'如果假设对，测交该是什么样'，最后用实验验证。"

### 跃升 9：系谱判读"两步走"

- **卡点**：拿到系谱图直接猜；"先定显隐、再定常/性"顺序混乱，一步跳步全错。
- **脚手架**（b18.1.3，3 页）：
  1. 立靶页：口诀判读闯关（Y29 `pedigree-quest`）——"无中生有是隐性，有中生无是显性"。给 4 张系谱图，只判显隐。
  2. 脚手架：第二步"看常/性"——伴 X 隐性交叉遗传特征（男患者的致病基因来自母亲、传给女儿）。分步向导：上一步不确定，不许进下一步。
  3. 严格化 → 回填链：基因型推断（携带者表型正常——**辨析②回填**）；回填 b18.1.4（遗传咨询："携带致病基因≠注定发病"）。
- **点拨话术**："看系谱图永远两步：**先定显隐（'无中生有'隐、'有中生无'显），再定常性。顺序不能反，一步都不能跳——跳步就是猜。**（生物队裁决 T15⚠️：口诀可用；适用边界"适用于孟德尔式单基因遗传系谱"已冻结（B-F6）；口诀只解决"定显隐"第一步）"

### 跃升 10：中心法则 → 性状=基因+环境（红线辨析②立靶）

- **卡点**："基因=性状"的直觉（"有这个基因就一定长这样"）；DNA → RNA → 蛋白质链条长，学生中途掉队。
- **脚手架**（b19.1.3–1.4，3 页；**红线辨析②立靶**）：
  1. 立靶页：转录—翻译流水线动画（Y30 `central-dogma`）——DNA → RNA → 蛋白质，"信息流水线，一站接一站"。
  2. 脚手架：同卵双生不同环境案例——"底稿（基因型）一样，成品（表现型）不一样，差在'加工条件'（环境）。"
  3. 严格化 → 回填链：辨析②表述定型——"**基因型是底稿、表现型是成品、环境是加工条件**"；回填 b18.1.3（系谱：携带者表型正常）、b18.1.4（人类遗传病："携带≠发病"）、b20.1.1（花生果实变异：可遗传 vs 不可遗传）。
- **点拨话术**："基因不是'性状本身'，是'生产性状的图纸'——DNA → RNA → 蛋白质 → 性状，是一条流水线。**记住：性状 = 基因 + 环境；携带致病基因 ≠ 注定发病。**（生物队裁决 T5⚠️："底稿/成品/加工条件"可用；边界句："加工条件"不是被动的——环境可影响基因表达（如表观遗传，见 b19.1.4 拓展）；性状=基因+环境是共同作用）"

### 跃升 11：进化是种群的事（红线辨析④立靶）

- **卡点**："个体为适应环境而进化"的拉马克式直觉；"长颈鹿伸长脖子"的故事深入人心，一考就写错。
- **脚手架**（b21.1.2，3 页；**红线辨析④立靶**）：
  1. 立靶页：抗药性形成动画（b21.1.1，**辨析④预告**）——"变异先存在，抗生素只是'选择'，不是'诱导'。"
  2. 脚手架：基因频率模拟——拖"选择压力"滑块，看种群中抗药基因频率定向上升。"进化 = 种群基因频率的定向改变。"
  3. 严格化 → 回填链：表述定型——"**自然选择作用于个体，进化体现在种群**"；回填 b21.1.1（抗药性案例复盘）、b21.1.3（物种形成：生殖隔离）、b20.1.2（突变发生在个体，频率改变在种群）。
- **点拨话术**："记住这句，一辈子别说反：**自然选择'选'的是个体（抗药的活下来），但'进化'的是种群（抗药基因频率上升）。**长颈鹿不是'想长脖子'长出来的，是脖子长的个体被留下，种群越来越长脖子。（生物队裁决 T6⚠️："算总账"仅限点拨口语；正式表述用红线口诀"进化是种群的事"＋"进化=种群基因频率的定向改变"）"

### 跃升 12：能量单向物循环（红线辨析③立靶）

- **卡点**："能量循环利用"的直觉；碳循环箭头乱画（方向即对错，画反即错）。
- **脚手架**（b24.3.2–3.3，3 页；**红线辨析③立靶**）：
  1. 立靶页：能量流动交互——每级只剩 10%–20%，拖滑块看能量"越流越少"。"能量像泼出去的水，回不来。"
  2. 脚手架：碳循环箭头闯关——"生产者 → 消费者 → 分解者 → 无机环境，方向错了打回；化石燃料 → 大气是单向！"。"物质像坐公交，循环往复。"
  3. 严格化 → 回填链：能量金字塔；回填 b24.3.3（能量 vs 物质箭头方向对比）、b03.1.5（碳—氧平衡预告兑现）。
- **点拨话术**："能量和物质，一个单向、一个循环：**能量沿食物链单向流动、逐级递减（10%–20%），用掉就没了；物质在生物群落和无机环境之间循环往复。记住：能量单向物循环——箭头方向就是对错。**（生物队裁决 T7⚠️："泼水/坐公交"可用；边界句："坐公交"指物质在生物群落与无机环境之间循环往复，不是指固定线路；化石燃料→大气是单向的）"

### b01.1 显微镜与细胞（b01.1.1–1.4）
