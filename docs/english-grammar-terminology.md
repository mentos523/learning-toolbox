# 英语语法术语清单（人教版口径 · 冻结版）

> ## 冻结声明
>
> 本清单由**英语专家队**于 **2026-10-14** 书面冻结。
> 依据：`docs/english-design-review.md` 开工条件 M3（术语口径以人教版为准）与红队审计结论 S1（术语全书一致性 ✅ 通过）。
> **后续生产与审计以此为据**：课程讲解、条件卡、例句、习题中的语法术语必须采用本清单术语；别名只许在"也叫"括号中出现一次且不许反向；**改动须走变更记录**（见文末"变更记录"节），未经变更记录的术语改动视为违规，红队审计时打回。

> 出处定位说明："七上/七下/八上/八下/九年级"指初中《Go for it!》对应年级册；"必修/选必"指高中相应模块；"人教版惯用"指人教版语法体系通用术语（各册语法总结沿用）；"语法侧新建"指本语法板块新建、讲词根侧引用时须标注来源的术语。

## 使用铁律（与本清单配套执行）

1. **别名不反向**：如"宾语从句（也叫名词性从句的一种）"只许出现一次，不许写成"名词性从句（也叫宾语从句）"（红队 S1 已核）。
2. **人话版仅限直觉页/点拨区/口诀**；严格页一律用本清单术语 + 条件卡（用户 2026-10-14 "先直觉后严格"定案）。
3. **拼写口径**：全书美式拼写，术语首次出现附英式异体（如 behavior / behaviour）。
4. **时态命名统一用"时"不用"式"**（"现在完成时"，不许"现在完成式"）；时态数量口径：中学主线 8 时态 + 高中拓展（将来进行时等另行标注"拓展"）。

## 一、考试简称—全称对照（冻结）

| 考试简称 | 全称 | 适用条件（必注） | 人教版定位 |
|---|---|---|---|
| 主将从现 | 主句用一般将来时，时间/条件状语从句用一般现在时代替将来 | **仅限时间/条件状语从句**；宾语从句中 will 正常（如 I wonder if it will rain.） | 九年级（gr15） |
| 三单现 | 主语为第三人称单数时的一般现在时（动词加 -s/-es） | 主语为 he/she/it 或单数名词/不可数名词 | 七上（gr05） |
| 主过从过 | 主句动词用过去时，宾语从句时态呼应也用相应的过去时 | 主句为过去时（said / wondered 等）；主句为现在时则从句时态不变 | 高中必修（gr13） |

## 二、句子成分与基本句型

| 术语 | 英文 | 人教版定位 | 备注/边界 |
|---|---|---|---|
| 主语 | subject | 人教版惯用（Go for it! 七上–九全语法总结；高中必修沿用） | 动作的发出者或被描述对象 |
| 谓语 | predicate (verb) | 人教版惯用 | 人教版口径中"谓语"即谓语动词；全书铁律"一个句子只能有一个谓语" |
| 宾语 | object | 人教版惯用 | 分直接宾语 direct object / 间接宾语 indirect object |
| 表语 | predicative (complement) | 人教版惯用 | 人教版用"表语"，不用"主语补足语" |
| 定语 | attribute | 人教版惯用 | 修饰名词；注意与"状语"区分 |
| 状语 | adverbial | 人教版惯用 | 修饰动词/形容词/全句 |
| 补语 | complement（宾语补足语 object complement） | 人教版惯用 | 人教版"补语"专指宾补；不与"表语"混淆 |
| 基本句型一 | S + V（主谓） | 人教版惯用 | 如 She runs. |
| 基本句型二 | S + V + P（主系表） | 人教版惯用 | P = predicative（表语） |
| 基本句型三 | S + V + O（主谓宾） | 人教版惯用 | |
| 基本句型四 | S + V + IO + DO（主谓间宾直宾） | 人教版惯用 | IO = indirect object，DO = direct object |
| 基本句型五 | S + V + O + C（主谓宾宾补） | 人教版惯用 | C = complement（宾语补足语） |

## 统计

- 考试简称 3 条（主将从现 / 三单现 / 主过从过，均配全称与适用条件）
- 术语条目 18 节、约 120 条（含考试简称 3 条），覆盖红队 S1 核对的全部术语（七大句子成分、五种基本句型、名词性从句、非谓语动词、独立主格、含蓄条件、形式主语/宾语、反意疑问句、否定转移）
- 人教版定位口径：初中《Go for it!》七上–九全 + 高中必修/选必；"人教版惯用"为语法体系通用术语；"语法侧新建"仅构词法后缀体系等 4 条
