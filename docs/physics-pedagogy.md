## 一、设计总纲：六条铁律 + 物理专属三条

### 1.1 沿用几何六条铁律（物理转述版）

1. **一页一概念**：一屏只讲透一个核心概念。宁可多一页，不可一页塞两个概念。物理课常犯"一页讲完 F=ma 又讲单位制"——拆开。
2. **先动手，后结论**：交互动画在前，文字解释在后。学生先拖拉力看到木块动起来，再看文字"这就是合力决定运动"。**交互区没有 exploreTip（动手提示）= 不合格**。
3. **图言永不分离**：每个物理结论旁边必须有对应的实验现象图/动画；**每个物理定义必须配一个"反例"**（"不是××的东西"）：每个公式的适用条件，本质上就是一组反例。只给公式不给现象 = 不合格。
4. **跃升必有台阶**：每个难度跃升点必须设计中间脚手架（见第四章），不许"显然""易得"式跳跃。**物理里最危险的跳跃是"公式跳跃"**：从现象直接跳到公式，中间缺了"为什么非得这么写"。
5. **密度上限**：每页 ≤ 3 个信息块（标题区 / 交互区 / 点拨区），≤ 2 个例子，文字总量 ≤ 150 字（讲解页 ≤ 300 字，见第五章）。
6. **（物理转述）现象中找不变**：物理的灵魂是"什么在变、什么守恒/不变"。凡是可调参的交互，必须同时标出**变了什么**和**没变什么**——不变的那个，就是要学的定律。对应几何"变化中找不变"，物理版叫**读数徽章**：实时显示带单位的读数（如 `F合 = 6 N`），徽章文字写清楚"没变的是：××"。

### 1.2 物理专属三条（黄队新增）

7. **条件先行**：**每个物理公式，必先讲适用条件，再讲公式**。条件不是"注意事项小字"，是公式的"身份证"——没有身份证的公式不许上场。教学顺序永远是：**现象 → 条件（什么时候成立） → 公式 → 反例（什么时候不成立）**。例如欧姆定律页：先玩"灯泡变亮电阻变了"的反例，再给公式，最后条件卡片"只对金属导体、纯电阻成立"。
8. **无实验不定**：**每个抽象概念，必先有一个可操作的实验/演示，学生亲手"摸"到现象之后，才下定义**。磁场、电流、电场强度、内能——凡是"看不见摸不着"的概念，定义页之前必须有一页"动手页"。定义的第一句话必须是人话版（"磁场就是磁铁周围'**能让小磁针转动**'的那片空间"），术语版放在第二句。
9. **箭头先行**：**矢量必先看箭头，再看数字**。凡涉及矢量的页面，教学顺序是：先看箭头指哪（方向）→ 再看箭头多长（大小）→ 最后才看数字。数字上的负号，永远先翻译成"箭头反了"。例如 p11.1.2 位移页：先拖出一条有向线段看方向，再读长度，最后讲"−5m 的负号是方向，不是比零小"。

## 二、每页结构规范（沿用几何三块式，物理微调）

### 2.1 页面结构

```
┌─────────────────────────────┐
│ 标题区（一句话概念）    │ ← ≤ 20 字，flex none
├─────────────────────────────┤
│ │
│ 交互区（主角，占 60%）  │ ← flex 1：虚拟实验/演示在这里
│ 读数徽章（小标签）    │ ← ★物理新增：实时显示"带单位的读数"
│ 现象徽章（状态文字）  │    如 F合 = 6 N；状态如"通路/断路/平衡"
├─────────────────────────────┤
│ 点拨区（≤ 60 字 + 下一步） │ ← flex none，"这就是××定律"点题
└─────────────────────────────┘
```

**物理微调说明**：

- **读数徽章**：交互区角落的小标签，随交互实时更新。**所有数值读数走 MathML、物理量符号斜体、单位与数值同行**（`F合 = 6 N`，不许裸文本 "6N"）。读数徽章是第六条铁律的落地——学生即使不看文字，也能从徽章里读出"谁在变、谁没变"。例如 P1 力拖拽页：徽章 `F合 = … N` + 趋势徽章"静止/向右加速"；P10 弹簧振子页：徽章 `T = 2π√(m/k) = … s`。
- **现象徽章（状态文字）**：物理特有——很多物理状态不能只靠图形读出来，必须配文字。通断（"通路"/"断路"/"短路！"）、平衡（"平衡 ✓"/"向右倾"）、物态（"固态（冰）"/"液态（水）"）、成像（"倒立缩小实像"）。**状态永远双编码：图形 + 文字，不只靠颜色**（沿用 interactions §0.3 第 4 条）。
- **安全徽章**（见第十章）：涉及电/激光/高温/高压的页，交互区顶部固定一条安全提示条（⚠ + 一句话），常驻不随交互消失。
- **时间诚实标注**：凡有调速/慢放的动画（P2 轨迹、P7 碰撞、P9 粒子、P10 振动），动画角常驻小字"慢放 ×0.5（非真实时间）"或"动画已调速"，不误导真实时间比例。

### 2.2 四类页面的分工（物理四步走：玩 → 看 → 懂 → 练）

| 页类型 | 作用 | 结构 | 占比 |
|---|---|---|---|
| **交互实验页** | 玩：动手调参，亲眼看到现象 | 三块式 + 读数徽章 + exploreTip | 约 38%（127 课每课 1 页起） |
| **演示/慢放页** | 看：思想实验、理想外推、慢动作拆解（如伽利略斜面外推、证明式推导） | 步骤条 + 画布（复用 slow-replay 范式，≤ 5 步） | 约 12% |
| **讲解页** | 懂：交互页之后 1–2 页完整讲解，条件卡片 + 反例 | 见第五章 | 约 40% |
| **习题页** | 练：每章末，答案折叠；**每章必有一道估算题** | 见第六章 | 约 10% |

**顺序铁律**：同一概念内，顺序必须是 **交互实验页 → 演示/慢放页（如有） → 讲解页 →（章末）习题页**。不许先给公式再让学生玩——公式是学生自己"玩出来"之后，黄队用文字帮他"说出来"。**特别地，公式页的顺序永远是：现象 → 条件 → 公式 → 反例**（第七条铁律）。

### 2.3 讲解页与交互实验页的衔接语规范

- 讲解页开头第一句必须是"认旧友"："还记得吗？你第 X 页把拉力拖到 8N 时，木块开始动了。"（沿用几何"认旧友"标注规范）
- 交互页的 exploreTip（≤ 40 字）只说"动手做什么"，不说结论。结论永远在点拨区，由学生"看到"之后黄队点题。
- **"先猜后验"**：鼓励每类交互实验页配一个"猜一猜"小条——学生先点选预测（"拉力再大一点会怎样？"），再动手验证。**不判对错**，只记录（给后续学习报告留接口）。此为黄队新增教学动作需求，走 interactions §14 增补流程（见第十一章）。

### 2.4 每页自查清单（物理版）

- [ ] 一屏能看完，不滚动（手机 390px 为准）
- [ ] 主交互是"动手改变点什么"（拖/调/连），不是纯播放
- [ ] 读数徽章带单位、走 MathML、物理量符号斜体；写清楚了"没变的是什么"
- [ ] 点拨区 ≤ 60 字，最后一句是"这就是××"式点题（定律/现象名）
- [ ] 公式页顺序：现象 → 条件 → 公式 → 反例；条件卡片独立成块（见 5.2）
- [ ] 颜色编码符合全局约定（力矢量三组色、已知蓝、待求朱红，见第九章）
- [ ] 矢量页先讲箭头（方向）再讲数字；负号已翻译成"箭头反了"
- [ ] 有生活化例子（主例进交互，次例进口拨）；例子注明了类比边界（如水流类比）
- [ ] 新名词标注了"就是你第 X 页玩过的那个动作/看到的那个东西"
- [ ] 涉及电/激光/高温/高压：安全徽章常驻，话术见第十章
- [ ] 调速/慢放动画有"非真实时间"常驻标注
- [ ] 估算页/数量级页：锚点数值来自 curriculum 审计清单第 5 条，不自编

## 三、难度跃升脚手架（11 个物理特有卡点）

> 每个脚手架 = 卡点描述 → 2–3 页分步脚手架 → 调用的交互编号（P1–P10 + 复用） → 点拨话术。

### 跃升 1：标量 → 矢量（"数"到"箭头"的第一次升级）

- **卡点**：学生学了 8 年"数"，第一次遇到"有方向的数"。负号被当成"比零小"，位移被当成路程，力被当成"劲儿"。
- **脚手架**（p11.1.2 位移与路程，3 页）：
  1. 交互页：画布上一条小路（弯的），学生拖小人从起点走到终点再走回来。读数徽章同时显示"路程 = … m"（越走越大）和"位移 = … m"（走回来变 0）。"同样是'走了多远'，两个数不一样。"
  2. 交互页：位移有向线段绘制——学生拖箭头，箭头指哪、位移就"指"哪；再拖一条反向的，读数出现负号。"负号不是比零小，是箭头掉头了。"
  3. 讲解页：标量 vs 矢量对照表（路程/位移、质量/力、温度/速度）。口诀："**矢量三问：多大？朝哪？负号是方向。**"
- **交互**：P2 motion-sim（改装：轨迹模式只画路径，不发射）+ slider-lab 复用；箭头绘制复用 vertex-drag 手柄。
- **点拨话术**："从今天起，物理里的'数'分两种：一种只管多大（标量），一种还要管朝哪（矢量）。**看到矢量，先看箭头，再看数字。**"

### 跃升 2："力是维持运动的原因" → "力是改变运动状态的原因"（对抗亚里士多德直觉）

- **卡点**：这是全书第一观念转折（curriculum p05.2.1 原话）。学生两千年的直觉是"不推就不动"——推桌子，桌子停了，"力没了所以停了"。直接讲牛顿第一定律会被当成"背下来"。
- **脚手架**（p05.2.1 牛顿第一定律，3 页）：
  1. 交互页（P1 力拖拽改装）：小车在毛巾/棉布/木板三种路面上滑，学生拖"表面粗糙度"滑块从粗到光滑。"路面越光滑，小车滑得越远。"——先建立"阻力越小、运动保持得越久"。
  2. 演示/慢放页：伽利略斜面理想外推——滑块继续拖到"完全光滑（想象）"，小车永远滑下去。"**这一步是'想'出来的，不是'做'出来的**——但'想'有依据：每一步都比上一步滑得远。"
  3. 讲解页：亚里士多德 vs 伽利略对照。"推桌子桌子停，不是因为'力没了'，是因为**摩擦力这个'反方向的力'还在**。"
- **交互**：P1 force-drag（加表面粗糙度滑块）+ slow-replay 思想实验步骤条。
- **点拨话术**："记住这句一辈子的话：桌子停下来，恰恰是因为有力（摩擦力）在改变它。**力不是维持运动的原因，是改变运动状态的原因。**"

### 跃升 3：公式条件意识（"公式身份证"）

- **卡点**：学生拿到公式就代数，"F=BIl""W=Fl""U=Ed"无条件乱用。curriculum 审计清单第 3 条列了十几个条件——条件是物理与数学的根本区别（数学公式无条件成立，物理公式全是"有条件的真话"）。
- **脚手架**（通用脚手架，首次完整亮相在 p08.2.3 欧姆定律；之后每公式复用同一版式，3 页）：
  1. 交互页：先玩反例——小灯泡的 I–U 图像：电压调上去，图像弯了（灯丝热了电阻变了）。"欧姆定律说 I=U/R 是直线，这条怎么弯了？"
  2. 讲解页：公式身份证卡片（固定版式，全书统一）：**公式 | 成立条件 | 反例（什么时候失效） | 量纲检查**。欧姆定律的身份证："I=U/R；条件：金属导体、纯电阻、温度不变；反例：小灯泡（温度变了）；量纲：A = V/Ω ✓"。
  3. 讲解页：条件口诀页——"**物理公式都是'有条件的真话'，背公式先背条件。**"配全书高频条件清单速查表（牛顿定律限宏观低速惯性系、库仑定律限真空点电荷……来自 curriculum 审计清单第 3 条）。
- **交互**：P3 circuit-build（I–U 图像模式；灯泡元件的非线性为教学点）+ 复用 plot-points 画 I–U 曲线。
- **点拨话术**："数学公式的条件写在定义域里，物理公式的条件是'身份证'。**以后看到公式，第一问永远是：它在什么时候成立？**"

### 跃升 4：比值定义陷阱（R=U/I、ρ=m/V、E=F/q、C=Q/U 四连击）

- **卡点**：学生看到 R=U/I 就说"电阻与电压成正比"。这是全书出现**四次**的同一个坑（curriculum 附录 A20：密度 p04.1.2、电阻 p08.2.2、电场强度 p15.1.3、电容 p15.1.5）。必须在第一次出现时彻底"打预防针"，后三次只做"回看"。
- **脚手架**（p04.1.2 密度，3 页；p08.2.2/p15.1.3/p15.1.5 各 1 页回看页）：
  1. 交互页：m–V 图像虚拟实验——铝块、铁块、水，三条过原点的直线，斜率不同。学生拖滑块加砝码（m 变大），V 跟着变大，但"斜率"（密度）徽章不动。"ρ 是 m–V 图像的'斜率'——m 变、V 跟着变，但斜率不变；m/V 是'量'密度的方法，不是'决定'密度的原因。"
  2. 讲解页：比值定义法说明书（固定版式，全书四次复用）："**比值定义 = 用两个量给第三个量'起名字'，不是说它俩决定它。** 密度是物质的脾气，电阻是导体的脾气，场强是场的脾气——脾气是它自己的，跟"量"它的人无关，不是算出来的。"
  3. 讲解页：正反比判定三步法——"① 看公式里谁变了谁跟着变；② 看'脾气'变没变；③ R=U/I 里，U 变 I 跟着变，R 动都不动——所以 R 与 U、I 无关。"
- **交互**：复用 slider-lab（m–V 图像斜率联动）；回看页配"还记得密度那页吗？"认旧友链接。
- **点拨话术**："**等号不代表因果。** R=U/I 是'量'电阻的办法，不是'决定'电阻的原因。电阻是导体的脾气，电压电流只是来'量脾气'的。"

### 跃升 5：电流"流"的类比与边界（水流类比何时失效）

- **卡点**：水流类比是讲电流的最好拐杖，也是最危险的拐杖。学生会推出"电流会被用掉""电子从电源跑到灯泡要跑很久"等错误结论（curriculum p08.1.3、p16.1.1 误区）。
- **脚手架**（p08.1.2 电流与电路 → p16.1.1 回填，3 页）：
  1. 交互页（P3 电路搭建）：串联电路里三个电流表（A1/A2/A3）读数永远相等。"水流过水车会被'用掉'吗？不会。水车转起来，水还是那些水——**电流是电荷的'队伍'在走，不是电荷被'吃掉'。**"
  2. 讲解页：类比边界卡（固定版式）——"水流类比**管用**的地方：有压力（电压）才有水流（电流）、水管细水流小（电阻）；**不管用**的地方：'用掉'的从来不是水也不是电荷，而是能量——水车用掉的是水的势能，灯泡用掉的是电荷的电势能；水和电荷本身都守恒。"
  3. 讲解页（p16.1.1 回填）：电子漂移 vs 电场传播对比动画——"灯瞬间亮，不是因为电子跑得快，是因为**电场像口令一样瞬间传到全电路**，所有电子同时起步。"
- **交互**：P3 circuit-build（多电流表读数联动）；p16.1.1 配对比动画（慢放 ×0.01 标注"示意，非真实比例"）。
- **点拨话术**："类比是拐杖，不是腿。**每次用类比，都要问一句：它在哪儿不管用了？**不管用的地方，往往就是真正的物理。"

### 跃升 6：看不见的场（磁场/电场的可视化）

- **卡点**：磁场、磁感线、电场强度——"看不见摸不着"，学生要么当成"玄学"，要么把磁感线当成真实存在的线（curriculum p10.1.1 误区：磁感线是模型）。
- **脚手架**（p10.1.1 磁现象与磁场，3 页）：
  1. 交互页（P8 field-viz 磁场模式）：拖条形磁铁转圈，8 个小磁针的 N 极跟着转。"磁铁周围有一片'**能让小磁针转动**'的空间——小磁针就是'试吃员'，N 极指的方向就是那点的磁场方向。"
  2. 交互页：铁屑磁感线虚拟实验——点"撒铁屑"，铁屑沿磁感线排布；再点"拿走磁铁"，铁屑散了。"**磁感线是铁屑'画'出来的地图，不是天上本来有的线。**地图是人画的，地形是真的。"
  3. 讲解页：模型说明书（固定版式，全书通用：光线 p02.1.1、磁感线 p10.1.1、电场线 p15.1.3 都用同一版式）——"模型三问：它帮我们看到了什么？它忽略了什么？什么时候不能用它？"
- **交互**：P8 field-viz（bfield 模式）+ tap-highlight 点选。
- **点拨话术**："看不见的东西，物理学家给它画地图。**记住：地图不是地形，但没有地图你寸步难行。**用模型的时候，永远记得它是个模型。"

### 跃升 7：电与磁的对称与不对称（电动机 vs 发电机）

- **卡点**：全章最大易混点（curriculum p10 原话）。学生把"电生磁"和"磁生电"背成对称的两句话，考题一换就错：电动机原理答成电磁感应。**对称的是"电与磁能互相转化"，不对称的是"条件和方向"**。
- **脚手架**（p10.1.3 → p10.1.4，3 页）：
  1. 交互页（P8 改装/新演示）：通电线圈在磁场里转起来（电动机模型，换向器慢动作）→ 把手摇发电机摇起来，灯泡亮了。"**一个是'通电就转'，一个是'转了就来电'——动作反了，能量反了。**"
  2. 对比页（side-compare 复用）：左右两栏对照表——电动机：电→机械能，"通电导体在磁场中受力"；发电机：机械→电，"闭合电路 + 磁通量变化"。中间一列红字："**名字像双胞胎，原理是反的。**"
  3. 讲解页：能量守恒收束——"电动机没'创造'转、发电机没'创造'电，都是能量在换衣服。**分不清的时候就问：能量从哪来、到哪去？**"
- **交互**：P8 field-viz（磁场模式）+ 复用 side-compare 对照表 + slow-replay（换向器慢动作）。
- **点拨话术**："电和磁像一对双胞胎：长得像，但能量流向是反的。**记住'能量从哪来'，就永远不会把电动机和发电机搞混。**"（"左撇子/右撇子"梗已删，等 p16.2 学完左手定则后再回填。）

### 跃升 8：波——"振动在传播，质点不迁移"（+ y–x vs x–t 图像）

- **卡点**：两个坑连在一起。坑一：学生以为波传过去的时候，介质也跟着跑了（"声波把空气从喇叭吹到我耳朵"）。坑二：y–x 图像和 x–t 图像长得一模一样，学生当成同一个东西（curriculum p17.1.3：全章第一纠偏点）。
- **脚手架**（p17.1.3 机械波，3 页）：
  1. 交互页：绳波传播虚拟实验——绳子上有 5 个彩色小球标记。波传过去，小球只在原地上下动。"**波走了，小球没走——传过去的是'振动这个动作'，不是小球。**"配"跟着一个小球看"按钮（高亮单个质点）。
  2. 交互页：y–x vs x–t 双图联动——上图是"空间照片"（y–x：同一时刻所有质点的位置），下图是"时间录像"（x–t：一个质点随时间的位置）。拖时间滑块：上图波形整体平移，下图描出正弦曲线。"**一张是照片，一张是录像——长得像，拍的不是一回事。**"
  3. 讲解页：因果链卡片——"v=λf 里，v 由**介质**定，f 由**波源**定，λ 是被决定的。**因果链不能反：不是'λ 变了所以 v 变了'。**"
- **交互**：P5 wave-tune（绳波模式）+ 复用 linked-dashboard（双图联动）。
- **点拨话术**："记住波的两句话：**振动在传播，质点不迁移；照片是空间，录像是时间。**"

### 跃升 9：微观 → 宏观的统计思想萌芽（温度、压强、布朗运动）

- **卡点**：从"一个分子"到"一杯水"，中间隔着 10²³ 个数量级。学生问"温度到底是什么"，答案"分子热运动剧烈程度"像一句空话——因为"剧烈程度"看不见。
- **脚手架**（p03.2.1 分子动理论 → p03.2.2 内能，3 页）：
  1. 交互页（P9 thermo-sim）：加热滑块从 20℃ 推到 100℃，120 个粒子越跑越快，读数徽章"平均速率"上升。"**温度就是'大家平均跑得多快'——一个分子没有温度，一群分子才有。**"
  2. 交互页：布朗运动虚拟观察——花粉颗粒被看不见的分子撞得乱走。"你看不到分子，但你能看到'被分子撞'的花粉——**看不见的东西，可以通过它'撞'的东西来证明。**"（与跃升 6 的"地图"思想呼应）
  3. 讲解页：统计思想第一课——"物理有时候不关心'每一个'，只关心'平均'。温度、压强都是'平均'出来的量。**从'一个'到'平均'，是物理思维的一次长大。**"（点到为止，不展开统计力学，呼应 curriculum 附录 C 留白）
- **交互**：P9 thermo-sim + 布朗运动观察（P9 改装：大颗粒 + 背景分子）。
- **点拨话术**："一个分子没有温度，就像一个人没有'平均分'。**有些物理量，是'一群'的量，不是'一个'的量。**"

### 跃升 10：图像即语言（v–t 图像三读法 + "图像≠轨迹"）

- **卡点**：v–t 图像是高中物理的"母语"，但学生把它当成"小球飞行的轨迹"（curriculum p11.2.2：全书级易错）。斜率、面积、截距三个读法一次全给会噎住。
- **脚手架**（p11.2.2 v–t 图像，3 页）：
  1. 交互页：v–t 图像交互——学生拖出一条斜线，旁边小车同步运动。"**这条线不是小车的'飞行路线'，是小车速度的'日记'**——横轴是时间，不是路。"配"轨迹 vs 图像"对比小窗：小车在直线上跑（轨迹是直线），v–t 图是斜线（图像是斜线）。
  2. 交互页：三读法分步点亮——点"读斜率"：斜率数值 = 加速度徽章；点"读面积"：阴影面积 = 位移徽章（配"分割求和"慢动作：面积被切成细条，一条条"码"成位移）；点"读截距"：t=0 的速度 = 初速度。"**斜率是加速度，面积是位移，截距是初速度——图像的三把钥匙。**"
  3. 讲解页：图像词典页（固定版式：s–t、v–t、a–t、F–l、I–U、p–V 全书图像统一用"三读法"版式）——"以后看到任何物理图像，先问三句话：横轴是什么？纵轴是什么？斜率/面积/截距各代表什么？"
- **交互**：P2 motion-sim（v–t 模式：图像 + 小车联动）+ 复用 plot-points 面积分割。
- **点拨话术**："**图像不是轨迹，是日记。**横轴写的是时间，纵轴写的是速度——它记的是'每一刻有多快'，不是'飞到了哪'。"

### 跃升 11：浮力双线程 + 楞次定律"增反减同"（初中第一难 & 全书最绕口诀）

- **卡点**：浮力是初中物理第一难——"受力分析"和"阿基米德原理"两条线程同时转：算浮力时忘了画受力图，画受力图时又把 F浮=G排 写成 F浮=G。楞次定律"增反减同"四字是全书最绕的口诀——"增"什么、"反"什么，背得滚瓜烂熟，一做题就反。
- **脚手架**（p06.2 浮力 + p16.3.1 楞次定律，4 页）：
  1. 交互页：浮力线程一（受力分析）——弹簧测力计提石块入水，先画三个箭头（G 向下、拉力 F′ 向上、浮力 F浮 向上），再列式 F浮=G−F′。"**先画箭头，再算数。**"
  2. 交互页：浮力线程二（阿基米德）——溢水杯实验，F浮=G排=ρ液gV排。"浮力只跟 ρ液、V排 有关，跟物体密度无关。"双线程合流：同一道漂浮题，左手受力分析（F浮=G）、右手阿基米德（F浮=ρ液gV排），两只手对答案。
  3. 交互页：楞次定律"增反减同"四步拆解——磁铁插入/拔出线圈：① 磁通量是"增"还是"减"？② 感应电流的磁场要"反"（增）还是"同"（减）？③ 用安培定则定电流方向。"口诀不背，步骤走三遍就会了。"
  4. 讲解页：浮力双线程检查清单（"受力图画全了吗？F浮 用的是哪个式子？"）+ "增反减同"判定流程图。
- **交互**：P1 force-drag（受力分析：G/F′/F浮 三箭头）+ 溢水杯虚拟实验 + P8 field-viz 改装（磁铁插入线圈，磁通量"增/减"示意）。
- **点拨话术**："**算浮力永远两只手：左手画受力图，右手想阿基米德——两只手对不上，就有东西漏了。**楞次定律别背咒语，走三步：磁通量增还是减？感应磁场反还是同？电流往哪流？"

## 四、讲解页规范（沿用几何五段式，物理微调）

### 4.1 为什么必须有讲解页

几何的教训同样适用于物理：光有交互，学生"玩得很开心，但说不清学到了什么"。物理比几何更需要讲解页——因为物理的结论是**定律**（带条件的），学生必须能用嘴说出来"什么时候成立、什么时候不成立"。

### 4.2 讲解页结构（六段式，一页一屏，文字上限 300 字）

```
1. 静态关键帧图（交互页最精彩的那一帧定格）+ 一句话：
   "还记得吗？你把××调到××时，××一直没变。"
2. ≤ 80 字的定义，人话先行，术语第二句：
   "磁场就是磁铁周围'**能让小磁针转动**'的那片空间。物理上叫：磁体周围存在的一种特殊物质。"
3. ★ 条件卡片（物理专属，固定版式）：
   ┌─────────────────────────┐
   │ 公式身份证：××定律       │
   │ 公式：……（MathML）      │
   │ 成立条件：……            │
   │ 反例（什么时候失效）：……│
   │ 量纲检查：…… ✓          │
   └─────────────────────────┘
4. 生活例 → 实验例 → 反例，各一句话 + 小图（反例强制）：
   - 生活例："……"
   - 实验例："第 X 页你亲手做的那个实验"
   - 反例："长得很像但不是××的东西"
5. 误区警示 1–2 个，格式固定："⚠️ 别搞混：××不是××，因为××"
6. 口诀 ≤ 20 字，能背下来的那种："全等要重合，相似只同形"（几何版）；物理版如"矢量先看箭头，公式先看条件"
```

### 4.3 讲解页写作四不许（物理版）

1. 不许"定义：…"式教科书腔开场——先人话，后术语（术语加括号标注，如"能让小磁针转动的那片空间（磁场）"）。
2. 不许只举一个例子——**三个是下限**（生活/实验/反例），不厌其烦是铁律。
3. 不许出现"显然""易知""同理可得"——要么写出来，要么写"这一步我们第 X 页玩过"。
4. 不许公式没有条件卡片就上场——**无身份证的公式不许出现在讲解页**。

### 4.4 术语"认旧友"标注规范

新术语第一次出现时，格式：**术语**（就是你第 X 页 + 动作/现象）。例如：
- **位移**（就是你第 1 页拖小人走的那条"从起点指到终点"的箭头）
- **电阻**（就是第 8 页电路里让灯泡变暗的那个"小脾气"）
- **磁感线**（就是第 3 页你撒铁屑"画"出来的那张地图）

## 五、习题页规范（每章末，答案折叠，必有一道估算题）

> 物理必须做题——"会玩"不等于"会算"，单位换算、公式选用、条件判断必须通过做题固化。

### 5.1 梯度结构（固定 5 档，每章 5–8 道）

| 档 | 数量 | 题型 | 例子（欧姆定律章） |
|---|---|---|---|
| ① 认现象 | 1–2 道 | 看图/看描述判断：这是什么现象？用哪条定律？ | "灯泡越调越暗，是哪个量在变？"（认出"电阻变了"） |
| ② 直用 | 1–2 道 | 公式直接套用，一步出答案（**必须写单位**） | "U=6V，R=2Ω，求 I"（答案无单位算错） |
| ③ 条件判断 | 1–2 道 | 给一个似是而非的情境，判断公式能不能用 | "小灯泡 U=3V 时 I=0.3A，U=6V 时能用 I=U/R 算吗？为什么？"（考条件意识） |
| ④ 小综合 | 1 道 | 2–3 步：受力分析/电路分析 → 选公式 → 求解 | 串联电路动态分析（滑片移动，电流表电压表示数变化） |
| ⑤ 估算 | 1 道（**每章强制**） | 费米问题：数量级正确即满分 | "估算你爬三层楼的功率"（体重×楼高÷时间，锚点 ~10² W） |

### 5.2 答案折叠规范

1. **三级折叠**：思路提示 →→ 关键步骤 →→ 完整答案。学生先看提示，实在不会再看步骤，最后对答案。
2. 思路提示 ≤ 30 字，只指方向不给过程："先问：公式的条件满足吗？"
3. 完整答案必须带**单位链**（每一步的单位都写出来），末尾附"条件检查：××条件满足 ✓"。
4. 每道题尾标注"用到的定律：××（第 X 页）"，形成回链。

### 5.3 手机做题与估算题特殊规范

- 选择/判断/读数题直接在页内点选；计算题、作图题不要求在线作答——给"**自查清单**"（"我的每一步都有单位吗？公式的条件检查了吗？"），学生对照着在纸上写。
- **不记分、不排名**，答错只给提示不给红叉。
- 估算题评分口径：数量级对即满分（如答 80W 和 200W 都算对，答 5W 或 5000W 算错）；**估算题必须写出"依据链"**（"我体重约 50kg→500N，三层楼约 9m，用时约 15s，所以 P≈300W"）——估算不是瞎猜，是有依据的数量级推理（curriculum p00.1.4 误区纠偏）。

| 电势 | 电荷在电场中"爬坡"类比重力势能（p15.1.4） | 等高线地图（等势面） | 零电势≠零场强；U=Ed 限匀强电场 |
| 电容 | 电容器充放电：Q–U 图像（p15.1.5） | 照相机闪光灯；触摸屏 | 电容是器件属性（比值陷阱第四次）；存的是电场能量 |
| 带电粒子运动 | 示波管：偏转电压滑块亮斑联动（p15.1.6） | 老式电视机显像管 | 类平抛受力恒定才成立（有条件） |
| 电流微观 | 电子漂移 vs 电场传播对比（p16.1.1） | 灯"瞬间"亮 | 漂移 mm/s，电场近光速（数量级重点） |
| 闭合电路 | 测 E、r：U–I 图像纵截距=E（p16.1.2） | 手机电池越用越"虚" | 断路时 U=E；E、r 理想化认为不变 |
| 安培力 | B/I/F 三维方向判定闯关（p16.2.1） | 电动机线圈受力 | F=BIl 限 B⊥I；左手定则 |
| 洛伦兹力 | 电子束圆周（洛伦兹演示仪虚拟）（p16.2.2） | 极光；质谱仪 | 永不做功；正负电荷受力反向 |
| 粒子在磁场中 | 粒子轨迹：v/B/q/m 可调（p16.2.3） | 回旋加速器 | T 与 v 无关；垂直射入才做圆周 |
| 楞次定律 | 磁铁插入/拔出：N极S极/快慢/匝数（p16.3.1） | 涡流缓降 | 需磁通量"变化"；"阻碍"≠"阻止" |
| 法拉第定律 | ΔΦ/Δt 滑块：感应电动势联动（p16.3.2） | 发电机转速越快灯越亮 | 看变化率不是变化量；E=Blv 限两两垂直 |
| 简谐运动 | 弹簧振子 x–t 图像实时绘制（p17.1.1） | 秋千；钟摆 | 图像是 x–t 不是轨迹；F=−kx 负号是方向 |
| 单摆 | 等时性：摆长/摆球/角度可调（p17.1.2） | 摆钟；傅科摆（拓展：证明地球自转） | 周期与质量无关；限小角度<5° |
| 机械波 | 绳波：质点振动 vs 波形推进（p17.1.3） | 水波；地震波 | 质点不迁移；y–x 是照片、x–t 是录像 |
| 干涉衍射 | 水波干涉：同频/异频对比（p17.1.4） | 噪声耳机（反相抵消） | 加强指振幅大；一切波都能衍射 |
| 全反射 | 临界角：入射角滑块，折射光消失点（p17.2.1） | 光导纤维；海市蜃楼 | 两条件缺一不可；sinC=1/n |
| 光的干涉 | 双缝干涉：λ/l/d 可调条纹联动（p17.2.2） | 肥皂泡彩色；相机镜头镀膜 | Δx=lλ/d 三个量；波粒二象性 |
| 交变电流 | 线圈转动发电：e–t 图像即正弦（p17.2.3） | 家庭用电 220V/50Hz | 有效值是方均根（限正弦式）；Em∝ω |
| 气体定律 | p–V / V–T 图像虚拟实验（p17.3.1） | 轮胎打气发热；高压锅 | 理想气体是模型；ΔU 符号法则规范 |
| 原子核 | 光电效应：频率/强度可调（p17.3.2） | 太阳能电池；核电站 | 看频率不是强度；谈核不色变（剂量决定危害） |

### p00.1 走进物理（p00.1.1–1.4）

- **怎么讲**：全章是"招生广告"——让学生觉得物理好玩、敢动手。策略：**现象拼图 + 亲手量一次 + 估一次**。p00.1.2 的探究七要素不要背，要走完一遍（摆的等时性）。
- **主生活例子**：① 彩虹、闪电、磁悬浮拖进"力热声光电"五个筐；② 用自己的手量课桌（一拃≈？cm），再用尺子验证——"身体是第一把尺"；③ 费米问题："我们学校有多少学生？"（分步估：每班×班级数）。
- **误区纠正**："物理=背公式做题"→"物理是先玩现象、再问为什么。公式是最后才出场的。"
- **自学路径**：先玩 p00.1.1 现象拼图 → p00.1.2 走完摆的等时性全流程（改三个量各试一次）→ p00.1.3 亲手读一次刻度尺 → p00.1.4 做一道估算题。

### p01.1 声音的产生、传播与特性（p01.1.1–1.5）

- **怎么讲**：声音是全书第一个"看不见"的对象，策略：**放大观察 + 波形调参台**。p01.1.3 是核心课——音调/响度/音色三者的区分全靠"耳朵+眼睛"双通道。
- **主生活例子**：① 音叉溅水花（"看不见振动？放大给你看"）；② 女高音 vs 男低音 vs 悄悄话（音调≠响度）；③ 倒车雷达"嘀嘀"变密（超声波测距的生活版）。
- **误区纠正**："高音就是大声"→"中文里'高'和'大'是两回事：高音是振动快（频率），大声是振动猛（振幅）。女高音可以很小声，男低音可以很响。"
- **自学路径**：先玩 p01.1.1 音叉溅水花 → p01.1.2 真空罩闹钟（注意"理想化"小字）→ p01.1.3 波形调参台（P5：只调频率听音调变、只调振幅听响度变）→ 再看讲解页三者对照表。

### p02.1 光的直线传播与反射（p02.1.1–1.3）

- **怎么讲**：光是全书第一个"模型"（光线）登场，策略：**先玩影子，再谈模型**。p02.1.3 平面镜成像是几何 g10 轴对称的"物理还魂"——直接调用几何记忆。
- **主生活例子**：① 小孔成像（孔调大调小，像怎么变）；② 镜子里的你走远走近（像不变小，是视角变小）；③ 黑板"不反光"？（漫反射：处处都在反射，只是没进你眼睛的方向）。
- **误区纠正**："光线是真实存在的细线"→"光线是物理学家画的'地图'（模型），光走的是直线这个'地形'是真的"；"反射角是与镜面的夹角"→"量角看的是法线，不是镜面——法线是那条'假想的垂线'。"
- **自学路径**：先玩 p02.1.1 小孔成像（P4 optics-ray 改装）→ p02.1.2 入射角滑块（反射角联动）→ p02.1.3 玻璃板蜡烛实验 → 讲解页"成像即轴对称"（回链几何 g10）。

### p02.2 光的折射与透镜（p02.2.1–2.4）

- **怎么讲**：本单元是"条件意识"的第一次实战（折射角<入射角有条件），策略：**激光演示 + 三条特殊光线跟画**。p02.2.3 凸透镜成像规律是探究课标杆——u 滑块是全书最值得多玩 10 分钟的交互。
- **主生活例子**：① 筷子在水里"折断"（折射）；② 照相机 vs 投影仪 vs 放大镜（u 的三种位置，三种人生）；③ 近视眼镜（凹）vs 老花镜（凸）摸厚度。
- **误区纠正**："折射角永远小于入射角"→"只在光从'稀'进'密'时成立。反过来（密→稀）折射角更大，大到一定程度就'全反射'了——这句话是 p17.2.1 的伏笔"；"u<f 时光屏上有像"→"虚像承接不到，只能透过透镜看——虚像用虚线画，因为光线没真交于那。"
- **自学路径**：先玩 p02.2.1 激光斜射入水（⚠ 安全徽章：现实中严禁直射眼睛）→ p02.2.2 三条特殊光线（P4，先只开两条）→ p02.2.3 u 滑块从远拖到近（看像由小变大、倒变正）→ p02.2.4 眼睛模型。

### p03.1 物态变化（p03.1.1–1.4）

- **怎么讲**：全是生活现象，策略：**温度–时间图像是主线**。p03.1.2 熔化曲线的"平台"是初中第一次"图像会说话"——平台=晶体判据。
- **主生活例子**：① 冰块化水时温度计不动（平台）；② 水烧开后"白气"（小水滴，不是水蒸气）；③ 冬天窗花的霜（凝华）、樟脑丸变小（升华）。
- **误区纠正**："熔化时温度一直上升"→"晶体熔化吸热但温度不变——图像上的'平台'就是证据。没平台的是非晶体（如石蜡）"；"'白气'是水蒸气"→"水蒸气看不见，你看到的'白气'是小水滴——看得见的都不是水蒸气本人。"
- **自学路径**：先玩 p03.1.2 海波 vs 石蜡熔化曲线（P9 thermo-sim + plot-points 画温度–时间图）→ p03.1.3 水的沸腾（看气泡、看温度平台）→ p03.1.4 干冰升华（⚠ 防冻伤提示）。

### p03.2 分子动理论与内能（p03.2.1–2.3）

- **怎么讲**：微观世界第一次登场，策略见**跃升 9**（统计思想萌芽）。p03.2.2 是"热量是过程量"的关键课——"热量"这个词本身就是个坑。
- **主生活例子**：① 加热滑块：粒子越跑越快（温度=平均剧烈程度）；② 沿海城市昼夜温差小（水的比热容大，"热得慢、冷得也慢"）；③ 布朗运动：花粉被看不见的分子撞得乱走。
- **误区纠正**："温度越高的物体内能越大"→"内能还看质量、状态——一杯开水 vs 一池温水，谁内能大？"；"热量是一种物质"→"热量是'过程量'：只能说'吸收了多少热量'，不能说'物体有多少热量'——就像不能说'我有多少跑步'。"
- **自学路径**：先玩 p03.2.1 布朗运动观察 → P9 thermo-sim 从 20℃ 加热到 100℃（看粒子加速、徽章液→气）→ p03.2.2 水 vs 沙子吸热对比 → p03.2.3 四冲程动画（配"能量转化"旁白）。

### p04.1 质量与密度（p04.1.1–1.5）

- **怎么讲**：p04.1.2 密度是**跃升 4（比值定义陷阱）的预防针**，全书第一次讲"比值定义法"。策略：**m–V 图像斜率**——让"斜率"这个词第一次有了物理血肉。
- **主生活例子**：① 天平称量（游码读数亲手试）；② 冰浮在水面（密度比水小）；③ 空心球判断（三解法：比密度/比质量/比体积）。
- **误区纠正**："密度与质量成正比、与体积成反比"→"ρ=m/V 是'量'密度的办法。m 变 V 跟着变，ρ（斜率）动都不动——密度是物质的脾气"；"质量=重量"→"质量带上月球不变，重量变了——质量是'多少物质'，重量是'地球拉你多用力'。"
- **自学路径**：先玩 p04.1.1 天平虚拟实验（调平+游码读数）→ p04.1.2 m–V 图像（铝/铁/水三条线，斜率徽章）→ 跃升 4 的三页脚手架 → p04.1.3 量筒读数（视线平视）→ p04.1.4 空心球判断。

### p05.1 力（p05.1.1–1.3）

- **怎么讲**：力的概念是全书地基，策略：**磁铁隔空吸铁钉开场**（"不接触也有力"先声夺人）→ 三要素 → 力的示意图（箭头先行，跃升 1 的预演）。p05.1.2 胡克定律是"条件意识"的第二次亮相（弹性限度内）。
- **主生活例子**：① 磁铁隔空吸铁钉；② 拔河（力的三要素：大小方向作用点，缺一个说不清）；③ 弹簧测力计调零（"先调零再测量"是实验素养）。
- **误区纠正**："力必须接触才能产生"→"磁铁隔空吸铁钉——不接触也有力。重力更是天天隔空拉着你"；"力是物体'拥有'的属性"→"力是'物体对物体的作用'——落单的物体没有力，力一定是成对出现的（伏笔：牛顿第三定律）。"
- **自学路径**：先玩 p05.1.1 磁铁隔空实验 → 力的示意图绘制（箭头三要素：起点/方向/长度）→ p05.1.2 F–x 图像（拉过头看不成正比）→ p05.1.3 重垂线+G=mg。

### p05.2 运动和力（p05.2.1–2.5）

- **怎么讲**：**全书第一重点单元**。"力是改变运动状态的原因"是 p05.2.1 的灵魂（跃升 2）。p05.2.3 二力平衡 vs p12.2.3 作用反作用是全书最长寿的易混对——这里第一次区分，高中再回填。
- **主生活例子**：① 斜面小车：毛巾→棉布→木板→"想象完全光滑"；② 急刹车往前冲、拍灰尘（惯性）；③ 走路（摩擦力是动力——"没有摩擦力你一步都走不了"）。
- **误区纠正**："力是维持运动的原因"→见跃升 2 点拨话术；"平衡力=作用力与反作用力"→"平衡力作用在**同一个**物体上（一本书静止：重力+支持力）；作用反作用在**两个**物体上（马拉车：马拉车的力在车上，车拉马的力在马上）——**数一数有几个物体**"；"摩擦力总是阻力"→"走路时摩擦力推你往前——摩擦力是'相对运动趋势'的阻力，不是'运动'的阻力。"
- **自学路径**：先玩跃升 2 的三页脚手架（p05.2.1）→ p05.2.2 惯性实例分析（急刹车/拍灰尘/跳远）→ p05.2.3 小车二力平衡探究（四条件逐个试：缺一个就不平衡）→ p05.2.4 摩擦力探究（P1 + 压力/粗糙度滑块）。

### p06.1 压强（p06.1.1–1.4）

- **怎么讲**：压强的难在"两个量决定一个量"（p=F/S），策略：**控制变量**——固定 F 变 S、固定 S 变 F，海绵凹陷程度说话。p06.1.2 液体压强是"h 是深度不是高度"的经典坑。
- **主生活例子**：① 菜刀磨快（S 小压强大）、滑雪板（S 大压强小）；② 大坝下宽上窄（液体压强随深度增）；③ 吸管喝水（大气压"压"你喝，不是"吸"）。
- **误区纠正**："压力就是重力"→"只有水平面静止才等大。压力的方向是**垂直于接触面**——斜面上的箱子，压力斜着指"；"液体压强与容器形状有关"→"只与 ρ、h 有关。h 是**深度**（从液面往下量），不是高度——帕斯卡裂桶：一杯水能压裂木桶"；"大气压'吸住'水"→"'吸'不是一种力——是大气压在'压'。"
- **自学路径**：先玩 p06.1.1 海绵凹陷（F/S 双滑块）→ p06.1.2 压强计（深度/方向/密度三探头）→ p06.1.3 覆杯实验+托里拆利动画 → p06.1.4 吹纸实验（流速大压强小）。

### p06.2 浮力（p06.2.1–2.4）

- **怎么讲**：浮力的难在"受力分析 + 阿基米德原理"双线程，策略：**称重法先行**（F浮=G−F′，看得见）→ 溢水杯（G排，看得见）→ 公式。p06.2.3 浮沉条件用潜水艇模型一以贯之。
- **主生活例子**：① 弹簧测力计提石块入水（示数变小=浮力）；② 王冠鉴别（排开水的体积鉴别王冠是否掺假）；③ 潜水艇注水下潜、排水上浮。
- **误区纠正**："漂浮的物体不受浮力"→"漂浮时 F浮=G——恰恰受浮力，而且浮力=重力"；"浮力与物体密度有关"→"只与 ρ液、V排有关——铁块扔水里沉底，压成船就浮了，铁的密度变了吗？"；"潜水艇靠改变浮力上浮"→"潜水艇体积不变，浮力不变——它是**注水变重**下潜、**排水变轻**上浮，改变的是自身重力。"
- **自学路径**：先玩 p06.2.1 称重法（石块入水示数差）→ p06.2.2 溢水杯（物块+排开水称重，F浮=G排）→ p06.2.3 潜水艇模型（注水/排水滑块）。

### p07.1 功与功率（p07.1.1–1.2）

- **怎么讲**："劳而无功"三情形是本单元的灵魂——策略：**先辨析"没做功"的三种死法，再讲"做功"的两个条件**。p07.1.2 功率配爬楼估算（全书第一个"人体功率"锚点 ~10² W）。

### p14.2 动量（p14.2.1–2.4）

- **主生活例子**：① 台球母球定住（等质量弹性碰撞交换速度）；② 安全气囊/海绵垫（延长 t 减小 F：F–t 图像面积=冲量）；③ 火箭发射（动量守恒：向后喷气、向前飞）。
- **误区纠正**："动量定理中的 F 是某个力"→"是**合外力**的冲量！——I=Ft 里的 F 是合外力"；"系统动量守恒则机械能一定守恒"→"**独立**！完全非弹性碰撞：动量守恒、机械能损失最大——两个守恒量，互不蕴含"；"'动量大'即'动能大'"→"p=√(2mEk)——同样动量，质量小的动能大（子弹 vs 卡车）。"
- **自学路径**：先玩 P7 collision-lab（等质量 e=1 对心撞：交换速度）→ 把 m₁ 调大再撞（动量传递更彻底）→ p14.2.1 缓冲实例（F–t 图像面积=冲量）→ p14.2.3 碰撞参数调节（弹性系数滑块：弹性/非弹性/完全非弹性）。

### p15.1 静电场（p15.1.1–1.7）

- **怎么讲**：本章核心思想是"**场是物质**"——电场强度与试探电荷无关（跃升 4 第三次）。策略：**P8 field-viz 电场模式**——亲手"画"电场线。p15.1.2 库仑定律与 p13.2.3 万有引力"平方反比双胞胎"对照。
- **主生活例子**：① 感应起电（导体 vs 绝缘体）；② 避雷针（尖端放电：电场线密集处）；③ 示波管（偏转电压滑块→亮斑联动：电场中的"平抛"）。
- **误区纠正**："E 与 F 成正比、与 q 成反比"→"**场是物质**，与试探电荷无关！——E=F/q 是'量'场强的办法（跃升 4 第三次：比值陷阱）"；"电势为零处场强为零"→"**无必然联系**！零电势是人为规定的'海平面'，场强是'坡度'——海平面处也可以有陡坡"；"U=Ed 无条件用"→"限**匀强电场**，d 是沿场强方向的距离——斜着量不行。"
- **自学路径**：先玩 P8 field-viz（放一个正电荷→场线放射；再加负电荷→场线弯向负极）→ p15.1.2 库仑扭秤思想实验 → p15.1.4 电荷"爬坡"类比重力势能 → p15.1.6 示波管（类平抛，y=qUl²/2mv₀²d）。

### p16.1 恒定电流（p16.1.1–1.2）

- **怎么讲**：p16.1.1 是跃升 5 的回填兑现（电子漂移 vs 电场传播），策略：**数量级震撼**——mm/s vs 近光速，两个数量级摆在一起。p16.1.2 闭合电路欧姆定律用 U–I 图像（斜率=−r、截距=E）讲透。
- **主生活例子**：① 灯"瞬间"亮（电场近光速建立，不是电子跑得快）；② 手机电池越用越"虚"（内阻 r：U=E−Ir）；③ 测 E、r 实验（U–I 图像纵截距=E）。
- **误区纠正**："开关闭合灯瞬间亮是因为电子跑得快"→"电子漂移仅 mm/s！灯亮是因为**电场以近光速建立**，全电路电子同时起步——数量级：10⁻³ vs 10⁸"；"外电路断开时路端电压为零"→"**= E**！断路时 U=E——这正是测电动势的原理（电压表直接接电源）。"
- **自学路径**：先玩 p16.1.1 漂移 vs 传播对比动画（慢放标注"示意，非真实比例"）→ p16.1.2 测 E、r 虚拟实验（U–I 图像：截距=E、斜率=−r）。

### p16.2 磁场（p16.2.1–2.3）

- **怎么讲**：左手定则是"手势口诀"课，策略：**B/I/F 三维判定闯关**（p16.2.1）——"左手定则"必须动手比划，不能只看图。p16.2.2 洛伦兹力"永不做功"是重点中的重点。
- **主生活例子**：① 电动机线圈受力（安培力应用）；② 极光（洛伦兹力+地磁场）；③ 质谱仪/回旋加速器（T 与 v 无关的原理应用）。
- **误区纠正**："F=BIl 无条件用"→"**限 B⊥I**！一般式 F=BIl sinθ——斜着就不行"；"洛伦兹力做功"→"**永不做功**！f⊥v，只改变方向不改变速率——电子束在磁场里转圈，越转越快？不，速率不变"；"带电粒子周期与速度有关"→"**无关**！T=2πm/qB——这就是回旋加速器能'共振加速'的原理。"
- **自学路径**：先玩 p16.2.1 安培力方向判定闯关（左手比划：B/I/F 三维）→ p16.2.2 洛伦兹演示仪虚拟实验（电子束圆周）→ p16.2.3 粒子轨迹（v/B/q/m 可调，看 r、T 联动）。

### p16.3 电磁感应（p16.3.1–3.3）

- **怎么讲**：楞次定律"增反减同"是全书最绕的口诀，策略：**磁铁插入/拔出虚拟实验**（N极S极/快慢/匝数三变量）→ "阻碍变化"四字嚼碎。p16.3.3 涡流配**安全警示**（高频感应加热）。
- **主生活例子**：① 手摇发电手电筒（摇得越快越亮：ΔΦ/Δt 大）；② 磁铁穿过铜管缓降（涡流阻尼）；③ 变压器铁芯用硅钢片（涡流有害→想办法减小）。
- **误区纠正**："磁通量大就有感应电流"→"需**变化**！——磁铁插在线圈里不动，再强也没电流（p10.1.4 回填严格化）"；"'阻碍'即'阻止'"→"'阻碍变化'不是'阻止变化'——磁铁还是插进去了，只是线圈产生了阻碍磁通量变化的感应电流"；"ΔΦ 大则 E 大"→"看**变化率**！——E=nΔΦ/Δt，变得快才大（导数思想，呼应点 25）。"
- **自学路径**：先玩 p16.3.1 磁铁插入/拔出（N极进 vs S极进 vs 快 vs 慢）→ 楞次定律"增反减同"判定练习 → p16.3.2 ΔΦ/Δt 滑块（感应电动势联动）→ p16.3.3 涡流演示（⚠ 高频感应加热警示）。

### p17.1 机械振动与机械波（p17.1.1–1.4）

- **怎么讲**：策略见**跃升 8**（波）+ **P10 spring-shm**（振动）。p17.1.1 的 x–t 图像是 p11.2.2 的"再现"——"图像不是轨迹"第二次。p17.1.2 单摆是"条件意识"的压轴（小角度<5°）。
- **主生活例子**：① 弹簧振子 x–t 图像实时绘制（振动"画"出正弦曲线）；② 摆钟（等时性：摆长定周期）；③ 噪声耳机（反相波抵消：干涉的应用）。
- **误区纠正**："振动图像是运动轨迹"→"是 **x–t 图像**！——振子在直线上来回跑，图像是正弦曲线（p11.2.2 再现）"；"单摆周期与摆球质量有关"→"**无关**！只与摆长和 g 有关——T=2π√(l/g)"；"干涉加强点始终位移最大"→"位移随时间变！加强指**振幅**大——加强点振动得'猛'，不是'一直顶在最高'。"
- **自学路径**：先玩 P10 spring-shm（k 调大→T 变小；m 调大→T 变大）→ p17.1.2 单摆等时性（摆长/摆球/角度可调）→ 跃升 8 的三页脚手架（p17.1.3）→ p17.1.4 水波干涉（同频/异频对比，P5 waveB 叠加）。

### p17.2 光与交变电流（p17.2.1–2.3）

- **怎么讲**：p17.2.1 是 p02.2.1 的回填兑现（全反射两条件严格化）。p17.2.3 交变电流的 e–t 图像是代数 8.3.2 正弦函数的"物理化身"（呼应点 4）。
- **主生活例子**：① 光导纤维（全反射应用）；② 肥皂泡彩色（薄膜干涉）；③ 家庭用电 220V/50Hz（有效值：220V 是有效值，不是最大值）。
- **误区纠正**："全反射只要入射角大"→"**两条件缺一不可**：光密→光疏 + 入射角≥临界角——p02.2.1 的伏笔在这里兑现"；"有效值=平均值"→"**方均根**！按热效应定义——而且**限正弦式**（条件！）"；"干涉证明光是波'所以光不是粒子'"→"**波粒二象性**——不是非此即彼。干涉证明波动性，光电效应证明粒子性。"
- **自学路径**：先玩 p17.2.1 全反射临界角（入射角滑块→折射光消失点）→ p17.2.2 双缝干涉（λ/l/d 可调→条纹间距联动）→ p17.2.3 线圈转动发电（e–t 图像实时绘制即正弦曲线）。

### p17.3 热学深化与近代物理（p17.3.1–3.3）

- **怎么讲**：本章是"集锦章"，三个单元弱依赖。策略：**理想气体是模型**（p17.3.1）+ **光电效应看频率**（p17.3.2）+ **谈核不色变**（剂量决定危害）。近代物理部分定性为主，不展开数学（呼应 curriculum 附录 C 留白）。
- **主生活例子**：① 轮胎打气发热（做功改变内能）；② 太阳能电池（光电效应应用）；③ 天然辐射无处不在（香蕉、石头都有微量辐射——剂量决定危害）。
- **误区纠正**："理想气体是真实气体"→"**模型**！忽略分子体积与相互作用——'理想'两个字就是告诉你它是假想的"；"光越强打出电子越多"→"**看频率**！低于截止频率，再强的光也打不出电子——这是光电效应最反直觉的一点"；"质量'转化'为能量"→"质量与能量是同一实在的两面——E=mc² 不是'质量消失了'，是'质量这种形态的能量释放出来了'。"
- **自学路径**：先玩 p17.3.1 气体定律虚拟实验（p–V/V–T 图像）→ p17.3.2 光电效应（频率/强度可调：先调强度看没反应，再调频率看"嘭"地打出电子）→ 核辐射防护页（⚠ 安全话术：剂量决定危害，天然辐射无处不在）。

## 八、颜色编码约定（沿用几何全局 + 物理增补）

### 8.1 沿用几何全局约定

- **已知量**：蓝色（`--phy-known`）——质量 m、初速 v₀、电阻 R、已知温度等题给条件。
- **待求量**：朱红（`--phy-target`）——合力 F合、待求速度、待求电流等，加粗 + 文字标签双编码。
- **辅助线/轨迹**：灰虚线（`--phy-track`）——运动轨迹、法线、平衡位置线、作图辅助线。
- **当前步骤高亮**：黄闪（`--phy-highlight`），配深色字。

### 8.2 物理增补：力矢量三组色（与 interactions §0.2 一致，全书强制）

| 组 | 颜色 | 语义变量 | 固定分工（**全书统一，不许串**） |
|---|---|---|---|
| A 组 | 橙 | `--phy-force-a` | **重力 G**（恒用橙） |
| B 组 | 天蓝 | `--phy-force-b` | 弹力 / 拉力 T / 推力 / 支持力 N |
| C 组 | 蓝绿 | `--phy-force-c` | 摩擦力 f / 阻力 / 浮力 |
| 合力 | 朱红加粗 | `--phy-target` | 合力 F合 / 向心力 F向（效果力），配 `F合` 文字标签 |

**铁律**：
1. 分组固定：重力永远是橙，学生翻到哪一章都不用重新认。合力永远是朱红加粗 + `F合` 标签。
2. 矢量三编码：每个矢量 = 颜色 + 箭头形状 + 文字标签（G/N/T/f/F合）。**灰度截图下仍能凭"标签 + 箭头指向 + 箭长对比"读出受力图**（白队 W-P1）。
3. 正负电荷：正电荷朱红 + "+"、负电荷蓝 + "−"（`--phy-charge-pos/neg`）；电流方向蓝绿 + 箭头（`--phy-current`）；场线天蓝 + 箭头（`--phy-field`）。
4. 光路：主光线实线 + 箭头（方向不靠颜色，`--phy-ray`）；法线灰虚线；实像实线、虚像虚线（不可反，白队 W-P11）。
5. 波形：A 波橙实线、B 波天蓝虚线（叠加对比时）。
6. 动量条独立配色：P7 碰撞动量条改用独立中性色，不与重力橙（A 组）复用——动量不是力，不能穿力的"衣服"。

### 8.3 颜色之外的编码（双编码清单）

- 状态（通/断/短路、平衡/倾斜、固/液/气）：颜色 + **文字徽章**，绝不只靠颜色。
- 大小：箭头长度 + 数字读数（带单位）。
- 方向：箭头形状（灰度可辨）。
- 实/虚：实线 vs 虚线 + 文字（"实像"/"虚像"）。

> 与 curriculum 安全红线（附录 A4）对齐。**原则**：虚拟实验可以"试错"，但每一页都要让学生清楚"现实中哪一步绝不能试"。安全徽章常驻交互区顶部（⚠ + 一句话），不随交互消失。

### 9.1 分场景话术（一句话版，全书统一）

| 场景 | 涉及课 | 安全徽章话术 | 讲解页补充话术 |

| 触电急救 | p09.1.5 | "⚠ 虚拟实验只做场景辨析——现实中绝不模仿触电" | "有人触电：**先断电**，再用干燥木棍挑开电线，打 120。**绝不用手直接拉**——你也会变成导体。" |

### 9.2 安全教学三原则

1. **虚拟与现实分界线**：每个安全徽章必须包含"虚拟/现实"对比句式——"虚拟实验里××，现实中××"。不许只写"注意安全"这种空话。
2. **先说"怎么做才对"，再说"错了会怎样"**：安全话术以正确操作为第一句（"先断电再操作"），后果为第二句。只吓唬不给方法 = 不合格。
3. **理想化声明**：每个虚拟实验注明理想化之处（如 p01.1.2 真空罩"现实中仍有残余空气"、p05.2.1"完全光滑是想象"）——这是 curriculum 附录 A17 的要求，也是科学诚实。

## 十一、风险点（黄队自查）

1. **"人话"滑向"错误直觉"**：如"磁场就是磁铁周围'能让小磁针转动'的那片空间"可能被理解为"力"。→ 对策：每句人话配术语第二句 + 模型说明书；全部经物理专家队"翻译"确认（10.1 审查点 1）。
2. **条件卡片信息过载**：全书十几个条件，学生记不住。→ 对策：条件卡片每页只写**本公式**的条件；全书高频条件清单做成独立的"速查表"页，不挤在公式页。
3. **比值定义四连击的节奏**：p04→p08→p15 间隔太长，学生忘了预防针。→ 对策：后三次全部配"认旧友"回看页（"还记得密度那页吗？"），每次 1 页，不多。
4. **电学抽象大山**：p08–p09 连上 14 课电学，初学者容易在中途掉队。→ 对策：p08.1.2 电流方向单独一页"方向课"；每 3 课配一个"生活应用小结页"（手电筒→家庭电路→电费单）。
5. **高中部分难度陡增**：p11 矢量化、p14 双守恒、p16 左手定则三维，是三个陡坡。→ 对策：三个陡坡各配完整跃升脚手架（跃升 1/10、P7、闯关页），不许"一页讲完左手定则"。
6. **虚拟实验替代真实体验的边界**：弹簧振子、天平、温度计——虚拟读数再真，也替代不了手感。→ 对策：Y2 仪表读数练习器页尾统一加一句"有条件的话，找真实的××试一次"；不强制，只邀请。
7. **页数口径**：专家队按 127 课×约 2.68 页/课估算 340 页；黄队策略（跃升脚手架 10×3 页、公式身份证、回看页）可能推高部分课页数，生产中以白队 QA 为准微调。

## 十二、与物理专家队 curriculum 的差异说明（只提建议，不擅改）

> 以下为黄队基于教学法的调整**建议**，课序/课时的最终决定权在物理专家队。留待评审。

1. **p08.1.2 建议拆出一页"电流方向专课"**：curriculum 将"电流方向与电子移动方向相反"放在 p08.1.2 的常见误区里。黄队建议升为独立半页/一页——这是全书级易错（curriculum 原话"全书级易错"），值得"方向课"待遇：先玩电子流动画，再定"规定方向"，最后默写三遍。**建议，不擅改**。
2. **p11.2.2 建议页数从 3 页增至 4 页**：curriculum 预估 3 页。黄队跃升 10 需要 3 页脚手架（日记→三读法→图像词典），加上习题，本课建议 4 页。**建议，不擅改**。
3. **p12.2.1 与 p05.2.1 的衔接建议加"回填认旧友页"**：curriculum 附录 B 已列回填关系，黄队建议在 p12.2.1 开头固定 1 页"还记得 p05.2.1 吗"——初中理想实验 → 高中惯性系表述的"升级感"是教学亮点，值得一页仪式感。**建议，不擅改**。
4. **p17 三个单元调序建议**：curriculum 注明三个单元弱依赖、可按需调序。黄队建议默认顺序为 **振动波（p17.1）→ 光与交变电流（p17.2）→ 热与近代物理（p17.3）**（即 curriculum 现状），理由：p17.1.4 干涉是 p17.2.2 光的干涉的前置直觉，调序会断链。**建议，不擅改**。
5. **p04.1.2 建议页数从 3 页增至 4 页**：跃升 4（比值定义陷阱）的预防针需要 3 页完整脚手架（m–V 图像→说明书→判定三步法），curriculum 预估 3 页偏紧。**建议，不擅改**。
6. **估算锚点建议汇总成"全书数量级速查表"**：curriculum 审计清单第 5 条要求每章至少一处估算锚点。黄队建议在 p00.1.4 之后设一页"全书数量级速查表"（活页，随学随填），培养"物感"从第一天开始。**建议，不擅改**。
