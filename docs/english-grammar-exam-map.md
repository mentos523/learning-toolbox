# 英语语法中考/高考考点清单（冻结版）

> ## 冻结声明
>
> 本清单由**英语专家队**于 **2026-10-14** 书面冻结。
> 依据：`docs/english-design-review.md` 开工条件 D4（以人教版教材语法体系 + 近 5 年真题题型为准）与红队审计结论 S4（中考/高考口径一致性 ✅ 通过）。
> **后续生产与审计以此为据**：凡标注中考/高考考点的课，其考点表述与设错方式须与本清单一致，不许自创"考点"；**改动须走变更记录**（见文末"变更记录"节）。
>
> 口径说明：
> - 考点表述中的真题口径（used to 三兄弟、一词四形填空、改错"一处只改一词"、美式 should 省略、将来进行时标高考低频）为红队 S4 已核口径，直接沿用。
> - 阶段列：中考 = 初中主线（gr00–gr09、gr12）；高考 = 高中主线（gr10、gr13–gr18）；中考/高考 = 跨学段（gr11 构词法、gr19 语篇总复习）。
> - 考法列缩写：单选（单项选择）、完形（完形填空）、语篇填空（语法填空/选词填空，含一词四形）、改错（短文改错）、书面表达、阅读（阅读理解）。
> - 课号与 `docs/english-grammar-curriculum.md` 一一对应，共 125 课。
