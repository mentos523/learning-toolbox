## 化学审计清单（化学专家队抓错清单 v1.0）

本清单是化学专家队每课必查的红线，任一条违反即打回重写：

1. **化学方程式配平与质量守恒**：配平只能调系数，**绝不改下标**（改下标 = 改物质种类，全书第一大错）；方程式配平方可用于计算；质量守恒指"参加反应的各物质"质量总和，开放体系逸散气体/沉淀不计入天平读数不算违背。
2. **化学式与化合价**：元素符号书写规范（一大二小）；化学式中原子团要加括号（如 Ca(OH)₂）；单质中元素化合价为零、化合物中正负化合价代数和为零；用化合价推写化学式，不背"死式"。
3. **宏观—微观—符号三重表征一致**：同一内容的宏观现象、微观粒子图像、符号表达三者必须自洽；化学变化的判据是"分子种类改变"，物理变化分子种类不变；表述时宏观/微观不许混用（"水由氢、氧两种元素组成" vs "一个水分子由两个氢原子和一个氧原子构成"）。
4. **实验安全与操作规范**：点燃可燃性气体（H₂、CO、CH₄）前必须验纯；加热、取用药品、闻气味（扇闻）、稀释浓硫酸（酸入水）等规范动作一步不错；有毒气体（CO、Cl₂、NO₂、SO₂）实验必须有尾气处理；虚拟实验凡涉及危险操作必须配"现实中不可如此操作 / 必须在通风橱中"提示。
5. **物质分类与命名**：纯净物/混合物、单质/化合物、酸/碱/盐/氧化物的判据一次讲清；俗名与学名严格对应（纯碱是盐不是碱、烧碱是碱、生石灰是氧化物）；分类必交代分类标准（标准不同结论不同）。
6. **定量计算规范**：纯量法——只把纯净物质量代入方程式；方程式不配平不计算；溶液计算先认清溶质（结晶水合物中溶质是无水物）；两种反应物先判限量反应物。
7. **有效数字与单位**：计算结果的有效数字与测量精度匹配，不编造精度；摩尔质量单位 g/mol 不得写成 g；气体摩尔体积 22.4 L/mol 限标准状况（0℃、101kPa）；浓度单位 mol/L；pH 无单位。
8. **氧化还原电子得失方向**："升失氧、降得还"四位一体一次讲对（化合价升高→失电子→被氧化→做还原剂；化合价降低→得电子→被还原→做氧化剂），方向不许反；电子转移守恒是氧化还原配平的依据；氧化剂/还原剂与氧化产物/还原产物的配对不错位。
9. **化学平衡"动态平衡"本质**：v(正)=v(逆)≠0，平衡是动态的不是静止的；平衡常数 K 只与温度有关；勒夏特列原理是"减弱"不是"抵消"；催化剂只改速率不改平衡、不改 K。
10. **电解质与离子方程式的书写条件**：电解质是化合物（单质、混合物不是电解质）；导电条件是"水溶液中或熔融态"（固态 NaCl 不导电）；离子方程式拆写规则——强酸、强碱、可溶性盐拆成离子，弱电解质、沉淀、气体、氧化物写化学式；电荷守恒 + 原子守恒双检查。
11. **化学用语规范**：化学方程式用等号不用箭头（可逆反应除外）；反应条件（点燃/加热/催化剂）标在等号上下；↑↓ 只用于溶液中的气体 / 反应物中无固体的沉淀；离子符号电荷数在前、正负号在后（Mg²⁺ 不是 Mg⁺²）；热化学方程式必须注明物质状态。
12. **条件边界意识（高频条件清单）**：金属活动性顺序四边界（溶液中、前置后、K/Ca/Na 先与水反应、盐须可溶）；溶解度四要素（一定温度、100g 水、饱和、克数）；复分解条件（沉淀/气体/水三者有其一）；浓硫酸/浓硝酸与稀溶液性质不同；燃烧条件三要素 vs 灭火原理一一对应；着火点是物质属性、不可"降低"。

## 全书级红线辨析：三重表征四辨析

化学全书反复使用的四组辨析，对应"宏观—微观—符号"三重表征的切换点。每一组都在首次出现处立靶，后续各章反复回填、互相印证：

**辨析① 化学式下标 vs 方程式系数**（符号之重内部的辨析）
下标是物质的"身份证号"：H₂O 中的"2"表示一个水分子中有两个氢原子，改了下标就是另一种物质（H₂O₂ 是双氧水，不是水）。系数是"粒子个数"：2H₂O 表示两个水分子。配平只能调系数、绝不改下标——这是全书第一铁律（cm03.1.3 立靶 → cm05.1.2 配平 → cm13.1.3 计量 → cm18.1.6 三段式，全程回填）。

**辨析② 系数比（粒子个数比）vs 质量比**（符号之重内部的辨析）
化学方程式中各物质的系数比 = 粒子个数比 = 物质的量比，但**不是质量比**。质量比 = 系数比 × 摩尔质量比。如 2H₂ + O₂ = 2H₂O 中质量比是 4∶32∶36，不是 2∶1∶2。把系数直接当质量用是计算第一大错（cm05.1.4 立靶 → cm13.1.3 严格化 → cm18.1.6 三段式）。

**辨析③ 化学变化 vs 物理变化**（宏观↔微观的辨析）
判据只有一个：**分子种类变没变**。发光发热、有颜色变化都不是判据（电灯发光发热是物理变化）。宏观现象（cm01.1.1 立靶）→ 微观验证（cm03.1.2 水电解粒子动画）→ 符号确认（cm05 方程式），三重表征对齐才是"真懂"。

**辨析④ 元素（宏观种类）vs 原子（微观粒子）**（宏观↔微观的辨析）
元素是宏观概念：具有相同质子数的一类原子的总称，只讲种类不讲个数（"水由氢、氧两种元素组成"）。原子是微观粒子：讲种类也讲个数（"一个水分子由两个氢原子和一个氧原子构成"）。"水由氢氧原子组成""水分子由氢氧元素构成"都是错句（cm03.2.2 立靶 → cm04.1.2 水的组成 → cm12.1.1 分类，全程回填）。
