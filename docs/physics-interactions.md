### 0.2 物理专属色板映射 `--phy-*`

物理**不另起色板**：定义 `--phy-*` 语义变量，值全部别名 `--geo-*`（浅色/深色两套色值自动跟随几何的深色切换，无需另写深色值）。

```css
:root {
  --phy-known:   var(--geo-known);    /* 已知量：蓝 —— 质量 m、初速 v₀、电阻 R、已知温度 */
  --phy-target:  var(--geo-target);   /* 待求量：朱红 —— 合力 F合、待求速度、待求电流 */
  --phy-force-a: var(--geo-corr-a);   /* 力矢量 A 组：橙 —— 如重力 G */
  --phy-force-b: var(--geo-corr-b);   /* 力矢量 B 组：天蓝 —— 如支持力 N / 拉力 T */
  --phy-force-c: var(--geo-corr-c);   /* 力矢量 C 组：蓝绿 —— 如摩擦力 f / 浮力 */
  --phy-body:    var(--geo-line);     /* 物体本体：常规描边色 */
  --phy-track:   var(--geo-aux);      /* 运动轨迹 / 辅助线：灰虚线 */
  --phy-ray:     var(--geo-line);     /* 光路主光线：实线 + 箭头（方向不靠颜色） */
  --phy-field:   var(--geo-corr-b);   /* 场线：天蓝 + 箭头（电场线/磁感线方向） */
  --phy-current: var(--geo-corr-c);   /* 电流方向：蓝绿 + 箭头 */
  --phy-charge-pos: var(--geo-target);/* 正电荷：朱红 + "+" 文字 */
  --phy-charge-neg: var(--geo-known); /* 负电荷：蓝 + "−" 文字 */
  --phy-wave-a:  var(--geo-corr-a);   /* 波形 A：橙实线 */
  --phy-wave-b:  var(--geo-corr-b);   /* 波形 B：天蓝虚线（叠加对比时） */
  --phy-highlight: var(--geo-highlight); /* 高亮闪烁：黄（配深色字） */
  --phy-momentum-a: var(--geo-aux);  /* 动量条 ①：灰（中性色，不与力矢量三组复用，避免误认为重力/弹力） */
  --phy-momentum-b: var(--geo-line); /* 动量条 ②：常规描边色（中性色，深色模式自动跟随） */
}
```

映射问答（任务书原问"力矢量=？"的答案）：**力矢量 = corrA/corrB/corrC 三组**（橙/天蓝/蓝绿），
分组固定——重力恒用 A 组（橙），弹力/拉力/支持力用 B 组（天蓝），摩擦力/阻力用 C 组（蓝绿）；
合力/待求量一律用 `--phy-target`（朱红）+ 加粗 + `F合` 标签（双编码：颜色 + 线宽 + 文字）。

### 0.3 全局铁律（物理页同样执行）

1. `params` 里**不出现具体色值**，只用 `--phy-*` 语义名；深色模式自动切换（别名机制，渲染器不重绘画布）。
2. **逻辑单位 0–100**（y 向上），不写死 px；触摸手柄半径 ≥ 6 逻辑单位（≈44px @ 390px 画布，见几何 cut-reassemble"最小边 ≥13 逻辑单位"口径的同源换算），热区再外扩 50%。
3. 反馈走 M6：吸附/落定/状态切换**视觉必选**（flash/ripple），`navigator.vibrate` 与合成音效为可选加分项。
4. 双编码：矢量方向 = 颜色 + 箭头形状 + 文字标签；大小 = 箭头长度 + 数字读数；状态（通/断、亮/灭）= 颜色 + 文字徽章，**绝不只靠颜色**。
5. 读数行一律走 MathML（物理量符号斜体，如 *v*、*F*），单位与数值同行（N、m/s、A、V、℃、Hz），不许裸文本。
6. 讲解页口径沿用几何：`pageKind: "explain"` + 全页 ≤300 字 + 点拨区 36vh 内滚动；交互页 ≤150 字。

## P1 · force-drag（受力示意拖拽）

拖动力的箭头（改大小/方向），合力矢量实时合成，物体给出运动趋势。
适用课型：**八下 · 第七章 力 / 第八章 运动和力**（力的合成、二力平衡）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `body` | object | ✅ | — | 物体：`{x, y, size, label?}`。逻辑坐标 0–100；`size` 为方块边长（逻辑单位，建议 12–18） |
| `forces` | array | ✅ | — | 非空；每项 `{id, kind, label, angleDeg, mag, min?, max?, fixed?}` |
| `forces[].kind` | string | ✅ | — | 枚举：`gravity`（重力，恒 A 组橙）/ `normal`（支持力，B 组）/ `pull`（拉力/推力，B 组）/ `friction`（摩擦力，C 组）/ `custom`（自定义，C 组） |
| `forces[].angleDeg` | number | ✅ | — | 初始方向角（度，数学惯例：0° 朝右、90° 朝上） |
| `forces[].mag` | number | ✅ | — | 初始大小（N，>0） |
| `forces[].fixed` | boolean | — | `false` | `true` 则该力不可拖（大小方向锁定，如重力默认锁定） |
| `showResultant` | boolean | — | `true` | 是否显示合力矢量（朱红加粗 + `F合` 标签） |
| `surface` | string | — | `"horizontal"` | `"horizontal"`（水平面）/ `"incline"`（斜面，需配 `inclineDeg`） |
| `inclineDeg` | number | — | `0` | 斜面倾角（度，0–45）；仅 `surface:"incline"` 时有效 |
| `unit` | string | — | `"N"` | 力的单位说明 |

- 拖拽方式：拖**箭头端点**改大小+方向；拖**箭身**只改方向（大小不变）；`fixed` 的力（如重力）箭头置灰虚线化、不可拖，文案注明"重力大小方向固定"。
- 摩擦力（`kind:"friction"`）方向由渲染器自动取"与运动趋势反向"，不暴露方向参数（防黄队写错）。
- 读数行：`F合 = … N`（MathML）+ 运动趋势徽章（`"静止"` / `"向右加速"` / `"向左加速"`，纯文本徽章）。

### 示例

```js
interaction: {
  type: "force-drag",
  params: {
    body: { x: 50, y: 40, size: 15, label: "木块" },
    forces: [
      { id: "g", kind: "gravity", label: "G", angleDeg: 270, mag: 10, fixed: true },
      { id: "n", kind: "normal",  label: "N", angleDeg: 90,  mag: 10, fixed: true },
      { id: "t", kind: "pull",    label: "T", angleDeg: 0,   mag: 6, min: 0, max: 20 },
      { id: "f", kind: "friction",label: "f", angleDeg: 180, mag: 6 }
    ],
    showResultant: true, surface: "horizontal", unit: "N"
  }
}
```

### 输入 / 输出

- 输入：手指/鼠标拖拽力矢量箭头（`pull` 类可拖；`fixed` 类锁定）。
- 输出：合力矢量实时重绘 + `F合` 读数 + 运动趋势徽章；拖拽松手时 M6 flash。

### 触控要求

- 箭头端点手柄：实心圆点，半径 ≥ 6 逻辑单位（约 44px），热区外扩 50%。
- 箭身拖拽热区：线宽热区 ≥ 44px（透明加粗描边实现）。
- 松手吸附：无网格吸附（连续量），但松手瞬间箭头做 150ms 缓动 + flash（M6）。

### 深色模式

- 力矢量取 `--phy-force-a/b/c`，合力取 `--phy-target`，深色自动提亮（别名 `--geo-*` 深色列）；
- 物体 `--phy-body` 深色下为近白描边；读数文字走 `--geo-text`。

### 双编码

- 每组力：颜色 + 力标签文字（G/N/T/f/F合）+ 箭头方向；大小 = 箭长 + 读数 N。
- 灰度检验：关掉颜色，仍能凭"标签 + 箭头指向 + 箭长对比"读出受力图。

### 复用几何

- 拖拽手柄机制复用 `vertex-drag`（可拖顶点 ≈ 可拖箭头端点）；
- 力编号徽章样式复用 `tap-highlight` 的编号徽章（颜色+数字）。

### 黄队接口（先动手后结论）

- 动手：学生拖拉力 T 从 0 慢慢加大 → 现象：F合 读数从 0 变大、徽章从"静止"跳"向右加速" → 结论点题："拉力大于最大静摩擦，木块才动——合力决定运动状态"。
- 建议配 `exploreTip`（≤40 字动手提示）与结论徽章文案，由黄队写。

### 蓝队评审

- ✅ **可实现**：纯 SVG 矢量绘制 + 矢量加法解析计算，零性能风险；Canvas/SVG 均可，建议 SVG（箭头复用 `<marker>`）。
- 离线预计算：无（全部实时解析计算）。

### 常见坑

1. **`fixed` 的力要在文案说明**：重力/支持力锁定时，页内必须有一句"重力大小方向不变"（否则学生会疑惑为什么拖不动）。
2. **摩擦力方向别手写**：`friction` 的 `angleDeg` 只作初始示意，渲染器按合力趋势自动反向；params 里写死方向是错的。
3. **合力为 0 的徽章**：`F合 = 0` 时徽章显示"静止（合力为零）"，不要只显示数字 0。

## P2 · motion-sim（运动轨迹模拟）

调初速度 v₀、发射角 θ，看抛体轨迹动画 + 射程/射高读数；或切圆周模式看向心力方向。
适用课型：**八上 · 第一章 机械运动**（运动快慢、轨迹）；**高中拓展**（抛体运动、圆周运动）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `mode` | string | ✅ | — | `"projectile"`（抛体）/ `"circle"`（匀速圆周） |
| `v0` | object | — | — | 抛体初速度：`{min, max, step, init}`（m/s，>0）；`mode:"projectile"` 时必填 |
| `angle` | object | — | — | 发射角：`{min, max, step, init}`（度，5–85）；`mode:"projectile"` 时必填 |
| `omega` | object | — | — | 角速度：`{min, max, step, init}`（rad/s）；`mode:"circle"` 时必填 |
| `g` | number | — | `9.8` | 重力加速度（m/s²，>0） |
| `dragHandle` | boolean | — | `true` | 画布发射手柄：拖手柄改 v₀/θ，与滑块双向同步 |
| `timeScale` | number | — | `1` | 慢放倍数（<1 为慢放，如 0.3）；动画角标注"慢放 ×0.3"，防误解为真实时间 |
| `showReadouts` | boolean | — | `true` | 是否显示读数行（射程 R / 最大高度 H / 飞行时间 T，或圆周的周期 T） |
| `maxFrames` | number | — | `120` | 轨迹点数上限（钳制 ≤ 300） |

- 播放控制：▶ 播放 / ⏸ 暂停 / ↺ 重播 / scrubber 时间轴（沿用代数 `slow-replay` 约定）。
- 读数行（MathML）：抛体 `R = … m`、`H = … m`、`T = … s`；圆周 `T = 2π/ω = … s` + 向心力箭头（实时指向圆心，`--phy-target` 朱红 + `F向` 标签）。
- 轨迹线：`--phy-track` 灰虚线 + 起点圆点标记；小球 `--phy-body`。

### 示例

```js
interaction: {
  type: "motion-sim",
  params: {
    mode: "projectile",
    v0: { min: 5, max: 30, step: 1, init: 15 },
    angle: { min: 15, max: 75, step: 5, init: 45 },
    g: 9.8, dragHandle: true, timeScale: 0.5, showReadouts: true
  }
}
```

### 输入 / 输出

- 输入：滑块调 v₀/θ/ω，或拖画布发射手柄（抛体模式）。
- 输出：轨迹动画 + 落点标记（ripple）+ 读数行实时更新；调参后自动重播（或点 ▶）。

### 触控要求

- 发射手柄：半径 ≥ 6 逻辑单位的蓝色圆点（可拖拽视觉约定，沿用几何"顶点可拖=蓝色"）；
- 滑块：原生 `<input type=range>`，轨道点击区高度 ≥ 44px；
- 播放按钮 ≥ 44px；scrubber 拖拽热区 ≥ 44px 高。

### 深色模式

- 轨迹虚线 `--phy-track` 深色取 `#9E9E9E`（别名 `--geo-aux` 深色列）；小球/读数自动跟随。

### 双编码

- 轨迹：虚线线型 + 起点/落点文字（"起点"/"落点"）；向心力：箭头 + `F向` 标签 + 朱红加粗。

### 复用几何

- 播放控制条复用代数 `slow-replay`（▶/⏸/↺/scrubber + 关键事件高亮）；
- 发射手柄双向同步复用几何 `ladder-slide`（画布手柄 ↔ 滑块）。

### 黄队接口（先动手后结论）

- 动手：固定 v₀=15，θ 从 15° 调到 75° → 现象：45° 时射程读数最大 → 结论点题："同样的力气，45° 扔得最远"。
- 圆周模式动手：拖动小球 → 现象：向心力箭头始终指向圆心 → 结论："做圆周运动，合力永远指向圆心"。

### 蓝队评审

- ✅ **可实现**：抛体/圆周均为解析式（`x=v₀t·cosθ, y=v₀t·sinθ−½gt²`），rAF 逐帧描点；轨迹点离线预计算（≤300 点，一次算完存数组）。
- 离线预计算：轨迹点列（调参时重算，<1ms，可实时）。
- 性能风险：无。

### 常见坑

1. **θ=90° 退化**：竖直上抛轨迹为直线——画布画竖线 + 上下箭头，文案写"竖直上抛是抛体的特例"；`angle.max` 若设 90 要在 hints 说明。
2. **v₀=0 禁播**：读数显示"—"，播放按钮置灰并提示"初速度不能为 0"。
3. **`timeScale` 必须标注**：动画角常驻小字"慢放 ×0.5（非真实时间）"，否则学生误以为小球真飞这么慢。

## P3 · circuit-build（电路搭建）

从元件库拖元件到网格点位，自动吸附连线；开关闭合 → 灯泡亮（光晕分档）→ 电流表读数联动。
适用课型：**九年级 · 第十五章 电流和电路 / 第十七章 欧姆定律**（串联电路、电流表使用）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `grid` | object | ✅ | — | 网格：`{cols, rows}`（如 6×4）；格点间距 ≥ 13 逻辑单位（44px 口径） |
| `components` | array | ✅ | — | 初始已放元件（可空）；每项 `{id, kind, cell:[col,row], value?}` |
| `components[].kind` | string | ✅ | — | 枚举：`battery`（电源）/ `bulb`（灯泡）/ `switch`（开关）/ `ammeter`（电流表）/ `resistor`（电阻）/ `wire`（导线） |
| `tray` | array | — | 全种类 | 元件库清单（`kind` 数组，缺省六种全有） |
| `battery` | object | — | `{voltage: 3}` | 电源电压（V，>0）；单电源（降级约束，见蓝队评审） |
| `goal` | string | — | — | 任务目标（一句话，如"连一个能让灯泡亮的电路"） |
| `allowParallel` | boolean | — | `false` | 是否允许并联模板；`true` 时仅开放"两支路各一灯泡"固定模板（降级约束） |
| `showCurrent` | boolean | — | `true` | 是否显示电流方向箭头（`--phy-current` 蓝绿 + 箭头） |

- 连线规则：元件拖到格点即占位；相邻格点自动用导线连接（`--phy-body` 实线）；元件可拖回元件库删除。
- 求解（降级版，见蓝队评审）：单回路串联 `I = U / ΣR`；灯泡按功率分三档亮度（暗/亮/很亮，光晕半径三档）；电流表读数 `I = … A`（MathML）。
- 短路保护（教学点）：导线直连电源两极 → 红色警告徽章"短路！电流过大" + 电路置"断路"态（灯泡不亮）。
- 烧表警告（判定行为）：电流表（`kind:"ammeter"`）被并联在用电器/电源两端 → 渲染器出"烧表"警告徽章（⚠ + 文字，话术占位"待黄队定"），电路置"断路"态。
- 通断徽章：`"通路"` / `"断路（开关没闭合）"` / `"短路"`，文字徽章 + 灯泡光晕，**不只靠颜色**。

### 示例

```js
interaction: {
  type: "circuit-build",
  params: {
    grid: { cols: 6, rows: 4 },
    components: [
      { id: "bat1", kind: "battery", cell: [1, 2] },
      { id: "sw1",  kind: "switch",  cell: [4, 2] }
    ],
    tray: ["bulb", "ammeter", "resistor", "wire"],
    battery: { voltage: 3 },
    goal: "从元件库拖灯泡和导线，连一个能让灯泡亮的电路",
    allowParallel: false, showCurrent: true
  }
}
```

### 输入 / 输出

- 输入：拖元件到格点 / 点开关切换开合 / 拖回元件库删除。
- 输出：通断判定 + 灯泡光晕分档 + 电流方向箭头 + 电流表读数；落定 M6 ripple。

### 触控要求

- 元件热区 ≥ 44px（格点间距 ≥ 13 逻辑单位保证）；
- 开关点击热区 ≥ 44px；元件库条目 ≥ 44px 高；
- 拖拽中元件半透明跟随手指，格点吸附时 ripple + 可选震动。

### 深色模式

- 导线 `--phy-body`（深色近白）；电流箭头 `--phy-current` 深色提亮蓝绿；灯泡光晕用 `--phy-highlight` 黄（深底天然高对比）。

### 双编码

- 元件符号符合 **GB/T 4728**（国标电路符号），符号本身即第一编码；
- 通断：光晕 + 文字徽章；电流：箭头方向 + `I` 标签；灯泡亮度三档各有文字（"暗/亮/很亮"）。

### 复用几何

- 拖放 + 吸附 + 落定锁定复用 `cut-reassemble`（散块 → 元件，目标轮廓 → 格点）；
- "一键拼好"兜底可复用为"一键连好示范电路"（`autoAssemble` 同构）。

### 黄队接口（先动手后结论）

- 动手：学生先连好电路但开关断开 → 现象：灯泡不亮、电流表为 0 → 动手闭合开关 → 现象：灯亮、电流表有读数 → 结论："电路要闭合，电流才有路可走——这就是通路"。
- 短路页动手：故意用导线连电源两极 → 现象：警告徽章 → 结论："短路电流很大，会烧坏电源——绝不允许"。

### 蓝队评审

- ⚠️ **降级可实现**：**不支持任意拓扑**——只做单回路串联解析求解（`I=U/ΣR`），并联仅开放固定双支路模板；元件总数 ≤ 8；不做通用节点分析（MNA）。SVG 绘制，性能无风险。
- 离线预计算：无（拓扑变化时重算回路，O(n)）。
- ❌ **明确不做**：多电源、混联任意拓扑、滑动变阻器连续调阻（降级为三档定值电阻）、交流电。

### 常见坑

1. **`allowParallel: true` 只是开模板**：不是"任意并联"，文案写"试试两条支路"而非"自由并联"。
2. **电流表内阻视为 0**：求解时忽略，文案小字注明（初中教学约定）。
3. **灯泡"亮度"只有三档**：不要承诺连续调光；三档配文字"暗/亮/很亮"。
4. **元件库拖拽方向**：只支持"库 → 画布"和"画布 → 库"，画布上元件之间不可直接交换位置（先拖回库再放）。

## P4 · optics-ray（光路作图）

拖光源/透镜位置、调焦距滑块，三条特殊光线实时重画，看成像性质。
适用课型：**八上 · 第五章 透镜及其应用**（凸透镜成像）；`mode:"mirror"` 用于**第四章 光现象**（平面镜/反射）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `mode` | string | ✅ | — | `"lens"`（透镜）/ `"mirror"`（平面镜反射） |
| `lens` | object | — | — | `mode:"lens"` 必填：`{x, f}`；`x` 为透镜中心逻辑横坐标，`f` 为焦距（可滑块调，见 `focal`） |
| `focal` | object | — | — | 焦距滑块 `{min, max, step, init}`（逻辑单位，>0） |
| `source` | object | ✅ | — | 光源/物体：`{x, y}` 可拖拽（箭头状物体，`--phy-body`） |
| `rays` | array | — | 全开 | 显示的光线：`"parallel"`（平行主光轴）/ `"center"`（过光心）/ `"focus"`（过焦点）的子集 |
| `showImage` | boolean | — | `true` | 是否画出像（实像实线 / 虚像虚线 + 像性质徽章） |
| `mirrorX` | number | — | — | `mode:"mirror"` 必填：平面镜横坐标（竖直镜面） |

- 成像计算：薄透镜公式 `1/f = 1/u + 1/v`（MathML 显示）；像性质徽章：`"倒立缩小实像"` / `"正立放大虚像"` / `"不成像（u=f）"` 等。
- 光线画法：入射/折射光线 `--phy-ray` 实线 + 箭头；法线 `--phy-track` 灰虚线；焦点 `F` 文字 + 圆点标记（双编码）。
- 反射模式：入射角 = 反射角自动满足（构造保证），量角读数可选。

### 示例

```js
interaction: {
  type: "optics-ray",
  params: {
    mode: "lens",
    lens: { x: 50, f: 15 },
    focal: { min: 8, max: 25, step: 1, init: 15 },
    source: { x: 22, y: 62 },
    rays: ["parallel", "center", "focus"],
    showImage: true
  }
}
```

### 输入 / 输出

- 输入：拖光源（改物距）/ 拖透镜 / 滑块调焦距。
- 输出：三条光线实时重画 + 像的位置/性质 + 薄透镜公式数值验算行。

### 触控要求

- 光源/透镜拖拽手柄 ≥ 6 逻辑单位；焦距滑块轨道 ≥ 44px 高；
- 焦点 F 为只读标记（不可拖），避免与"调焦距"混淆。

### 深色模式

- 光线 `--phy-ray` 深色近白实线；法线 `--phy-track` 深色浅灰虚线；焦点标记文字走 `--geo-text`。

### 双编码

- 实像/虚像：实线 vs 虚线 + 文字徽章；光线方向：箭头（灰度可辨）；焦点：`F` 文字 + 圆点。

### 复用几何

- 三条特殊光线的分步讲解复用 `construction-step`（"看一遍→跟一遍"画光路）；
- 拖拽手柄复用 `vertex-drag`。

### 黄队接口（先动手后结论）

- 动手：光源从远处往透镜拖 → 现象：像由小变大、由倒立缩小变为放大 → 结论点题："物距越小，像越大——照相机与投影仪的区别就在这"。
- 动手：物距拖到 f 以内 → 现象：折射光线发散、虚像出现在同侧 → 结论："放大镜的秘密：u < f 成正立放大虚像"。

### 蓝队评审

- ✅ **可实现**：几何光学全解析计算（直线求交 + 薄透镜公式），SVG 直线绘制，零性能风险。
- ❌ **明确不做**：衍射、干涉、波前、色散（降级声明：本交互只做几何光线）。
- 离线预计算：无。

### 常见坑

1. **u=f 时显示"不成像"**：不要画发散到无穷的线硬凑像；徽章写清"不成像"。
2. **虚像画虚线**：实像/虚像线型不能反；文案"虚像用虚线画，因为光线没真交于那"。
3. **`rays` 子集教学**：初学只开 `["parallel", "center"]` 两条，第三条作为"挑战"后开——params 支持子集就是为此。

## P5 · wave-tune（波形调节）

调振幅 A、频率 f、相位 φ，看正弦波形实时变化；可叠加第二列波看干涉示意；"听一听"用 Web Audio 合成声音。
适用课型：**八上 · 第二章 声现象**（声音的特性：音调/响度）；**高中拓展**（波的叠加）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `amp` | object | ✅ | — | 振幅滑块 `{min, max, step, init}`（>0） |
| `freq` | object | ✅ | — | 频率滑块 `{min, max, step, init}`（Hz，>0） |
| `phase` | object | — | `{min:0,max:360,step:15,init:0}` | 相位滑块（度，0–360 循环） |
| `waveB` | object | — | — | 第二列波（可选）：`{amp, freq, phase}` 固定值或同构滑块；用于叠加演示 |
| `showSum` | boolean | — | `false` | 是否显示合成波（`waveB` 存在时有效；合成波用 `--phy-target` 朱红粗线） |
| `playSound` | boolean | — | `true` | 是否显示"听一听"按钮（Web Audio 合成，零音频文件） |
| `audibleMax` | number | — | `2000` | 发声频率上限（Hz）；超过只画波形不发声（听力保护） |
| `showLabels` | boolean | — | `true` | 是否标注波峰/波谷（圆点 + "峰"/"谷"文字）与波长读数 |

- 读数行（MathML）：`A = …`、`f = … Hz`、`λ = v/f = …`（v 取声速 340 m/s，文案注明）。
- 发声：`OscillatorNode` 正弦，频率钳制 20–`audibleMax` Hz；低于 20Hz 显示"太低听不见，只看波形"。
- 波形移动动画：相位随时间推进的演示速度钳制，**频闪 ≤ 3Hz**（光敏安全，见 §13 W-P8）。

### 示例

```js
interaction: {
  type: "wave-tune",
  params: {
    amp: { min: 1, max: 5, step: 0.5, init: 3 },
    freq: { min: 100, max: 1000, step: 10, init: 440 },
    phase: { min: 0, max: 360, step: 15, init: 0 },
    playSound: true, audibleMax: 2000, showLabels: true
  }
}
```

### 输入 / 输出

- 输入：三个滑块；"听一听"按钮；可选 waveB 叠加开关。
- 输出：波形 Canvas 实时重绘 + 读数行 + 合成音（落定不播音，按按钮才播）。

### 触控要求

- 滑块轨道 ≥ 44px 高；"听一听"按钮 ≥ 44px；
- 频率滑块建议配 `−`/`+` 步进按钮（手机上精调 440Hz 这类目标值）。

### 深色模式

- 波形 A `--phy-wave-a`（橙实线）、波形 B `--phy-wave-b`（天蓝虚线），深色自动提亮；坐标轴 `--geo-grid` 深色弱对比。

### 双编码

- 两列波：颜色 + 线型（实线/虚线）+ 图例文字"波 A"/"波 B"；波峰波谷：圆点 + "峰"/"谷"文字。

### 复用几何

- 滑块 + 表达式联动范式复用代数 `slider-lab`；
- 音效走白队 Web Audio 合成约定（`white-team-lessons.md` §三），零音频文件。

### 黄队接口（先动手后结论）

- 动手：固定振幅，只调频率 200→800Hz → 现象：波形变密、"听一听"音调变高 → 结论："频率越快音调越高——女高音的秘密"。
- 动手：固定频率，只调振幅 → 现象：波形变高、声音变响 → 结论："振幅决定响度"。
- 叠加动手：开 waveB 等幅反相 → 现象：合成波几乎为零 → 结论："噪声耳机的原理：用反相波抵消噪声"。

### 蓝队评审

- ✅ **可实现**：`y = A·sin(2πft + φ)` 逐点绘制（≤400 点/帧，rAF）；Web Audio 合成（沿用英语页验证过的模式）。
- ⚠️ **约束**：发声频率钳制 20–2000Hz；波形动画频闪 ≤ 3Hz；`playSound` 需用户手势触发（AudioContext 自动播放策略）。
- ❌ **明确不做**：驻波严格推导（降级为两列波叠加示意）、真实乐器音色采样（零音频文件铁律）。

### 常见坑

1. **相位滑块是循环的**：0°=360°，拖到头可回绕；文案别写"相位越大波越右"这类绝对化表述（周期性）。
2. **"听一听"不是落定音效**：滑块拖动过程中不发声（避免噪声轰炸），只响应按钮。
3. **λ 读数注明声速假设**：`v = 340 m/s` 写进小字，温度变化声速变是拓展话术。

## P6 · pulley-lever（滑轮杠杆）

杠杆模式：拖支点 O / 调力臂，看杠杆倾斜与 `F₁L₁=F₂L₂` 实时验算；滑轮模式：定/动滑轮切换，拉绳看省力一半。
适用课型：**八下 · 第十二章 简单机械**（杠杆平衡条件、滑轮）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `mode` | string | ✅ | — | `"lever"`（杠杆）/ `"pulley"`（滑轮） |
| `fulcrumX` | object | — | — | `mode:"lever"` 必填：支点横坐标滑块/拖拽 `{min, max, step, init}`（逻辑单位） |
| `load` | object | ✅ | — | 阻力端：`{weight（N）, armInit（逻辑单位）}`；阻力大小固定（钩码），力臂可随支点变 |
| `effortArm` | object | — | — | 动力臂滑块 `{min, max, step, init}`（`mode:"lever"` 可选；不填则由支点位置导出） |
| `pulleyKind` | string | — | — | `mode:"pulley"` 必填：`"fixed"`（定滑轮）/ `"movable"`（动滑轮） |
| `showEquation` | boolean | — | `true` | 是否显示 `F₁L₁ = F₂L₂` 实时验算行（MathML，`✓` 标记） |
| `unit` | string | — | `"N"` | 力的单位 |

- 杠杆绘制：杠杆 `--phy-body` 粗线；支点三角形标记 + `O` 文字；动力臂/阻力臂弧线标记（复用几何 corrA/corrB + 单弧/双弧双编码）；动力 `F₁`（`--phy-target` 朱红待求）/ 阻力 `F₂`（`--phy-force-a` 橙已知）。
- 平衡判定：`|F₁L₁ − F₂L₂| / max < 2%` → 徽章`"平衡 ✓"`，杠杆水平；否则按力矩差方向倾斜（动画角度钳制 ±15°）。
- 滑轮模式：绳 `--phy-body` 实线；动滑轮省力徽章 `"F = G/2（省一半力）"`；拉绳手柄可拖（`--phy-known` 蓝）。

### 示例

```js
interaction: {
  type: "pulley-lever",
  params: {
    mode: "lever",
    fulcrumX: { min: 30, max: 70, step: 1, init: 50 },
    load: { weight: 10, armInit: 20 },
    showEquation: true, unit: "N"
  }
}
```

### 输入 / 输出

- 输入：拖支点 O / 滑块调力臂 / 滑轮模式拖拉绳。
- 输出：杠杆倾斜动画 + 动力读数 `F₁ = … N` + 平衡验算行 + 省力/费力徽章。

### 触控要求

- 支点 O 手柄：三角形标记 + ≥ 6 逻辑单位热区；拉绳手柄同 P1；
- 倾斜动画 300ms 缓动；平衡瞬间 M6 flash。

### 深色模式

- 杠杆/绳 `--phy-body`；力臂弧线 `--phy-force-a/b`；动力 `--phy-target`；自动跟随深色。

### 双编码

- 动力臂/阻力臂：颜色 + 单弧/双弧标记（复用几何等长/等角标记体系）；
- 平衡：`✓` 文字 + 徽章，不只靠杠杆水平。

### 复用几何

- 滑块 + 画布手柄双向同步复用 `ladder-slide`；
- `F₁L₁=F₂L₂` 验算行复用 `pythag-grow` / `ratio-slider` 的 badge 实时验算范式。

### 黄队接口（先动手后结论）

- 动手：支点 O 从中间往阻力端拖 → 现象：动力 F₁ 读数变小、徽章"省力" → 结论："支点离重物越近，越省力——撬棍要抵在靠近重物的地方"。
- 滑轮动手：定/动滑轮切换拉同一重物 → 现象：动滑轮拉力读数减半 → 结论："动滑轮省一半力，但要多拉一倍绳子"。

### 蓝队评审

- ✅ **可实现**：静态力矩平衡解析计算；倾斜是绕支点的旋转动画（CSS/SVG transform），无刚体物理仿真。
- 离线预计算：无。性能风险：无。

### 常见坑

1. **力臂为 0 钳制**：支点拖到端点时对应力臂 → 0，读数显示"—"并提示"支点不能压在端点上"。
2. **平衡容差 2%**：手指拖不到绝对平衡，容差内即判平衡（文案写"基本平衡"）。
3. **倾斜角钳制 ±15°**：真按力矩比转会翻过去，教学示意即可。

## P7 · collision-lab（碰撞实验）

调两车质量/初速度，播放碰撞，看碰后速度 + 动量守恒验算 + 动量条对比。
适用课型：**高中 · 动量守恒**（拓展）；初中可做"小车碰撞"定性观察页（`restitution` 锁定 1）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `m1` / `m2` | object | ✅ | — | 质量滑块 `{min, max, step, init}`（kg，>0） |
| `v1` / `v2` | object | ✅ | — | 初速度滑块 `{min, max, step, init}`（m/s，可为负表示反向；至少一车速度非 0） |
| `restitution` | number | — | `1` | 恢复系数 e（0–1；1=完全弹性，0=完全非弹性） |
| `showMomentumBars` | boolean | — | `true` | 是否显示动量条（碰前/碰后两组条形，长度 ∝ p，配数值） |
| `maxFrames` | number | — | `120` | 碰撞动画帧数上限（钳制 ≤ 200） |

- 求解：一维碰撞解析解（动量守恒 + 恢复系数定义式联立）；读数行（MathML）：`p前 = p后 = … kg·m/s ✓`。
- 播放控制：▶/⏸/↺/scrubber（沿用 `slow-replay`）；碰撞瞬间：两车 flash + 动量条高亮。
- 小车：①②车 `--phy-body`（物体本体色）+ ①②编号文字；动量条：① `--phy-momentum-a`（灰）/ ② `--phy-momentum-b`（常规描边色）+ 条长 + 数值；速度矢量箭头（长度 ∝ v + 读数）。（m6 修补：动量条用独立中性色，不与力矢量 A/B 组复用，避免误认为重力）

### 示例

```js
interaction: {
  type: "collision-lab",
  params: {
    m1: { min: 1, max: 5, step: 0.5, init: 2 },
    m2: { min: 1, max: 5, step: 0.5, init: 2 },
    v1: { min: -5, max: 5, step: 0.5, init: 4 },
    v2: { min: -5, max: 5, step: 0.5, init: 0 },
    restitution: 1, showMomentumBars: true
  }
}
```

### 输入 / 输出

- 输入：四个滑块调 m/v；播放碰撞动画。
- 输出：碰后速度读数 + 动量守恒验算行 + 动量条对比 + 经典结论徽章（如等质量弹性碰撞"交换速度"）。

### 触控要求

- 滑块 ≥ 44px；播放按钮 ≥ 44px；动量条为只读显示（不可点）。

### 深色模式

- 小车/动量条取 `--phy-body` / `--phy-momentum-a/b`（中性色），深色自动跟随；验算行文字走 `--geo-text`。

### 双编码

- 两车：颜色 + ①②编号；动量：条长 + 数值；守恒：`✓` + "碰前=碰后"文字。

### 复用几何

- 播放控制条复用代数 `slow-replay`；守恒验算徽章复用 `ratio-slider` 的不变量徽章范式。

### 黄队接口（先动手后结论）

- 动手：m₁=m₂、v₂=0、e=1，v₁ 从小调大播放 → 现象：①车停下、②车以 v₁ 冲出去 → 结论："动量从①车传给了②车——台球母球定住的秘密"。
- 动手：把 m₁ 调到最大再撞 → 现象：②车飞得更快 → 结论："大质量撞小质量，动量传递更彻底"。

### 蓝队评审

- ✅ **可实现**：一维碰撞解析解（两方程两未知数），rAF 动画 ≤200 帧；Canvas/SVG 均可。
- ❌ **降级声明**：二维碰撞不做（统一一维沿 x 轴）；斜碰/旋转不做。
- 离线预计算：碰后速度（调参时 <1ms）。

### 常见坑

1. **两车都静止禁播**：v₁=v₂=0 时播放按钮置灰，"两车都不动，撞不起来"。
2. **e 的取值文案**：初中页锁定 `restitution: 1` 并隐藏该参数；高中页才暴露 0–1。
3. **动量条零值**：p=0 的车条形不画，配文字"p=0"，别画一条零长度的线让人找。

## P8 · field-viz（电场/磁场可视化）

点选放置点电荷（≤4 个），电场线自动生成；拖探测手柄看场强方向。磁场模式：拖条形磁铁看小磁针偏转。
适用课型：**九年级 · 电磁**（电荷、电场概念；磁现象、磁场）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `mode` | string | ✅ | — | `"efield"`（电场）/ `"bfield"`（磁场） |
| `charges` | array | — | `[]` | `mode:"efield"` 时：初始电荷 `[{x, y, q}]`；`q` 为 +1（正）/ −1（负）；学生点选空白处放置新电荷（总数 ≤ 4，超限提示） |
| `lineCount` | number | — | `32` | 场线条数上限（钳制 ≤ 48；电荷数多时自动降密，见蓝队评审） |
| `probeDrag` | boolean | — | `true` | 探测手柄：可拖动的"试探点"，显示该点场强方向箭头 + `E` 读数（方向文字如"向右偏上"） |
| `magnet` | object | — | — | `mode:"bfield"` 必填：`{x, y, angle}` 磁铁中心与角度（可拖可转） |
| `needleCount` | number | — | `8` | 小磁针数量（钳制 ≤ 12，环形布置） |
| `showFieldLines` | boolean | — | `true` | 磁场模式是否显示磁感线（`--phy-field` + 箭头） |
| `ironFilings` | boolean | — | `false` | `mode:"bfield"` 时"撒铁屑"开关：铁屑沿磁感线排布示意（静态纹理，非真实随机模拟） |

- 电场线生成：从每个电荷出发按角度均分发射追踪（RK2 数值积分，终止于异号电荷或画布边界）；同号电荷相斥偏折自动呈现。
- 电荷绘制：正电荷 `--phy-charge-pos`（朱红圆 + "+"），负电荷 `--phy-charge-neg`（蓝圆 + "−"）；电荷可拖动（重算场线）/ 双击删除。
- 小磁针：N 极 `--phy-charge-pos`（朱红）+ "N"、S 极 `--phy-charge-neg`（蓝）+ "S"；静止时 N 极指向该点磁感应方向。

### 示例

```js
interaction: {
  type: "field-viz",
  params: {
    mode: "efield",
    charges: [ { x: 35, y: 50, q: 1 }, { x: 65, y: 50, q: -1 } ],
    lineCount: 32, probeDrag: true
  }
}
```

### 输入 / 输出

- 输入：点选放置/拖动/删除电荷；拖磁铁（磁场模式）；拖探测手柄。
- 输出：场线重绘 + 探测点场强箭头 + 方向文字；磁针实时偏转。

### 触控要求

- 电荷热区 ≥ 44px；点选放置时落点 ripple（M6）；磁铁旋转手柄 ≥ 44px；
- 电荷总数 ≤ 4 的限制在页内文案说明（"最多放 4 个电荷"）。

### 深色模式

- 场线 `--phy-field` 深色提亮天蓝；电荷圆深色描边加粗一档（深底上朱红/蓝需 ≥3:1）。

### 双编码

- 正/负电荷：颜色 + "+"/"−" 文字；场线方向：箭头（灰度可辨）；磁针 N/S：颜色 + "N"/"S" 文字。

### 复用几何

- 点选放置热区复用 `tap-highlight`（透明点击热区 ≥44px）；
- 电荷编号徽章复用编号徽章样式。

### 黄队接口（先动手后结论）

- 动手：先放一个正电荷 → 现象：场线放射状向外 → 动手再放一个负电荷在旁边 → 现象：场线从正弯向负 → 结论："电场线从正电荷出发，回到负电荷——它们是'有头有尾'的"。
- 磁场动手：拖磁铁转圈 → 现象：小磁针 N 极跟着转 → 结论："磁针 N 极指的方向，就是那点的磁场方向"。

### 蓝队评审

- ⚠️ **降级可实现**：
  - 只做 **2D 平面切片**，3D 场可视化不做（明确降级）；
  - 电荷 ≤ 4 个时场线 RK2 追踪离线预计算（≤48 条 × 200 点，实测 <50ms，电荷拖动松手后重算，拖动中只移动电荷圆点不重算场线——防卡顿）；
  - 磁场为静磁场示意（条形磁铁偶极子场解析式），不做电磁感应动态场；
  - 电荷运动时不做实时场重算（静态场假设，文案可写"电荷静止时的电场"）。
- ❌ **明确不做**：3D 电场线、运动电荷的辐射场、铁屑实验的随机纹理模拟。
- 性能风险点：`lineCount` 与电荷数的乘积钳制（4 电荷 × 48 线为上限）；低端机降 `lineCount` 到 24（`matchMedia` 或 UA 启发式，渲染器内部处理，不暴露 params）。

### 常见坑

1. **电荷重叠**：两电荷中心距 < 8 逻辑单位时不许放置（提示"电荷叠在一起了，挪开一点"）。
2. **场线不穿电荷**：追踪终止条件写死（距任一电荷 < 3 逻辑单位即停），params 不暴露。
3. **探测手柄读数**：只给方向文字 + 相对强弱（"强/中/弱"三档），不给 E 的绝对数值（点电荷电量 q=±1 是示意单位，文案注明"示意"）。

## P9 · thermo-sim（热学模拟）

加热/冷却滑块调温度，容器内分子运动速率随温度变化；配固/液/气三态徽章（以水为例）。
适用课型：**八上 · 第三章 物态变化**（温度、分子热运动定性）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `temp` | object | ✅ | — | 温度滑块 `{min, max, step, init, unit}`；如 `{min:-20, max:120, step:5, init:20, unit:"℃"}` |
| `particleCount` | number | — | `120` | 分子数（钳制 ≤ 400，见蓝队评审） |
| `showStates` | boolean | — | `true` | 是否显示物态徽章（固态/液态/气态 + 熔点 0℃/沸点 100℃ 标注，以水为例） |
| `heatButtons` | boolean | — | `true` | 是否显示"加热 🔥 / 制冷 ❄"长按按钮（与滑块双向同步，手机友好） |
| `speedScale` | number | — | `1` | 动画速度归一化系数（内部参数；高温粒子太快时渲染器自动降速并标注"已慢放"） |
| `brownian` | boolean | — | `false` | 布朗运动示意：叠加一颗大颗粒做随机游走（文案注明"示意，非真实碰撞"） |

- 分子模型（示意）：速率 `∝ √T`（T 取开尔文），方向随机，边界弹性反射；不做分子间作用力（降级声明）。
- 速率分档着色：慢速 `--phy-charge-neg`（蓝）/ 中速 `--phy-force-a`（橙）/ 快速 `--phy-charge-pos`（朱红）+ 点粒子显示瞬时速率（三档文字"慢/中/快"）；第二编码：圆点形状分档（慢=圆、中=三角、快=方），灰度下可辨。
- 物态徽章：`T < 0` → "固态（冰）"；`0 ≤ T < 100` → "液态（水）"；`T ≥ 100` → "气态（水蒸气）"；0℃/100℃ 处滑块刻度线高亮（M6 flash）提示相变点。

### 示例

```js
interaction: {
  type: "thermo-sim",
  params: {
    temp: { min: -20, max: 120, step: 5, init: 20, unit: "℃" },
    particleCount: 120, showStates: true, heatButtons: true
  }
}
```

### 输入 / 输出

- 输入：温度滑块 / 长按加热·制冷按钮。
- 输出：粒子运动动画（速率实时跟随温度）+ 温度读数 + 物态徽章切换（0℃/100℃ 处 flash）。

### 触控要求

- 滑块 ≥ 44px；加热/制冷按钮 ≥ 56px（长按操作，宜更大）；
- 相变点徽章切换时 flash + 可选短音（M6）。

### 深色模式

- 容器 `--phy-body`；粒子三档色深色自动提亮；徽章文字走 `--geo-text`。

### 双编码

- 速率：颜色 + 形状（慢=圆、中=三角、快=方）+ "慢/中/快"文字（点粒子抽查）；物态：文字徽章 + 形态图标（❄/💧/☁️ 为装饰，文字为主）。

### 复用几何

- 滑块范式复用代数 `slider-lab`；"加热三阶段"静态讲解页可用 `step-play`（固→液→气三帧）。

### 黄队接口（先动手后结论）

- 动手：从 20℃ 长按加热到 100℃ → 现象：粒子越跑越快、徽章从"液态"跳"气态" → 结论："温度越高，分子跑得越快——温度就是分子热运动剧烈程度的标志"。
- 动手：在 0℃ 附近来回拨 → 现象：徽章在固/液之间跳 → 结论："0℃ 是冰的熔点——吸热熔化，温度不变"（后半句为拓展话术，黄队定）。

### 蓝队评审

- ⚠️ **降级可实现**：
  - 分子 = "速率 ∝ √T 的随机运动圆点"**示意**，不做 Lennard-Jones、格子气、相变潜热（明确降级）；
  - 粒子数钳制 ≤ 400（Canvas 2D 实测 60fps 上限；`particleCount` 超限渲染器自动钳制并 console 告警）；
  - 碰撞只做边界反射，粒子之间不做碰撞求解；
  - 背景容器离屏预渲染，粒子层每帧只重绘圆点（性能优化点，渲染器内部实现）。
- ❌ **明确不做**：布朗运动严格统计、扩散方程、真实相变潜热平台（温度-时间图像另起页用 `plot-points` 做，与本交互解耦）。
- 离线预计算：无（每帧 O(n) 更新，n ≤ 400）。

### 常见坑

1. **"以水为例"必须写**：0℃/100℃ 是水的熔/沸点，文案注明，其他物质不一样。
2. **开尔文换算内部处理**：`√T` 用 T(K)=T(℃)+273.15，params 只暴露摄氏度，不暴露换算。
3. **低温粒子几乎不动**：T ≤ 0 时配小字"分子仍在振动，动画已放大显示"（防"绝对零度误解"，黄队话术定稿）。

## P10 · spring-shm（弹簧振子）

调劲度系数 k、质量 m，看弹簧振子振动；周期 `T=2π√(m/k)` 实时显示；x-t 图像同步描点。
适用课型：**八下 · 机械运动拓展 / 高中 · 简谐运动**（周期与 k、m 的关系）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `k` | object | ✅ | — | 劲度系数滑块 `{min, max, step, init}`（N/m，>0） |
| `m` | object | ✅ | — | 质量滑块 `{min, max, step, init}`（kg，>0） |
| `dragAmp` | boolean | — | `true` | 振子可拖拽改振幅（松手即从该位置释放，初相位=0） |
| `showXTGraph` | boolean | — | `true` | 是否显示 x-t 联动图像（下方小画布，同步描点） |
| `showEquation` | boolean | — | `true` | 是否显示 `T = 2π√(m/k) = … s` 实时验算行（MathML） |
| `damping` | boolean | — | `false` | 是否开阻尼演示；`true` 时仅定性"振幅渐小"示意，不做阻尼方程数值解（降级声明） |

- 振动：解析解 `x = A·cos(ωt)`，`ω = √(k/m)`；动画用归一化时间（`T` 过大/过小时调速并标注"动画已调速"）。
- 平衡位置：`--phy-track` 灰虚线 + `O` 文字；振幅：双箭头线段 + 读数 `A = …`。
- x-t 图：`--phy-wave-a` 实线描点（≤300 点），当前时刻游标线。

### 示例

```js
interaction: {
  type: "spring-shm",
  params: {
    k: { min: 10, max: 200, step: 10, init: 50 },
    m: { min: 0.5, max: 5, step: 0.5, init: 1 },
    dragAmp: true, showXTGraph: true, showEquation: true
  }
}
```

### 输入 / 输出

- 输入：k/m 滑块；拖振子改振幅。
- 输出：振动动画 + x-t 曲线同步描点 + 周期读数实时更新。

### 触控要求

- 振子拖拽手柄 ≥ 6 逻辑单位；滑块 ≥ 44px；
- 调参后振动自动从新振幅/新周期重起（不许"参数变了动画还按旧周期跑"）。

### 深色模式

- 弹簧 `--phy-body`；平衡线 `--phy-track`；x-t 曲线 `--phy-wave-a`；自动跟随。

### 双编码

- 平衡位置：虚线 + `O` 文字；振幅：双箭头 + 读数；周期：公式 + 数值。

### 复用几何

- "一量变多视图同步"复用代数 `linked-dashboard`（振子 + x-t 图 + 读数三联动）；
- x-t 描点复用代数 `plot-points` 的逐点绘制。

### 黄队接口（先动手后结论）

- 动手：固定 m，只把 k 调大 → 现象：振动变快、T 读数变小 → 结论："弹簧越硬（k 越大），振动越快"。
- 动手：固定 k，把 m 调大 → 现象：振动变慢 → 结论："质量越大越'懒得'改变运动状态，周期越长"。
- 对比动手：k×4 与 m×4 各试一次 → 现象：T 变化倍数都是 2 → 结论点题："T 只跟 m/k 的比值有关"（呼应公式）。

### 蓝队评审

- ✅ **可实现**：SHM 解析解，零数值积分；x-t 图逐点绘制（≤300 点）；Canvas/SVG 均可。
- ❌ **降级声明**：阻尼振动只做定性"振幅渐小"示意，不做阻尼微分方程数值解；受迫振动/共振不做（另起页）。
- 离线预计算：x-t 曲线点列（调参时重算，<1ms）。
- 性能风险：无。

### 常见坑

1. **T 极端值调速标注**：k=200、m=0.5 时 T≈0.31s 看不清，k=10、m=5 时 T≈4.4s 等太久——渲染器归一化动画速度，角落常驻"动画已调速，非真实时间"。
2. **拖振幅即释放**：`dragAmp` 松手后从当前位置开始振动（初相位 0），不要回弹到旧振幅。
3. **`damping: true` 的文案**：写"振幅慢慢变小（示意）"，不写"阻尼系数 γ=…"（没真算）。

## Y1 · guess-verify（先猜后验）

页面级 widget：交互实验页配"猜一猜"——学生先点选预测，再动手验证。
适用：全书交互实验页通用（pedagogy 2.3"先猜后验"）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `question` | string | ✅ | — | 猜测题干（≤ 30 字，如"拉力再大一点，木块会怎样？"） |
| `options` | array | ✅ | — | 2–4 个选项（字符串数组） |
| `recordKey` | string | ✅ | — | 记录键，字段名冻结为 `phy_guess_<课号>`（如 `phy_guess_p05.2.1`），供学习报告读取 |
| `showAfter` | string | — | `"manual"` | 固定 `"manual"`：学生手动点"动手验证"后才可看到现象，不自动揭晓 |

- 铁律：**不判对错、无红叉**——只记录选项，供后续学习报告用；答"错"不给负反馈。
- localStorage 禁用时降级为内存记录，不报错、不阻断页面。
- 布局：交互区上方一句话题干 + 选项横排（触摸目标 ≥ 44px）；验证后该条折叠，不占屏。


### 蓝队评审

- ✅ **可实现**：纯 DOM 组件，无 Canvas；记录写 localStorage（key 即 `recordKey`）。
- ❌ **明确不做**：判分、排行榜、答案解析自动生成（解析由黄队写进点拨区）。

## Y2 · read-gauge（仪表读数练习器）

刻度尺 / 温度计 / 电流表 / 电压表 / 天平游码的读数练习：视线、量程、估读、试触。
适用课：p00.1.3、p03.1.1、p04.1.1、p08.1.4。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `gauge` | string | ✅ | — | 枚举：`ruler`（刻度尺）/ `thermometer`（温度计）/ `ammeter`（电流表）/ `voltmeter`（电压表）/ `balance`（天平游码） |
| `range` | object | ✅ | — | 量程 `{min, max, unit}`（如 `{min: -20, max: 120, unit: "℃"}`） |
| `divisions` | number | ✅ | — | 分度值（如 1℃、0.1A）；`estimate` 为真时估读到分度值下一位 |
| `estimate` | boolean | — | `true` | 是否要求估读到分度值下一位 |
| `eyeLine` | boolean | — | `true` | 视线练习：俯视/仰视/平视三选一，选错给提示（不判错） |
| `trialTouch` | boolean | — | `false` | 仅电流表：两步流程——大量程试触 → 选合适量程；其他仪表忽略 |
| `tolerance` | string | — | `"1division"` | 容差：分度值 × 1（±1 个分度值内算读对） |

- 降级边界：试触**不做真实电路仿真**（只走"选量程"流程）；天平游码 = 线性拖拽；温度计零下 = 符号 + 读数双练。
- 口径标注：**v1.0，生产前黄队可微调**。

### 示例

```js
interaction: {
  type: "read-gauge",
  params: {
    gauge: "thermometer",
    range: { min: -20, max: 120, unit: "℃" },
    divisions: 1, estimate: true, eyeLine: true,
    tolerance: "1division"
  }
}
```

### 蓝队评审

- ✅ **可实现**：SVG 刻度绘制 + 拖拽/点选读数；五种仪表共用刻度引擎，表盘皮肤按 `gauge` 切换。
- 降级：`trialTouch` 只做流程（试触→换量程），不解电路方程。

### 常见坑

1. **估读只到下一位**：`estimate:true` 时读数输入框只多一位小数，多写不算对（文案写清"估读一位"）。
2. **电流表试触顺序**：必须先大量程试触，直接小量程接入要出提示（教学规范，不是真烧表）。

## Y3 · formula-id（公式身份证卡片）

## Y4 · graph-reader（图像三读法）

物理图像通用读数器：点"读斜率 / 读面积 / 读截距"分步点亮，面积配分割求和慢动作。
适用：p11.2.2（首秀）、p14.1.1、p08.2.3、p16.1.2。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `source` | object | ✅ | — | 数据源 `{kind, expr/points, xLabel, yLabel}`；`kind` 枚举：`function`（解析式，用 `expr`）/ `points`（散点，用 `points` 数组） |
| `steps` | array | — | 全开 | 三读法子集可配：`"slope"`（读斜率）/ `"area"`（读面积）/ `"intercept"`（读截距）的子集 |
| `areaSlices` | number | — | `40` | 面积分割慢动作的切片数（钳制 ≤ 60） |

- 斜率：只在直线段给精确值；曲线段标注"近似"（切线斜率示意）。
- 面积：跨横轴时分段着色 + 正负文字说明（话术占位"黄队定"）。
- 定位：降级方案——复杂图像仍可用 P2/P10 等专用交互，本组件保底通用。

### 示例

```js
interaction: {
  type: "graph-reader",
  params: {
    source: { kind: "function", expr: "v = 2*t + 1", xLabel: "t/s", yLabel: "v/(m/s)" },
    steps: ["slope", "area", "intercept"],
    areaSlices: 40
  }
}
```

### 蓝队评审

- ✅ **可实现**：`kind:"function"` 解析表达式求值描点；`kind:"points"` 直接连线；面积分割为 Canvas 矩形条动画（复用 P2 `plot-points` 面积分割范式）。
- 降级：`areaSlices` 超 60 钳制并 console 告警。

### 常见坑

1. **"近似"必须写**：曲线段斜率不给精确数字，只标"近似" + 切线示意（防学生当成精确值抄）。
2. **面积正负**：跨轴部分用两种着色 + 文字"轴上为正/轴下为负"（话术黄队定稿前用占位）。

### 读数徽章组件 spec（冻结）

> pedagogy 1.1 第 6 条铁律（现象中找不变）的落地组件。全书统一实现，spec 冻结：

```js
readoutBadge: {
```

### 12.2 主动降级项（一句话版）

1. **P3 电路拓扑**：⬇ 主动降级（教学聚焦）——"任意拓扑通用求解"降级为单回路串联解析 + 固定双支路并联模板，元件 ≤ 8；多电源/混联不做。（真实理由：技术上可实现，但初中教学不需要，QA 成本过高。）**2026-10-15 修订**：滑动变阻器连续调阻已实现为 P3 `rheostat` 元件（滑片拖动→接入电阻连续变化→电流表读数实时联动，初值取阻值最大处），电压表实现为 `voltmeter` 元件（探头语义，不进回路拓扑）。
2. **P8 场可视化**：⬇ 主动降级（教学聚焦）——3D 场可视化降级为 2D 平面切片；电荷 ≤ 4；运动电荷辐射场不做；场线拖动中不重算、松手后重算。（真实理由：零依赖/file:// 约束下 ROI 为负。）
3. **P9 热学粒子**：⬇ 主动降级（教学聚焦）——真实分子动力学降级为"速率 ∝ √T 随机圆点"示意；粒子 ≤ 400；无粒子间碰撞；相变潜热平台不做（另起页）。（真实理由：零依赖/file:// 约束下 ROI 为负。）
4. **P7 碰撞**：⬇ 主动降级（教学聚焦）——二维碰撞降级为统一一维沿 x 轴解析解。（真实理由：技术上可实现，但初中教学不需要，QA 成本过高。）
5. **P4 光路**：⬇ 主动降级（教学聚焦）——波动光学降级为只做几何光线；衍射/干涉/色散不做。（真实理由：技术上可实现，但初中教学不需要，QA 成本过高。）
6. **P5 波**：⬇ 主动降级（教学聚焦）——超声发声与真实音色降级为发声钳制 20–2000Hz；驻波只做两列波叠加示意。（真实理由：技术上可实现，但初中教学不需要，QA 成本过高。）
7. **P10 阻尼**：⬇ 主动降级（教学聚焦）——阻尼方程数值解降级为 `damping` 仅定性"振幅渐小"示意。（真实理由：技术上可实现，但初中教学不需要，QA 成本过高。）

## §14 与黄队教学的接口：教学动作链

黄队铁律"先动手后结论"——每种交互标注的"动手 → 现象 → 点题"链路（详见各 P 章节"黄队接口"）：

| 编号 | 动手（学生先做） | 现象（看到什么） | 点题（结论句方向，黄队定稿） |
|---|---|---|---|
| P1 | 拖拉力 T 从 0 加大 | F合从 0 变大，"静止"→"向右加速" | 合力决定运动状态 |
| P2 | 固定 v₀，θ 从 15° 调到 75° | 45° 射程读数最大 | 同样力气，45° 最远 |
| P3 | 开关断开→闭合；导线直连电源 | 灯不亮→亮；"短路！"警告 | 闭合才有电流；短路绝不允许 |
| P4 | 光源从远处往透镜拖；物距 < f | 像由小变大；同侧虚像 | 物距越小像越大；放大镜 u<f |
| P5 | 只调频率 / 只调振幅 | 波形变密+音调高；波形变高+更响 | 频率定音调，振幅定响度 |
| P6 | 支点 O 往阻力端拖；定/动滑轮切换 | F₁ 变小"省力"；拉力减半 | 支点近重物省力；动滑轮省一半力 |
| P7 | 等质量 e=1 对心撞；m₁ 调大 | 交换速度；②车更快 | 动量从①传给②；大撞小传递彻底 |
| P8 | 单正电荷→加负电荷；转磁铁 | 场线放射→弯向负极；磁针跟转 | 电场线起于正止于负；磁针 N 极指磁场方向 |
| P9 | 加热到 100℃；0℃ 附近拨动 | 粒子加速、液→气；固/液徽章跳 | 温度是分子热运动剧烈程度的标志 |
| P10 | k 调大 / m 调大 | T 变小 / T 变大 | k 大振动快，m 大周期长；T 只跟 m/k 有关 |

**接口约定**：
1. 黄队写页时，每页配 `exploreTip`（≤40 字动手提示）+ 现象观察点 + 结论徽章文案；蓝队保证"动手动作"在 params 里可配（如 P4 `rays` 子集、P7 `restitution` 锁定）。
2. 黄队若提出本文件未覆盖的教学动作（如"先猜后验"的猜测输入框），走增补流程：白队先做压力预估 → 蓝队评估 → 修订本文件版本号，不直接改渲染器。
3. 协作铁律：黄队教学需求不妥协——凡 §14 链路需要的 params 能力，蓝队必须提供或给出书面降级替代方案（见 §12.2）。
