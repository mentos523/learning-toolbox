# 白队前端检查清单（英语页）

每次数据扩词或 UI 改动后，白队按此清单执行视觉与布局检查。

## 一、词素高亮

- [ ] 全库扫描：每个单词的词根变体必须在拼写中可见（`heroWordHtml` 能匹配）
- [ ] 分隔符"·"统一：词素前后有其他词素时必须有"·"（react→re·act）
- [ ] 整词匹配时不加多余"·"
- [ ] 多变体时取最长匹配

## 二、拨盘布局（一屏，无滚动）

- [ ] `.dial-mean` 固定高度，必须容纳全库最大词义数（当前：2 义 → 5em）
- [ ] 新增词根后检查：是否有超过当前最大词义数的词根
- [ ] 多义词根切换时，拨轮位置不动（不被挤压）
- [ ] 三端（1400/900/390px）均一屏，无页面滚动，无横向溢出

## 三、拨盘交互

- [ ] 快速滚动无卡顿、无错乱
- [ ] 卡塔音效：每次落定响一声，初始加载静默
- [ ] 卡入动画：选中项回弹 0.18s
- [ ] 移动端震动：navigator.vibrate 生效，桌面端跳过

## 四、数据一致性

- [ ] 词根数、单词数与提交说明一致
- [ ] 音标覆盖率 100%（缺失时 UI 自动隐藏音标行）
- [ ] 按词频排序（词根内单词降序、词根按最高频词）

## 五、降级

- [ ] `phon.js` 缺失时正常显示
- [ ] localStorage 禁用时正常
- [ ] `file://` 直接打开正常

## 历史问题归档

- v15：多义词根撑高 `.dial-mean` 挤压拨轮 → 固定高度 5em
- v16：分隔符"·"前后缀不一致 → `heroWordHtml` 统一
- v17：底部朗读栏挤压词义区 → 移至顶部 header
- 数据补丁：12 个词素不可见词补音变变体（number/course/center/voice/peace/content/letter/reign/promise/destroy/exist）
