### 0.2 化学专属色板映射 `--chm-*`

化学**不另起色板**：定义 `--chm-*` 语义变量，值全部别名 `--geo-*`（浅色/深色两套色值自动跟随几何的深色切换，无需另写深色值）。

```css
:root {
  --chm-known:    var(--geo-known);    /* 已知量：蓝 —— 已知质量、已知浓度、已知 pH */
  --chm-target:   var(--geo-target);   /* 待求量：朱红 —— 待求质量、可调配平系数（加粗） */
  --chm-cation:   var(--geo-target);   /* 阳离子：朱红 + "+" 文字（如 Na⁺） */
  --chm-anion:    var(--geo-known);    /* 阴离子：蓝 + "−" 文字（如 Cl⁻） */
  --chm-metal:    var(--geo-corr-a);   /* 金属（区）：橙 + "金"角标/图例文字 */
  --chm-nonmetal: var(--geo-corr-b);   /* 非金属（区）：天蓝 + "非"角标/图例文字 */
  --chm-acid-tag: var(--geo-target);   /* 酸性标签：朱红 + "酸性"文字（试纸/指示剂旁） */
  --chm-base-tag: var(--geo-known);    /* 碱性标签：蓝 + "碱性"文字 */
  --chm-oxidizer: var(--geo-corr-b);   /* 氧化剂：天蓝 + "氧化剂"文字（得电子者，与 C10 得电子同色） */
  --chm-reducer:  var(--geo-corr-a);   /* 还原剂：橙 + "还原剂"文字（失电子者，与 C10 失电子同色） */
  --chm-reactant: var(--geo-known);    /* 反应物：蓝（方程式左侧） */
  --chm-product:  var(--geo-target);   /* 生成物：朱红（方程式右侧） */
  --chm-electron: var(--geo-corr-b);   /* 电子：天蓝小点 + e⁻ 文字 */
  --chm-lose-e:   var(--geo-corr-a);   /* 失电子/化合价升高：橙 + ↑ + "升高/失"文字 */
  --chm-gain-e:   var(--geo-corr-b);   /* 得电子/化合价降低：天蓝 + ↓ + "降低/得"文字 */
  --chm-apparatus: var(--geo-line);    /* 实验仪器描边：常规色 */
  --chm-vapor:    var(--geo-aux);      /* 气体/烟雾示意：灰（+ ↑ 文字/箭头） */
  --chm-highlight: var(--geo-highlight); /* 高亮闪烁：黄（配深色字） */
}
```

映射问答：

- **阳离子/阴离子 = ？** 朱红 + "+" / 蓝 + "−"（沿用物理正负电荷约定 `--phy-charge-pos/neg`，跨学科一致）。
- **金属/非金属 = ？** 橙 / 天蓝（corrA/corrB），**必须配"金"/"非"角标 + 图例文字**（C4 周期表分区）。
- **酸/碱指示剂色 = ？** 指示剂**真实颜色按化学事实渲染**（石蕊酸红/碱蓝、酚酞碱红、pH 试纸按标准比色卡），**不套用 `--chm-*`**；但旁边必须配 `--chm-acid-tag`/`--chm-base-tag` 文字徽章（"酸性"/"碱性"/"变红"/"变蓝"），**绝不只靠颜色**（色盲 + 深色模式）。
- **氧化剂/还原剂 = ？** 天蓝（得电子者）/ 橙（失电子者），与 C10 电子追踪的得/失色一致，文字标签必备。
- **反应物/生成物 = ？** 蓝（左）/ 朱红（右），中间等号 + 反应条件文字。
- **微观粒子 = ？** 原子画"球 + 元素符号文字"（双编码）；球色遵循教科书惯例（H 白/浅灰、O 红、C 深灰/黑、N 蓝、Cl 绿），**每个球必须带元素符号文字**（深色模式下深色球描边加粗一档）；**原子大小不按真实比例时，页内必须注明"示意，未按比例"**（见 §15 B4 统一文案）。

### 0.3 全局铁律（化学页同样执行）

1. `params` 里**不出现具体色值**，只用 `--chm-*` 语义名；深色模式自动切换（别名机制，渲染器不重绘画布）。
2. **逻辑单位 0–100**（y 向上），不写死 px；触摸手柄半径 ≥ 6 逻辑单位（≈44px @ 390px 画布），热区再外扩 50%。
3. 反馈走 M6：吸附/落定/状态切换**视觉必选**（flash/ripple），`navigator.vibrate` 与合成音效为可选加分项。
4. 双编码：离子 = 颜色 + 电荷符号文字（Na⁺/Cl⁻）；化合价升降 = 颜色 + ↑↓ + 文字；酸碱性 = 颜色 + "酸性/碱性"文字；状态（固/液/气）= 颜色 + 文字徽章 + 粒子排布形态，**绝不只靠颜色**。
5. 读数行一律走 MathML（化学量符号斜体，如 *w*、*c*、*pH* 无单位），单位与数值同行（g、mL、mol/L），不许裸文本；化学式下标用 `<msub>`（H₂O），离子电荷数在前（Mg²⁺）。
6. 讲解页口径沿用几何：`pageKind: "explain"` + 全页 ≤300 字 + 点拨区 36vh 内滚动；交互页 ≤150 字。
7. 化学用语铁律（审计清单第 11 条）：方程式用**等号**不用箭头（可逆反应 ⇌ 除外）；↑↓ 只用于溶液中的气体 / 反应物中无固体的沉淀；页内化学式/方程式由渲染器统一走 MathML，不许手写裸文本。

## C1 · particle-view（微观粒子视角）

看固/液/气三态下粒子的排布与运动；调温度滑块，粒子运动快慢实时跟随，跨过熔/沸点时三态徽章切换。
适用课型：**cm03.1.1 分子与原子（上）**（分子运动/间隔/扩散）；**cm09.1.1 溶液的形成**（蔗糖溶解微观）；
**cm01.1.1**（水沸腾 vs 水电解对比页的"物理变化分子种类不变"演示）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `substance` | object | ✅ | — | 物质：`{name（如"水"), meltC（熔点℃), boilC（沸点℃)}`；熔/沸点决定徽章切换阈值 |
| `temp` | object | ✅ | — | 温度滑块 `{min, max, step, init, unit}`（如 `{min:-20, max:120, step:5, init:20, unit:"℃"}`） |
| `particleCount` | number | — | `120` | 粒子数（钳制 ≤ 400，见蓝队评审） |
| `stateMode` | string | — | `"auto"` | `"auto"`（按温度与熔/沸点自动判定三态）/ `"fixed-solid"` / `"fixed-liquid"` / `"fixed-gas"`（锁定某一态做排布对比） |
| `heatButtons` | boolean | — | `true` | 是否显示"加热 🔥 / 制冷 ❄"长按按钮（与滑块双向同步，手机友好） |
| `showScaleNote` | boolean | — | `true` | 是否显示"示意，未按比例"声明（默认 true，不可关闭） |

- 粒子模型（示意）：速率 `∝ √T`（T 取开尔文，内部换算）；固态 = 格点附近振动（配小字"振动已放大显示"）；
  液态 = 较密无序平动；气态 = 稀疏高速；边界弹性反射；不做粒子间作用力（降级声明）。
- 三态徽章：文字（"固态"/"液态"/"气态"）+ 排布形态图标（❄/💧/☁️ 为装饰，文字为主）+ 物质名
  （如"固态（冰）"）；跨过熔/沸点时徽章 flash（M6）；滑块在熔/沸点处刻度线高亮。

### 示例

```js
interaction: {
  type: "particle-view",
  params: {
    substance: { name: "水", meltC: 0, boilC: 100 },
    temp: { min: -20, max: 120, step: 5, init: 20, unit: "℃" },
    particleCount: 120, stateMode: "auto", heatButtons: true
  }
}
```

### 输入 / 输出

- 输入：温度滑块 / 长按加热·制冷按钮；`stateMode` 为 fixed 时为三态切换按钮。
- 输出：粒子运动动画（速率实时跟随温度）+ 温度读数（MathML，*T* = … ℃）+ 三态徽章切换。

### 触控要求

- 滑块轨道点击区高度 ≥ 44px；加热/制冷按钮 ≥ 56px（长按操作宜更大）；
- 熔/沸点刻度线为只读标记（不可拖），避免与"调温度"混淆。

### 深色模式

- 粒子 `--chm-known`（蓝）或按物质配 `--chm-*` 语义色，深色自动提亮；容器 `--chm-apparatus`（深色近白描边）；
- 徽章文字走 `--geo-text`。

### 双编码

- 三态：文字徽章 + 粒子排布形态（固=规则排列、液=较密无序、气=稀疏）——关掉颜色仍能凭排布认出三态；
- 温度：数字读数 + "加热/制冷"文字按钮。

### 复用几何

- 粒子引擎复用物理 P9 `thermo-sim`（速率 ∝ √T、边界反射、Canvas 粒子层）；
- 滑块范式复用代数 `slider-lab`；三态静态讲解页可用 `step-play`（固→液→气三帧）。

### 黄队接口（先动手后结论）

- 动手：从 20℃ 长按加热到 100℃ → 现象：粒子越跑越快、徽章从"液态（水）"跳"气态（水蒸气）" → 结论点题："温度越高，分子运动越剧烈——这就是'热'的微观样子"。
- 动手：`stateMode` 切三态对比 → 现象：固态排布整齐、气态稀疏乱跑 → 结论："三态差别不在分子本身，在排布和运动"（呼应红线辨析③：物理变化分子种类不变）。

### 蓝队评审

- ✅ **可实现**：原生 JS + Canvas 2D + MathML（读数行），零依赖；粒子引擎与 P9 同构，可直接复用渲染器模块。
- 离线预计算：无（每帧 O(n) 更新）。
- 性能红线：`particleCount` 钳制 ≤ 400；**低端机建议 ≤ 200**（渲染器按设备启发式自动降档，不暴露 params）。

### 常见坑

1. **"示意，未按比例"必须写**：粒子大小/数量/速度均非真实，`showScaleNote` 默认 true 不可关（见 §15 B4）。
2. **"以水为例"必须写**：0℃/100℃ 是水的熔/沸点；换 `substance` 时阈值与徽章文案同步换。
3. **固态粒子也要动**：格点振动 + 小字"分子永不停息运动，振动已放大显示"（防"固体分子静止"误解）。
4. **与 P9 的分工**：C1 化学侧重"三态排布 + 分子种类不变"，P9 物理侧重"温度—速率定量关系"；两页文案不许互相矛盾。

## C2 · molecule-build（分子模型拼搭）

从原子托盘拖原子球到画布，拼出目标分子；成键数实时校验（H 只能 1 键、O 2 键、C 4 键），超键即警告。
适用课型：**cm04.2.1 化学式（上）**（H₂O 四层含义、红线辨析①"下标是身份证"立靶）；
**cm14.3.1 化学键（上）**（H₂/HCl/Cl₂ 共用电子对）；**cm17.1.1**（甲烷正四面体结构）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `target` | object | — | — | 目标分子（`mode:"target"` 时必填）：`{formula（如"H₂O"), atoms:{H:2,O:1}, bonds:[["O","H"],["O","H"]]}` |
| `mode` | string | — | `"target"` | `"target"`（拼出指定分子）/ `"free"`（自由拼搭，只做成键数校验） |
| `tray` | array | ✅ | — | 原子托盘：每项 `{element（如"H"), count, maxBonds（如 1)}`；`maxBonds` 为成键数上限 |
| `bondLength` | number | — | `14` | 键长（逻辑单位，建议 12–16） |
| `showTetraHint` | boolean | — | `false` | 是否显示正四面体提示（如 CH₄ 页：109.5° 键角示意虚线） |

- 拼搭：拖原子球到画布；两球中心距 < 8 逻辑单位时吸附成键（M6 ripple）；点已成键可断开（拖回托盘删除）。
- 成键数校验：某原子成键数 > `maxBonds` 时，该原子 flash + 警告条"氢（H）只能形成 1 个共价键"（元素名+符号+上限，黄队可配文案）。
- 目标判定（`mode:"target"`）：原子种类/数目/连接关系与 `target` 一致 → "拼搭成功 ✓" + 分子式徽章（MathML 下标）。

### 示例

```js
interaction: {
  type: "molecule-build",
  params: {
    target: { formula: "H₂O", atoms: { H: 2, O: 1 }, bonds: [["O","H"],["O","H"]] },
    mode: "target",
    tray: [
      { element: "H", count: 4, maxBonds: 1 },
      { element: "O", count: 2, maxBonds: 2 }
    ]
  }
}
```

### 输入 / 输出

- 输入：拖原子球到画布 / 拖近成键 / 拖回托盘删除 / 点键断开。
- 输出：分子结构实时成形 + 成键数校验警告 +（目标模式）拼搭成功徽章。

### 触控要求

- 原子球半径 ≥ 6 逻辑单位（约 44px），热区外扩 50%；
- 成键吸附阈值 8 逻辑单位（手指好操作）；键为只读显示（点键弹出"断开"按钮 ≥44px，不直接点细线）。

### 深色模式

- 球色按教科书惯例 + 元素符号文字（深色下 C 黑球转近白描边、描边加粗一档）；
- 键棍 `--chm-apparatus`（深色近白）；警告文字走 `--geo-text`。

### 双编码

- 原子：颜色 + 元素符号文字（H/O/C 必有文字，灰度可辨）+ 球大小级差（**注明"示意，未按比例"**）；
- 成键：棍 + 键数读数（"O 已成键 2/2"）；超键：flash + 文字警告，不只靠红色。

### 复用几何

- 拖放 + 吸附 + 落定锁定复用几何 `cut-reassemble`（散块 → 原子球，目标轮廓 → 成键位）；
- "一键拼好"兜底可复用为"看示范拼法"（`autoAssemble` 同构）。

### 黄队接口（先动手后结论）

- 动手：给 H×4、O×2，目标 H₂O → 现象：拼出两个水分子、O 的键数 2/2 顶满 → 结论点题："H₂O 里 2 是下标——一个水分子里有 2 个氢原子，改了它就不是水了"（红线辨析①）。
- 动手：故意给 O 连 3 个 H → 现象：超键警告 → 结论："氧只能形成 2 个共价键——成键数是元素的'脾气'"。

### 蓝队评审

- ✅ **可实现**：原生 JS + SVG（球/棍/吸附）+ MathML（分子式），零依赖；成键判定为距离阈值 + 计数器，纯前端。
- 离线预计算：无。
- 性能红线：单分子原子数 ≤ 12；**明确不做**有机大分子、配合物、大π键（cm20/cm21 另起静态页）。

### 常见坑

1. **球大小注明"示意，未按比例"**：真实原子半径比（H:O ≈ 0.37）画出来没法看，教学球大小只分档，声明必须有。
2. **NaCl 不能用 C2 拼**：离子化合物无分子概念；NaCl 形成用 C7 粒子动画页，C2 页内要有一句"离子化合物不拼分子"（防概念混淆，审计清单第 5 条）。
3. **甲烷必须给正四面体提示**：平面画法会让学生以为 CH₄ 是平面正方形（cm17.1.1 误区）；`showTetraHint:true` 时画 109.5° 示意。
4. **成键数 ≠ 化合价**：警告文案写"形成 N 个共价键"，不写"化合价是 N"（cm04.2.2 误区：化合价与成键相关但概念不同）。

## C3 · equation-balance（方程式配平交互）

调系数步进器配平方程式；**只能调系数、不能改下标**——点下标会触发红线警告
"⚠ 下标是物质的身份证，改了它就是另一种物质"；配平成功后做质量守恒称量动画。
适用课型：**cm05.1.2 化学方程式（上）**（配平铁律立靶）；**cm05.1.3 化学方程式（下）**
（配平闯关：H₂+O₂→H₂O、Fe₂O₃+CO 等）；**cm12.2.2**（氧化还原配平·电子守恒版）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `equation` | object | ✅ | — | `{reactants:[{formula, atoms:{H:2}}], products:[...], conditions（如"点燃"), reversible:false}`；`atoms` 为该物质的原子组成（锁定，不可改） |
| `coeffInit` | array | — | 全 1 | 系数初值（与反应物+生成物总数等长） |
| `coeffMax` | number | — | `9` | 系数上限（1–9 步进） |
| `trapSubscript` | boolean | — | `true` | 下标陷阱开关：`true` 时下标可点，点击弹红线警告（教学陷阱，黄队可配 `trapText`） |
| `trapText` | string | — | 占位 | 下标警告文案（默认占位"待黄队定"，生产前必须定稿，见 §15 B5） |
| `mode` | string | — | `"normal"` | `"normal"`（原子守恒）/ `"redox"`（加"得失电子守恒"第二检查行） |
| `answer` | array | — | — | 标准答案系数（黄队配；多组解时配最小整数比，见 §15 B1） |
| `showWeigh` | boolean | — | `true` | 配平成功后是否播放质量守恒称量动画（天平：反应前总质量 = 反应后总质量） |

- 配平区：每个化学式前配 `−`/`+` 系数步进器（`--chm-target` 朱红加粗，"可调"双编码）；
  下标数字常规色 + 锁形小标（`trapSubscript:true` 时可点，affordance 见 W-C8）。
- 原子计数表：每种元素一行，左右原子数实时对照（`--chm-reactant` 蓝 / `--chm-product` 朱红 + 数字）；
  全部相等 → "配平成功 ✓"徽章（蓝绿 + 文字）+ 称量动画。
- `mode:"redox"` 时加第二行"得电子总数 = 失电子总数 = … e⁻"（MathML），两行全 ✓ 才算成功。
- 称量动画：SVG 天平，左右托盘分别标注"反应前" / "反应后"总质量（相对质量，用原子个数×示意质量，黄队配），
  天平平衡 + "质量守恒 ✓"（注：开放体系气体逸散页配文案"称的是密闭体系"，审计清单第 1 条）。

### 示例

```js
interaction: {
  type: "equation-balance",
  params: {
    equation: {
      reactants: [{ formula: "H₂", atoms: { H: 2 } }, { formula: "O₂", atoms: { O: 2 } }],
      products: [{ formula: "H₂O", atoms: { H: 2, O: 1 } }],
      conditions: "点燃"
    },
    coeffInit: [1, 1, 1], coeffMax: 9, trapSubscript: true,
    trapText: "⚠ 下标是物质的身份证——把 H₂O 改成 H₂O₂，它就变成双氧水，不再是水了！配平只能调系数。",
    mode: "normal", answer: [2, 1, 2], showWeigh: true
  }
}
```

### 输入 / 输出

- 输入：`−`/`+` 步进器调系数；点下标（陷阱）→ 红线警告；"检查"按钮。
- 输出：原子计数表实时更新 + 配平成功徽章 + 质量守恒称量动画；调系数落定 M6 flash。

### 触控要求

- 系数步进按钮 ≥ 44px；防连击（300ms 去重，见 W-C2）；
- 下标点击热区 ≥ 44px（陷阱也要好点），affordance：虚线下划线 + 锁形小标（见 W-C8）。

### 深色模式

- 可调系数 `--chm-target`（深色提亮朱红 + 加粗）；锁定下标 `--geo-line`（深色近白）+ 锁标；
- 警告徽章 `--geo-target` 底 + ⚠ + 文字（不只靠红色）。

### 双编码

- 系数：朱红 + 加粗 + 数字（"可调"）；下标：常规色 + 锁形标（"不可改"）；
- 配平成功：蓝绿 + "✓ 配平成功"文字；原子计数：元素符号 + 左右数字对照。

### 复用几何

- 不变量徽章范式复用代数 `ratio-slider`（左右原子数相等 ✓）；
- 步进器复用 `slider-lab` 的 `−`/`+` 精调按钮约定。

### 黄队接口（先动手后结论）

- 动手：学生先试着点 H₂O 的"2" → 现象：红线警告弹出 → 动手调系数 2、1、2 → 现象：计数表 H:4=4、O:2=2，称量动画天平平衡 → 结论点题："配平只能调系数，绝不改下标——下标是物质的身份证"（全书第一铁律，cm05.1.2）。
- 氧化还原页动手：`mode:"redox"` 配平 CuO+H₂ → 现象：原子行 ✓ 后电子行还差 → 结论："氧化还原配平，电子守恒说了算"。

### 蓝队评审

- ✅ **可实现**：原生 JS + DOM/SVG + MathML（方程式/计数表），零依赖；原子计数为查表求和，纯前端实时计算。
- 离线预计算：标准答案系数（黄队配，见 §15 B1 多组解口径）；称量动画为 SVG 关键帧，无物理仿真。
- 性能红线：无（DOM 量小）。

### 常见坑

1. **多组解判定**：2H₂+O₂→2H₂O 与 4H₂+2O₂→4H₂O 都"配平"了——判定口径见 §15 B1（默认：任一使各元素左右相等且系数为正整数的解都算对，另给"最简整数比"徽章）。
2. **系数禁 0/禁负**：步进器下限 1；`coeffMax` 钳制 9。
3. **↑↓/反应条件不参与判定**：是静态文本（审计清单第 11 条规范），不要做成可调参数。
4. **C10 双线桥不进 C3**：电子转移箭头画法是 C10 的事；C3 的 `redox` 模式只做"得失电子数相等"第二检查行。
5. **陷阱文案必须黄队定稿**：默认占位不可进生产（见 §15 B5）；陷阱是教学设计，不是 bug——页内要有一句"试试点一下下标？"的引导（`exploreTip`）。

## C4 · periodic-explore（周期表探索）

点元素格看原子结构示意图 + 基本性质；族/周期/金属-非金属分区高亮；递变规律箭头演示。
适用课型：**cm03.2.2 元素**（点元素看质子数/符号）；**cm14.1.2 元素周期表**（编排原则、周期/族）；
**cm14.2.1 元素周期律（上）**（原子半径/金属性递变箭头）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `range` | array | — | `[1, 20]` | 元素范围 `[起, 止]`（≤ 36；1–20 为初中版，21–36 高中版） |
| `highlightMode` | string | — | `"none"` | `"none"` / `"period"`（按周期着色）/ `"group"`（按族着色）/ `"metal"`（金属/非金属分区） |
| `trendArrows` | boolean | — | `false` | 是否显示递变箭头（如"同周期从左到右原子半径减小 →"）；`true` 时需配 `trend` 文案 |
| `trend` | string | — | — | `trendArrows:true` 时必填（一句话，如"同周期从左到右，原子半径逐渐减小"） |
| `showDetail` | boolean | — | `true` | 点选后是否显示详情卡（原子结构示意图 + 质子数/核外电子数/相对原子质量） |

- 元素数据：1–36 号内嵌（`window.CHEMISTRY_ELEMENTS`，字段见 §15 B11）；点格 → 详情卡。
- 原子结构示意图：同心圆（电子层）+ 电子点；1–20 号按 K/L 层 2/8 规则；21–36 号注明"排布规则更复杂（能级交错），此处为简化示意"。
- 分区着色：金属 `--chm-metal`（橙）/ 非金属 `--chm-nonmetal`（天蓝），每格配"金"/"非"角标 + 图例文字（双编码）。

### 示例

```js
interaction: {
  type: "periodic-explore",
  params: {
    range: [1, 20], highlightMode: "metal", trendArrows: false, showDetail: true
  }
}
```

### 输入 / 输出

- 输入：点元素格；分区模式切换；递变箭头开关。
- 输出：详情卡（原子结构示意图 + 质子数/电子数/相对原子质量）+ 分区着色 + 图例。

### 触控要求

- 390px 下 18 列网格单格约 20px —— **补偿交互**（见常见坑 1）：点选后详情卡带"←/→"切换相邻元素按钮（≥44px），
  滑动详情卡也可切换；元素格热区外扩至 44px（重叠时取最近格心）。
- 分区模式切换按钮 ≥ 44px。

### 深色模式

- 分区色 `--chm-metal`/`--chm-nonmetal` 深色自动提亮；格线 `--geo-grid`；文字走 `--geo-text`；
- 详情卡原子结构示意图电子点深色加粗一档。

### 双编码

- 金属/非金属：颜色 + "金"/"非"角标 + 图例文字（灰度可辨）；
- 周期/族高亮：着色 + 周期数字/族数字标签；
- 递变箭头：箭头方向 + `trend` 文字一句话。

### 复用几何

- 点选热区复用 `tap-highlight`（透明点击热区）；
- 详情卡编号徽章复用编号徽章样式。

### 黄队接口（先动手后结论）

- 动手：点 Na（11 号）→ 现象：L 层 1 个电子、金属区橙色 → 动手点 Cl（17 号）→ 现象：L 层 7 个电子、非金属区天蓝 → 结论点题："最外层电子数，决定了元素的'脾气'"（位置—结构—性质，cm14.2.2）。
- 递变动手：开 `trendArrows`，从 Na 横着点到 Ar → 现象：箭头一路向右、"半径减小" → 结论："同周期从左到右，原子半径减小——核电荷多了，抓得更紧"。

### 蓝队评审

- ⚠️ **降级可实现**：原生 JS + SVG（网格）/DOM（详情卡）+ MathML（符号如 Na⁺ 备用），零依赖；
  元素数据 1–36 内嵌静态表（构建时写入，运行时零外部依赖）；原子结构示意图为简化同心圆（明确降级：不做轨道形状）。
- 离线预计算：无。
- 性能红线：36 格 SVG 无风险；**明确不做**镧系/锕系展开（占位一句"此处省略"）。

### 常见坑

1. **390px 点选精度**：18 列网格单格 < 44px 是硬伤——必须配"详情卡 ←/→ 切换"补偿交互（W-C5 验收项），不能只靠点格。
2. **21–36 号电子排布简化声明**：过渡元素排布涉能级交错，示意图必须注"简化示意"，否则与 cm20.1.1 构造原理矛盾。
3. **小圈内数字 = 质子数**：详情卡原子结构示意图圈内数字旁注"质子数"（cm14.1.1 误区：学生以为是"原子核"三个字）。
4. **族 ≠ 列无条件**：第Ⅷ族占三列，`highlightMode:"group"` 时Ⅷ族三列同着 + 文案注"第Ⅷ族占三列"（cm14.1.2 误区）。

## C5 · lab-assemble（实验装置组装与步骤回放）

从仪器托盘拖部件组装实验装置（制 O₂/CO₂/H₂/乙炔），吸附校验 + 规范检查；
"步骤回放"逐步高亮操作顺序；安全检查点不通过则不能进入加热/点火步骤。
适用课型：**cm02.1.3 氧气的制取（上）**（气密性→装药→收集→验满）；
**cm06.2.1 二氧化碳的制取**（长颈漏斗下端伸入液面下）；**cm07.2.2**（H₂ 验纯）；
**cm21.1.2**（乙炔制取：分液漏斗 + 防倒吸）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `apparatus` | string | ✅ | — | 装置模板枚举：`"o2-heat"`（加热固体制 O₂）/ `"o2-liquid"`（H₂O₂ 制 O₂）/ `"co2"`（固液不加热制 CO₂）/ `"h2"`（固液不加热制 H₂）/ `"c2h2"`（乙炔：分液漏斗） |
| `pieces` | array | ✅ | — | 仪器托盘：每项 `{id, kind, label}`；`kind` 枚举 ≤ 12 种：`testTube`（试管）/ `flask`（锥形瓶）/ `funnel`（长颈漏斗）/ `sepFunnel`（分液漏斗）/ `tube`（导管）/ `trough`（水槽）/ `gasJar`（集气瓶）/ `lamp`（酒精灯）/ `stand`（铁架台）/ `plug`（单孔/双孔塞）/ `balloon`（气球·尾气收集）/ `naohBottle`（NaOH 尾气吸收瓶） |
| `slots` | array | ✅ | — | 槽位：每项 `{id, accepts:[kind], hint}`；拖错部件 → 警告（如长颈漏斗下端未伸入液面下） |
| `steps` | array | ✅ | — | 步骤回放序列：每项 `{caption（一句话）, highlight:[slotId], note?}`（如"检查气密性→装药品→…"） |
| `safetyChecks` | array | ✅ | — | 安全检查点：每项 `{id, text, mustPass:true}`；如 H₂ 模板必有"点燃前验纯"；CO/Cl₂ 相关必有"尾气处理" |
| `mode` | string | — | `"assemble"` | `"assemble"`（组装）/ `"replay"`（步骤回放，可从组装完成态进入） |
| `realityNote` | string | ✅ | — | "现实差异"小字（必填，如"现实中铁丝燃烧瓶底要放水防炸裂；本动画为示意"） |

- 组装校验：部件拖到槽位即吸附（M6 ripple）；`accepts` 不符 → 警告条（⚠ + 文字，不只靠颜色）；
  关键规范硬校验：`co2` 模板长颈漏斗下端必须伸入液面下；`h2` 模板点火步骤前必须通过"验纯"检查点。
- 步骤回放：▶/⏸/↺ + 步骤序号（"3/7"）+ 字幕；当前步骤槽位高亮（`--chm-highlight` 黄闪）。
- 安全检查点：弹窗确认（"我已确认：点燃 H₂ 前已验纯" + 确认按钮 ≥44px）；不通过则加热/点火步骤按钮置灰。

### 示例

```js

  type: "lab-assemble",
  params: {
    apparatus: "co2",
    pieces: [
      { id: "p1", kind: "flask", label: "锥形瓶" },
      { id: "p2", kind: "funnel", label: "长颈漏斗" },
      { id: "p3", kind: "plug", label: "双孔塞" },
      { id: "p4", kind: "tube", label: "导管" },
      { id: "p5", kind: "gasJar", label: "集气瓶" }

      { id: "s3", accepts: ["gasJar"], hint: "向上排空气法收集" }
    ],
    steps: [
      { caption: "检查装置气密性", highlight: ["s1"] },
      { caption: "装入石灰石，塞紧双孔塞", highlight: ["s1", "s2"] },

```

### 输入 / 输出

- 输入：拖仪器到槽位 / 点安全检查点确认 / 步骤回放控制。

### 黄队接口（先动手后结论）

- 动手：学生故意把长颈漏斗下端留在液面上 → 现象：警告"气体会从漏斗口跑掉" → 结论点题："规范动作不是形式——每一步都在防一个具体事故"。

## C6 · solution-mix（溶液配制模拟）

溶质质量分数计算 → 称量 → 量取 → 溶解四步配制模拟；稀释模式配
"稀释前后溶质质量不变"徽章（`m(浓)×w(浓) = m(稀)×w(稀)`）。
适用课型：**cm09.2.1 溶质质量分数（上）**（配制 50g 6% NaCl 溶液）；
**cm09.2.2 溶质质量分数（下）**（稀释/增浓/混合计算）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `mode` | string | ✅ | — | `"prepare"`（配制）/ `"dilute"`（稀释） |
| `solute` | object | ✅ | — | `{name（如"NaCl"), hydrate?}`；`hydrate` 为结晶水合物时（如 CuSO₄·5H₂O）配"溶质是无水物"提示 |
| `target` | object | ✅ | — | `mode:"prepare"` 时：`{mass（g), percent（%)}`；`mode:"dilute"` 时：`{mass, percent, percentTarget}` |
| `calcCheck` | boolean | — | `true` | 是否要求学生先输入计算结果（溶质 g / 水 mL）再放行，错了给提示（不判错） |
| `sigFig` | number | — | `3` | 有效数字位数（见 §15 B2，默认 3，生产前冻结） |
| `steps` | array | — | 默认四步 | 配制步骤：`["计算","称量","量取","溶解"]`；稀释模式：`["计算","量取浓溶液","加水","混匀"]` |

- 计算校验：学生输入溶质质量/水体积 → 与标准值比对（容差 ±1 个最小分度，类比 Y2 `tolerance`）；
  对了亮 ✓，错了给提示（"再想想：溶质质量 = 溶液质量 × 质量分数"），不判错。
- 称量/量取：简化天平（砝码+游码示意）与量筒（读数走 Y2 `read-gauge` 仪表读数器复用）；
  文案注"规范读数练习见仪表读数器"，本页不重复造。
- 稀释徽章：`m(浓)×w(浓) = m(稀)×w(稀)`（MathML）+ "稀释前后溶质质量不变 ✓"徽章（蓝绿 + 文字）。

### 示例

```js
interaction: {
  type: "solution-mix",
  params: {
    mode: "prepare",
    solute: { name: "NaCl" },
    target: { mass: 50, percent: 6 },
    calcCheck: true, sigFig: 3
  }
}
```

### 输入 / 输出

- 输入：计算结果输入框 / 天平游码拖拽 / 量筒读数（复用 Y2）/ 步骤推进按钮。
- 输出：分步 ✓ + 配制完成徽章（"50g 6% NaCl 溶液配制完成"）/ 稀释不变徽章。

### 触控要求

- 数字输入框高度 ≥ 44px；游码拖拽热区 ≥ 44px；步骤按钮 ≥ 44px；
- 输入框配数字键盘（`inputmode="decimal"`）。

### 深色模式

- 溶液 `--geo-known` 蓝（+ "溶液"文字标签）；溶质颗粒 `--geo-line`；徽章文字走 `--geo-text`；
- 天平/量筒描边 `--chm-apparatus`。

### 双编码

- 溶质/溶剂：颜色 + "溶质"/"溶剂"文字标签 + 质量读数（g/mL）；
- 稀释不变：公式 + "✓ 溶质质量不变"文字徽章。

### 复用几何

- 量筒读数复用 Y2 `read-gauge`（`gauge:"cylinder"` 化学扩展，见 Y1–Y4 节说明）；
- 不变量徽章复用 `ratio-slider` 范式；步骤推进复用 `step-play`。

### 黄队接口（先动手后结论）

- 动手：配制 50g 6% NaCl → 现象：算出 3g 盐、47mL 水，一步步 ✓ → 结论点题："质量分数是'盐占盐水的比例'——先算对，再动手"。
- 稀释动手：把 6% 稀释成 3% → 现象：徽章"溶质质量不变"，盐的克数前后一样 → 结论："加的是水，盐一分没多——稀释前后溶质质量不变"（cm09.2.1 重点）。

### 蓝队评审

- ✅ **可实现**：原生 JS + DOM（表单/校验）+ SVG（天平/量筒示意）+ MathML（公式），零依赖；计算校验纯前端。
- 离线预计算：无。
- 性能红线：无；**明确不做**真实天平物理仿真（游码为示意拖拽，规范读数走 Y2）。

### 常见坑

1. **有效数字口径**：计算结果保留几位？见 §15 B2（默认 3 位，须与量筒/天平精度匹配，不编造精度，审计清单第 7 条）。
2. **结晶水合物特别提示**：`solute.hydrate` 非空时（如 CuSO₄·5H₂O），页内必须有一句"溶质是 CuSO₄（无水物），不是晶体"（cm09.2.2 误区）。
3. **水体积≈质量要注明**：量取水的 mL 数按密度 1g/mL 换算，小字注明（初中约定）。
4. **稀释只教质量型**：`m₁w₁ = m₂w₂`；涉及体积与密度的稀释是高中内容，页内注边界（"体积稀释以后再学"）。

## C7 · reaction-particle（反应过程粒子动画）

反应微观过程的关键帧粒子动画（如 Zn+稀硫酸、酸碱中和、水电解）；
配"反应前后原子种类/个数不变"计数器；可选旁观离子淡出。
适用课型：**cm03.1.2 分子与原子（下）**（水电解：H₂O 分子破裂 → H、O 原子重组）；
**cm05.1.1 质量守恒定律**（微观解释：原子三不变）；**cm10.2.2 中和反应**
（实质 H⁺+OH⁻→H₂O）；**cm12.2.1**（CuO+H₂ 电子转移动画）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `reaction` | object | ✅ | — | `{equation（MathML 字符串）, equationText（如"Zn + H₂SO₄ → ZnSO₄ + H₂↑")}` |
| `particles` | array | ✅ | — | 粒子清单：每项 `{id, kind:"atom"/"ion"/"molecule", label（如"Zn"), charge（如"+2"/"−1"/null), role:"reactant"/"product"/"spectator", count}` |
| `keyframes` | array | ✅ | — | 关键帧序列：每项 `{caption（一句话字幕）, moves:[{id, from:[x,y], to:[x,y]}], fade:[id], form:[{ids, label}]}`；`form` 为"重组"（如 2H⁺ → H₂） |
| `counter` | boolean | — | `true` | 是否显示原子计数器（反应前后各元素原子个数对照表） |
| `spectatorFade` | boolean | — | `true` | 旁观离子是否淡出（如中和页的 Na⁺）；`false` 时旁观离子保留但标注"旁观离子" |
| `slowmo` | boolean | — | `true` | 是否提供慢放档（0.5×）与逐帧步进 |

- 播放控制：▶/⏸/↺/scrubber（沿用代数 `slow-replay` 约定）+ 慢放 0.5× + 逐帧"下一步"；
  动画角常驻"示意动画，非真实速率"小字。
- 计数器：每种元素一行，"反应前 / 反应后"两列数字；全等 → "原子种类、个数都不变 ✓"徽章
  （蓝绿 + 文字；**写清是"原子"计数**，见 W-C9）。
- 电子转移（`reaction.eTransfer:true` 时）：电子画天蓝小点 `--chm-electron` + 箭头，
  方向从失电子元素指向得电子元素（审计清单第 8 条，方向禁反）。

### 示例

```js
interaction: {
  type: "reaction-particle",
  params: {
    reaction: { equationText: "Zn + H₂SO₄ → ZnSO₄ + H₂↑" },
    particles: [
      { id: "zn1", kind: "atom", label: "Zn", charge: null, role: "reactant", count: 1 },
      { id: "h1", kind: "ion", label: "H", charge: "+1", role: "reactant", count: 2 },
      { id: "so4", kind: "ion", label: "SO₄", charge: "−2", role: "spectator", count: 1 }
    ],
    keyframes: [
      { caption: "Zn 把 H⁺ 中的 H '换'了出来", moves: [{ id: "zn1", from: [20, 50], to: [45, 50] }] },
      { caption: "2 个 H⁺ 得电子变成 H₂ 分子，冒出去了", form: [{ ids: ["h1"], label: "H₂" }], fade: [] },
      { caption: "Zn²⁺ 与 SO₄²⁻ 结合成 ZnSO₄（旁观离子 SO₄²⁻ 淡出）", fade: ["so4"] }
    ],
    counter: true, spectatorFade: true, slowmo: true
  }
}
```

### 输入 / 输出

- 输入：播放/暂停/重播/scrubber/慢放/逐帧。
- 输出：粒子重组动画 + 字幕 + 原子计数器实时对照 + "原子三不变 ✓"徽章。

### 触控要求

- 播放控制条 ≥ 44px（▶/⏸/↺ 按钮与 scrubber 热区 ≥ 44px 高）；
- 粒子为只读动画（不可拖），防误触（W-C6）。

### 深色模式

- 阳离子 `--chm-cation`（朱红 + "+"）、阴离子 `--chm-anion`（蓝 + "−"）、原子 `--chm-apparatus` 描边；
- 旁观离子淡出用透明度（不只靠颜色变灰，另配"旁观离子"文字标签）。

### 双编码

- 离子：颜色 + 电荷符号文字（H⁺/SO₄²⁻，电荷数在前）；
- 重组：动画 + 字幕一句话 + 计数器数字；气体逸出：↑ + "H₂↑" 文字。

### 复用几何

- 播放控制条复用代数 `slow-replay`（▶/⏸/↺/scrubber + 关键事件高亮）；
- 不变量徽章复用 `ratio-slider` 范式。

### 黄队接口（先动手后结论）

- 动手：慢放看 Zn+稀硫酸 → 现象：H⁺ 变成 H₂ 跑了，计数器 Zn:1=1、H:2=2、S:1=1、O:4=4 → 结论点题："原子没生也没灭，只是重新组合——这就是质量守恒的微观原因"。
- 中和页动手：开 `spectatorFade` → 现象：Na⁺ 淡出，只剩 H⁺+OH⁻→H₂O → 结论："中和的实质，是 H⁺ 和 OH⁻ 结合成水——旁观离子只是'看客'"。

### 蓝队评审

- ⚠️ **降级可实现**：原生 JS + Canvas/SVG + MathML，零依赖；粒子运动为**关键帧插值**（`keyframes` 路径离线预计算），
  **不是分子动力学模拟**（明确降级，页内注"示意"）。
- 离线预计算：每反应的 `keyframes` 路径点（蓝队按黄队分镜生成，见 §15 B12）。
- 性能红线：粒子总数 ≤ 60；**低端机建议 ≤ 40**（教学示意，数量不求多）。

### 常见坑

1. **"示意"声明常驻**：粒子大小/数量/速度/路径均为示意，动画角小字不可关（"示意动画，非真实速率"）。
2. **计数器是"原子"计数**：表头写"原子个数"，不写"分子个数"（W-C9；分子种类变了，原子没变——这正是红线辨析③）。
3. **中和页别画 Na⁺ 当主角**：`spectatorFade:true` 或明确标注"旁观离子"（否则学生以为 Na⁺ 参与了反应）。
4. **电子箭头方向禁反**：eTransfer 动画箭头必须从失电子元素指向得电子元素（审计清单第 8 条；C10 同规范）。

## C8 · ph-scale（pH 试纸/标尺）

拖溶液到 pH 试纸/标尺，看试纸颜色 + pH 读数 + "酸性/中性/碱性"文字；
pH 滑块联动 c(H⁺) 条形——"pH 差 1，c(H⁺) 差 10 倍"可视化。
适用课型：**cm10.2.3 pH 与溶液酸碱度**（pH 标度、试纸规范、对数直观版）；
**cm19.1.2 水的电离与溶液 pH**（`mode:"strict"`：pH = −lg c(H⁺) 严格化回填）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `solutions` | array | ✅ | — | 溶液：每项 `{name（如"白醋"), ph（如 3)}`，建议 4–6 种覆盖酸/中/碱 |
| `mode` | string | — | `"intuitive"` | `"intuitive"`（cm10：不讲 log，只看"差 1 差 10 倍"）/ `"strict"`（cm19：显示 pH = −lg c(H⁺)） |
| `phSlider` | object | — | `{min:0,max:14,step:1,init:7}` | pH 滑块（步进 1，配 `−`/`+` 精调按钮） |
| `tenfoldViz` | boolean | — | `true` | 是否显示 c(H⁺) 10 倍跳动条（对数刻度条形 + "×10" 文字） |
| `paperColors` | object | — | 内置 | 试纸标准比色卡（构建时写入，见 §15 B8；params 不暴露色值） |

- 试纸：拖溶液瓶到试纸 → 试纸按 `paperColors[ph]` 变色 + pH 读数（MathML，*pH* = …，**无单位**）+
  "酸性"/"中性"/"碱性"文字徽章（`--chm-acid-tag`/`--geo-line`/`--chm-base-tag`）。
- 10 倍条：pH 每 ±1，c(H⁺) 条形按对数刻度 ×10/÷10 跳动，配文字"pH 差 1，c(H⁺) 差 10 倍"；
  `mode:"strict"` 时加读数 `c(H⁺) = 10⁻ᵖᴴ mol/L`。

### 示例

```js
interaction: {
  type: "ph-scale",
  params: {
    solutions: [
      { name: "白醋", ph: 3 }, { name: "雨水", ph: 6 }, { name: "纯水", ph: 7 },
      { name: "肥皂水", ph: 10 }, { name: "稀 NaOH", ph: 13 }
    ],
    mode: "intuitive", tenfoldViz: true
  }
}
```

### 输入 / 输出

- 输入：拖溶液瓶到试纸 / pH 滑块（± 步进）。
- 输出：试纸颜色 + pH 读数 + 酸碱性文字徽章 + c(H⁺) 10 倍跳动条。

### 触控要求

- 溶液瓶/试纸热区 ≥ 44px；pH 滑块轨道 ≥ 44px 高 + `−`/`+` 步进按钮（手机精调）；
- 拖放吸附阈值 8 逻辑单位（复用 `cut-reassemble`）。

### 深色模式

- 试纸颜色按标准比色卡渲染（深色下**可辨性验收**，见 W-C4）；酸碱性**文字徽章不依赖颜色**；
- 10 倍条 `--chm-known`，文字走 `--geo-text`。

### 双编码

- 酸碱性：试纸颜色 + "酸性/中性/碱性"文字 + pH 数字（三编码）；
- 10 倍：对数条长 + "×10" 文字 + pH 差值数字。

### 复用几何

- 拖放吸附复用 `cut-reassemble`；pH 滑块复用 `slider-lab`（+ `−`/`+` 精调约定）。

### 黄队接口（先动手后结论）

- 动手：拖"白醋"到试纸 → 现象：试纸变色 + pH≈3 + "酸性" → 动手把 pH 滑块从 3 拨到 4 → 现象：c(H⁺) 条缩成 1/10 → 结论点题："pH 大 1，氢离子浓度小 10 倍——pH 是'浓度的密码'"（cm10.2.3 对数直观版）。
- `strict` 页动手：pH=1 vs pH=3 → 现象：c(H⁺) 差 100 倍 → 结论："pH = −lg c(H⁺)——学完对数，这就是它的严格样子"（cm19.1.2 回填）。

### 蓝队评审

- ✅ **可实现**：原生 JS + DOM/SVG + MathML，零依赖；试纸比色卡为构建时内嵌色值表（见 §15 B8）；
  c(H⁺) = 10^(−pH) 纯前端计算。
- 离线预计算：无（比色卡构建时写入）。
- 性能红线：无。

### 常见坑

1. **颜色必须配文字**：试纸颜色 + "酸性/中性/碱性"文字缺一不可（W-C3；色盲学生只靠颜色会全错）。
2. **pH 可 <0 或 >14**：直观版注明"0–14 是常用范围，超浓酸 pH 可小于 0"（cm10.2.3 误区）。
3. **试纸测的是近似值**：页内一句"试纸测大概，精确用 pH 计"（防"试纸万能"误解）。
4. **石蕊/酚酞是另一套**：C8 只做 pH 试纸 + 标尺；石蕊（酸红碱蓝）/酚酞（碱红）在 cm10.1.1 用静态对照页 + C5 实验，不在本交互混排（防变色规则混淆）。

## C9 · rate-equilibrium（速率与平衡）

浓度/温度/压强三滑块联动 v(正)/v(逆) 曲线；"动态平衡 v(正)=v(逆)≠0"徽章；
改条件看平衡移动（勒夏特列"减弱"标注）。
适用课型：**cm16.1.1 化学反应速率**（v = Δc/Δt，影响因素）；**cm16.1.2/16.1.3**
（动态平衡 / 平衡移动）；**cm18.2.1–18.2.3**（`mode:"quantitative"`：活化能/K/Qc 深化）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `reaction` | object | ✅ | — | `{equationText（如"N₂+3H₂ ⇌ 2NH₃"), gasStoich:{fwd:4, rev:2}}`；`gasStoich` 用于压强影响方向判定 |
| `sliders` | object | ✅ | — | `{conc:{min,max,step,init,label}, temp:{...}, pressure:{...}}`（至少配 1 个） |
| `mode` | string | — | `"qualitative"` | `"qualitative"`（cm16：定性，只看曲线相对变化）/ `"quantitative"`（cm18：显示 K、Qc 读数） |
| `equilibriumBadge` | boolean | — | `true` | 是否显示"v(正)=v(逆)≠0 · 动态平衡"徽章（默认 true，不可关闭） |
| `shiftNote` | string | — | 占位 | 平衡移动标注文案（默认"减弱这种改变"——勒夏特列，黄队可改，cm18.2.3） |

- v–t 图：v(正) `--chm-reducer` 橙实线（`--geo-corr-a`）/ v(逆) `--chm-gain-e` 天蓝虚线（`--geo-corr-b`）+
  图例文字"v(正)"/"v(逆)"（双编码：颜色 + 线型 + 文字）。
- 曲线模型（示意）：指数趋近 `v(t) = v∞(1−e^(−kt))`；改滑块 → 目标值 v∞ 变 → 曲线重绘；
  **页内注"曲线为示意，非真实动力学模拟"**（见 §15 B3 数据源口径）。
- 平衡态：两线重合 → 徽章"v(正) = v(逆) ≠ 0 · 动态平衡 ✓"（**≠0 必须渲染**）；
  改条件 → 两线先分开（"平衡移动中"）→ 重合到新高度（"新平衡"）+ `shiftNote`。
- `mode:"quantitative"` 时：K 只随温度变（读数行 MathML，*K* = …），Qc 随浓度/压强变；
  催化剂为独立开关：两线同等变陡、平衡位置不动（cm18.2.3 误区纠偏）。

### 示例

```js
interaction: {
  type: "rate-equilibrium",
  params: {
    reaction: { equationText: "N₂ + 3H₂ ⇌ 2NH₃", gasStoich: { fwd: 4, rev: 2 } },
    sliders: {
      conc: { min: 1, max: 10, step: 1, init: 5, label: "反应物浓度" },
      temp: { min: 300, max: 800, step: 50, init: 500, label: "温度/K" },
      pressure: { min: 1, max: 100, step: 5, init: 10, label: "压强/MPa" }
    },
    mode: "qualitative", equilibriumBadge: true,
    shiftNote: "增大压强，平衡正向移动——减弱这种改变，不是抵消"
  }
}
```

### 输入 / 输出

- 输入：浓度/温度/压强滑块；催化剂开关（定量模式）。
- 输出：v(正)/v(逆) 曲线实时重绘 + 平衡徽章三态（"动态平衡"/"移动中"/"新平衡"）+（定量模式）K/Qc 读数。

### 触控要求

- 滑块轨道 ≥ 44px 高；曲线为只读（不可点）；
- 徽章区固定高度（防曲线重绘时布局抖动）。

### 深色模式

- v(正) 橙实线 / v(逆) 天蓝虚线深色自动提亮；坐标轴 `--geo-grid`；徽章文字走 `--geo-text`。

### 双编码

- 两条曲线：颜色 + 实线/虚线 + 图例文字"v(正)"/"v(逆)"；
- 平衡：徽章文字"v(正)=v(逆)≠0"（≠0 必写）+ 两线重合形态。

### 复用几何

- 滑块范式复用代数 `slider-lab`；曲线描点复用代数 `plot-points`；
- 图像判读可叠加 Y4 `graph-reader`（读斜率/读交点）。

### 黄队接口（先动手后结论）

- 动手：等平衡后把压强滑块往大拨 → 现象：两条线先分开（v(正) 冲得更高），又重合到更高处 → 结论点题："平衡是动态的——条件变了，它会'挪'到一个新的平衡"（cm16.1.3）。
- 动手：盯着徽章看 → 现象：平衡时徽章写着"≠0" → 结论："v(正)=v(逆)≠0——平衡不是静止，是'跑得一样快'"（全书级重点，审计清单第 9 条）。

### 蓝队评审

- ⚠️ **降级可实现**：原生 JS + Canvas + MathML，零依赖；曲线为**教学示意函数**（指数趋近），
  **不是真实动力学数值解**（明确降级）；定量模式的 K 值由黄队按温度配表（见 §15 B3）。
- 离线预计算：曲线点列（调参时重算，<1ms）。
- 性能红线：曲线点数 ≤ 300；**明确不做**真实碰撞理论模拟、活化能分布曲线数值积分。

### 常见坑

1. **"示意"必须写**：曲线是示意函数，不是解出来的真实动力学（W-C11）。
2. **≠0 必须渲染**：徽章只写"v(正)=v(逆)"是教学事故——学生会当成"反应停了"（审计清单第 9 条）。
3. **催化剂只改速率不改平衡**：催化剂开关 → 两线同等变陡、交点（平衡位置）不动；文案"催化剂不改 K"（cm18.2.3）。
4. **压强影响看气体计量数**：`gasStoich` 决定移动方向；无气体参与的反应，压强滑块应置灰 + 注"压强只影响有气体参与的平衡"。

## C10 · redox-track（氧化还原电子追踪）

点元素标化合价 → 校验；点起点/终点画电子得失箭头 → 方向校验；
填得失电子数 → 电子守恒校验；"升失氧、降得还"四步对照表一次呈现。
适用课型：**cm12.2.1 氧化还原反应（上）**（"升失氧、降得还"四位一体）；
**cm12.2.2 氧化还原反应（下）**（双线桥/单线桥、电子守恒配平）；
**cm19.2.1 原电池（深化）**（电极反应式三守恒）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `equation` | object | ✅ | — | `{reactants:[{formula, atoms}], products:[...]}`（同 C3 结构，`atoms` 锁定） |
| `valences` | object | ✅ | — | 标准答案：`{reactants:{"CuO.Cu":"+2", ...}, products:{...}}`（键为"式.元素"，黄队配） |
| `transfer` | object | ✅ | — | `{from:"H", to:"Cu", electrons:2}`（失电子元素 → 得电子元素，得失电子数） |
| `motto` | array | — | 默认四步 | "升失氧、降得还"对照表：`[{element, change:"升高"/"降低", e:"失 2e⁻"/"得 2e⁻", reaction:"氧化反应"/"还原反应", role:"还原剂"/"氧化剂"}]` |
| `arrowMode` | string | — | `"tap"` | 固定 `"tap"`：点起点元素 → 点终点元素（**不许手指手绘箭头**，QA 成本，见常见坑 4） |

- 标变价：点元素 → 弹出化合价选择器（`−2/−1/0/+1/+2…` 按钮 ≥44px）→ 即时 ✓/✗；
  单质先立规矩：页内一句"单质中元素化合价为 0"（审计清单第 2 条）。
- 画箭头：点失电子元素（起点）→ 点得电子元素（终点）→ 箭头 `--chm-lose-e` 橙（起点）→ `--chm-gain-e` 天蓝（终点）+
  "失 2e⁻ / 得 2e⁻"文字；方向反了 → 警告"箭头指反了：电子从失电子的元素流向得电子的元素"。
- 四步对照表：化合价升降 / 得失电子 / 氧化还原反应 / 氧化剂还原剂四列，逐项 ✓；
  全对 → "升失氧、降得还 ✓"徽章（蓝绿 + 文字）。

### 示例

```js
interaction: {
  type: "redox-track",
  params: {
    equation: {
      reactants: [{ formula: "CuO", atoms: { Cu: 1, O: 1 } }, { formula: "H₂", atoms: { H: 2 } }],
      products: [{ formula: "Cu", atoms: { Cu: 1 } }, { formula: "H₂O", atoms: { H: 2, O: 1 } }]
    },
    valences: {
      reactants: { "CuO.Cu": "+2", "CuO.O": "−2", "H₂.H": "0" },
      products: { "Cu.Cu": "0", "H₂O.H": "+1", "H₂O.O": "−2" }
    },
    transfer: { from: "H", to: "Cu", electrons: 2 },
    motto: [
      { element: "H", change: "升高", e: "失 2e⁻", reaction: "氧化反应", role: "还原剂" },
      { element: "Cu", change: "降低", e: "得 2e⁻", reaction: "还原反应", role: "氧化剂" }
    ]
  }
}
```

### 输入 / 输出

- 输入：点元素标化合价 / 点两端画箭头 / 输入得失电子数 / "检查"按钮。
- 输出：逐项 ✓/✗ + 箭头 + 四步对照表 + "升失氧、降得还 ✓"徽章。

### 触控要求

- 元素点选热区 ≥ 44px（复用 `tap-highlight`）；化合价选择器按钮 ≥ 44px；
- 箭头绘制只用"点两端"，不许手绘（防误触 + 方向判定 QA 成本）。

### 深色模式

- 失电子 `--chm-lose-e`（橙）/ 得电子 `--chm-gain-e`（天蓝）深色自动提亮；
- 箭头 + ↑↓ + 文字三编码，深色下仍可辨。

### 双编码

- 化合价升/降：颜色 + ↑/↓ + "升高/降低"文字；
- 得失电子：箭头方向 + "失 2e⁻/得 2e⁻"文字；
- 四步对照表：文字为主，颜色为辅。

### 复用几何

- 点选热区复用 `tap-highlight`；逐项校验徽章复用 `ratio-slider` 不变量徽章范式。

### 黄队接口（先动手后结论）

- 动手：先点 Cu 标 +2 → 点 Cu（生成物）标 0 → 现象：Cu"那一栏"显示"降低 / 得 2e⁻ / 还原反应 / 氧化剂" → 结论点题："化合价降低 → 得电子 → 被还原 → 做氧化剂——四位一体，一次记全"（审计清单第 8 条）。
- 动手：故意把箭头从 Cu 点向 H → 现象：方向警告 → 结论："电子从失电子的流向得电子的——箭头方向就是电子流向"。

### 蓝队评审

- ✅ **可实现**：原生 JS + DOM/SVG + MathML，零依赖；校验逻辑为查表比对（标准答案黄队配），纯前端。
- 离线预计算：无。
- 性能红线：无；**明确不做**自由输入方程式的自动标价（解析 QA 成本高，只做给定例题，见 Y4 边界）。

### 常见坑

1. **双线桥箭头方向规范**：从失电子元素指向得电子元素（cm12.2.2 误区）；`transfer.from/to` 即规范数据源。
2. **剂/产配对不错位**：四步对照表一次呈现四列（升降/得失/氧化还原/剂），不许只记半句（审计清单第 8 条）。
3. **单质化合价为 0 先立**：页内一句，否则学生标 H₂ 的 H 为 +1。
4. **箭头不许手绘**：手指画线方向判定 QA 成本过高（抖动、折线）——降级为"点起点→点终点"是冻结口径。

## Y4 · ion-split（离子方程式拆写练习）

**预测需求场景**：cm12.1.3 离子反应（下）"写→拆→删→查"四步——黄队大概率要分步拆写练习：

### Schema 草案

1. **不许自创类型**：写页时 `type` 必须为 `side-compare`（白队按附校验清单拦）。
2. 对照维度必须"条件—产物"对齐，错位对照 = 不合格（黄队自查）。

## Y12 · stoich-steps（计算步骤展示）【新增类型】

分步填空 + 查表校验的计算步骤展示（设 / 写 / 找 / 列 / 解 / 答六步，黄队配模板）。
适用课型：**cm05.2.1/cm05.2.2**（方程式计算；红线辨析②立靶）；**cm13.1.3**（n—N—m—V—c 五量互换）；
**cm18.2.4**（三段式）；**cm09.2.2**（溶液综合计算）。pedagogy 5.2"配平/计算类习题要求步骤展示"的组件落点。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `title` | string | ✅ | — | 例题标题（如"49g KClO₃ 完全分解生成 O₂ 多少克？"） |
| `steps` | array | ✅ | — | 步骤模板（黄队配）：每项 `{key:"设"/"写"/"找"/"列"/"解"/"答", prompt（填空提示）, hint}`；冻结：模板黄队配（见 §15 B13.5） |
| `checkTable` | object | ✅ | — | 查表校验：标准答案对照表 `{步骤key: 标准值}`（黄队配） |
| `foldLevels` | number | — | `3` | 冻结：答案三级折叠（思路提示 → 关键步骤 → 完整答案；B13.5） |
| `sigFig` | number | — | `3` | 有效数字口径（沿用 §15 B2） |
| `recordKey` | string | ✅ | — | 记录键，冻结为 `chm_stoich_<课号>` |

- 校验：学生填一步 → 与 `checkTable` 查表比对（数值归一化比对，**不做语义解析**，B13.5）；对 ✓ / 错给提示。

### 示例

```js
interaction: {
  type: "stoich-steps",
  params: {
    title: "49g KClO₃ 完全分解生成 O₂ 多少克？",
    steps: [
      { key: "设", prompt: "设生成 O₂ 质量为 x", hint: "未知量设 x，带单位" },
      { key: "写", prompt: "写出配平的化学方程式", hint: "2KClO₃ = 2KCl + 3O₂↑（先配平！）" },
      { key: "找", prompt: "找出已知量与未知量的质量关系", hint: "245 : 96 = 49g : x" },
      { key: "列", prompt: "列比例式", hint: "" },
      { key: "解", prompt: "解出 x", hint: "" },
      { key: "答", prompt: "答", hint: "别忘单位和有效数字" }
    ],
    checkTable: { "解": "19.2g" },
    foldLevels: 3, sigFig: 3, recordKey: "chm_stoich_cm05.2.1"
  }
}
```

### 输入 / 输出

- 输入：分步填空（一步一核对）。
- 输出：查表比对 ✓/✗ + 提示；三级折叠答案（思路提示 → 关键步骤 → 完整答案）。

### 触控要求

- 填空框/核对按钮 ≥ 44px；390px 下六步纵向排布不溢出。

### 深色模式

- ✓/✗ 用语义色 + 文字（深色可辨，文字对比度 ≥ 4.5:1）。

### 双编码

- 对错：颜色 + "对 ✓"/"再想想"文字；步骤 key（设/写/找/列/解/答）文字常驻。

### 复用几何

- 三级折叠范式复用几何折叠约定；分步填空为化学新增（纯 DOM）。

### 黄队接口（先动手后结论）

- 动手：一步一步填"设/写/找/列/解/答" → 现象：每步即时核对 → 结论点题："计算不是列式，是走流程——'写'（配平）在'列'前面，顺序错了全错"。

### 蓝队评审

- ✅ **可接（新增类型）**：分步填空 + 查表校验，纯 DOM 零风险；校验只做查表比对（不做语义解析）——冻结（B13.5）。

### 常见坑

1. **不做语义解析**：学生填"2.45" vs "2.450"按有效数字口径（B2）判定，不猜意图（W-C18）。
2. **答案三级折叠完整**：思路提示 → 关键步骤 → 完整答案，缺一级 = 不通过（W-C18）。
3. **计算题自查清单必须存在**（"方程式配平了吗？代入的是纯净物质量吗？单位写对了吗？"，W-C18）。

## Y13 · safety-quiz（安全闯关）【新增类型】

安全情景闯关：错一步即警示 + 给正确做法。
适用课型：**cm00.1.3 化学实验室安全铁律**（扇闻 / 灯帽盖灭 / 药品取用三不）；**cm06.2.3/cm07.2.2**（点燃可燃性气体前验纯）；
**cm10.1.2**（浓硫酸稀释：酸入水）；**cm13.2.2**（84 + 洁厕灵禁混用）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `title` | string | ✅ | — | 闯关标题（如"点燃 H₂ 前，你先做什么？"） |
| `scenarios` | array | ✅ | — | 情景题（黄队配）：每项 `{scene（情景描述）, options:[...], correctId, warnText（错一步警示文案）, correctDo（正确做法一句话）}` |
| `noScore` | boolean | — | `true` | 冻结：不记分不排名（沿用全书口径；见 §15 B13.6） |
| `recordKey` | string | ✅ | — | 记录键，冻结为 `chm_safety_<课号>` |

- 话术一致性：与 C5 `safetyChecks` / Y2 `safety-badge` 同一安全规范的说法不打架（黄队定稿，B13.6）。

### 示例

```js
interaction: {
  type: "safety-quiz",
  params: {
    title: "点燃 H₂ 前，你先做什么？",
    scenarios: [
      { scene: "集气瓶里收集满了 H₂，准备点燃",
        options: [{id:"a", text:"直接点燃"}, {id:"b", text:"先验纯，确认纯净再点燃"}],
        correctId: "b",
        warnText: "⚠ 直接点燃可能爆炸！尖锐爆鸣 = 不纯",
        correctDo: "先验纯，后点燃——是玩火的第一条命" }
    ],
    noScore: true, recordKey: "chm_safety_cm06.2.3"
  }
}
```

### 输入 / 输出

- 输入：情景点选。
- 输出：选错即警示（`warnText`）+ 正确做法（`correctDo`）；选对过关（无分数、无排名）。

### 触控要求

- 选项按钮 ≥ 44px；390px 下情景描述不溢出（一屏）。

### 深色模式

- 警示用语义色（`--geo-danger` 别名）+ ⚠ 文字；深色可辨。

### 双编码

- 警示：⚠ + 文字；过关：✓ + 文字（不只靠颜色）。

### 复用几何

- 点选闯关范式复用几何选择题约定；话术与 C5/Y2 对齐（不重复造安全文案体系）。

### 黄队接口（先动手后结论）

- 动手：故意选错一次 → 现象：警示 + 正确做法 → 结论点题："安全规范每一条背后，都是一个真实事故——闯关就是让你'犯错'在虚拟里"。

### 蓝队评审

- ✅ **可接（新增类型）**：闯关 + 错一步警示，纯 DOM 零风险；话术一致性由黄队定稿（B13.6）。

### 常见坑

1. **错一步即警示 + 给正确做法**：只警示不给做法 = 不通过（W-C19）。
2. **不记分不排名**（沿用全书口径；W-C19）。
3. **三处说法不打架**：同一安全规范在 C5 `safetyChecks` / Y2 `safety-badge` / Y13 三处说法一致（黄队定稿，B13.6）。

## §14 与黄队教学的接口：教学动作链

黄队铁律"先动手后结论"——每种交互标注的"动手 → 现象 → 点题"链路（详见各 C 章节"黄队接口"）：

| 编号 | 动手（学生先做） | 现象（看到什么） | 点题（结论句方向，黄队定稿） |
|---|---|---|---|
| C1 | 20℃ 加热到 100℃；三态对比 | 粒子越跑越快、液→气；固整齐/气稀疏 | 温度是分子热运动剧烈程度的标志；三态差在排布不在分子 |
| C2 | 拼出 H₂O；故意给 O 连 3 个 H | O 键数 2/2 顶满；超键警告 | 下标是物质的身份证；成键数是元素的"脾气" |
| C3 | 点下标 → 调系数 2、1、2 | 红线警告；计数表全等 + 天平平衡 | 配平只能调系数，绝不改下标 |
| C4 | 点 Na 再点 Cl；横着点 Na→Ar | L 层 1e⁻ vs 7e⁻；半径递变箭头 | 最外层电子数决定"脾气"；同周期半径减小 |
| C5 | 长颈漏斗下端留液面上；跟步骤收到集 | 警告"气体会跑掉"；"等气泡连续均匀" | 规范每一步都在防一个具体事故 |
| C6 | 配制 50g 6% NaCl；6% 稀释成 3% | 3g 盐 47mL 水；盐克数前后一样 | 先算对再动手；稀释前后溶质质量不变 |
| C7 | 慢放 Zn+稀硫酸；中和页开旁观离子淡出 | 计数器全等；Na⁺ 淡出 | 原子不生不灭——质量守恒的微观原因；中和实质是 H⁺+OH⁻→H₂O |
| C8 | 拖白醋到试纸；pH 3→4 | pH≈3"酸性"；c(H⁺) 条缩成 1/10 | pH 是"浓度的密码"：差 1 差 10 倍 |
| C9 | 平衡后加压；盯着徽章看 | 两线分开又重合到更高处；"≠0" | 平衡是动态的；v(正)=v(逆)≠0 不是静止 |
| C10 | 标 Cu +2→0；箭头从 Cu 点向 H | 四步对照表逐项 ✓；方向警告 | 升失氧、降得还——四位一体一次记全 |

**接口约定**：
1. 黄队写页时，每页配 `exploreTip`（≤40 字动手提示）+ 现象观察点 + 结论徽章文案；蓝队保证"动手动作"在 params 里可配（如 C3 `trapSubscript`、C4 `trendArrows`、C9 `mode`）。
2. 黄队若提出本文件未覆盖的教学动作，走增补流程：白队先做压力预估 → 蓝队评估 → 修订本文件版本号，不直接改渲染器。
3. 协作铁律：黄队教学需求不妥协——凡 §14 链路需要的 params 能力，蓝队必须提供或给出书面降级替代方案（见 §12.2）。
