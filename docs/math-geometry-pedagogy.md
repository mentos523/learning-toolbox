# 数学·几何 教学设计（黄队）

> 定位：教学法设计。数学严谨性（定义准确、体系完整）由绿队负责，本文件只解决"怎么教、怎么让初学者自学"。
> 约束（用户拍板）：几何从生活中的图形一路到圆与变换；**每个几何概念必须有图形动画**；每页一屏、可交互动画、MathML 公式渲染、手机可用。
> 核心目标（用户铁律）：初学者能自学的教材——讲清楚、多举例子、不厌其烦。

---

## 一、设计总纲：六条铁律（沿用代数五条 + 几何专属一条）

1. **一页一概念**：一屏只讲透一个核心概念。宁可多一页，不可一页塞两个概念。
2. **先动手，后结论**：交互动画在前，文字解释在后。学生先拖顶点"看到"规律，再看文字"这就是××"。
3. **图言永不分离**：每个几何结论旁边必须有对应的图；**每个文字定义必须配一张"反例图"**（见 2.4）。只给文字不给图 = 不合格。
4. **跃升必有台阶**：每个难度跃升点必须设计中间脚手架（见第三章），不许"显然""易得"式跳跃。
5. **密度上限**：每页 ≤ 3 个信息块（标题区 / 交互区 / 点拨区），≤ 2 个例子，文字总量 ≤ 150 字（讲解页放宽，见第五章）。
6. **（几何专属）变化中找不变**：几何的灵魂是"什么在变、什么没变"。凡是能拖拽/旋转/切割的交互，必须同时标出**变了什么**和**没变什么**——不变的那个，就是要学的定理。

## 二、每页结构规范（沿用代数三块式，几何微调）

### 2.1 页面结构

```
┌─────────────────────────┐
│ 标题区（一句话概念） │ ← ≤ 20 字，flex none
├─────────────────────────┤
│ │
│ 交互区（主角，占 60%） │ ← flex 1：图形画布在这里
│ 不变量徽章（小标签） │ ← ★几何新增：实时显示"没变的是：××"
├─────────────────────────┤
│ 点拨区（≤ 60 字 + 下一步） │ ← flex none，"这就是××"点题
└─────────────────────────┘
```

**几何微调说明**：
- **不变量徽章**：画布角落一个小标签，随交互实时更新。例如拖三角形顶点时显示"没变的是：内角和 = 180°"；拖全等三角形时显示"没变的是：三条边、三个角"。这是第六条铁律的落地——学生即使不看文字，也能从徽章里读出定理。
- **颜色编码全书统一**（给蓝队的全局约定）：对应元素永远同色。对应边用同色描边、对应角用同色弧线标记、已知条件用蓝色、求证目标用红色、辅助线用灰色虚线。**全书 13 章（代数+几何）统一这一套**，学生翻到哪页都不用重新认颜色。

### 2.2 三类页面的分工（几何四步走：看 → 做 → 懂 → 练）

代数是"交互页 + 讲解页"两类；几何多一类**作图/证明页**，少一类"不做题"（几何要做题，见第六章）：

| 页类型 | 作用 | 结构 | 占比 |
|---|---|---|---|
| **交互页** | 看：拖/转/切，亲眼看到规律 | 三块式 + 不变量徽章 | 约 50% |
| **作图页 / 证明页** | 做：跟着一步步画 / 一步步看证明 | 步骤条 + 画布（见 4.1、4.2） | 约 20% |
| **讲解页** | 懂：交互页之后 1+ 页完整讲解，反复举例 | 见第五章 | 约 20% |
| **习题页** | 练：每章末 5–8 道，答案折叠 | 见第六章 | 约 10% |

**顺序铁律**：同一概念内，顺序必须是 **交互页 → 作图/证明页（如有） → 讲解页 →（章末）习题页**。不许先给定义再让学生玩——定义是学生自己"看出来"之后，黄队用文字帮他"说出来"。

### 2.3 每页自查清单（黄队写完一页后自己打勾）

- [] 一屏能看完，不滚动（手机 390px 为准）
- [] 主交互是"动手改变点什么"（拖/点/输），不是纯播放
- [] 不变量徽章写清楚了"没变的是什么"
- [] 点拨区 ≤ 60 字，最后一句是"这就是××"式点题
- [] 颜色编码符合全局约定（对应同色、辅助线灰虚线）
- [] 有生活化例子（主例进交互，次例进口拨）
- [] 新名词标注了"就是你第 X 页玩过的那个动作/看到的那个东西"

## 三、难度跃升脚手架（8 个关键跃升点）

### 跃升 1：生活中的形 → 几何图形（"抽掉"颜色材质）

- **卡点**：学生觉得几何图形是"简笔画"，和真实物体没关系。
- **脚手架**：三页"抽掉"动画——
1. 一页：一张桌子照片 → 滑块拖动，颜色、木纹、阴影一层层"抽掉"，最后剩下线框长方体。"抽掉的都是几何不关心的，留下的是几何关心的：形状和大小。"
2. 一页：反过来，给线框长方体，点"穿衣服"按钮，随机穿上桌子/纸箱/大楼三种外衣——"同一件几何衣服，可以穿很多件生活外衣"。
3. 点拨："几何就是研究'形状和大小'的学问，**不管它是什么做的、什么颜色**。"
- **交互**：图层剥离滑块（照片 → 线框）；"穿衣服"随机按钮。

### 跃升 2：看图 → 画图（从"认识"到"构造"）

- **卡点**：学生能认出等边三角形，但让画一个就懵了——"看"和"做"之间缺一座桥。
- **脚手架**：
1. 一页：给出画好的等边三角形，点"倒带"按钮，看它被"画出来"的全过程（圆规画弧 → 交点 → 连线），可暂停、可单步。
2. 一页：同一步骤，这次学生自己点"下一步"画，画错了（比如圆规半径变了）会看到图形"塌了"——"半径一变，就不是等边了"。
3. 点拨："几何图形不是'长这样的'，而是'这么画出来的'。**画法就是定义**。"
- **交互**：construction-step（作图步骤机，见 7.2），支持倒带/单步/跟做模式。

### 跃升 3：度量 → 性质（"量出来"到"想出来"）

- **卡点**：学生满足于"量了一下是 180°"，不理解为什么"永远是 180°"。
- **脚手架**：
1. 一页：拖三角形三个顶点，量角器实时读数，三个角加起来永远 180°（不变量徽章置顶）。
2. 一页："只量三个三角形就敢说永远？"——点"随机 100 个三角形"按钮，100 个三角形的内角和排成一列，全是 180°。"量 100 个也是'量'，不是'证'。"
3. 一页：撕角拼角动画——把三个角撕下来拼到一条直线上，正好拼成平角。"拼一次就够了，因为**拼的动作不依赖这个三角形长什么样**——这就是证明的雏形。"
- **交互**：vertex-drag（拖顶点）+ 批量随机验证 + cut-reassemble（撕角拼角）。

### 跃升 4：实验 → 证明（"看到"到"说清楚为什么"）

- **卡点**：证明的每一步"因为…所以…"像八股文，学生不知道每步在干什么。
- **脚手架**：
1. 一页：先给"一句话证明"——"过 C 点作 AB 的平行线，三个角就排排坐到一条直线上了"（配慢动作动画）。
2. 一页：proof-replay（证明慢放机，见 4.2）：5 步以内，每步画布高亮对应部位 + 右侧一张文字卡片（"这一步在干什么"人话版），点"为什么可以这样？"展开依据（已知/定理名）。
3. 点拨："证明 = 把动画里的每一个动作，用'因为…所以…'说清楚。**你先会做动作，再学说话**。"
- **交互**：proof-replay，≤ 5 步/页，超 5 步拆成两页。

### 跃升 5：全等 → 相似（"一样"到"像"）

- **卡点**："全等"是"完全一样"好懂，"相似"是"形状一样大小不一样"，学生容易把"对应边成比例"背成口诀而不理解。
- **脚手架**：
1. 一页：两张拼图，一张能严丝合缝拼上（全等），一张形状一样但大一圈（相似）。拖动小图去"套"大图——全等的能重合，相似的"套不进去但轮廓贴合"。
2. 一页：照片放大滑块——拖滑块，照片从 1 倍变到 3 倍，人脸没变形。"没变的是形状，变的是大小。**形状不变，就是对应角相等、对应边成比例**。"
3. 一页：反例——把照片只拉宽不拉高，人脸变胖。"这样还'像'吗？不像了。所以相似要求**所有方向按同一比例变**。"
- **交互**：拼图套合拖拽 + 照片缩放滑块 + 单向拉伸反例。

### 跃升 6：平面 → 立体（"看图"到"看穿"）

- **卡点**：三视图、展开图需要空间想象，平面图上"看"不出来。
- **脚手架**：
1. 一页：一个纸盒，拖"旋转"看它各个面，再点"压扁"——纸盒被压成平面展开图，再点"折起来"复原。**展开 ↔ 折叠可逆动画**，多看几遍。
2. 一页：三视图"探照灯"——三束不同方向的光（前、上、左）照物体，墙上留下三个影子。"三视图就是三个影子。"
3. 点拨："看不懂立体图时，记住两招：**转一转**（换角度）、**拆一拆**（展开图）。"
- **交互**：3D 旋转（简化版，固定几个视角档位，手机友好）+ 展开/折叠动画 + 三向投影。

### 跃升 7：静图 → 变换（平移/旋转/对称是"动作"不是"图形"）

- **卡点**：学生把"轴对称图形"背成"长得对称的图"，不理解对称是一种"翻折动作"。
- **脚手架**：
1. 一页：一张纸，对折，剪个洞，展开——两个洞对称。"**对称是'折'这个动作的结果**，不是图形天生的长相。"
2. 一页：图形沿直线翻折动画（慢动作，看每一点"飞"到另一边），翻过去和原图形重合——"重合的那个瞬间，就是对称。"
3. 一页：旋转 60° 的雪花：点"转一下"，转 6 次回到原样。"转多少度能回到自己？这就是旋转对称。"
- **交互**：翻折慢动作 + 旋转步进器（每次转固定角度，数"几转回原样"）。

### 跃升 8：形 → 数（几何的代数翻译：勾股定理是第一座桥）

- **卡点**：a² + b² = c² 对初学者只是一串字母，不知道它在说什么。
- **脚手架**：
1. 一页：直角三角形三条边上各"长"出一个正方形（动画生长），拖滑块改变三角形形状，三个正方形面积实时显示——"两块小的面积加起来，永远等于大的那块。"
2. 一页：切割拼补——两个小正方形被切成 5 块，拼进大正方形，严丝合缝。"**面积守恒**，这就是勾股定理在说的话。"
3. 点拨："a² 不是'字母的平方'，是'边长为 a 的正方形的面积'。**每个代数式背后都站着一个图形**——这就是代数第 2.2 章（乘法公式几何证明）的回声。"
- **交互**：正方形生长动画 + cut-reassemble 拼补 + 面积读数联动。
- **对应**：与代数 2.2.1（平方差）、2.2.2（完全平方）的几何证明页互相链接。

## 四、几何特有教学策略

### 4.1 作图步骤怎么教（construction-step 作图步骤机）

**核心原则**：作图教学 = "看一遍 → 跟一遍 → 自己来一遍"。三遍缺一不可，但**三遍可以在同一页完成**（倒带/跟做/自由三种模式一键切换）。

**步骤条规范**：
1. **每步一句话指令**，≤ 15 字，动词开头："以 A 为圆心，AB 为半径画弧"。不许出现"显然""作""得"这种黑话式省略。
2. **每步一幅图**：当前步新画的线用**红色**高亮，之前的步骤退为灰色细线（作图痕迹保留，但不抢戏）。
3. **步骤数 ≤ 6 步**：超过 6 步的作图（如过一点作已知直线的垂线完整版）必须拆成两页，第一页的终点是第二页的起点（"未完待续"式衔接，页尾写"下一步：连接交点"）。
4. **"为什么这样画"折叠条**：每步下方一个小问号，点开是人话解释（"为什么半径要取 AB？因为我们要保证… "）。默认折叠，不打断跟做的节奏；好奇的学生自己点开。
5. **跟做模式**：学生点"下一步"之前，画布是"待画"状态，学生先在自己心里/手指上比划，再点下一步验证。**验证失败不惩罚**：给"再看一遍上一步"按钮，不扣分、不红叉（这是自学教材，不是考试系统）。

**一笔画出图形的特殊处理**（如画角平分线、画中垂线）：
- 用"**慢动作描红**"：画布先显示虚线轨迹，学生手指/鼠标沿虚线描，描到 80% 以上算"画出来了"，虚线变实线。
- 描红轨迹支持重播，速度档：慢速（教学）/ 常速（检验）。

**经典作图清单**（每种 1 页倒带+跟做，共 8 页）：
1. 作一条线段等于已知线段
2. 作一个角等于已知角
3. 作角的平分线
4. 作线段的垂直平分线
5. 过一点作已知直线的垂线
6. 过直线外一点作已知直线的平行线
7. 作三角形（已知三边 / 两边夹角 / 两角夹边，三种各半页，拼成 2 页）
8. 作圆（已知圆心半径 / 过三点作圆，难点在后者，配"为什么三点定圆"讲解页）

### 4.2 证明步骤怎么拆（proof-replay 证明慢放机）

**核心原则**：证明不是"读文字"，是"看动作"。每个证明步骤 = **画布上的一个动作** + **一张人话卡片**。

**慢放机规范**：
1. **步骤数 ≤ 5 步**：超 5 步拆页。拆页点选在"阶段性结论"处（如证完"△ABE ≌ △CDF"先停一页，下一页再用这个结论往下走）。
2. **每步三件套**：
- **画布高亮**：当前步涉及的边/角/线闪烁或变粗，其他部分变淡；
- **人话卡片**：≤ 40 字，说"这一步在干什么"（"把 DE 这条线连起来，造出两个三角形"）；
- **"为什么可以？"折叠**：点开展示依据——"已知条件" / "定理：××（第 X 页）" / "作图痕迹"。**每个"因为"都必须能点开看到出处**，不许"显然"。
3. **两栏式收尾**：慢放播完，出一页"证明书"——左栏"陈述"（做了什么），右栏"理由"（凭什么），学生可以上下滑动对照。这是给"要交作业"的学生的正式版本，但**正式版本永远在慢放版之后**。
4. **证明阅读器三问**（每页证明页页尾固定）：
- 已知是什么？（蓝色标出）
- 求证是什么？（红色标出）
- 第一步为什么敢这么做？（回到依据）
5. **一题多证**：经典定理（如勾股定理）给 2–3 种证法，每种独立一页，页尾对比"哪种你最喜欢？为什么？"——**让学生对证明产生审美，而不是恐惧**。

**首批 proof-replay 清单**（每种 1–2 页）：
1. 三角形内角和 = 180°（撕角拼角 → 平行线法，两版）
2. 对顶角相等
3. 平行线判定/性质（一组即可，判定和性质对比一页）
4. 三角形全等判定 SAS（叠合法：两个三角形"叠"到一起的动画就是证明）
5. 等腰三角形"三线合一"（对折法：沿对称轴对折，重合即证明）
6. 勾股定理（赵爽弦图版 / 总统证法版，任选其一为主，另一为"换种看法"）
7. 平行四边形对角线互相平分（旋转 180° 重合法）
8. 圆周角定理（分三种情形，圆心在角内/角上/角外——**这是"分类讨论"第一次正式亮相**，每种情形一页）

### 4.3 动画演示设计原则（几何六式）

| 动画式 | 干什么用 | 设计要点 | 典型例子 |
|---|---|---|---|
| **拖拽顶点** | 看变化中什么不变 | 必须配不变量徽章；拖动时数值/标记实时更新；边界情况要"兜住"（如三角形拖成直线时提示"它快不是三角形了"） | 三角形内角和、四边形内角和、全等判定 |
| **旋转/翻折** | 看对称、全等叠合 | 慢动作 + 定格关键帧（0°/90°/180°/重合瞬间）；旋转中心用红点标出；支持"转半圈看看"一键按钮 | 轴对称、中心对称、SAS 叠合法证明 |
| **切割拼补** | 看面积守恒 | 块用不同颜色编号（①②③④）；切割线先虚线预览再实切；拼的过程中允许"块飞过去"的动画，但落点必须精确 | 勾股定理、平行四边形面积→矩形、圆面积→近似长方形 |
| **生长/收缩** | 看数量关系 | 滑块控制参数，图形连续变形；关键数值（如面积）同步显示；变形过程 ≤ 3 秒 | 勾股正方形生长、相似比变化、扇形面积随圆心角变 |
| **分层剥离** | 看结构 | 生活照片→线框（跃升 1）；立体→三视图（跃升 6）；复杂图形→基本图形（"这个图形里藏着几个三角形？"） | 组合图形面积、展开图 |
| **轨迹追踪** | 看动点规律 | 点运动时留下轨迹（可开关）；轨迹逐点绘制不是一次性出现；配"暂停看此刻" | 中点轨迹、角平分线上的点到两边距离、圆的定义（到定点等距的点的轨迹） |

**通用铁律**：
- 动画时长 ≤ 3 秒完成一次完整演示，支持重播和 scrubber（拖进度条）。
- 纯播放动画只能做辅交互；主交互必须是学生能动手改变点什么的。
- 手机端：拖拽目标 ≥ 44px 触摸区，顶点拖拽加"吸附"（靠近特殊位置如中点、垂直时自动吸附并震动提示，复用英语页卡塔音效经验）。
- 所有动画必须有"**定格提问**"：在关键帧暂停，弹出一个问题（"现在两个三角形能重合吗？"），学生点了"是/否"（不判对错，只记录）才继续——**把"看动画"变成"想问题"**。

## 五、讲解页规范（代数重构的经验：交互页后 1+ 页完整讲解）

### 5.1 为什么必须有讲解页

代数重构的教训：光有交互，学生"玩得很开心，但说不清学到了什么"。讲解页是把"手感"变成"能说出口的知识"的唯一桥梁。几何比代数更需要——因为几何的结论（定理）是要被记住和调用的。

### 5.2 讲解页结构（五段式，一页一屏，文字上限放宽到 300 字）

```
1. 静态关键帧图（交互页最精彩的那一帧定格）+ 一句话：
"还记得吗？你拖到这里时，××一直没变。"
2. ≤ 80 字的定义，用生活语言先说一遍：
"全等，就是'能完全重合'——像复印机印出来的两张纸。"
3. 生活例 → 图形例 → 反例，各一句话 + 小图：
- 生活例："两扇一样的门"
- 图形例：两个三角形，三边三标记同色
- 反例："大小不一样的两扇门，形状一样但不能重合——那叫相似，不是全等"
★ 反例是强制的：每个概念的讲解页必须有一个"长得很像但不是"的东西。
4. 1–2 个，格式固定："⚠️ 别搞混：××不是××，因为××"
5. ≤ 20 字，能背下来的那种："全等要重合，相似只同形"
```

### 5.3 讲解页写作四不许

1. 不许"定义：…"式教科书腔开场——先人话，后术语（术语加括号标注，如"完全重合（全等）"）。
2. 不许只举一个例子——**三个是下限**（生活/图形/反例），不厌其烦是铁律。
3. 不许出现"显然""易知""同理可得"——要么写出来，要么写"这一步我们第 X 页玩过"。
4. 不许一页讲两个定理——判定和性质必须分开讲（如"平行线的判定"和"平行线的性质"是两页讲解页，中间用对比页衔接："判定是'因为平行所以… '还是'因为…所以平行'？把'因为''所以'换个位置，意思就反了"）。

### 5.4 术语"认旧友"标注规范

新术语第一次出现时，格式：**术语**（就是你第 X 页 + 动作/现象）。例如：
- **全等**（就是你第 12 页把两个三角形"叠"到一起的那个动作）
- **对应边**（就是叠上去之后压在一起的那两条边，同色的那两条）
- **圆心角**（就是第 30 页你拖的那个"角"，顶点在圆心上）

## 六、习题页规范（每章末 5–8 道，由易到难，答案折叠）

> 说明：代数模块"不做题"是因为练习另有模块；几何不同——**几何的"看图说话"能力必须通过做题固化**，且用户要求"作图、证明步骤都要直观"，习题是检验自学效果的唯一闭环。所以几何每章末设习题页。

### 6.1 梯度结构（固定 5 档，共 5–8 道）

| 档 | 数量 | 题型 | 例子（全等章） |
|---|---|---|---|
| ① 认图 | 1–2 道 | 看图选/判断：这是不是××？ | "下面哪两块拼图是全等的？"（拖拽配对） |
| ② 直用 | 1–2 道 | 定理直接套用，一步出答案 | "已知 △ABC ≌ △DEF，AB=3，求 DE" |
| ③ 小综合 | 1–2 道 | 2–3 步：找对应 → 列式 → 求解 | "长方形 ABCD，E 是中点，求证 △ADE ≌ △BCE"（给图，需自己标对应） |
| ④ 变式 | 1 道 | 图形换个方向/位置，考"认不认得" | 把上一题的长方形旋转 45°，再问一次 |
| ⑤ 生活建模 | 1 道 | 真实场景：先把生活翻译成图形，再解 | "两扇门一边大一边小，师傅说'看着差不多'，你怎么用全等的知识说服他返工？" |

### 6.2 答案折叠规范

1. **三级折叠**：→→，逐级展开。学生先看提示，实在不会再看步骤，最后对答案。
2. 思路提示 ≤ 30 字，只指方向不给过程："先找对应顶点，A 对的是谁？"
3. 证明题的完整答案用两栏式（陈述|理由），与 4.2 的"证明书"格式一致。
4. 每道题尾标注"用到的定理：××（第 X 页）"，形成回链。

### 6.3 手机做题

- 选择/配对/判断题直接在页内点选；
- 证明题、作图题不要求在线作答——给"**自查清单**"（"我的证明里每个'因为'都有理由吗？"），学生对照着在纸上写，写完对照折叠答案；
- **不记分、不排名**，答错只给提示不给红叉（自学教材的底线：不制造挫败感）。

| 圆面积 | 切成 16/32/64 瓣拼成长方形（滑块加瓣数，越拼越"方"） | 披萨分瓣 | 与积分思想呼应（代数第十二章回链） |

| 三视图 | 探照灯三束光（主交互）；从三个方向拍物体 | 工程图纸 | 易错：左视图是从左"看"到的，不是左边"有"什么 |
| 展开图 | 纸盒压扁↔折起（可逆动画）；正方体 11 种展开图（"一四一""二三一"口诀 + 可拖验证） | 快递纸箱、牛奶盒 | 反例："田"字形折不成正方体（四个连一排的中间那个） |
| 坐标系 | 电影院找座位（几排几号）；下棋记谱 | 寻宝游戏：按坐标找宝藏 | 象限：一二三四"逆时针转圈"口诀 |
| 两点间距离 | 勾股定理的坐标版（画直角三角形看坐标差就是勾和股） | 地图两点距离估算 | 与代数"数轴上两点距离=|a-b|"回链 |

## 八、与代数的呼应（数形结合的双向打通）

几何不是另起炉灶，而是代数"形"的那一半的展开。以下页面与代数模块**双向链接**（页尾"回看代数第 X 页"/"预告几何第 Y 页"）：

| 代数页 | 几何呼应页 | 呼应方式 |
|---|---|---|
| 导论 P1 猜数字（x+5=12） | 导论：线段图 | 用线段的长度表示未知数：画一条"比 5 长一点"的线段，它是几？——**数与形的第一次握手** |
| 0.1.3 无理数（√2） | 勾股定理：边长为 1 的等腰直角三角形，斜边"量不出来" | "√2 不是算出来的，是**画出来的**"——正方形对角线就是 √2，几何给无理数一个"家" |
| 0.1.4 分配律 a(b+c)=ab+ac | 矩形面积拼图 | 同一页面的两种讲法：代数页用面积图证分配律，几何页用分配律算组合图形面积 |
| 2.2.1 平方差公式 | 平方差的几何证明（大正方形挖小正方形） | 代数 2.2.1 的"数形结合点"就是这页——两边做成**同一交互的不同入口** |
| 2.2.2 完全平方公式 | 正方形四块分割图 | 同上；另加"(a+b)² 的展开图"可拖动 a/b 滑块 |
| 代数重构专项：x² 是正方形 | 几何第一章：正方形的面积就是 x² | **用户钦定的单开图形动画页**：一个正方形，边长滑块 x，面积读数 x²——"x² 不是'叉方'，是一个**正方形**" |
| 不等式（数轴） | 射线/数轴 | "x > 3"在几何里就是"从 3 出发的一条射线"——不等式的解集第一次有了"形状" |
| 一次函数 y=kx+b | 平面直角坐标系 + 直线 | 函数图像的"纸"就是坐标系；斜率 k 就是几何里的"坡度"（与"爬坡"例子同一语言） |
| 二次函数抛物线 | 对称章：抛物线是轴对称图形 | "抛物线的对称轴"——代数里的 x=-b/2a，几何里就是"对折线" |
| 圆周率 π（0.1.3） | 圆的周长/面积 | "π 是圆的周长和直径的比值"——滚一圈量一量（交互：圆滚动，轨迹长度 = πd） |
| 比例/分式 | 相似比 | "a:b = c:d"就是"两张照片的缩放比一样"——比例第一次有了"看得见"的意义 |
| 数列（离散点列） | 轨迹 | 代数第九章的"点列"和几何"轨迹"是同一个东西：动的点留下的痕迹 |

**呼应页写作规范**：
1. 页内明确写出来龙去脉："这个式子你在代数第 X 页见过，当时我们说它是××；现在看它的'长相'。"
2. 不重复讲代数内容，只讲"形"的部分——"数的部分回代数第 X 页复习"。
3. 代数已上线的 273 页中，凡标注"数形结合点"的课，几何侧建页时优先做呼应页（清单见上表）。

## 十、风险点（黄队自查）

1. **手机作图精度**：手指在小屏幕上画弧/描红误差大。→ 对策：跟做模式以"点下一步"代替手画；必须手画处用吸附+容差（描红 80% 通过线）。
2. **证明过长劝退**：圆周角定理等证明步骤多、分支多。→ 对策：硬拆 5 步/页；一题多证只给"换种看法"入口，不并排。
3. **"不变量徽章"信息过载**：有的交互不变量有好几个（如拖平行四边形顶点）。→ 对策：每页只徽章**本课要教的那一个**不变量，其他的写进"细心的你发现了吗"折叠条。
4. **反例图画蛇添足**：反例选得不好会制造新误解（如用"椭圆轮子"讲圆，可能让学生记住椭圆）。→ 对策：反例必须经绿队审"数学上干净"；反例图加"❌ 不是××"水印式标注。
5. **与代数 273 页的术语一致性**："对应边""不变量"等词在代数页出现过，需统一说法。→ 对策：开工前蓝队从代数数据文件抽术语表，黄队逐词对齐后再写几何页。
6. **图片版权**：photo-peel 需要生活照片（桌子、纸盒、剪刀等）。→ 对策：全部用**自拍/自绘**，不用网上搜图；或用 CSS/SVG 简笔画代替照片（黄队倾向后者：零版权风险、file:// 零加载）。
7. **绿队几何课程体系未出**：本文件章节是黄队建议稿，页数估算（约 120–150 页）待绿队体系确认后调整。
