## 一、设计总纲：六条铁律 + 地理专属三条

### 1.1 沿用几何六条铁律（地理转述版）

1. **一页一概念**：一屏只讲透一个核心概念。宁可多一页，不可一页塞两个概念。地理课常犯"一页讲完经线又讲纬线"——拆开（dg01.2.1、dg01.2.2 各自独立成课已有此意，页内更要守住）。
2. **先动手，后结论**：交互动画在前，文字解释在后。学生先拖着地球仪转、亲手量出"北京在武汉的北边"，再看文字"这就是相对位置"。**交互区没有 exploreTip（动手提示）= 不合格**。
3. **图言永不分离**：每个地理结论旁边必须有对应的地图/景观图/示意图；**每个地理定义必须配一个"反例"**（"不是××的东西"）：每个判读规则的适用边界，本质上就是一组反例。只给文字不给图 = 不合格——地理是"看图说话"的学科，无图的讲解页直接判不合格。
4. **跃升必有台阶**：每个难度跃升点必须设计中间脚手架（见第三章），不许"显然""易得"式跳跃。**地理里最危险的跳跃是"读图跳跃"**：从地图直接跳到结论，中间缺了"你是怎么从图上看出来的"。
5. **密度上限**：每页 ≤ 3 个信息块（标题区 / 交互区 / 点拨区），≤ 2 个例子，文字总量 ≤ 150 字（讲解页 ≤ 300 字，见第四章）。地图页默认只开 ≤ 3 个图层（见 2.1 图层预算）。
6. **（地理转述）位置—格局—过程三问**：地理的灵魂是"它在哪、它长什么样、为什么是这样"。凡是讲区域/现象的交互，必须能回答三问：**位置**（在哪）、**格局**（怎么分布、长什么样）、**过程**（为什么是这样、以后会怎样）。对应几何"变化中找不变"，地理版叫**读数徽章 + 图层开关**：实时显示带规范单位的读数（如 `武汉：30°N, 114°E`、最冷月均温 `3℃`），徽章文字写清楚"这一层在回答三问中的哪一问"。

### 1.2 地理专属三条（黄队新增）

7. **图先文后（读图先行）**：**每个概念必先有一页"读图页"，学生从图里读出规律之后，才看文字结论**。地图是地理的第二语言——先学会"读"，再学"说"。教学顺序永远是：**看图 → 动手（量/找/判） → 说规律 → 文字确认**。例如 dg01.3.3 等高线：先拖"水位"滑块看等高线一条条"长"出来，再判读山脊山谷，最后文字给"凸高为谷、凸低为脊"。
8. **位置—格局—过程，顺序不许颠倒**：讲任何区域/现象，必须先定位（dg00.1.4 的方法），再描述格局，最后解释成因。**不许先讲成因再让学生找位置**——"为什么长江中下游多洪涝"之前，学生必须先在图上找到长江中下游、看到"地势低平+降水集中"的格局。例如 dg07 各国课：每国第一页永远是"在地图上找到它"。
9. **要素叠图综合观**：**任何一个区域的解释页，必须有一张"要素叠加"交互**：地形/气候/河流/人口/交通/产业图层可开关，关掉某一层看结论怎么变。自然要素与人文要素必须"叠"起来看——"武汉为什么是九省通衢"，答案不在任何一张单图里，在"长江+铁路+平原"三张图的叠加里。这是可持续发展（dg15.3）的思维地基。

### 1.3 "先直觉后严格"分层与口径记录

地理全书有三处"本书直觉版 → 后章严格版"的分层（与地理专家队冲突时，按"本页给直觉版、注'严格表述见后章回填'"处理；以下口径差异已记录，待地理专家队确认）：

1. **区域认知方法**：dg00.1.4 课内讲"定位 → 描述 → 解释"三步（直觉版，好上手）；全书贯穿时黄队用"定位 → 描述 → 解释 → 应用（预测/评价）"四步（dg12、dg13、dg15 的区域分析页落到"应用"——如"如果你是武汉市长，防汛先保哪"）。课名"区域认知的方法（定位→描述→解释）"照抄骨架不改动，第四步在教学中延伸为"学以致用"页。**口径待确认**：四步法是否为全书统一口径，或仅作黄队教学延伸。
2. **气候**：dg03 讲"天气的平均脸""以温定带、以水定型"判读口诀（直觉版，会判读）；dg14.3 讲气候的形成机制——纬度、海陆、环流、地形（严格版，懂成因）。dg03 的口诀页必须注"为什么是这样，dg14.3 告诉你"，dg14.3 必须"认旧友"回填。
3. **板块/地貌**：dg02.2 讲"拼图能拼上、大陆在动"（直觉版，建信念）；dg14.4.2 讲内力作用与地貌类型（严格版，给机制）。dg02.2 不许出现"消亡边界/生长边界"术语（超纲词，见 4.3），只说"板块会相互挤压或张裂"。
4. **区时**：dg14.2.4 讲"向东追时间、东加西减"（直觉版，会计算）；国际日期变更线、"同一时刻全球日期不同"的严格化在同一课后半段完成（本课内分层，不跨章）。

## 二、每页结构规范（沿用物理三块式，地理微调）

### 2.1 页面结构

```
┌─────────────────────────────┐
│ 标题区（一句话概念） │ ← ≤ 20 字，flex none
├─────────────────────────────┤
│ │
│ 交互区（主角，占 60%） │ ← flex 1：地图/地球仪/判读器在这里
│ 读数徽章（小标签） │ ← ★地理版：经纬度/气温/降水等规范读数
│ 三要素条（方向/比例尺/图例）│ ← ★地理新增：每张地图的"身份证"
│ 图层开关（≤ 3 个默认开） │ ← 要素叠图页专用
├─────────────────────────────┤
│ 点拨区（≤ 60 字 + 下一步） │ ← flex none，"这就是××"式点题
└─────────────────────────────┘
```

**地理微调说明**：

- **读数徽章**：交互区角落的小标签，随交互实时更新。**所有数值读数走 MathML、单位与数值同行**（`30°N, 114°E`，不许裸文本 "30N,114E"；`最冷月均温 = 3℃`，不许裸文本 "3度"）。经纬度符号规范：度 °、分 ′（如需），东经 E/西经 W、北纬 N/南纬 S。读数徽章是第六条铁律的落地——学生即使不看文字，也能从徽章里读出"位置/格局"信息。例如 dg01.2.3 经纬网定位页：徽章 `经度 = …，纬度 = …`；dg03.2.4 气候判读页：徽章 `最冷月 = …℃（定带）｜年降水 = …mm（定型）`。
- **三要素条（地图身份证）**：**每张地图下方常驻一行小字：方向（指向标/N）｜比例尺（数字式/线段式）｜图例（本图颜色含义）**。缺任何一项 = 不合格（dg01.3.2 的内容，前置为全书所有地图页的强制检查项）。示意图（非精确地图）三要素条改为"**示意**｜非精确比例｜方向仅供参考"（见第九章）。
- **图层预算**：要素叠图页默认只开 ≤ 3 个图层，其余折叠在"更多图层"里。图层开关切换时，页面顶部小字明示"现在叠的是：地形 + 气候"（对应化学三重表征切换器的"明示当前视角"）。
- **投影/变形声明**：世界地图页角落常驻小字"××投影：面积/形状有变形"（见第九章），不误导"地图即真实"。
- **"先猜后验"**：每类判读/定位交互页配"猜一猜"小条——学生先点选预测（"武汉在北京的哪个方向？"），再动手验证。**不判对错**，只记录（蓝队 Y1 `guess-verify` 复用物理）。

### 2.2 四类页面的分工（地理四步走：看 → 找 → 懂 → 练）

| 页类型 | 作用 | 结构 | 占比 |
|---|---|---|---|
| **读图页** | 看：在地图/景观图上观察，读出第一印象 | 三块式 + 三要素条 + exploreTip（"在图上找到××"） | 约 25% |
| **交互定位/判读页** | 找：动手量方向、算比例尺、判读等高线/气候图 | 三块式 + 读数徽章 + 闯关（Y14–Y18） | 约 30%（113 课每课 1 页起） |
| **讲解页** | 懂：读图之后 1–2 页完整讲解，位置→格局→过程 | 见第四章 | 约 35% |
| **习题页** | 练：每章末，答案折叠；**每章必有一道读图题 + 一道"生活中的地理"题** | 见第五章 | 约 10% |

**顺序铁律**：同一概念内，顺序必须是 **读图页 → 交互定位/判读页 → 讲解页 →（章末）习题页**。不许先给结论再让学生看图——结论是学生自己"从图上读出来"之后，黄队用文字帮他"说出来"。**特别地，判读规则页的顺序永远是：看图 → 动手判 → 口诀 → 反例/边界**（第七条铁律）。

### 2.3 讲解页与交互页的衔接语规范

- 讲解页开头第一句必须是"认旧友"："还记得吗？你第 X 页拖着地球仪转，看到武汉在北京的南边。"（沿用几何"认旧友"标注规范）
- 读图页/判读页的 exploreTip（≤ 40 字）只说"动手做什么"（"在图上找到长江，描出它的干流"），不说结论。结论永远在点拨区，由学生"看到"之后黄队点题。

### 2.4 每页自查清单（地理版）

- [] 一屏能看完，不滚动（手机 390px 为准）
- [] 主交互是"动手改变点什么"（拖/转/开关图层/点选判读），不是纯播放
- [] 读数徽章走 MathML、经纬度/单位规范；写清楚了"这一层在回答三问中的哪一问"
- [] 每张地图有三要素条（方向/比例尺/图例），缺一项即不合格；示意图已标"示意"
- [] 点拨区 ≤ 60 字，最后一句是"这就是××"式点题（规律/地名/结论）
- [] 判读规则页顺序：看图 → 动手判 → 口诀 → 反例/边界；口诀 ≤ 20 字
- [] 颜色编码符合全局约定（地形分层设色、暖流红/寒流蓝等，见第八章）；状态永远双编码（颜色 + 文字/图案）
- [] 有生活化例子（主例进交互，次例进口拨）；武汉/湖北例子注明了落点课号（见第六章）
- [] 新名词标注了"就是你第 X 页玩过的那个动作/看到的那个东西"
- [] 世界地图页有投影/变形声明；数据页注明了年份（人口/经济数据）

## 三、难度跃升脚手架（10 个地理特有卡点）

> 每个脚手架 = 卡点描述 → 分步脚手架（**立靶页 → 脚手架 → 严格化 → 回填链**）→ 点拨话术。课号取自任务课程骨架（dg00–dg15）。

### 跃升 1：平面地图 → 三维地球（经纬网三维想象）

- **卡点**：学生看惯平面地图，把经纬网当"方格纸"。纬线圈越往两极越小、经线在极点相交——平面图上"看"不出来，一考"最短航线"就错。
- **脚手架**（dg01.2.1–2.3，3 页）：
1. 立靶页：可旋转地球仪交互（Y14 `latlon-lab`）——拖一拖，读数徽章实时显示指到点的经纬度。"经纬网是地球的'渔网'：经线是竖网线，纬线是横网线——但这张网越往两极，网眼越小。"
2. 脚手架：东西经/南北纬判定闯关——"0°经线以东是东经，赤道以北是北纬"；切到极点视角，看经线"汇成一点"、纬线变成同心圆。"纬线圈有大有小（赤道最大），经线圈都一样大。"
3. 严格化 → 回填链：dg14.2.4 区时回填（"经度差 15°，时间差 1 小时——渔网眼的'时间版'"）；dg14.2.3 晨昏线回填（"高纬昼夜长短变化大，正因为网眼随纬度变"）。
- **点拨话术**："经纬网是地球的'渔网'，但这张网越往两极眼越小。**记住两句：纬线圈有大有小，经线圈都一样大——极点是经线的'交汇点'，所有经线到那儿都交汇；到了极点，'网眼'缩成一个点。**（T1 翻译确认：渔网是罩在球上的球形网，不是平铺的方格纸）"

### 跃升 2：等高线判读（平面线条 → 立体地形）

- **卡点**：等高线是全书第一个"把立体压成平面"的符号。"凸高为谷、凸低为脊"与生活直觉（"凸起=山包"）正好相反——全书级易错，不立靶必错。
- **脚手架**（dg01.3.3，3 页）：
1. 立靶页：等高线图 ↔ 3D 地形联动（Y15 `contour-quest`）——拖"水位"滑块，等高线一条条"长"出来。"等高线是'等高楼的楼层线'：同一条线上，海拔一样高，就像同一层楼的地板一样高。"
2. 脚手架：山脊/山谷判读闯关——"水往低处流"：等高线"凸向高处"的地方，水顺着凸的方向流下去成河，是山谷；反之是山脊。口诀：**凸高为谷、凸低为脊**（红线辨析①）。
3. 严格化 → 回填链：dg09.1.1 中国地形回填（用地形剖面图读"西高东低、三级阶梯"）；dg14.4.2 地貌回填（"流水侵蚀形成山谷——'谷'字有了成因，不再是口诀"）。
- **点拨话术**："看等高线，先问'水往哪流'——水往低处流，顺着等高线'凸'的方向流下去的地方就是山谷。**凸高为谷、凸低为脊，这句一辈子别记反。**（T2 翻译确认：'等高楼的楼层线'只讲'等高'——陡崖处等高线重合是'楼层叠在一起'，图边被截断是'楼没画完'；判山脊山谷只看水流方向，不许用'楼层'反推）"

### 跃升 3：比例尺"大详小略"

- **卡点**："比例尺大"被理解成"图画得大"；"分母越小、比例尺越大"反直觉，一考就反。
- **脚手架**（dg01.3.1，2 页）：
1. 立靶页：同一地区两幅图对比（1:10000 vs 1:1000000）——"哪张看得细？"拖缩放滑块看细节出现/消失。"**大详小略**：比例尺大（分母小），内容详细、范围小；比例尺小（分母大），内容简略、范围大。"
2. 严格化：数字式/线段式/文字式三式互换；"图上 1 厘米代表实地多少千米"换算闯关。→ 回填链：dg01.3.3（"地形图多用大比例尺——看得细，才画得出等高线"）。
- **点拨话术**："比例尺的'大'说的是比值，不是纸大。**分母小、比例尺大、看得细；分母大、比例尺小、看得略——大详小略。**"

### 跃升 4：地球自转 → 昼夜交替与晨昏线

- **卡点**："昼夜交替是因为地球自转"停留在背诵；晨昏线是"动"的、斜的，学生把它当成画在地图上不动的一条线。
- **脚手架**（dg14.2.1 → dg14.2.3，3 页）：
1. 立靶页：地球自转动画（Y18 `terminator-sim`）——太阳照一边。"转一圈是一天：亮的那半是白天，暗的那半是黑夜。"
2. 脚手架：晨昏线"扫"过武汉——拖时间滑块，"武汉天亮了 → 天黑了"。"晨昏线是昼夜的分界线，它跟着地球一起转，不是钉在地图上的。"
3. 严格化 → 回填链：dg14.2.3 昼夜长短——拖"日期"滑块到 6 月/12 月，武汉昼夜长短读数变化；回填 dg03（"昼夜长短的季节变化 → 太阳辐射的季节变化 → 四季和气候"）。
- **点拨话术**："昼夜交替不是太阳'绕着我们跑'，是我们在'转着晒太阳'。**晨昏线是会动的分界线——它扫到哪，哪就天亮。**"

### 跃升 5：区时计算"东加西减"

- **卡点**：方向基准混乱——"以谁为东？"；日期在国际日期变更线处加减反；"东边时间早"被当成无条件真理。
- **脚手架**（dg14.2.4，3 页）：
1. 立靶页：世界时区图（Y16 `timezone-calc`）——"向东追时间"：往东走一格，钟表拨快一小时。"**东加西减**——加还是减，看'目标在已知地的东边还是西边'：基准是两地的**相对方位**，不是'地图的东边'。"
2. 脚手架：分步计算闯关（定时区 → 定东西 → 加减小时 → 看日期）：北京时间 8 点，纽约（西边）是几点？悉尼（东边）是几点？
3. 严格化 → 回填链：国际日期变更线——"向东追时间追过头，日期要减一天"；回填 dg01.2（"经度差 15° = 1 小时——渔网眼的'时间版'"）。
- **点拨话术**："**东加西减，基准是'相对方位'**——目标在东边就加，在西边就减。'东边时间早'只在同一天内成立；跨过日界线，日期要'找回来'：向东过日界线减一天，向西过加一天。（T3 翻译确认：'追时间'追的是'先到的时刻'——东边先看到日出，所以东边的时刻先到；方向基准是两地的相对方位/东经度增大方向，不是地图的东边）"

### 跃升 6：气候判读"以温定带、以水定型" + 气候资料图双读

- **卡点**：气温曲线 + 降水柱状图两个变量一起读，学生只看一个；"温度带"与"具体类型"的判定顺序混乱，一上来就猜"地中海气候"。
- **脚手架**（dg03.2.4，3 页）：
1. 立靶页：气候资料图判读器（Y17 `climate-chart`）——两步向导：第一步"以温定带"（先看最冷月均温：>15℃ 热带、0～15℃ 亚热带、最冷月<0℃ 温带；再看最热月：<10℃ 寒带）；第二步"以水定型"（看年降水总量 + 季节分配）。"气候是'天气的平均脸'：先看脸的冷暖（温度带），再看表情的干湿（降水型）。"
2. 脚手架：武汉 / 北京 / 广州三地真实资料对比判读闯关（武汉：最冷月约 4℃、年降水约 1200mm → 亚热带季风气候）。
3. 严格化 → 回填链：dg14.3.3 气候的形成（"'以温定带'背后是纬度/太阳辐射，'以水定型'背后是海陆位置/大气环流——口诀有了成因"）。
- **点拨话术**："判读气候永远两步：**先以温定带，再以水定型**——温度定'带'（冷暖），降水定'型'（干湿）。顺序不能反，两个变量不能只看一个。（T4 翻译确认：'平均脸'是多年平均的'常态'；但气候也会'变脸'——年际变化、极端天气（台风/寒潮）就是平均之外的表情，dg09.2.3 回填）"

### 跃升 7：季风成因（海陆热力差异 + 气压带风带季节移动）

- **卡点**：两个成因一次全给会噎住；"夏季风从海洋吹来"被背成孤立结论，与气压带风带（dg14.3.1）脱节。
- **脚手架**（dg14.3.2，3 页）：
1. 立靶页：季风模拟（Y19 `monsoon-sim`）——冬/夏切换：冬天陆地冷高压、风从陆地吹向海洋；夏天反过来。"季风是'会掉头的风'：**夏天从海洋吹来（暖湿多雨），冬天从陆地吹去（干冷少雨）。**"
2. 脚手架：海陆热力差异实验——沙子 vs 水，谁升温快、谁降温快？"陆地'脾气急'：升温快、降温也快——夏天陆地热成低压，冬天陆地冷成高压；风从高压流向低压。"
3. 严格化 → 回填链：dg14.3.1 回填（"季风的大背景是气压带风带的季节移动"）；回填 dg09.2.2（"武汉的梅雨和伏旱，都是季风'掉头'闹的：6–7 月江淮准静止锋 → 梅雨，7–8 月副高控制 → 伏旱"）。
- **点拨话术**："记住季风的两句话：**陆地脾气急，冬夏压力反；风从高压流向低压，冬夏方向掉个头。**（T8 翻译确认：'掉头'是东亚季风的直觉版（冬夏风向大致相反）；南亚季风的'掉头'还叠加了气压带风带的季节移动，严格版见 dg14.3.2）"

### 跃升 8：板块构造（看不见的运动）

- **卡点**：板块运动"看不见、摸不着"，一年只动几厘米，"大陆在动"像神话；直接讲六大板块变成背地名。
- **脚手架**（dg02.2.2，3 页）：
1. 立靶页：板块拼图（Y20 `plate-puzzle`）——把南美洲和非洲拼起来，海岸线"严丝合缝"。"板块是'漂在软流层上的拼图块'——拼图能拼上，不是巧合。"
2. 脚手架：证据链三拼图——大陆轮廓 + 古生物化石 + 岩层："三条证据都指向同一个结论：它们以前连在一起。"
3. 严格化 → 回填链：六大板块 + "挤压/张裂"两种运动（本课不讲"消亡边界/生长边界"术语，见 4.3）；回填 dg14.4.2（"喜马拉雅山还在长高——印度洋板块向亚欧板块下'钻'"）、dg02.2.1（"'沧海桑田'有了机制"）。
- **点拨话术**："**拼图能拼上，化石对得上，岩层连得上——三条证据，一个结论：大陆在动，只是动得慢，一年几厘米。**（T9 翻译确认：'漂'字只在引入时用，严格表述一律用'缓慢移动'——软流层是塑性固体，不是水）"

### 跃升 9：区域差异与综合分析（秦岭—淮河线）

- **卡点**：区域差异要素多（气温/降水/植被/农业/生活），学生"各背各的"，形不成"一线之隔、处处不同"的整体感；分界线被当成"刀切"的一条几何线。
- **脚手架**（dg12.1.1，3 页）：
1. 立靶页：区域要素叠图（Y21 `region-overlay`）——秦岭—淮河线南北对照：1 月 0℃ / 800mm 年降水 / 水田旱地 / 水稻小麦，图层一个个叠上去。"这条线是'中国南北的分界线'：一线之隔，冬天冷暖、雨多少、种什么、吃什么都不一样。"
2. 脚手架：湖北定位——"湖北在哪一边？"（湖北大部在线以南 → 亚热带、种水稻；鄂西北山区接近分界线，冬季更冷）。"分界线不是'刀切'的，是过渡带——**大致**以这条线为界。"
3. 严格化 → 回填链：dg12.1.2–1.4 四大地理区域综合（"每个区域都是一张'要素叠加图'"）；回填 dg15.3（"'因地制宜'就是区域差异的政策版"）。
- **点拨话术**："**区域差异不是'背差异'，是'叠图看'——把气温、降水、农业一张张叠上去，差异自己'长'出来。记住：分界线是过渡带的中心线，**大致**以这条线为界，不是刀切线。**（T10 翻译确认：一线六义——气温、降水、温度带、干湿区、耕地、作物，线南线北各不同）"

### 跃升 10：产业区位与可持续发展（多要素权衡）

- **卡点**：区位因素背清单（原料/市场/交通/劳动力/政策……），一做题就"哪个都重要"；可持续发展停留在口号，"不吃子孙饭"不会用。
- **脚手架**（dg15.2.1 → dg15.3.3，3 页）：
1. 立靶页：产业区位权衡器（Y22 `site-select`）——给钢铁厂 / 软件园 / 服装厂选址：同样的三个城市，答案不一样。"**区位没有标准答案，只有'权重'不同——原料对钢铁厂是命，对软件园是路人。**"
2. 脚手架：武汉案例——"为什么武汉能成'九省通衢'？"（长江黄金水道 + 京广线 + 高铁枢纽 + 江汉平原腹地——交通区位的叠加；Y21 要素叠图复用）。
3. 严格化 → 回填链：dg15.3 可持续发展——"发展不能'吃子孙饭'：武汉湖泊保护（东湖） vs 围湖造田的历史教训"；回填全书（"'人地关系'是地理的终极问题——dg00.1.1 的问题，在这里收束"）。
- **点拨话术**："**选址不是背清单，是'称权重'——先问'这个产业最怕缺什么'，再看哪个城市给得起。可持续发展就是：当代人要发展，子孙的'本钱'不能动。**（T12 翻译确认：'称权重'首次出现时配定义——就是找'主导因素'（对结果影响最大的因素）；T13 翻译确认：'不吃子孙饭'讲的是代际公平，三原则（公平性、持续性、共同性）的人话版在 dg15.3.3 严格化——'当代人之间也要公平，南北国家共同但有区别的责任'）"

## 四、讲解页规范（沿用物理六段式，地理微调）

### 4.1 为什么必须有讲解页

光有交互，学生"玩得很开心，但说不清学到了什么"。地理比物理更需要讲解页——因为地理的结论是**从图上读出来的规律**（位置 → 格局 → 过程），学生必须能用嘴说出来"我在图上看到了什么、它说明了什么"。

### 4.2 讲解页结构（六段式，一页一屏，文字上限 300 字）

```
1. 读图回顾（交互页最精彩的那一帧定格）+ 一句话：
   "还记得吗？你把水位拖到 200 米时，等高线围成了一个小圈圈。"
2. 人话定义（≤ 80 字），人话先行，术语第二句：
   "等高线就是'等高楼的楼层线'：同一条线上，海拔一样高。地理上叫：地图上连接海拔相同各点的闭合曲线。"
3. ★ 要素/成因卡片（地理专属，固定版式）：
   ┌─────────────────────────┐
   │ 位置 → 格局 → 过程       │
   │ 位置：它在哪（经纬/相对位置）│
   │ 格局：它长什么样/怎么分布（读图）│
   │ 过程：为什么是这样（成因/机制）│
   └─────────────────────────┘
4. 生活例 → 身边例（武汉/湖北优先）→ 反例，各一句话 + 小图（反例强制）：
   - 生活例："……"
   - 身边例："武汉/湖北的××"
   - 反例："长得很像但不是××的东西"
5. 误区警示 1–2 个，格式固定："⚠️ 别搞混：××不是××，因为××"
6. 口诀 ≤ 20 字 + 下一步（"下一页我们去××看看" / 回填链接）
```

### 4.3 讲解页写作四不许（地理版）

1. 不许"定义：…"式教科书腔开场——先人话，后术语（术语加括号标注，如"等高楼的楼层线（等高线）"）。
2. 不许只举一个例子——**三个是下限**（生活/身边/反例），不厌其烦是铁律；身边例优先武汉/湖北（见第六章）。
3. 不许出现"显然""易知""同理可得"——要么写出来，要么写"这一步我们第 X 页玩过"。
4. 不许超纲术语提前用——本课没讲的术语不许提前用（如 dg02 不许出现"消亡边界/生长边界"，dg03 不许出现"气压带风带"，dg09 不许出现"季风环流"机制）；必须用时加"预告"标注并配"直观版"一页（见 1.3 分层）。

### 4.4 术语"认旧友"标注规范

新术语第一次出现时，格式：**术语**（就是你第 X 页 + 动作/现象）。例如：
- **等高线**（就是第 X 页你拖水位"长"出来的那一圈圈"楼层线"）
- **季风**（就是第 X 页你切冬天/夏天、看到风向"掉头"的那个风）
- **秦岭—淮河线**（就是第 X 页你一层层叠图、看到南北"一线两样"的那条线）

## 五、习题页规范（每章末，答案折叠，必有一道读图题 + 一道生活题）

> 地理必须做题——"会看图"不等于"会判读"：方向判读、比例尺换算、等高线判读、气候图双读、区时计算必须通过做题固化。

### 5.1 梯度结构（固定 5 档，每章 5–8 道）

| 档 | 数量 | 题型 | 例子 |
|---|---|---|---|
| ① 认图 | 1–2 道 | 看图认：这是什么图？三要素齐了吗？ | "这张图的比例尺是数字式还是线段式？缺了什么？"（认三要素） |
| ② 填图/直用 | 1–2 道 | 在图上描/填/量：描出长江干流、量算实地距离 | "图上 2 厘米，比例尺 1:1000000，实地多少千米？"（**必须写单位与换算过程**） |
| ③ 读图判读 | 1–2 道 | 给一幅新图，判读：山脊/山谷、气候类型、方向 | "这幅等高线图上，A 处是山脊还是山谷？为什么？"（考红线①） |
| ④ 区域综合 | 1 道 | 2–3 步：定位 → 读格局 → 说成因 | "读武汉气候资料图：先定带、再定型，并说出判读依据"（考红线③） |
| ⑤ 生活中的地理 | 1–2 道（**每章强制 1 道生活题**） | 武汉/湖北真实情境综合题：定位 → 格局 → 对策 | "7 月去武汉旅游要带什么？用气候资料说明理由"（生活 + 读图） |

**每章末习题强制要求**：必有一道**读图综合题**（第③档或④档，给一幅没见过的图现场判读）+ 一道**"生活中的地理"题**（第⑤档，优先武汉/湖北情境）。计算类（比例尺换算、区时计算）必须写出步骤，答案无单位算错。

### 5.2 答案折叠规范

1. **三级折叠**：思路提示 →→ 关键步骤 →→ 完整答案。学生先看提示，实在不会再看步骤，最后对答案。
2. 思路提示 ≤ 30 字，只指方向不给过程："先问：三要素齐了吗？再看等高线凸向哪边。"
3. 完整答案必须带**读图依据**（"依据：等高线凸向高处 → 山谷（红线①）"），末尾附"口诀检查：×× ✓"。
4. 每道题尾标注"用到的规律：××（第 X 页）"，形成回链。

### 5.3 手机做题特殊规范

- 选择/判断/点选判读题直接在页内点选；填图/计算题不要求在线作答——给"**自查清单**"（"三要素检查了吗？口诀用对了吗？单位写了吗？步骤全吗？"），学生对照着在纸上写。
- **不记分、不排名**，答错只给提示不给红叉。
- 读图题评分口径：判读结论正确、依据说对即满分；鼓励学生把答案"讲给家人听"（费曼口径：能讲清楚才是真懂）。

### 6.3 例子使用三原则

1. **武汉优先，但不垄断**：每个概念优先找武汉/湖北的例子；找不到合适的不硬套（如热带雨林用新加坡、寒带用南极），并在页尾注明"为什么用它"。
2. **数据注年份**：人口、GDP、排名类数据必须注年份（如"2020 年第七次人口普查"）；气候用"多年平均"，不确定的写"约"。
3. **例子进红线**：例子不得与全书级红线四辨析冲突——如讲等高线必须用"凸高为谷"的正确判读举例，不许用"看起来像山包"的生活直觉举例。

## 九、地图科学诚实与规范（地理特有）

> 对应化学第九章"实验安全教学"。地理没有试管，但有另一条红线：**地图即权力**——国界、投影、数据年份，错一处就是事故。

### 9.1 分场景规范（一句话版，全书统一）

| 场景 | 涉及课 | 页面标注话术 | 讲解页补充话术 |
|---|---|---|---|
| 世界地图投影 | 全书世界地图页 | "××投影：面积/形状有变形"（角落常驻小字） | "地图是'翻译'：把圆球铺成平面，必有变形——看面积用等积投影，看形状用等角投影" |
| 示意图 vs 真实地图 | 全部示意页 | "**示意**｜非精确比例｜方向仅供参考"（三要素条变形版） | "这张图是'示意'：讲道理用，不查距离——查距离请用带比例尺的真图" |
| 国界/行政区划 | dg05.1.1、dg08 全章、dg13 | 口径与 curriculum 一致；争议处标"示意" | "台湾是中国领土不可分割的一部分；藏南、阿克赛钦按官方口径制图"（具体口径待地理专家队确认） |
| 人口/经济数据 | dg04、dg05、dg08.2、dg15 | 数据后注年份（如"2020 年第七次人口普查"） | "数据会过时：看年份！2020 年的数据，2026 年引用要说明" |
| "约/一般"用词 | 全书 | 不确定的数字写"约"（约 4 万千米、约 14 亿） | "'约'不是马虎，是诚实——测不准、变不停的数，硬写精确才是错" |
| 地形夸张 | dg01.3.3、dg09.1.1 剖面图 | "垂直比例夸大××倍（示意）" | "剖面图把高山'拉高'了，不然看不见——看趋势，不量高度" |
| 虚拟地形 | Y15 等高线 3D、Y18 晨昏线 | "示意，非真实比例/速度" | 同化学粒子动画标注规范 |

### 9.2 地图教学三原则

1. **三要素齐全**：每张真图必有方向/比例尺/图例（2.1 三要素条）；示意图必须标"示意"，不许拿示意图当真图用。
2. **先说"图能告诉你什么"，再说"图不能告诉你什么"**：投影页先讲"这张图适合看什么"（等积看面积），再讲"别用它量形状"。只给图不给边界 = 不合格。
3. **国界口径一票否决**：凡涉国界/行政区划的图，以地理专家队 curriculum 口径为准，黄队不自创、不"艺术加工"。

## 十一、风险点（黄队自查）

1. **"人话"滑向"错误直觉"**：如"板块漂浮"可能被理解为船浮水面。→ 对策：每句人话配边界句 + 术语第二句；全部经地理专家队"翻译"确认（10.4 清单）。
2. **地图页信息过载**：一张图上要素太多，学生看不过来。→ 对策：图层预算（默认 ≤3 层）；讲解页六段式固定顺序，不许"一图讲完一个章"。
3. **"背地图"倾向**：学生把"读图"学成"背图"（背下中国政区图）。→ 对策：习题第③档强制"给一幅没见过的图现场判读"；判读看**方法**（三要素+口诀），不看记忆。
4. **武汉案例过度集中**：全书"一城讲全书"亲切，但可能挤占其他区域案例（如西北、青藏的例子被武汉稀释）。→ 对策：6.3 第 1 条"武汉优先，但不垄断"；dg12.1.4、dg13.2 等区域课强制用本地案例。
5. **数据时效**：人口、GDP、排名类数据会过时。→ 对策：数据必注年份；curriculum 侧建"数据年份清单"，黄队页内引用时照抄。
6. **投影变形误导**：世界地图默认投影若不声明，学生会把格陵兰当成"很大"。→ 对策：第九章投影声明为强制检查项（白队 checklist）。
7. **初高中两套话语衔接**：dg03（直觉版"平均脸"）→ dg14.3（严格版"四因子"）之间隔着 11 章，学生可能"学了新的，忘了旧的"。→ 对策：回填页强制"认旧友"；dg14.3.3 开篇即复习 dg03 口诀再升级。
8. **国界/行政区划口径**：教学用图稍有不慎即事故。→ 对策：黄队不自绘国界图，所有涉界图以地理专家队审定底图为准（见 9.2 第 3 条）。
