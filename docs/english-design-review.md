## 第一轮：交叉找茬

### 🔴 英语专家队 → 黄队（英语正确性审查）

**5 项严重（E-M1–E-M5，全部采纳修补）**：

- **E-M1**："be 是'有礼貌的动词'"人话版边界不清——可能被理解为 be 有"礼貌"语义。✅ 采纳：仅限 gr00.1.1 直觉页；边界句已写入 pedagogy gr00.1 策略（"专门站在形容词前面"）；严格页一律用"系动词"。
- **E-M2**："although 和 but 是'仇人'"缺条件——复句/语篇中 although 与 but 可分属不同分句（如 "Although…, … But…" 跨句）。✅ 采纳：边界句"仅限单句内"已写入条件卡（G7）与 curriculum gr15.2.1（审计清单第 11 条：规则必注适用条件）。
- **E-M3**："条件从句里 will 被'没收'"缺条件——宾语从句中 will 正常（如 I wonder if it will rain.）。✅ 采纳：条件卡限定为"时间/条件状语从句"；gr13.1.1 设对照反例。
- **E-M4**："used to 三兄弟"口诀核查——used to do / be used to doing / be used to do 三分法表述准确，无概念错误。✅ 采纳保留（红队审计时复核例句）。
- **E-M5**："a 是'随便一个'"缺条件——不可数名词/复数不用 a。✅ 采纳：pedagogy gr01.2 策略已补条件句（"a 只管'可数单数'"）。

**6 项轻微（e-m1–m6，全部采纳）**：e-m1"信号灯" -s 灯文案确认（"主语是他/她/它时灯亮"）；e-m2"天平"比较级确认；e-m3"脱衣检查"改"成分槽归位"（避免"脱衣"歧义）；e-m4"变形车间"三出口标注 gr09/gr10 回填课号；e-m5"仇人"可视化配色不用红黑对立（避免"仇恨"联想，改用 ✗ 标记）；e-m6 例子库 E7"白日梦"注明仅限直觉页。
