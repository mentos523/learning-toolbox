### 0.2 语法专属色板映射 `--eng-*`

语法**不另起色板**：定义 `--eng-*` 语义变量，值全部别名 `--geo-*`（浅色/深色两套色值自动跟随几何的深色切换）。

```css
:root {
  --eng-subject:  var(--geo-known);    /* 主语：蓝 —— 句子成分标注 */
  --eng-verb:     var(--geo-target);   /* 谓语动词：朱红 —— 全书最重要的颜色 */
  --eng-object:   var(--geo-corr-a);   /* 宾语：橙 */
  --eng-complem:  var(--geo-corr-b);   /* 表语/补语：天蓝 */
  --eng-adverb:   var(--geo-corr-c);   /* 状语：蓝绿 */
  --eng-attrib:   var(--geo-aux);      /* 定语：灰（中性） */
  --eng-clause:   var(--geo-highlight);/* 从句块：黄底（配深色字） */
  --eng-error:    var(--geo-target);   /* 错误标记：朱红 + ✗ 文字（双编码） */
  --eng-correct:  var(--geo-corr-c);   /* 正确标记：蓝绿 + ✓ 文字（双编码） */
  --eng-card:     var(--geo-line);     /* 条件卡/规则卡描边：常规色 */
}
```

**映射问答**：句子成分 = subject 蓝 / verb 朱红 / object 橙 / complement 天蓝 / adverbial 蓝绿 / attributive 灰；**谓语动词恒用朱红**（全书视觉锚点："找动词先找朱红"）。从句块黄底 + "从句"文字标签（双编码：颜色 + 文字）。

### 0.3 全局铁律（语法页同样执行）

1. `params` 里**不出现具体色值**，只用 `--eng-*` 语义名；深色模式自动切换。
2. **逻辑单位 0–100**（y 向上），不写死 px；拖拽手柄热区 ≥ 44px，热区再外扩 50%。
3. 反馈走 M6：标注落定/判分**视觉必选**（flash/✓✗），`navigator.vibrate` 与合成音效为可选加分项。
4. 双编码：成分类型 = 颜色 + 文字标签；对错 = 颜色 + ✓/✗ 文字；从句 = 黄底 + "从句"标签，**绝不只靠颜色**。
5. 例句英文用常规字、中文释义小字灰字；例句词汇限初中考纲（超纲词加注）；语域标签（口语/书面）。
6. 讲解页口径沿用几何：`pageKind: "explain"` + 全页 ≤300 字 + 点拨区 36vh 内滚动；交互页 ≤150 字。

## §1–§8 语法专属交互 G1–G8

### G1 句子成分拖拽标注 constituent-tagging

- **用途**：gr00/gr12/gr19（成分识别、长难句拆解"剥洋葱"）。
- **玩法**：句子以词块呈现，学生把"主/谓/宾/表/定/状/补"标签拖到词块上；谓语块恒朱红高亮（视觉锚点）。
- **params**：`{ sentence: [{w, }], slots: ["主语","谓语","宾语","表语","定语","状语","补语"], allowMulti: bool }`
- **判分**：即时（对 ✓ / 错 ✗ + 一句话提示，不给答案，错 2 次后高亮正确标签位置）。
- **蓝队结论**：✅ 可接。纯 DOM 拖拽，零依赖可实现。
- **白队结论**：✅ 可接。增补 W-G1：390px 下词块自动换行不断句意、标签热区 ≥44px。

### G2 时态时间轴 tense-timeline

- **用途**：gr05/gr06（时态）、gr16（虚拟"时光倒流一格"）。
- **玩法**：横向时间轴（过去—现在—将来），拖动时间点 → 例句动词形态联动变化（go/went/gone/will go）；完成时显示"过去动作 → 现在结果"双点连线。
- **params**：`{ points: [{t, label, verbForm}], linkPastNow: bool, virtualZone: bool }`
- **蓝队结论**：⬇ **主动降级（教学聚焦）**：一期只做形态联动 + 双点连线；**不做**"听发音辨时态"（真实语音辨别在零依赖/file:// 约束下 ROI 为负，且与"零音频文件"铁律冲突）。真实理由已写明，非技术不可行。
- **白队结论**：✅ 可接。增补 W-G2：时间轴拖动手柄 ≥44px、虚拟区用虚线 + "假装区"文字（双编码，不只靠虚线）。

### G3 句型积木拼装 sentence-builder

- **用途**：gr00（五种基本句型）、gr12（并列句）、gr13–gr15（从句拼装）。
- **玩法**：主/谓/宾等积木块，拖入句型槽拼句；五种基本句型五种槽形；拼出双谓语（两个谓语块）时报警（跃升 1）。
- **params**：`{ pattern: "SVO"|"SVP"|"SVIO DO"|"SVOC"|"SV", blocks: [{w, role}] }`
- **蓝队结论**：✅ 可接。G1 的复用变体，共用拖拽引擎。
- **白队结论**：✅ 可接。增补 W-G3：积木块文字 ≥14px、槽位空态有虚线框 + 文字提示。

### G4 改错找茬 error-hunt

- **用途**：全书（中式纠偏条、gr19 改错十看）。
- **玩法**：句子中藏 1 个错误，学生点选"茬"（错误词块）；点对 ✓ + 纠偏话术条，点错 ✗ + "再想想"。
- **params**：`{ sentence, errorIndex, fixTip, cnNote }`
- **蓝队结论**：⬇ **主动降级（教学聚焦）**：一期只做**选择式找茬**（点选词块）；**不做**自由输入批改（自然语言批改需模型，零依赖约束下不可做）。真实理由已写明。
- **白队结论**：✅ 可接。增补 W-G4：✗/✓ 必须配文字（色盲双编码）、纠偏话术条 ≤40 字。

### G5 从句槽 clause-slots

- **用途**：gr13/gr14/gr15（从句是成分）。
- **玩法**：主句挖空一个成分槽（主/宾/定/状四槽），学生把从句块（黄底）拖入；放错槽弹回 + 提示（"that 从句不能当状语"）。
- **params**：`{ mainSlots: [...], clauseBlocks: [{text, kind}] }`
- **蓝队结论**：✅ 可接。G3 引擎复用 + 槽类型校验。
- **白队结论**：✅ 可接。增补 W-G5：从句块黄底 + "从句"文字标签（§0.2 双编码）。

### G6 词性换装 morph-dressup

- **用途**：gr11（构词法桥章）。
- **玩法**：词根小人 + 后缀外套（-tion/-ly/-ful…），穿上后词性标签变化；friendly 穿 -ly 仍是形容词→"卧底"报警。
- **params**：`{ root, suffixes: [{suf, pos}], traps: [...] }`
- **蓝队结论**：✅ 可接。纯展示 + 状态机。
- **白队结论**：✅ 可接。增补 W-G6："卧底"报警用 ✗ + 文字，不只靠颜色。

### G7 规则身份证 rule-id

- **用途**：全书（条件卡组件化）。
- **玩法**：规则卡片 = 规则（一句话）+ 身份证（适用条件）+ 反例（✗）；点击翻面（规则面 ↔ 条件面）。
- **params**：`{ rule, condition, counterExample }`
- **蓝队结论**：✅ 可接。复用物理 Y3 formula-id 范式。
- **白队结论**：✅ 可接。增补 W-G7：卡片翻面动画 <200ms、反例 ✗ 配文字。

### G8 中式对拍 cn-contrast

- **用途**：全书（中式纠偏条组件化）。
- **玩法**：左右对拍——左：中式句（✗ 灰底），右：地道句（✓）；中间"为什么"一句话；点击"为什么"展开汉语对照桥。
- **params**：`{ cnWrong, correct, why }`
- **蓝队结论**：✅ 可接。静态对照组件。
- **白队结论**：✅ 可接。增补 W-G8：左右布局在 390px 下改为上下堆叠（对拍方向注记"上✗下✓"）。

## §9–§12 黄队教学动作组件 Y1–Y4

> 黄队新增交互需求按 Y 编号流程处理：黄队提需求 → 蓝队评可实现性 → 白队评可用性 → 结论写入本节。**降级接受必须写明真实理由，不许用"否决"式措辞**（沿用物理 v1.1 §12.2 措辞规范）。

### Y1 先猜后验 guess-verify

- **需求**（黄队）：每类交互页配"猜一猜"小条，学生先点选预测再动手验证；**不判对错**，只记录（给后续学习报告留接口）。
- **spec**：沿用物理 Y1 口径（`recordKey` 冻结，见物理 interactions §14 Y1）。
- **蓝队结论**：✅ 可接（页面级 widget，不判对错）。
- **白队结论**：✅ 可接。增补 W-G9：猜测条不抢主交互焦点。

### Y2 例句朗读 sentence-speak

- **需求**（黄队）：例句配朗读按钮，学生跟读；语速可调。
- **spec**：`speechSynthesis` 英文朗读（`lang: "en-US"`，rate 0.5–1.0 可调）；**不支持时隐藏按钮**（降级，不报错）。
- **蓝队结论**：✅ 可接，带降级边界（特性检测 `in` 判断，不支持则隐藏；与讲词根板块 TTS 口径一致——浏览器合成语音，零音频文件）。
- **白队结论**：✅ 可接。增补 W-G10：朗读按钮 ≥44px、朗读时例句高亮跟随（可选，不阻塞）。

### Y3 改错判分 error-check

- **需求**（黄队）：习题页选择/填空判分，即时反馈。
- **spec**：选择题即时判分；填空题**大小写不敏感、前后空格容忍**；错 2 次后给提示（不直接给答案）。
- **蓝队结论**：✅ 可接。填空只做字符串归一化比对，不做语义批改（G4 降级边界同理）。
- **白队结论**：✅ 可接。增补 W-G11：判分反馈 ✓/✗ 配文字、填空输入框 ≥44px 高。

### Y4 成分标注练习 constituent-quiz

- **需求**（黄队）：G1 的练习模式——随机抽句，限时标注（不排名，只记录正确率）。
- **spec**：题库按章取句（curriculum 例句方向 → 生产队成句）；正确率记录 localStorage（try/catch 降级）。
- **蓝队结论**：✅ 可接。G1 引擎 + 题库配置。
- **白队结论**：✅ 可接。增补 W-G12：练习模式有明确"退出"按钮、一屏内完成。
