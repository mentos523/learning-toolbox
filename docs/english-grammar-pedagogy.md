> **英语严谨性由英语专家队负责**：规则表述、术语、适用条件与例外、例句合法性，全部以 `docs/english-grammar-curriculum.md`（英语专家队 v1.0）为准。黄队不发明语法说法，**黄队的生活化表达需经英语专家队"翻译"成站得住的说法**（curriculum 设计原则原话）。
> **约束**（用户拍板）：纯静态 HTML/CSS/JS、零 CDN、零外部字体、全相对路径、file:// 可打开；每页一屏、每页可交互、手机可用。
> **核心目标**（用户铁律）：初学者能自学的教材——讲清楚、多举例子、不厌其烦。**协作铁律（最高优先级）：黄队教学需求不妥协**，其他队全力满足黄队。

## 一、设计总纲：六条铁律 + 语法专属三条

### 1.1 沿用几何六条铁律（语法转述版）

1. **一页一概念**：一屏只讲透一个语法点。宁可多一页，不可一页塞两个规则。语法课常犯"一页讲完一般过去时又讲过去进行时"——拆开。
2. **先动手，后结论**：交互在前，文字解释在后。学生先在"时态时间轴"上拖动时间点看到动词形态变化，再看文字"这就是现在完成时"。**交互区没有 exploreTip（动手提示）= 不合格**。
3. **图言永不分离**：每个语法结论旁边必须有对应的可视化（时间轴、成分标注图、句型积木）；**每个语法规则必须配一个"反例"**（"这样说是错的"）：规则的适用条件，本质上就是一组反例。只给规则不给反例 = 不合格。
4. **跃升必有台阶**：每个难度跃升点必须设计中间脚手架（见第四章），不许"显然""易得"式跳跃。**语法里最危险的跳跃是"术语跳跃"**：从例句直接跳到"宾语从句"，中间缺了"从句是披着句子外衣的成分"。
5. **密度上限**：每页 ≤ 3 个信息块（标题区 / 交互区 / 点拨区），≤ 2 个例子，文字总量 ≤ 150 字（讲解页 ≤ 300 字，见第七章）。
6. **（语法转述）例句中找不变**：语法的灵魂是"什么在变、什么不变"。凡是可调参的交互，必须同时标出**变了什么**和**没变什么**——不变的那个，就是要学的规则。例如时态时间轴：拖时间点，变的是动词形态（go/went/gone），没变的是"主语 + 谓语"骨架。

### 1.2 语法专属三条（黄队新增）

7. **条件先行**：**每条语法规则，必先讲适用条件，再讲规则本身**。条件不是"注意事项小字"，是规则的"身份证"——没有身份证的规则不许上场。教学顺序永远是：**现象（例句） → 条件（什么时候成立） → 规则 → 反例（什么时候不成立）**。例如主将从现页：先玩"If it will rain"被判错的反例，再给规则，最后条件卡片"只在时间/条件状语从句中成立"。
8. **汉语对照是桥不是路**：**每条英语规则，先讲"汉语是怎么说的"，再讲"英语为什么不一样"**——桥的作用是定位差异，过桥之后必须拆桥，不许把汉语语序/逻辑留下来当英语规则。例如三单 -s 页：先承认"汉语'他跑'不用变"，再讲"英语用 -s 标记'他'和'现在'"，最后强调"这是英语的规矩，不是汉语的翻译"。
9. **例句先行**：**任何术语出现之前，学生必须先见过 3 个真实例句**。术语是给现象起名字，不是现象的入场券。例如"宾语从句"四字出现前，学生已在交互里拖拽拼出 3 个 "I know…" 句子；"定语从句"出现前，学生已玩过"the book (that) I bought"的积木。

## 二、每页结构规范（沿用几何三块式，语法微调）

### 2.1 页面结构

```
┌─────────────────────────────┐
│ 标题区（一句话规则）    │ ← ≤ 20 字，flex none
├─────────────────────────────┤
│ │                           │
│ 交互区（主角，占 60%）  │ ← flex 1：时间轴/成分标注/句型积木
│ 条件卡（小标签）      │ ← ★语法新增：规则的"身份证"
│ 反例条（"这样说是错的"）│    如"只在时间/条件状语从句中成立"
├─────────────────────────────┤
│ 点拨区（≤ 60 字 + 下一步） │ ← flex none，"这就是××"式点题
└─────────────────────────────┘
```

**语法微调说明**：

- **条件卡**：交互区角落的小标签，写清规则的适用条件（第七条铁律的落地）。例如 although 页条件卡："只在单句内成立（although…but 禁止）"；used to 页条件卡："只讲过去的习惯"。
- **反例条**：每条规则配一个"这样说是错的"反例，带 ✗ 标记与一句话纠正。反例不是吓唬，是条件的另一种讲法。
- **中式纠偏条**：凡 curriculum 标"中式英语误区"的课，交互区底部固定一条纠偏条（⚠ + 中式句 ✗ → 地道句 ✓ + 一句话为什么）。**纠偏话术见第八章，措辞须经英语专家队确认不引入新错误**。
- **例句区规范**：例句英文用常规字、中文释义用小字灰字；例句词汇严格限初中考纲词（超纲词加注中文）；例句须标注语域（口语/书面小标签）。
- **讲解页口径**：`pageKind: "explain"` + 全页 ≤300 字 + 点拨区 36vh 内滚动；交互页 ≤150 字。

### 2.2 四类页面的分工（语法四步走：看 → 玩 → 懂 → 练）

| 页类型 | 作用 | 结构 | 占比 |
|---|---|---|---|
| **例句观察页** | 看：先看 3 个真实例句，猜规律 | 三例句 + "你发现了什么？"猜一猜条 | 约 25% |
| **交互玩法规页** | 玩：拖时间轴/拼句型积木/标成分，亲手"摸"到规则 | 三块式 + 条件卡 + 反例条 + exploreTip | 约 30% |
| **讲解页** | 懂：交互之后 1–2 页完整讲解，条件卡 + 反例 + 中式纠偏 | 见第七章 | 约 35% |
| **习题页** | 练：每章末，答案折叠；**每章必有一道"改中式英语"题** | 见 2.4 | 约 10% |

**顺序铁律**：同一语法点内，顺序必须是 **例句观察页 → 交互玩法规页 → 讲解页 →（章末）习题页**。不许先给术语再让学生玩——术语是学生自己"玩出来"之后，黄队用文字帮他"说出来"。**特别地，规则页的顺序永远是：例句 → 条件 → 规则 → 反例**（第七条铁律）。

### 2.3 讲解页与交互页的衔接语规范

- 讲解页开头第一句必须是"认旧友"："还记得吗？你上一页把时间点拖到'昨天'时，go 变成了 went。"
- 交互页的 exploreTip（≤ 40 字）只说"动手做什么"，不说结论。结论永远在点拨区，由学生"看到"之后黄队点题。
- **"先猜后验"**：鼓励每类交互页配一个"猜一猜"小条——学生先点选预测（"时间点拖到'明天'，动词会变成什么？"），再动手验证。**不判对错**，只记录（给后续学习报告留接口）。此为黄队新增教学动作需求，走 interactions 文档 Y 编号增补流程。

### 2.4 每页自查清单（语法版）

- [ ] 一屏能看完，不滚动（手机 390px 为准）
- [ ] 主交互是"动手改变点什么"（拖/拼/标），不是纯播放
- [ ] 条件卡写清了适用条件；反例条有 ✗ 例句 + 一句话纠正
- [ ] 点拨区 ≤ 60 字，最后一句是"这就是××"式点题（规则名）
- [ ] 规则页顺序：例句 → 条件 → 规则 → 反例
- [ ] 术语出现前学生已见过 3 个真实例句（第九条铁律）
- [ ] 有汉语对照（第八条铁律），且对照后有"拆桥"句（"这是英语的规矩"）
- [ ] 颜色编码符合全局约定（主语/谓语/从句标记色，见 interactions §0.2）
- [ ] 例句词汇在初中考纲内（超纲词已加注）；例句标注语域
- [ ] 中式纠偏条话术来自第八章话术库，措辞经英语专家队确认

## 三、中国孩子学语法的特有难点与通用讲解策略

| # | 特有难点（汉语 vs 英语） | 通用讲解策略 | 落点章 |
|---|---|---|---|
| D1 | 汉语无时态形态 → 动词不变，时态靠"昨天/将"等时间词；英语动词必须变形 | **时间轴脚手架**：一切时态先上时间轴，时间点拖动 → 动词形态联动变化；"汉语用时间词，英语用动词变形——两种记时间的办法" | gr05/gr06 |
| D2 | 汉语无单复数形态、无冠词 → a/the 乱加乱漏，复数 -s 漏 | **"数数测试"**：能数吗？能数 → 可数 → 单复数/冠词三问；"汉语'个'不分，英语'个'要分" | gr01 |
| D3 | 汉语"是"字句（"她很漂亮"）→ 漏 be（She very beautiful.） | **"英语句子不能没有动词"铁律**：gr00.1.1 立规矩，每课成分标注先找动词；be 是"有礼貌的动词"（人话版，专家队已确认） | gr00 |
| D4 | 汉语话题结构（"这本书我看过"）→ 语序照搬、残留代词（The book that I bought it） | **成分积木**：从句连接词占位可视化——that 已经占了宾语的位置，it 就没地方站了 | gr14 |
| D5 | 汉语"因为…所以…""虽然…但是…"成对 → although…but、because…so | **"一句话只能有一个'但是'"**口诀 + 反例条常驻；although 与 but 是"仇人"，见面只能留一个 | gr15 |
| D6 | 汉语无主谓一致 → 三单 -s 漏、There be 配错 | **"三单 -s 是英语的'他'标记"**：-s 不是装饰，是"主语是他/她/它"的信号灯；There be 就近口诀"离 be 近的说了算" | gr05/gr12/gr18 |
| D7 | 汉语动词连用（"我想去吃饭"）→ 英语双谓语（I want go） | **"一个句子只能有一个谓语"铁律**（gr00.1.1 立）：第二个动词必须"变形"（to do/doing/done）——非谓语三章的总纲 | gr09/gr10 |
| D8 | 汉语无虚拟形态 → 虚拟语气"时态后退"不可理喻 | **"要是…就好了"直觉先行**：先讲汉语的"要是"，再讲英语把"要是"语法化了——过去式不是过去，是"假装" | gr16 |

**自学路径总纲**：每章开头一页"本章地图"（本章几条规则、哪条是中考/高考考点、学完能做什么）；每章末尾"自查三问"（规则复述/反例识别/中式纠偏）；gr19.2.3 设全书诊断与回填路径。

## 四、语法特有跃升脚手架（10 个）

| # | 跃升点 | 脚手架设计 | 落点 |
|---|---|---|---|
| 跃升 1 | gr00.1.1"谓语唯一"（全书总纲） | "找动词"游戏：每句话先圈动词，圈出两个就报警；报警文案"一个句子只能有一个'老大'（谓语），多的那个要'变形'" | gr00 |
| 跃升 2 | gr05.1.1 三单 -s | "信号灯"：主语是 he/she/it 时 -s 灯亮；交互拖主语，-s 灯联动 | gr05 |
| 跃升 3 | gr06.2.1 现在完成时"对现在有影响" | 双时间轴（过去动作 → 现在结果）；"丢钥匙"场景：I lost my key（过去）vs I have lost my key（现在没钥匙，进不了门）——影响可视化 | gr06 |
| 跃升 4 | gr07.1.4 不及物无被动 | "被动体检"：动词先过"及物安检"——happen/die/appear 无安检章，不许进被动车间；was happened 判 ✗ 动画 | gr07 |
| 跃升 5 | gr09/gr10"第二个动词变形" | "变形车间"：第二个动词进车间，三选一出口（to do/doing/done）；选错出口报警并给回填课号 | gr09/gr10 |
| 跃升 6 | gr11 后缀改性 | "词性换装"：词根小人穿 -tion 外套变名词、穿 -ly 外套变副词；friendly 穿 -ly 却是形容词——"卧底"反例卡 | gr11 |
| 跃升 7 | gr13–gr15"从句是披着句子外衣的成分" | "脱衣检查"：从句拖进主句成分槽（主/宾/定/状四个槽），放错槽弹回；连接词是"身份证"，that/if/when 各有各的槽 | gr13–gr15 |
| 跃升 8 | gr14 关系代词残留 it | "占位可视化"：that 占了宾语位，it 无处可站 → 被弹飞动画；口诀"that 在，it 走" | gr14 |
| 跃升 9 | gr16 虚拟"时态后退" | "时光倒流一格"：真实（现在）→ 虚拟（过去式）；"过去式不是过去，是假装"——时间轴上虚拟区用虚线画 | gr16 |
| 跃升 10 | gr19 长难句拆解 | "剥洋葱"：长句先找主句骨架（谓语动词），再一层层剥从句；每剥一层标注成分 | gr19 |

## 五、34 个单元讲解策略（课号与 curriculum 一一对应）

> 每单元格式：核心难点 → 讲解策略（含例句先行方向） → 对比纠偏话术 → 自学路径。话术措辞需经英语专家队确认，红队审计时复核。

### gr00.1 句子的骨架

- **核心难点**：D3（漏 be）、D7（双谓语）；"成分"是全书第一批术语。
- **讲解策略**：例句先行——3 个短句（I run. / She is happy. / I like apples.）先圈动词，再起名词（主语/谓语/宾语/表语）；五种句型用"积木拼句"玩出来。
- **对比纠偏话术**："汉语说'她很漂亮'不用'是'，英语不行——英语句子不能没有动词，is 就是那个'有礼貌的动词'，专门站在形容词前面。"
- **自学路径**：本章地图（4 课：骨架→成分→句型→词类）→ 每课"认旧友" → 章末自查三问。

### gr01.1 名词

- **核心难点**：D2（可数/不可数）；advice/information/news 反直觉。
- **讲解策略**："数数测试"三问（能数吗？→ 单数还是复数？→ 加不加 a？）；不可数名词用"水"类比（水不能数"一个水"，advice 同理）。
- **对比纠偏话术**："汉语'一个建议'，英语不能说 a advice——advice 像水，数不了；要数就说 a piece of advice（一'片'建议）。"
- **自学路径**：可数↔不可数对照表 → 不规则复数记忆卡（30 个，中考范围）。

### gr01.2 冠词与限定词

- **核心难点**：D2（冠词）；the 特指 vs 泛指；some/any 例外（Would you like some…?）。
- **讲解策略**："故事引入法"——a dog（第一次提到，不认识）→ the dog（第二次，认识了）；零冠词用"老熟人免票"人话版（专家队确认：仅限直觉页，严格页用"泛指/习惯用法"）。
- **对比纠偏话术**："汉语没有'这一个/那个'的冠词，英语有——a 是'随便一个'，the 是'就是那个'。"
- **自学路径**：冠词四分法一张表 → 习惯用法记忆卡 → some/any 例外卡。

### gr02.1 人称、物主、反身、指示代词

- **核心难点**：主格/宾格；形容词性 vs 名词性物主代词。
- **讲解策略**："岗位制"——主格站主语岗、宾格站宾语岗，站错岗报警；my/mine "my 后面必须跟名词，mine 独立"。
- **对比纠偏话术**："汉语'我'站哪都叫'我'，英语'我'站主语叫 I，站宾语叫 me——换岗换衣服。"
- **自学路径**：代词总表 → 岗位配对练习。

### gr02.2 疑问、不定代词与指代一致

- **核心难点**：who 作主语不倒装；some-/any- 系列；everyone…their（语域注）。
- **讲解策略**：特殊疑问句"拆装"——先陈述句，再把疑问词"拎"到句首；who 作主语"拎出来后面不动"。
- **对比纠偏话术**："Who broke the window? 里 who 自己就是主语，后面不用再加 did——主语已经在了。"
- **自学路径**：疑问词总表 → some-/any- 四系列图。

### gr03.1 形容词与副词的基本功

- **核心难点**：形容词修饰名词、副词修饰动词；hardly 陷阱；good→well。
- **讲解策略**："装修队"类比（专家队确认边界：仅讲修饰关系）——形容词装修名词，副词装修动词/形容词；hardly = "几乎不"反例卡常驻。
- **对比纠偏话术**："He runs quick. 里 quick 装修错了地方——跑得快是装修'跑'，要用副词 quickly。"
- **自学路径**：-ly 规律表 → 特例记忆卡（fast/hard/late/well）。

### gr03.2 比较句型

- **核心难点**：比较级 + than；as…as；the…the…；倍数表达。
- **讲解策略**："天平"可视化——比较级是天平倾斜，as…as 是天平平衡；the bigger, the better 双联动滑块。
- **对比纠偏话术**："more taller 是'更更'——比较级只能有一个'更'。"
- **自学路径**：比较句型全家福表 → 倍数表达专项。

### gr04.1 介词

- **核心难点**：in/on/at 时空三维；look forward to + doing。
- **讲解策略**："三维口诀"可视化——时间轴（in 大/on 中/at 小）、空间盒（in 里/on 上/at 点）；look forward to 的 to 是介词"卧底"（to 后跟 doing）。
- **对比纠偏话术**："汉语'在'一个字，英语 in/on/at 三个——in 是'在里面'，on 是'在上面'，at 是'在点上'。"
- **自学路径**：时空三维图 → 动词+介词搭配表。

### gr05.1 一般现在时与一般过去时

- **核心难点**：D6（三单 -s）；不规则动词表；used to。
- **讲解策略**：跃升 2"信号灯"；不规则动词"分组记忆"（go-went-gone / eat-ate-eaten 按元音分组）；used to 对比现在（but now…）。
- **对比纠偏话术**："He go to school. 少了 -s——英语用 -s 告诉你是'他'在跑，汉语不用，英语要。"
- **自学路径**：三单 -s 自查（主语是 he/she/it？）→ 不规则动词 30 个过关卡（**中考**范围）。

### gr05.2 一般将来时

- **核心难点**：will vs be going to；will 后加 to。
- **讲解策略**："电话响了"场景——I'll get it!（临时决定）vs I've planned…（计划）；will 是"裸奔"（后直接跟动词原形，不加 to）。
- **对比纠偏话术**："will to go 多穿了一件衣服——will 后面直接跟动词，不穿 to。"
- **自学路径**：will/be going to 对照表 → 三时态时间轴总表。

### gr06.1 进行时

- **核心难点**：D1（进行时）；be + doing 缺 be；状态动词不用进行时。
- **讲解策略**：时间轴"正在"高亮段；be 是"进行时的门票"，没票（be）不许进；状态动词"VIP 不用排队"（know/like 直接进，不用进行时）。
- **对比纠偏话术**："He running now. 缺了门票 be——进行时 = be + doing，两个都要。"
- **自学路径**：三进行时时间轴总表 → 状态动词黑名单。

### gr06.2 完成时

- **核心难点**：D1（完成时无汉语对应）；since/for；have + done 缺 have。
- **讲解策略**：跃升 3 双时间轴；"影响可视化"——have lost my key → 现在没钥匙（画门打不开）；since（点）/for（段）时间轴标注。
- **对比纠偏话术**："I lost my key. 只说了过去丢了；I have lost my key. 还说了现在没钥匙——完成时是'过去连着现在'。"
- **自学路径**：8 时态总表 → since/for 配对练习 → **中考**真题方向练。

### gr07.1 被动语态

- **核心难点**：be + done 缺 be；make sb do 被动 to 回归；不及物无被动（D4 相关）。
- **讲解策略**："主被调座位"——主动句主语宾语换座位，动词穿 be+done 制服；跃升 4"被动体检"；make 的 to "出差回来"。
- **对比纠偏话术**："The window broken. 缺了 be——被动语态 = be + done，be 是制服上衣，不能不穿。"
- **自学路径**：主动改被动三步 → 不及物黑名单（happen/die/appear/take place）。

### gr08.1 情态动词

- **核心难点**：mustn't vs don't have to；情态后加 to/-s；should have done。
- **讲解策略**："红绿灯"——mustn't 红灯（禁止），don't have to 绿灯（不必）；情态是"裸奔族"（后直接跟动词原形）。
- **对比纠偏话术**："'不必'是 don't have to，不是 mustn't——mustn't 是'不许'，说反了意思全反。"
- **自学路径**：情态意义总表 → mustn't/don't have to 对照卡。

### gr09.1 动词不定式

- **核心难点**：D7（双谓语）；want to do 缺 to；It's…for sb to do。
- **讲解策略**：跃升 5"变形车间"；"愿望三兄弟"（want/hope/decide + to do）；for sb 是"动作的'主人'"。
- **对比纠偏话术**："I want go. 里 go 是第二个动词，必须变形——want 后面跟 to go，to 是'变形通知书'。"
- **自学路径**：to do 句型表 → 逻辑主语判定（for sb/of sb）。

### gr09.2 动名词

- **核心难点**：enjoy + doing；stop/remember/forget 辨析；used to 三兄弟。
- **讲解策略**："三兄弟身份证"（used to do / be used to doing / be used to do 对照卡）；stop to do（停下来去做）vs stop doing（不做了）场景剧。
- **对比纠偏话术**："enjoy 后面只跟 doing，没有 to do——enjoy 是'doing 俱乐部'的会员。"
- **自学路径**：三兄弟对照卡 → **中考**高频辨析练。

### gr10.1 分词

- **核心难点**：-ing vs -ed；悬垂分词（D4 相关）。
- **讲解策略**："感情温度计"——-ing 让别人…（boring），-ed 自己感到…（bored）；跃升"分词找主语"自查口诀。
- **对比纠偏话术**："I'm boring. 是说'我很无聊（让人无聊）'——想说'我感到无聊'要用 I'm bored。"
- **自学路径**：-ing/-ed 对照表 → 悬垂分词改错练。

### gr10.2 独立主格与非谓语总表

- **核心难点**：独立主格结构；with 复合结构。
- **讲解策略**："独立小分队"——名词/代词带自己的分词，不跟主句抢主语；with 是"队长"。
- **对比纠偏话术**："Weather permitting,… 里 weather 自带 permitting，不借主句的主语——这就是'独立'。"
- **自学路径**：非谓语三分法总表（to do/doing/done）→ **高考**非谓语练。

### gr11.1 前缀、后缀与复合词

- **核心难点**：前缀拼写同化（in-→im-）；-ly 副词 vs 形容词（friendly）。
- **讲解策略**：跃升 6"词性换装"；前缀"变脸不变心"（改义不改性）；friendly "卧底"反例卡。
- **对比纠偏话术**："happyness 拼错了——y 变 i 再加 ness，这是后缀的'换装规则'。"
- **自学路径**：前缀表 → 后缀词性总表；**呼应讲词根**：前缀词条跳转。

### gr11.2 词性转换双向路

- **核心难点**：一词四形；零转换；后缀认错。
- **讲解策略**："一条链走完"（success→succeed→successful→successfully）；**中考**一词四形填空专项。
- **对比纠偏话术**："He successed. 里 success 是名词，不能当动词——动词是 succeed。"
- **自学路径**：一词四形表 → 生词"先判词性再猜义"（阅读技能）；**呼应讲词根**：猜词义技能升级。

### gr12.1 简单句与并列句

- **核心难点**：There have（D3 相关）；run-on 句；反意疑问。
- **讲解策略**："There be 安检"——there 后面不许跟 have；run-on "缺连词报警"（两个句子中间必须有连词或分号）。
- **对比纠偏话术**："There have a book. 是中式'有'直译——英语的'有'叫 there be，不是 there have。"
- **自学路径**：There be 自查 → 并列连词表 → 反意疑问特例卡。

### gr13.1 宾语从句

- **核心难点**：从句陈述语序；that/if/whether；时态呼应。
- **讲解策略**：跃升 7"脱衣检查"（宾语槽）；"语序复位"——从句里疑问词后面跟陈述语序；whether 三条身份证。
- **对比纠偏话术**："He asked me where did I live. 里从句倒装了——从句是'披着句子外衣的宾语'，里面用陈述语序。"
- **自学路径**：连接词三问（缺什么成分？）→ **高考**宾语从句练。

### gr13.2 主语/表语/同位语从句与间接引语

- **核心难点**：It 形式主语；同位语 vs 定语从句；间接引语时态后退。
- **讲解策略**："it 替身"——真正的主语太长，it 先顶班；"that 作不作成分"判定法（同位语 that 不作成分，定语 that 作成分）。
- **对比纠偏话术**："the fact that he was late 里 that 不作成分——fact 的'说明书'，不是定语。"
- **自学路径**：名词性从句总表 → 间接引语三步（人称/时态/状语）。

### gr14.1 关系代词与关系副词

- **核心难点**：关系词选择；that 残留 it（D4）；限制 vs 非限制。
- **讲解策略**：跃升 8"占位可视化"；"先行词查户口"（人/物/时间/地点）；逗号"呼吸测试"（非限制读出来有停顿）。
- **对比纠偏话术**："The book that I bought it. 里 it 多余——that 已经占了宾语的位置，it 没地方站。"
- **自学路径**：关系词选择流程图 → 限制/非限制对照。

### gr14.2 难点与简化

- **核心难点**：that/which；介词 + 关系代词；定语从句简化。
- **讲解策略**："that 必用/禁用"口诀卡；介词"正式前置、口语后置"（语域注）；简化 = gr10 分词回填（the boy playing）。
- **对比纠偏话术**："the house in that… 错了——介词后面不许跟 that，用 which。"
- **自学路径**：that/which 对照卡 → **高考**定语从句练。

### gr15.1 时间、条件、原因、目的、结果

- **核心难点**：主将从现；because…so（D5）；unless 双重否定。
- **讲解策略**："主将从现"是条件卡不是口诀——时间/条件从句里 will 被"没收"；because 与 so "仇人"可视化。
- **对比纠偏话术**："If it will rain… 里 will 被没收了——条件从句里不许用将来时，用现在时代替。"
- **自学路径**：八种状语从句总表（分两次）→ 主将从现专项。

### gr15.2 让步、比较、方式与总表

- **核心难点**：although…but（D5）；as if 虚拟预告。
- **讲解策略**："一句话只能有一个'但是'"口诀 + 反例条常驻；as if "假装"（gr16 预告）。
- **对比纠偏话术**："Although…but… 里 but 多余——although 和 but 是仇人，一句话只能留一个。"
- **自学路径**：状语从句总表 → 简化（gr10 呼应）。

### gr16.1 if 条件句虚拟

- **核心难点**：D8（虚拟无汉语对应）；were 通用；混合虚拟。
- **讲解策略**：跃升 9"时光倒流一格"；"If I were you" 直觉先行（换位思考场景）；混合虚拟时间错位表。
- **对比纠偏话术**："If I was you… 口语能听懂，书面要用 were——虚拟的 be 不分人称，一律 were。"
- **自学路径**：三时态对照表 → **高考**虚拟练。

### gr16.2 其他虚拟

- **核心难点**：suggest 虚拟 should 省略（语域）；insist 陈述 vs 虚拟；It's time 虚拟。
- **讲解策略**："suggest 是'要求'不是'建议'"（suggest 后虚拟三兄弟：suggest/order/insist）；It's time we left "该走了"场景。
- **对比纠偏话术**："He suggested that we should leave. 里 should 可省——美式英语直接说 we leave，should 藏起来了。"
- **自学路径**：虚拟总表 → 语域注（美式省/英式留）。

### gr17.1 倒装与强调

- **核心难点**：倒装触发词；so/neither；强调句 that。
- **讲解策略**："倒装触发器"——否定词/only 开头像扳机，一扳就倒装；So do I "附和拍手"场景。
- **对比纠偏话术**："Only then I realized… 没倒装——only 开头是扳机，后面必须倒装：Only then did I realize。"
- **自学路径**：倒装触发词表 → 强调句拆解（It is…that 框）。

### gr17.2 省略与 it

- **核心难点**：省略后成分残缺；it 形式宾语漏 it。
- **讲解策略**："省略是'熟人免介绍'"——并列/回答中重复的不说；find it "it 占位符"（it 先占着，真正的宾语 to do 在后面）。
- **对比纠偏话术**："I find hard to learn. 缺了 it——it 是占位符，先占着宾语的位置。"
- **自学路径**：省略还原练习 → it 三用法表。

### gr18.1 主谓一致与特殊句式

- **核心难点**：就近原则；a number of；否定转移。
- **讲解策略**："离动词近的说了算"（就近）；a number of（许多，复数）vs the number of（…的数量，单数）对照卡；否定转移"否定词爬楼梯"（从从句爬到主句）。
- **对比纠偏话术**："The number of students is… 里主语是 number（单数），不是 students——'数量'是单数。"
- **自学路径**：主谓一致三原则表 → **高考**改错热身。

### gr19.1 语篇中的语法

- **核心难点**：语法放回语篇；改错十看；写作句式升级。
- **讲解策略**：完形"找逻辑词"（转折/因果）；改错十看法口诀；写作"同一意思三种说法"升级对照。
- **对比纠偏话术**："改错不能凭语感——十看法一个一个过：时态？主谓？冠词？…"
- **自学路径**：**中考**完形策略 → **高考**改错十看 → 写作升级库。

### gr19.2 总复习与诊断

- **核心难点**：全书串联；薄弱回填。
- **讲解策略**：跃升 10"剥洋葱"；时态语态总表、从句总表两张大图；自测清单"错哪回哪章"。
- **对比纠偏话术**："长难句先找主句的谓语——谓语是骨架，从句是肉。"
- **自学路径**：全书诊断 → 联合学习路径（词汇 ↔ 语法）；**呼应讲词根**：两子卡跳转。

## 八、中式英语纠偏话术库（12 条，对接 curriculum 附录 A）

| # | 中式句（✗） | 地道句（✓） | 一句话为什么 |
|---|---|---|---|
| 1 | I like him is kind. | I like him because he is kind. / I think he is kind. | 一个句子只能有一个谓语（老大），多的那个要变形或加连词。 |
| 2 | Although it rained, but we went. | Although it rained, we went. | although 和 but 是仇人，一句话只能留一个。 |
| 3 | There have a book. | There is a book. | 英语的"有"叫 there be，不是 there have。 |
| 4 | The accident was happened. | The accident happened. | happen 是不及物动词，没"被动"这件衣服。 |
| 5 | He go to school. | He goes to school. | 主语是"他"时，动词要穿 -s 制服——这是"他"的信号灯。 |
| 6 | He asked me where did I live. | He asked me where I lived. | 从句是披着句子外衣的宾语，里面用陈述语序，不倒装。 |
| 7 | The book that I bought it. | The book that I bought. | that 已经占了宾语的位置，it 没地方站。 |
| 8 | Walking along the street, a car hit me. | Walking along the street, I was hit by a car. | 分词要找自己的主语——走路的是"我"，不是"车"。 |
| 9 | You mustn't come if you are busy.（表"不必"）/ play the basketball | You don't have to come if you are busy. / play basketball | mustn't 是"不许"（红灯），don't have to 才是"不必"（绿灯）；球类运动前不加 the。 |
| 10 | If it will rain, we will stay. | If it rains, we will stay. | 条件从句里 will 被"没收"了，用现在时代替将来。 |
| 11 | I used to getting up late. | I used to get up late. | used to do（过去常常）/ be used to doing（习惯于）是两兄弟，别认错。 |
| 12 | I very much like it. | I like it very much. | very much 是"程度副词"，站句尾，不站动词前面。（正式文体可前置，考试用句尾式） |
