# 数学·代数 教学设计（黄队）

> 定位：教学法设计。数学严谨性（定义准确、体系完整）由绿队负责，本文件只解决"怎么教、怎么让初学者自学"。
> 约束（用户拍板）：代数从最简方程一路到微积分；所有知识点数形结合；每环节一页、不超过一屏；每页有可交互动画。

---

## 一、设计总纲：五条铁律

1. **一页一概念**：一屏只讲透一个核心概念。宁可多一页，不可一页塞两个概念。
2. **先动手，后结论**：每页的交互动画在前，文字解释在后。学生先拖滑块"看到"规律，再看文字"这就是××"。
3. **数形永不分离**：每个代数式旁边必须有对应的形（天平/数轴/图像/面积）。只给公式不给图 = 不合格。
4. **跃升必有台阶**：每个难度跃升点必须设计中间脚手架（见第三章），不许"显然""易得"式跳跃。
5. **密度上限**：每页 ≤ 3 个信息块（标题区 / 交互区 / 点拨区），≤ 2 个例子，文字总量 ≤ 150 字。

## 二、导论设计（2 页）：让零基础学生在 10 分钟内建立代数直觉

导论的目标不是"讲完基础知识"，而是回答三个问题：**代数是什么？等号是什么意思？为什么要用字母？**
答完这三个问题，学生就可以自学下去了。

### 导论 P1：从"猜数字"到"为什么需要字母"

**核心概念**：未知数 = 一个"还没知道的数"，字母是它的名字。

**教学流**（一屏三块）：

1. **标题区**（一句话）："我想了一个数，加上 5 等于 12，它是几？"
2. **交互区**（主角）：一个滑块，范围 0–20，旁边实时显示"滑块上的数 + 5 = ?"。
   学生拖动滑块，当显示"= 12"时，滑块"咔哒"锁定（复用英语页的卡塔音效+震动），弹出"你找到了：7"。
3. **点拨区**（≤ 60 字）：
   "如果这个数是 10369 呢？一个一个试太慢了。
   我们给'还没知道的数'起个名字，叫它 x。于是问题变成：x + 5 = 12。
   这就是代数：**先把问题写下来，再想办法解它**。"

**为什么这样设计**：
- 从具体游戏开始，零门槛；滑块的"试"对应算术思维
- "10369"制造算术的挫败感，字母的出现是"被需要的"，不是"被灌输的"
- 点拨区最后一句是整章的方法论总纲，后面每页都在重复它

**数形结合**：滑块本身就是"数轴"的雏形；"= 12"的判定是等式的第一次亮相。

### 导论 P2：天平与等式——等号不是"得出答案"

**核心概念**：等式是"天平平衡"，解方程是"让天平保持平衡的同时、把 x 单独留下"。

**教学流**：

1. **标题区**："= 不是'然后答案是'，而是'两边一样重'。"
2. **交互区**（主角）：一架天平。左边托盘有"1 个 x 盒子 + 3 个 1g 砝码"，右边有"8 个 1g 砝码"，天平平衡。
   学生可以拖走/放上砝码：**规则是"两边同时拿走同样多，天平依然平衡"**。
   目标：把 x 盒子单独留在左边。学生拖走左边 3 个 1g、右边 3 个 1g → 左边剩 x 盒子，右边剩 5 个 → "x = 5"。
3. **点拨区**（≤ 60 字）：
   "你刚才做的，就是解方程 x + 3 = 8 的全过程。
   移项、合并同类项这些名词，以后慢慢认；**动作你已经会了**。"

**为什么这样设计**：
- 直接摧毁"等号=计算器"的算术残留直觉，这是初学者最大的认知障碍
- "解方程"从抽象规则变成身体动作（拖、拿），记忆锚点极强
- 点拨区把学生的操作"正名"为数学，后续学名詞时是"认旧友"不是"背新词"

**与 P1 的衔接**：P1 的 x + 5 = 12 在 P2 的天平上重演一遍（x 盒子 + 5 = 12），两页形成闭环。

## 三、难度跃升脚手架（7 个关键跃升点）

每个跃升点格式：**从 → 到** / 学生的卡点 / 脚手架设计 / 落点页的交互。

### 跃升 1：具体数字 → 字母（P1 已铺垫，此处是"字母运算"关）

- **卡点**："3 + x"不能算出得数，学生觉得"没做完"，想把 x 消掉。
- **脚手架**："盒子合并"动画。3 个苹果 + 1 个装着 x 个苹果的盒子 = "3 + x 个苹果"，**不能打开盒子数**，所以这就是最简形式。
  再给一页：2 个 x 盒子 + 3 个 x 盒子 → 拖到一起变成 5 个 x 盒子（合并同类项的形）。
- **交互**：拖拽合并同类项（盒子/苹果图标）。

### 跃升 2：算术 → 方程（逆向思维）

- **卡点**：习惯"从已知算未知"（3+5=?），不习惯"把未知摆上台面列式"（3+x=8）。
- **脚手架**：三步台阶，每步一页——
  1. "□ + 5 = 12，□ 是几？"（方框占位，幼儿园就会）
  2. "△ + 5 = 12"（换个图形，无压力过渡）
  3. "x + 5 = 12"（"数学家偷懒，用 x 代替方框"——一句话带过，不隆重）
- **交互**：占位符 morph 动画：□ → △ → x 渐变，强调"同一个东西换了件衣服"。

### 跃升 3：一次 → 二次（从直线到曲线）

- **卡点**：二次方程的图像是弯的，"配方""判别式"全是代数操作，学生看不见意义。
- **脚手架**：先扔球，后看式。
  1. 一页：扔铅球的慢动作，轨迹是抛物线。滑块拖时间 t，看高度 h 变化。
  2. 一页：把每一时刻的 (t, h) 点画在坐标系里，点连成线——"这条线就是 h = -5t² + 20t + 2 的**画像**"。
  3. 一页：球落地时 h = 0，"求落地时间" = "画像与 t 轴的交点" = 解二次方程。**方程的解原来是交点的横坐标**。
- **交互**：时间滑块 ↔ 抛物线描点联动；拖动二次项系数看抛物线开口变化。

### 跃升 4：静态方程 → 动态函数（"x 变，y 跟着变"）

- **卡点**：方程是"求一个数"，函数是"两个数一起变"，思维框架要换。
- **脚手架**："机器"隐喻 + 联动滑块。
  1. 一页：一台机器，投入 x，产出 y = 2x + 1。拖 x 滑块，y 表盘同步转。
  2. 一页：把 (x, y) 每一对都画成点，"机器的工作记录"连起来就是直线。
  3. 点拨："方程问'机器输出 7 时投入了几'，函数问'投入变的时候输出怎么变'——同一台机器，两种问法。"
- **交互**：x 滑块 → y 数值 → 坐标点，三者联动。

### 跃升 5：离散 → 连续（数列 → 极限的心理准备）

- **卡点**："无限接近"反直觉，0.999…=1 像诡辩。
- **脚手架**：数值实验先行，证明靠后。
  1. 一页：1/2 + 1/4 + 1/8 + …，每点一次"加一项"，看和的变化：0.5 → 0.75 → 0.875 → …，进度条逼近 1 但永远差一点。
  2. 一页：把"和"画成点列，点越来越密，"它们在往哪儿挤？"
  3. 点拨："'无限接近 1'不是玄学，是你亲手点的 20 次'加一项'看到的趋势。极限就是给这个趋势起的名字。"
- **交互**："加一项"按钮 + 累计和的动态数轴/进度条。

### 跃升 6：平均变化率 → 瞬时变化率（微积分的核心一跃）

- **卡点**：从"一段时间内的平均速度"到"某一瞬间的速度"，需要极限思想。
- **脚手架**："放大镜"三部曲，每部一页——
  1. 一页：汽车里程表。0–10 秒走了 100 米，平均速度 10 m/s。"但第 5 秒那一瞬间有多快？平均速度回答不了。"
  2. 一页：曲线 y = x² 上两点连直线（割线），滑块把两点越靠越近，割线斜率实时显示：从 3.0 → 2.1 → 2.01 → …
  3. 一页：放大镜 zoom in：曲线局部被不断放大，"放大到足够大，曲线看起来像直线了——这条直线的斜率，就是那一点的瞬时变化率，也就是**导数**。"
- **交互**：割线两点距离滑块 + 斜率实时读数；放大镜 zoom 动画（曲线局部 → 近似直线）。

### 跃升 7：有限 → 无限（积分思想："切碎再拼"）

- **卡点**：曲边图形的面积怎么算？"无限细分"难以想象。
- **脚手架**：从"数格子"开始。
  1. 一页：曲线下的面积，先数完整格子，再估半格——"这是古人（阿基米德）的做法"。
  2. 一页：格子越分越细（滑块控制份数 n = 4 → 16 → 64 → 256），矩形面积和实时逼近真实值，误差条缩短。
  3. 点拨："n → ∞ 时，'近似'变成了'精确'。这个'切碎、求和、取极限'的三步，就叫**积分**。"
- **交互**：份数滑块 + 矩形动态细分 + 面积和/误差实时显示。
- **对应绿队章节**：第十二章（定积分）。

## 五、交互动画类型清单（每页选 1 个主交互 + 可选 1 个辅交互）

| 类型 | 说明 | 适用概念 | 技术要点（给白队） |
|---|---|---|---|
| **滑块实验** | 拖参数，看结果实时变 | 系数对图像的影响、变化率 | input range + 重绘，防抖 |
| **拖拽天平** | 拖砝码/盒子，保持平衡 | 等式、移项、合并同类项 | 拖拽 + 重量求和判定 |
| **联动仪表盘** | 一个量变，多个表示同步变 | 函数（x→y→点）、导数（点→切线→斜率） | 单一数据源，多视图订阅 |
| **描点成像** | 逐点绘制，点连成线 | 二次函数、指数函数图像生成 | 逐帧绘制动画 |
| **放大镜 zoom** | 局部不断放大，看"变直" | 瞬时变化率、极限 | 坐标变换 + 重采样 |
| **数值实验台** | 点按钮/输数，看趋势 | 极限、无穷级数、0.999… | 累加器 + 趋势图 |
| **细分动画** | 份数滑块，矩形越分越细 | 积分、圆面积公式溯源 | n 份矩形重绘 |
| **占位符 morph** | □→△→x 渐变 | 算术→方程过渡 | SVG/CSS 形变 |
| **对比并排** | 左右两图同步变 | 一次 vs 二次、平均 vs 瞬时 | 双画布同步参数 |
| **慢动作回放** | 轨迹逐帧播放 | 抛物线、追及问题 | 时间轴 scrubber |

**选用原则**：
- 主交互必须让学生"动手改变点什么"（拖/点/输），纯播放动画只能做辅交互。
- 每页主交互 ≤ 1 个，避免注意力分散。
- 动画时长 ≤ 3 秒可完成一次完整演示，支持重播。

## 六、一页一屏教学节奏规范

### 6.1 页面结构（三块式，复用英语页布局经验）

```
┌─────────────────────────┐
│ 标题区（一句话概念）      │  ← ≤ 20 字，flex none
├─────────────────────────┤
│                         │
│ 交互区（主角，占 60%）    │  ← flex 1，动画/滑块/画布在这里
│                         │
├─────────────────────────┤
│ 点拨区（≤ 60 字 + 下一步） │  ← flex none，"这就是××"点题
└─────────────────────────┘
```

### 6.2 信息密度红线

| 指标 | 上限 | 说明 |
|---|---|---|
| 核心概念 | 1 个/页 | 两个概念 = 两页 |
| 文字总量 | ≤ 150 字/页 | 含标题、点拨，不含按钮标签 |
| 例子 | ≤ 2 个/页 | 主例进交互，次例进口拨 |
| 公式 | ≤ 3 个/页 | 每个公式必须配"人话翻译" |
| 交互 | 1 主 + ≤ 1 辅 | 主交互必须动手 |

### 6.3 章节节奏（与绿队课程体系配合）

- **导论**：2 页（P1 猜数字→字母，P2 天平→等式），10 分钟内完成。
- **常规单元**：每单元 4–8 页，每页 3–5 分钟（含动手时间）。
- **跃升页**：每个跃升点 2–3 页（脚手架本身占页），节奏放慢，允许重复玩交互。
- **复习页**：每章末 1 页"一图流"——本章所有概念在一张动态图里串起来（可拖时间轴回放）。

### 6.4 自学支持（目标：初学者无老师也能走下去）

1. **每页"卡住了？"**：点拨区下方小字提示"如果滑块拖了没感觉，先回看第 X 页"（前向引用，不跳转，由学生自主）。
2. **术语"认旧友"**：新名词出现时，标注"就是你第 X 页玩过的那个动作"。
3. **不做题**：本模块不设习题页（练习是另一模块的事），每页的"动手"就是练习。
4. **进度可见**：侧边栏章节-单元-课程目录（绿队设计）实时高亮当前位置，完成的页打勾。
