### 0.2 生物专属色板映射 `--bio-*`

生物**不另起色板**：定义 `--bio-*` 语义变量，值全部别名 `--geo-*`（浅色/深色两套色值自动跟随几何的深色切换，无需另写深色值）。

```css
:root {
  --bio-known:     var(--geo-known);    /* 已知/基准：蓝 —— 正常生理值、对照组、已知结构 */
  --bio-target:    var(--geo-target);   /* 待求/强调：朱红 —— 实验变量、待判读性状、关键结论 */
  --bio-substrate: var(--geo-corr-a);   /* 反应物/底物：橙 —— 淀粉、葡萄糖、抗原 */
  --bio-product:   var(--geo-corr-b);   /* 产物：天蓝 —— 麦芽糖、ATP、抗体 */
  --bio-organelle: var(--geo-corr-c);   /* 细胞器/能量相关：蓝绿 —— 线粒体、叶绿体 */
  --bio-gene:      var(--geo-corr-angle);/* 基因/遗传：紫红 —— 等位基因、DNA 链、系谱符号 */
  --bio-membrane:  var(--geo-line);     /* 细胞边界/常规描边 */
  --bio-grid:      var(--geo-grid);     /* 网格/坐标底（曲线图、显微镜视野网格） */
  --bio-highlight: var(--geo-highlight);/* 高亮：黄 —— 当前步骤、选中项（配深色字） */
  --bio-aux:       var(--geo-aux);      /* 辅助线：灰虚线 —— 假设线、进化树分支、模式图示意线 */
  --bio-bg:        var(--geo-bg);       /* 背景 */
  --bio-text:      var(--geo-text);     /* 文字（含 MathML 公式渲染） */
}
```

映射问答：**能量流动箭头 = `--bio-organelle`（蓝绿）+ 箭头形状 + "能量"文字**（B8/B9；
方向 = 被吃者 → 捕食者，单向）；**物质循环箭头 = `--bio-aux`（灰虚线环形）+ "循环"文字**（B8）；
对照组恒用 `--bio-known`（蓝），实验变量/待求一律用 `--bio-target`（朱红）。
状态（通/断、变蓝/不变蓝）永远 = 颜色 + 文字徽章，**绝不只靠颜色**。

### 0.3 全局铁律（生物页同样执行）

1. `params` 里**不出现具体色值**，只用 `--bio-*` 语义名；深色模式自动切换（别名机制，渲染器不重绘画布）。
2. **逻辑单位 0–100**（y 向上），不写死 px；触摸手柄半径 ≥ 6 逻辑单位（≈44px @ 390px 画布），热区再外扩 50%。
3. 反馈走 M6：拖拽吸附/落定/状态切换**视觉必选**（flash/ripple），`navigator.vibrate` 与合成音效为可选加分项；**不判对错、无红叉**（答"错"只给提示，沿用 Y1 铁律）。
4. 双编码：方向/状态 = 颜色 + 形状/文字；数值 = 读数 + 单位；灰度截图下所有关系仍可辨。
5. 读数行一律走 MathML（生物量符号如放大倍数、×、%、mmol/L、mmHg），**单位与数值同行**，不许裸文本。
6. 讲解页口径沿用几何：`pageKind: "explain"` + 全页 ≤300 字 + 点拨区 36vh 内滚动；交互页 ≤150 字。
7. **模式图声明常驻**：凡结构示意图角落常驻小字"**模式图：非等比、非实物**"；显微/电镜照片注明"**实物图**"（审计清单第 7 条）。
8. **实验页三徽章**：实验三问徽章（为什么设对照/为什么只变一个量/为什么要重复，点开展开一句话答案）+
   读数徽章（MathML + 规范单位）+ 安全徽章（口腔上皮取样/酒精灯/盐酸解离/野生菌，常驻顶部不随交互消失）。
9. **示意类动画常驻标注**："示意，非真实速度/比例"；虚拟实验页角落常驻"虚拟实验：现实中须××"。
10. 零音频文件（Web Audio 现场合成）；`file://` 双击可运行；localStorage 禁用可运行（记录降级为内存）。

## B1 · cell-builder（细胞结构拼搭）

拖拽结构卡（细胞壁/细胞膜/叶绿体/线粒体/液泡/细胞核…）到细胞模式图正确位置；
点结构弹出"结构—功能"一句话；动/植物模式切换。
落点：**b01.1.3**（动植物细胞异同）、**b12.1.3**（细胞器分工合作）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `mode` | string | — | `"animal"` | `"animal"`（动物细胞）/ `"plant"`（植物细胞）；模式切换 |
| `organelles` | array | ✅ | — | 结构卡数组（非空）；每项 `{id, label, func（一句话功能）, plantOnly?, animalOnly?}` |
| `zones` | array | ✅ | — | 目标区域数组；每项 `{zoneId, label, accepts:[organelleId...], hint}` |
| `showFuncPop` | boolean | — | `true` | 落定后点结构是否弹出"结构—功能"一句话卡片 |
| `diagramNote` | string | — | `"模式图：非等比、非实物"` | 常驻声明文案（冻结，见 B-F1） |
| `resetOnModeSwitch` | boolean | — | `true` | 切换动/植物模式时是否清空已放卡片（需二次确认） |

- 吸附：卡片中心进入目标区域即吸附（M6 ripple）；放错区域温和回弹到卡片栏，**无红叉、不判错**，配提示"再想想它该待在哪"。
- 动/植物差异：`plantOnly`（细胞壁/叶绿体/大液泡）在 `mode:"animal"` 时卡片置灰不可拖，文案"动物细胞没有它"；反之 `animalOnly`（中心体）在植物模式置灰。
- 功能卡：落定后点任意已放结构，弹出 `func` 一句话（如线粒体："有氧呼吸的主要场所——内膜嵴多，适合大量供能"），一次回答"结构—功能对问"。

### 示例

```js
interaction: {
  type: "cell-builder",
  params: {
    mode: "animal",
    organelles: [
      { id: "nucleus", label: "细胞核", func: "遗传信息库——指挥细胞的各项生命活动" },
      { id: "mito", label: "线粒体", func: "有氧呼吸的主要场所——内膜嵴多，适合大量供能" },
      { id: "chloro", label: "叶绿体", func: "光合作用的场所", plantOnly: true },
      { id: "wall", label: "细胞壁", func: "支持和保护", plantOnly: true }
    ],
    zones: [
      { zoneId: "z1", label: "中央大结构", accepts: ["nucleus"], hint: "指挥中心在哪？" },
      { zoneId: "z2", label: "能量站", accepts: ["mito"], hint: "供能的在哪？" }
    ],
    showFuncPop: true
  }
}
```

### 输入 / 输出

- 输入：拖结构卡到模式图区域；点已放结构看功能卡；切换动/植物模式。
- 输出：吸附落定（ripple）+ 功能一句话卡片；全部放对出"拼搭完成"徽章（配文字，不只靠颜色）。

### 触控要求

- 结构卡热区 ≥ 44px；目标区域 ≥ 13 逻辑单位边长；拖拽中卡片半透明跟随手指。
- 模式切换按钮 ≥ 44px；`resetOnModeSwitch` 触发时二次确认弹窗。

### 深色模式

- 模式图描边 `--bio-membrane`；细胞器填充 `--bio-organelle`（深色自动提亮）；功能卡文字走 `--bio-text`。

### 双编码

- 结构卡：颜色 + 名称文字；目标区域：虚线轮廓 + 区域标签文字；`plantOnly` 置灰 + "动物细胞没有它"文字。

### 复用已有类型

- 拖放 + 吸附 + 落定锁定复用 `cut-reassemble`；功能卡弹窗复用 `tap-highlight` 的信息卡范式。

### 黄队接口（先动手后结论）

- 动手：学生把"线粒体"卡拖到能量站区域 → 现象：吸附落定 + 弹出"内膜嵴多，适合大量供能" →
  结论点题："结构为功能服务——这就是'形配其用'"（红线辨析①，b05.1.3 认旧友）。
- 动手：切到植物模式 → 现象：细胞壁/叶绿体卡片可用了 → 结论："植物细胞多了三样，动物细胞没有——这就是异同"。

### 蓝队评审

- ✅ **可实现**：纯 SVG 拖放 + 区域命中判定（`accepts` 查表），零性能风险；Canvas/SVG 均可，建议 SVG。
- 离线预计算：无。

### 常见坑

1. **模式切换清空要二次确认**：`resetOnModeSwitch:true` 时误触切换会丢进度，弹窗确认"切换模式会清空已放卡片，继续吗？"。
2. **`plantOnly` 卡片不是"消失"**：置灰 + 文字说明原因，消失会让学生以为"这种细胞器不存在"。
3. **功能卡一句话**：`func` 必须同时回答"长什么样"和"适合干什么"（结构—功能对问），只写名称 = 不合格（白队抽查，W-B2）。

## B2 · microscope-sim（显微镜操作模拟）

全流程分步操作机：安放 → 对光 → 低倍观察 → 高倍观察；步序错了不许进下一步；
玻片移动与视野移动反向实时演示；"偏哪移哪"闯关；污点三步排查。
落点：**b01.1.1**（显微镜的使用）、**b01.1.2**（观察动植物细胞）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `steps` | array | — | `["安放","对光","低倍观察","高倍观察"]` | 操作步骤（顺序冻结，不可跳步，见 B-F2） |
| `startMag` | string | — | `"low"` | 冻结：默认低倍起步（见 B-F2） |
| `magLevels` | array | — | `[{label:"40×"},{label:"100×"},{label:"400×"}]` | 放大倍数档位（`放大倍数 = 目镜 × 物镜`，MathML 读数） |
| `stageChallenge` | boolean | — | `true` | "偏哪移哪"闯关：视野物像偏某方向，学生点玻片移动方向 |
| `spotQuiz` | boolean | — | `true` | 污点三步排查：转动目镜 / 移动装片 / 转动物镜 |
| `reverseDemo` | boolean | — | `true` | 玻片移动与视野反向实时演示（倒像 = 旋转 180°图示） |
| `safetyNote` | string | — | `"口腔上皮取样：一次性消毒牙签，用后按规范处理"` | 安全徽章文案（b01.1.2 常驻） |

- 步序机：当前步骤高亮（`--bio-highlight`），做错/跳步时该步骤闪烁 + 提示"先完成上一步"，**不许进下一步**（阻塞式，非跳过提示）。
- 倒像演示：视野中画"上"字样张，玻片拖动时视野内容反向等量移动；配"旋转 180°"小图示（T9 口诀的严格配图）。
- 高倍切换：必须先"低倍找到物像 → 移到视野中央"，否则转高倍按钮置灰并提示"先在低倍下把物像移到中央"。
- 污点排查：三步按钮顺序点选，每步配"污点动了/没动→污点在哪"的判定文字。

### 示例

```js
interaction: {
  type: "microscope-sim",
  params: {
    steps: ["安放", "对光", "低倍观察", "高倍观察"],
    startMag: "low",
    magLevels: [{ label: "40×" }, { label: "100×" }, { label: "400×" }],
    stageChallenge: true, spotQuiz: true, reverseDemo: true
  }
}
```

### 输入 / 输出

- 输入：按步骤点选/拖拽操作（对光：调反光镜角度；观察：拖玻片）；闯关点选方向。
- 输出：步骤进度条 + 视野画面（倒像）+ 放大倍数读数（MathML）；步序错误时阻塞提示。

### 触控要求

- 步骤按钮 ≥ 44px；玻片拖拽热区 ≥ 44px；反光镜调节手柄 ≥ 6 逻辑单位。
- 视野区固定高度，一屏内不滚动。

### 深色模式

- 视野底 `--bio-grid`（显微镜视野网格）；物像 `--bio-membrane`；当前步骤高亮 `--bio-highlight`（配深色字）。

### 双编码

- 步骤状态：颜色 + "✓ 已完成"/"当前步骤"文字；倒像方向：箭头 + "玻片向左，物像向右"文字。

### 复用已有类型

- 分步操作机复用 `slow-replay` 的步骤条范式；闯关点选复用 `tap-highlight`。

### 黄队接口（先动手后结论）

- 动手：学生走完"对光"（视野变亮）→ 现象：视野从暗到亮 → 结论点题："对光就是让光线穿过通光孔——视野亮了才能看"。
- 动手：闯关"物像偏左上，玻片往哪移" → 现象：点"左上"后物像移到中央 → 结论点题："偏哪移哪——因为显微镜里是倒像"。

### 蓝队评审

- ✅ **可实现（含降级）**：纯 SVG/DOM 步骤机 + 视野示意渲染。
- ⬇ **主动降级（教学聚焦）**：视野画面为**示意渲染**（简化的细胞轮廓），不做真实光学成像仿真；
  放大倍数只支持 40×/100×/400× 三档，不做连续变倍。（真实理由：技术上可实现连续变倍与光学仿真，
  但初中教学只需要"三档 + 倒像 + 反向"三个观念，QA 成本过高。）

### 常见坑

1. **阻塞不是卡死**：步序错误时必须给"回退到上一步"的明确按钮，不能只闪一下让学生猜。
2. **"偏哪移哪"口诀要配严格图示**：闯关页必须同时有"旋转 180°"小图示，口诀不能替代本质（T9）。
3. **高倍按钮置灰要有原因文字**："先在低倍下把物像移到中央"——置灰无文案 = 不合格。

## B3 · experiment-3q（实验三问设计器）

给定实验目的，学生选对照组设置、圈出"只变的一个量"、定重复次数；
实验三问徽章常驻；答错回放"如果不设对照会怎样"思想实验。
落点：**b03.1.1**（首立：绿叶实验）、**b05.1.2**（唾液淀粉酶）、**b11.1.5**（有机物鉴定）、
**b12.1.5**（质壁分离）、**b23.1.1**（温特实验）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `purpose` | string | ✅ | — | 实验目的（一句话，如"证明光是光合作用的条件"） |
| `controlOptions` | array | ✅ | — | 对照组设置选项（2–4 个字符串，含正确项与典型误项） |
| `variableOptions` | array | ✅ | — | "只变的一个量"选项（2–4 个，如"光照/温度/叶片大小"） |
| `repeatOptions` | array | ✅ | — | 重复次数选项（如"1 次/3 次/10 次"） |
| `answer` | object | ✅ | — | `{control, variable, repeat}` 正确项索引（渲染器内部校验用，不向学生展示） |
| `thoughtExp` | string | ✅ | — | 思想实验文本（答错时回放，如"如果不设遮光对照，叶片变蓝了，你怎么知道是光的功劳？"） |
| `recordKey` | string | — | — | 记录键，冻结为 `bio_3q_<课号>`（如 `bio_3q_b03.1.1`，见 B-F3） |
| `showBadge` | boolean | — | `true` | 实验三问徽章常驻（为什么设对照/为什么只变一个量/为什么要重复） |

- 三问顺序冻结：对照 → 单一变量 → 重复（见 B-F3）；每问答对出 ✓ 徽章，答错回放 `thoughtExp` 对应段落，**不判错、不扣分**。
- 三问徽章：实验页常驻，每问点开展开一句话答案（如"对照组是'参照物'：没它不知道变没变"）。
- 首立页（b03.1.1）配绿叶实验全流程回放入口；后续各课只换 `purpose`/`options`，组件同构。

### 示例

```js
interaction: {
  type: "experiment-3q",
  params: {
    purpose: "证明光是光合作用的条件",
    controlOptions: ["一半遮光、一半见光", "两片叶子都见光", "两片叶子都遮光"],
    variableOptions: ["光照", "温度", "叶片大小"],
    repeatOptions: ["1 次", "3 次", "10 次"],
    answer: { control: 0, variable: 0, repeat: 1 },
    thoughtExp: "如果不设遮光对照，叶片变蓝了，你怎么知道是光的功劳？可能是叶子本来就有淀粉。",
    recordKey: "bio_3q_b03.1.1"
  }
}
```

### 输入 / 输出

- 输入：三问依次点选；点徽章展开一句话答案。
- 输出：每问 ✓ 徽章 + 思想实验回放（答错时）；三问全对出"实验设计通过"徽章。

### 触控要求

- 选项按钮 ≥ 44px 高；选项 2–4 个横排/竖排自适应 390px；徽章点展热区 ≥ 44px。

### 深色模式

- 正确徽章 ✓ 走 `--bio-organelle`（蓝绿）+ 文字；思想实验回放区 `--bio-bg` + `--bio-text`。

### 双编码

- 对/提示：✓/文字徽章 + 思想实验文字，不只靠颜色；对照组选项配"参照物"小标签。

### 复用已有类型

- 点选 + 即时反馈复用 `tap-highlight`；记录走 localStorage（沿用 Y1 `recordKey` 口径，key 冻结格式见 B-F3）。

### 黄队接口（先动手后结论）

- 动手：学生选"两片叶子都见光"作对照 → 现象：回放"没有参照物，不知道变没变" →
  结论点题："对照组是'参照物'——没它，实验白做"。
- 动手：三问全对 → 现象："实验设计通过"徽章 → 结论点题："对照、单一变量、重复——这三问，全书每个实验都要过一遍"。

### 蓝队评审

- ✅ **可实现**：纯 DOM 组件（点选 + 条件回放），零 Canvas；记录走 localStorage（key 即 `recordKey`）。
- 离线预计算：无。

### 常见坑

1. **`answer` 索引不能写错**：`answer` 与选项数组的对应关系是校验项（见附校验清单第 4 条），黄队配页时蓝队要程序化校验越界。
2. **思想实验要具体**：`thoughtExp` 必须针对本题写（"如果不设××会怎样"），通用话术（"对照很重要"）= 不合格。
3. **三问顺序别自创**：对照 → 单一变量 → 重复是冻结顺序（B-F3），页内不得调换。

## B4 · photosyn-sandbox（光合速率调控沙盘）

光照强度 / CO₂ 浓度 / 温度三滑块调参，看光合速率（相对值）实时变化 + 速率曲线描点；
"抓主要限制因素"提示；直观版读图（不讲函数定义）。
落点：**b03.1.5**（温室调控沙盘）、**b14.1.4**（光合速率的影响因素与应用）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `light` | object | ✅ | — | 光照强度滑块 `{min, max, step, init, unit}`（相对值，如 0–100） |
| `co2` | object | ✅ | — | CO₂ 浓度滑块 `{min, max, step, init, unit}`（相对值） |
| `temp` | object | ✅ | — | 温度滑块 `{min, max, step, init, unit}`（℃，如 5–40） |
| `showCurve` | boolean | — | `true` | 是否实时绘制速率曲线（相对值纵轴） |
| `limitHint` | boolean | — | `true` | 是否显示"主要限制因素"提示（如"当前光照是短板"） |
| `relativeNote` | string | — | `"相对值（非实测数据）"` | 常驻标注文案（冻结，见 B-F4） |

- 速率模型（示意）：`rate = f(light) × g(co2) × h(temp)`，三段均为饱和型示意函数；
  纵轴一律相对值并常驻 `relativeNote`（审计清单第 9 条：用相对值时必须注明）。
- 限制因素提示：取三段函数中最小值对应的因素，文案"当前××是短板——生产上先补短板"（b14.1.4 误区"单因论"专治）。
- 读数行（MathML）：`光合速率（相对值） = …` + 当前限制因素徽章。

### 示例

```js
interaction: {
  type: "photosyn-sandbox",
  params: {
    light: { min: 0, max: 100, step: 5, init: 60, unit: "相对值" },
    co2:   { min: 0, max: 100, step: 5, init: 40, unit: "相对值" },
    temp:  { min: 5, max: 40, step: 1, init: 25, unit: "℃" },
    showCurve: true, limitHint: true
  }
}
```

### 输入 / 输出

- 输入：三滑块调参。
- 输出：速率读数实时更新 + 曲线描点 + 限制因素徽章；调参后曲线自动重绘。

### 触控要求

- 滑块轨道 ≥ 44px 高；建议配 `−`/`+` 步进按钮（精调目标值）。

### 深色模式

- 曲线 `--bio-organelle`（蓝绿）；限制因素徽章 `--bio-target`（朱红）+ 文字。

### 双编码

- 限制因素：颜色 + "短板：××"文字；曲线：实线 + 纵轴"相对值"文字标注。

### 复用已有类型

- 滑块范式复用代数 `slider-lab`；曲线描点复用 `plot-points`。

### 黄队接口（先动手后结论）

- 动手：光照拉满但 CO₂ 很低 → 现象：速率上不去、徽章"当前 CO₂ 是短板" →
  结论点题："影响因素综合作用——生产上先补短板（温室增施 CO₂）"。
- 动手：温度调到 40℃ → 现象：速率反而下降 → 结论点题："温度太高酶活性下降——不是越高越好"（回填 b13.1.2）。

### 蓝队评审

- ✅ **可实现（含降级）**：三段饱和函数解析求值 + Canvas 描点（≤200 点），rAF 无压力。
- ⬇ **主动降级（教学聚焦）**：速率曲线为**示意函数**，不做真实光合动力学模型；
  纵轴一律相对值，不承诺真实单位换算。（真实理由：零依赖/file:// 约束下，
  真实动力学参数拟合的 QA 成本过高；教学只需要"综合作用 + 抓短板"两个观念。）

### 常见坑

1. **`relativeNote` 不许删**：相对值纵轴必须常驻"相对值（非实测数据）"，删了就是编造数据精度（审计清单第 9 条）。
2. **限制因素提示别写成"唯一因素"**：文案是"当前短板"，不是"唯一原因"（防单因论回潮）。
3. **温度上限的文案**：40℃ 处配小字"温度过高，酶活性下降"——别让学生以为曲线会一直涨。

## B5 · punnett-lab（分离比模拟实验室）

次数滑块（10/100/1000 次）看性状分离比收敛；Punnett 方格点选配子组合；
9:3:3:1 棋盘格拼搭；"大量统计"徽章常驻。
落点：**b17.1.2**（性状分离比的模拟）、**b17.1.3**（自由组合定律）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `pairs` | number | — | `1` | 相对性状对数：`1` → 2×2 方格（3:1）；`2` → 4×4 棋盘格（9:3:3:1） |
| `trials` | object | — | `{min:10, max:5000, step:10, init:100}` | 模拟次数滑块（冻结默认，见 B-F5） |
| `alleles` | object | ✅ | — | `{dom:"高茎", rec:"矮茎"}` 等位基因标签（黄队配，生物队审术语） |
| `showRatio` | boolean | — | `true` | 是否显示实时比例徽章（如 `高茎 : 矮茎 = …`，MathML） |
| `statBadge` | boolean | — | `true` | "大量统计的结果"徽章常驻（冻结，见 B-F5） |
| `gridSize` | number | — | `2` | 冻结：默认 2×2（`pairs:1`）；`pairs:2` 时为 4（见 B-F5） |

- 模拟：前端伪随机抽样（`Math.random`），每次试验独立；次数滑块拖到 1000+ 时看比例收敛到理论比。
- Punnett 方格：行/列为配子，学生点选格子填基因型组合；填错只给提示"再想想配子怎么组合"，不判错。
- 概率数值校验（渲染器内部）：方格总数 = 4^`pairs`（2×2=4，4×4=16）；显性比例显示分式 + 文字（如 `3/4` + "约 75%"）。
- 9:3:3:1 棋盘格：`pairs:2` 时 16 格拼搭，配"独立遗传才成立"边界小字（审计清单第 5 条）。

### 示例

```js
interaction: {
  type: "punnett-lab",
  params: {
    pairs: 1,
    trials: { min: 10, max: 5000, step: 10, init: 100 },
    alleles: { dom: "高茎(D)", rec: "矮茎(d)" },
    showRatio: true, statBadge: true
  }
}
```

### 输入 / 输出

- 输入：次数滑块；点选方格填基因型。
- 输出：比例徽章实时收敛 + 方格填充状态；次数 ≥1000 时出"接近理论比"提示。

### 触控要求

- 方格每格 ≥ 44px（4×4 棋盘格在 390px 下用横向滚动兜底 + 格内字号 ≥12px）；滑块 ≥ 44px。

### 深色模式

- 显性 `--bio-gene`（紫红）+ "显"文字；隐性 `--bio-known`（蓝）+ "隐"文字；比例徽章文字走 `--bio-text`。

### 双编码

- 基因型：颜色 + "DD/Dd/dd"文字；比例：分式 + 百分比文字；收敛：徽章文字"接近 3:1"。

### 复用已有类型

- badge 实时验算复用 `ratio-slider`；点选填格复用 `tap-highlight`。

### 黄队接口（先动手后结论）

- 动手：次数从 10 拖到 1000 → 现象：比例从乱跳到稳定在 3:1 附近 →
  结论点题："3:1 不是每次恰好，是'大量统计的结果'——抛 10 次硬币不一定 5 正 5 反"。
- 动手：点选方格填 Dd × Dd 组合 → 现象：4 格中 3 格显性 → 结论点题："方格里的 3:1，就是模拟器里跑出来的 3:1"。

### 蓝队评审

- ✅ **可实现**：伪随机抽样 + 方格查表，O(n) 轻量；4×4 棋盘格 16 格 DOM 无压力。
- ✅ **用户拍板扩展（2026-10-14，D3 定案）**：模拟统计＋**解析概率推导页**。推导内容：Punnett 2×2 方格配子组合计数（D×D、D×d、d×D、d×d → 显性 3 格 : 隐性 1 格），从"数格子"直接得到 3∶1 的理论比；仍不引入概率定义（分数乘法即可），零数学前置。（真实理由：原降级理由"初中不讲概率定义、教学聚焦统计直觉"成立，但用户定案要求加推导；推导页用组合计数实现，不增加数学前置。）

### 常见坑

1. **`statBadge` 不许关**：没有"大量统计的结果"徽章，学生会把模拟当成"证明"（审计清单第 5 条）。
2. **4×4 格在手机上别硬塞**：390px 下 16 格每格 <44px 是硬伤——允许横向滚动或"点格放大填"，白队验收（W-B7）。
3. **等位基因标签术语要审**：`alleles` 的 D/d 大小写、显隐标注由生物队审，黄队不自创（b17.1.1 直觉页前不许出现"等位基因"术语，用"高/矮"；严格页（跃升 8）首次引入）。

## B6 · pedigree-quest（系谱判读闯关）

分步向导：先定显隐 → 再定常/性 → 再推基因型；上一步不确定不许进下一步；
"无中生有/有中生无"口诀卡；携带者表型正常标注（辨析②回填）。
落点：**b18.1.3**（系谱图判读实战）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `pedigree` | object | ✅ | — | 系谱数据（黄队配）：`{members:[{id, sex, affected, generation}], answer:{dominance, location}}` |
| `steps` | array | — | `["显隐","常性","基因型"]` | 分步顺序（冻结，不可跳步，见 B-F6） |
| `mottoCard` | boolean | — | `true` | 口诀卡常驻："无中生有是隐性，有中生无是显性"（文字逐字冻结，见 B-F6） |
| `carrierNote` | boolean | — | `true` | 携带者表型正常标注（辨析②回填，如"携带者不发病，但能传递"） |
| `scopeNote` | string | — | `"适用于孟德尔式单基因遗传系谱"` | 适用边界小字（冻结，见 B-F6；T15） |

- 分步向导：每步点选判读（显性/隐性；常染色体/X/Y）；上一步未确定时下一步按钮置灰 + 提示"先完成上一步"。
- 口诀卡：常驻侧栏/顶部，文字逐字冻结；配"先看代际，再看口诀"使用提示。
- 基因型推断步：点选成员推基因型，携带者配"表型正常"标注（`--bio-known` 蓝 + 文字）。
- 答错：给提示（"再看看第Ⅱ代：无中生有了吗？"），不判错、不扣分。

### 示例

```js
interaction: {
  type: "pedigree-quest",
  params: {
```

## B7 · central-dogma（中心法则流水线）

半保留复制亲代链去向追踪（两条链不同颜色）；转录—翻译流水线动画
（DNA → mRNA → 核糖体 → 肽链）；碱基配对拼搭（A—T/G—C）；复制 n 次 → 2ⁿ 直观版。
落点：**b19.1.2**（DNA 的复制）、**b19.1.3**（转录与翻译）、**b19.1.4**（基因对性状的控制）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `stations` | array | — | `["复制","转录","翻译"]` | 流水线三站（步骤条 ≤ 5 步口径） |
| `parentColor` | string | — | `--bio-gene` | 亲代链用 `--bio-gene`（紫红），冻结（见 B-F7） |
| `newColor` | string | — | `--bio-product` | 新合成链用 `--bio-product`（天蓝），冻结（见 B-F7） |
| `basePair` | object | — | 冻结 | `{A:"T", T:"A", G:"C", C:"G"}` 碱基互补配对规则（见 B-F7） |
| `pow2demo` | boolean | — | `true` | 复制 n 次 → 2ⁿ 直观版（n 滑块 1–5，看 DNA 数翻倍） |
| `replay` | boolean | — | `true` | 播放控制 ▶/⏸/↺（复用 slow-replay 约定） |
| `diagramNote` | string | — | `"模式图：非等比、非实物"` | 常驻声明（球棍模型/示意链，审计清单第 7 条） |

- 复制站：双链解开动画 → 亲代链（紫红）各带一条 → 新链（天蓝）合成；子代 DNA 一条紫红一条天蓝，
  配文字"亲代链 / 新合成链"（T14："各带一条"配完整句）。
- 转录站：DNA → mRNA（U 代替 T 配对，`basePair` 扩展 `{A:"U"}`）；翻译站：mRNA → 核糖体 → 肽链（氨基酸小球串起）。
- 碱基配对拼搭：拖碱基卡到互补位，配对错误温和回弹（复用 B1 吸附口径）。
- 2ⁿ 直观版：n 滑块 1–5，DNA 数 2→4→8→16→32 动画翻倍，配"直观版：只看翻倍感觉"小字。

### 示例

```js
interaction: {
  type: "central-dogma",
  params: {
    stations: ["复制", "转录", "翻译"],
    pow2demo: true, replay: true
  }
}
```

### 输入 / 输出

- 输入：▶ 播放三站流水线；拖碱基卡配对；n 滑块看翻倍。
- 输出：亲代链去向追踪（两色）+ 肽链生成 + 2ⁿ 读数（MathML）。

### 触控要求

- 播放按钮 ≥ 44px；碱基卡热区 ≥ 44px；n 滑块 ≥ 44px。

### 深色模式

- 亲代链 `--bio-gene` 深色提亮紫红；新链 `--bio-product` 深色提亮天蓝；链上配"亲代"/"新"文字标签。

### 双编码

- 亲代/新链：颜色 + "亲代链"/"新合成链"文字；碱基：字母 + 配对连线；复制方式：动画 + "半保留"文字徽章。

### 复用已有类型

- 三站播放控制复用 `slow-replay`；碱基拼搭吸附复用 `cut-reassemble`。

### 黄队接口（先动手后结论）

- 动手：播放复制站 → 现象：两条紫红链分开，各带一条天蓝链 → 结论点题："亲代两条链'各带一条'传下去——这叫半保留"。
- 动手：n 滑块从 1 拖到 5 → 现象：DNA 数 2→4→8→16→32 → 结论点题："复制 n 次，2ⁿ 个——翻倍的感觉"（直观版）。

### 蓝队评审

- ✅ **可实现（含降级）**：SVG 链条动画 + 关键帧，无分子模拟。
- ⬇ **主动降级（教学聚焦）**：动画为**示意**（链的粗细/速度非真实比例），不做分子动力学；
  常驻"示意，非真实速度/比例"。（真实理由：零依赖/file:// 约束下真实分子模拟 ROI 为负；
  教学只需要"半保留去向 + 三站顺序"两个观念。）

### 常见坑

1. **亲代/新链颜色冻结**：`parentColor`/`newColor` 不得自创配色（B-F7），全书统一。
2. **"半保留"三个字必须出现**：动画再清楚，徽章文字"半保留复制"不能少（防"全保留"直觉回潮）。
3. **转录的 U 要讲清**：mRNA 中 A—U 配对，params 的 `basePair` 扩展要在 hints 写清"RNA 中没有 T，用 U"。

## B9 · popgrowth-sim（种群增长曲线模拟）

资源无限/有限切换看 J 型/S 型曲线分叉；拖环境条件看 K 值升降；
曲线读图直观版；样方法计数小游戏（生物自带抽样直觉）。
落点：**b24.1.1**（种群的特征与数量变化）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `mode` | string | — | `"unlimited"` | 冻结默认：`"unlimited"`（J 型）/ `"limited"`（S 型）（见 B-F9） |
| `kSlider` | object | — | `{min:50, max:500, step:10, init:200, unit:"只"}` | 环境容量 K 滑块（`mode:"limited"` 时启用） |
| `envNote` | string | — | `"K 值由环境决定：环境改善，K 可升"` | 常驻提示文案（冻结，见 B-F9） |
| `showSampling` | boolean | — | `true` | 样方法计数小游戏（随机撒点 → 框选计数 → 估算总量） |
| `curveNote` | string | — | `"示意曲线（非实测数据）"` | 常驻标注（冻结，见 B-F9） |

- 曲线：J 型（指数示意）/ S 型（逻辑斯谛示意），`plot-points` 逐点描画；切换模式时两条曲线同屏对比 1 秒后分叉。
- K 值：滑块拖动 → S 型曲线平台实时升降 + `envNote` 常驻；K 值处画虚线 + "K"文字标记。
- 读数行（MathML）：`K = … 只` + 当前曲线类型徽章（"J 型：资源无限" / "S 型：资源有限"）。
- 样方法小游戏：随机撒 N 个点 → 学生拖框计数 → 估算总量公式 `总量 ≈ 框内数 × 总面积/框面积`（直观版，不讲统计定义）。

### 示例

```js
interaction: {
  type: "popgrowth-sim",
  params: {
    mode: "unlimited",
    kSlider: { min: 50, max: 500, step: 10, init: 200, unit: "只" },
    showSampling: true
  }
}
```

### 输入 / 输出

- 输入：模式切换；K 值滑块；样方法框选计数。
- 输出：曲线分叉动画 + K 虚线升降 + 估算结果读数。

### 触控要求

- 模式切换按钮 ≥ 44px；K 值滑块 ≥ 44px；样方框拖拽手柄 ≥ 6 逻辑单位。

### 深色模式

- J 型曲线 `--bio-organelle`（蓝绿实线）；S 型曲线 `--bio-target`（朱红实线）；K 虚线 `--bio-aux` 灰虚线 + "K"文字。

### 双编码

- J/S 型：颜色 + "J 型"/"S 型"文字徽章 + 线型（J 型实线/S 型实线+K 虚线）；K 值：虚线 + 文字。

### 复用已有类型

- 滑块复用 `slider-lab`；曲线描点复用 `plot-points`。

### 黄队接口（先动手后结论）

- 动手：从"资源无限"切到"资源有限" → 现象：曲线从 J 型"飞上天"变成 S 型"趴下来" →
  结论点题："资源有限，增长会碰到天花板——这个天花板叫 K"。
- 动手：拖 K 值滑块 → 现象：S 型平台上下动 → 结论点题："K 不是曲线的属性，是环境的容量——池塘能养多少鱼，池塘说了算"。

### 蓝队评审

- ✅ **可实现（含降级）**：示意函数描点（≤200 点），K 值只做曲线平移/缩放。
- ⬇ **主动降级（教学聚焦）**：曲线为**示意函数**（指数/逻辑斯谛形态示意），不做真实种群动力学拟合；
  样方法小游戏为计数示意，不做真实抽样统计推断。（真实理由：技术上可实现拟合，
  但教学只需要"J/S 形态 + K 由环境定"两个观念，直观版读图已够。）

### 常见坑

1. **`curveNote` 不许删**：示意曲线必须标注"非实测数据"（审计清单第 9 条）。
2. **K 值虚线别画成实线**：K 是"环境容量"不是"种群数量"，虚线 + 文字缺一不可。
3. **默认模式是 J 型**：`mode` 默认 `"unlimited"` 冻结（B-F9）——先给"无约束"的直觉，再加约束。

## B10 · enzyme-lab（酶条件实验室）

温度/pH 双滑块看酶活性曲线；"锁钥"配对小游戏（酶—底物专一性）；
高温不可恢复 vs 低温可恢复对比演示。
落点：**b13.1.2**（酶的特性）、**b05.1.2**（唾液淀粉酶：专一性回填）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `temp` | object | — | `{min:0, max:70, step:1, init:37, unit:"℃"}` | 温度滑块（冻结默认，见 B-F10） |
| `ph` | object | — | `{min:0, max:14, step:0.5, init:7}` | pH 滑块（冻结默认，见 B-F10） |
| `lockKey` | boolean | — | `true` | "锁钥"配对小游戏（拖底物到对应的酶） |
| `irreversDemo` | boolean | — | `true` | 高温不可恢复 vs 低温可恢复对比演示 |
| `curveNote` | string | — | `"示意曲线（非实测数据）"` | 常驻标注 |

- 活性曲线：温度/ pH 单变量示意曲线（钟形），另一变量固定在最适值；读数行（MathML）：`相对活性 = …%`。
- 锁钥小游戏：3 把"锁"（酶）+ 3 把"钥匙"（底物），拖配对；配错温和回弹；配对成功出"专一性"徽章 + 边界小字"结合时会微调（诱导契合）"（T3）。
- 不可恢复对比：温度拖到 70℃ → 曲线"烫坏"（锁图标裂开 + "不可恢复"文字）→ 调回 37℃ 活性不恢复；
  拖到 0℃ → "冻住"（雪花图标 + "可恢复"文字）→ 调回 37℃ 活性恢复。两态用图标 + 文字双编码，不只靠颜色。

### 示例

```js
interaction: {
  type: "enzyme-lab",
  params: {
    temp: { min: 0, max: 70, step: 1, init: 37, unit: "℃" },
    ph: { min: 0, max: 14, step: 0.5, init: 7 },
    lockKey: true, irreversDemo: true
  }
}
```

### 输入 / 输出

- 输入：温度/pH 双滑块；拖底物配酶。
- 输出：活性曲线游标 + 读数 + "烫坏/冻住"状态徽章 + 专一性徽章。

### 触控要求

- 双滑块 ≥ 44px；锁/钥匙卡片热区 ≥ 44px；状态徽章字号 ≥ 14px。

### 深色模式

- 曲线 `--bio-target`（朱红）；最适点 `--bio-highlight`（黄）+ "最适"文字；烫坏/冻住图标配文字。

### 双编码

- 活性：曲线 + 百分比读数；烫坏/冻住：裂开锁图标/雪花图标 + "不可恢复"/"可恢复"文字。

### 复用已有类型

- 滑块复用 `slider-lab`；曲线游标与滑块双向同步复用 `ladder-slide`；配对吸附复用 `cut-reassemble`。

### 黄队接口（先动手后结论）

- 动手：温度从 37℃ 拖到 70℃ 再拖回 → 现象："烫坏，不可恢复" → 结论点题："高温把锁'烫变形'，回不来——这就是为什么发烧太高危险"。
- 动手：温度拖到 0℃ 再拖回 37℃ → 现象："冻住，可恢复" → 结论点题："低温只是'冻住'，回温能恢复——'烫坏'和'冻住'两回事"。
- 动手：锁钥配对 → 现象：淀粉酶只认淀粉 → 结论点题："一把锁只开一把钥匙——这就是专一性（回填 b05.1.2：唾液只消化淀粉）"。

### 蓝队评审

- ✅ **可实现**：示意曲线求值 + 状态机（正常/烫坏/冻住），纯前端。
- 离线预计算：无。

### 常见坑

1. **"烫坏"状态要锁死**：一旦进入不可恢复态，调回最适温度活性也不恢复——状态机必须真锁死，不能"假装"。
2. **锁钥边界句不能少**：`lockKey` 成功后必须出"结合时会微调"小字（T3：刚性模型的边界）。
3. **pH 滑块步长**：`step:0.5` 保证手机能调到 7.0 这类目标值；配 `−`/`+` 步进按钮（W-P9 同源口径）。

## B11 · mitosis-stage（分裂时期辨认）

根尖虚拟制片（解离 → 漂洗 → 染色 → 制片，步序规范）；低倍找分生区 → 高倍认时期闯关；
"间期最长"计数器（数一数各时期细胞数）。
落点：**b16.1.1**（有丝分裂）、**b16.1.2**（观察根尖分生区细胞有丝分裂）。

### Schema

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `prepSteps` | array | — | `["解离","漂洗","染色","制片"]` | 制片步骤（顺序冻结，不可跳步，见 B-F11） |
| `observeSteps` | array | — | `["低倍找分生区","高倍认时期"]` | 观察步骤（顺序冻结） |
| `stages` | array | — | `["间期","前期","中期","后期","末期"]` | 时期（直觉版在前、术语版在后，见 B-F11） |
| `countQuiz` | boolean | — | `true` | "间期最长"计数器：数各时期细胞数，看间期最多 |
| `safetyNote` | string | — | `"盐酸解离：戴手套操作，解离后必须漂洗"` | 安全徽章文案（常驻） |

- 制片步序机：跳过"漂洗"直接"染色" → 阻塞 + 提示"解离液会干扰染色，先漂洗！"（实验规范教学点）。
- 找分生区：低倍视野中点选"排列紧密、近正方形"的区域；点错给提示"分生区的细胞小而排列紧密"。
- 认时期闯关：高倍视野给 6 张细胞图，学生点选时期；直觉版先认"复制/排队/分开/进两个细胞"动作，再对术语名。
- 计数器：统计各时期细胞数，柱状图显示"间期最多"→ 结论"间期最长"（b16.1.2 误区"中期最多"专治）。

### 示例

```js
interaction: {
  type: "mitosis-stage",
  params: {
    prepSteps: ["解离", "漂洗", "染色", "制片"],
    countQuiz: true
  }
}
```

### 输入 / 输出

- 输入：按步序点选制片操作；低倍点选分生区；高倍点选时期。
- 输出：制片进度 + 视野画面 + 时期判定反馈 + 计数柱状图。

### 触控要求

- 视野点选热区 ≥ 44px；步骤按钮 ≥ 44px；细胞图 ≥ 56px（认时期可辨）。

### 深色模式

- 染色体 `--bio-gene`（紫红）；纺锤丝 `--bio-aux`（灰虚线）；当前时期高亮 `--bio-highlight`。

### 双编码

- 时期：颜色 + 时期名文字 + 染色体行为小字（如"着丝粒排在赤道板"）；计数：柱高 + 数字。

### 复用已有类型

- 步序机复用 `slow-replay` 步骤条；点选认时期复用 `tap-highlight`。

### 黄队接口（先动手后结论）

- 动手：跳过"漂洗"点"染色" → 现象：阻塞 + "先漂洗！" → 结论点题："解离液不洗掉，染色染不上——规范就是结论的一部分"。
- 动手：数完 6 张图的时期 → 现象：间期柱最高 → 结论点题："间期最长——视野里中期细胞最多是错觉"。

### 蓝队评审

- ✅ **可实现**：纯 DOM/SVG 步骤机 + 点选判定；细胞图为示意 SVG（非真实显微照片）。
- 离线预计算：无。

### 常见坑

1. **示例顺序即冻结顺序**：示例 `prepSteps` 即 B-F11 冻结值（`["解离","漂洗","染色","制片"]`），黄队配页时照抄。
2. **细胞图要示意化声明**：认时期的细胞图是示意 SVG，角落配"模式图"声明（审计清单第 7 条）。
3. **直觉版在前**：先认动作（复制/排队/分开），再对术语名——顺序反了就是术语轰炸（分层口径，B-F11）。

## B12 · immuno-flow（免疫流程推演）

疫苗回填链接 b08.1.3。

### Schema

|---|---|---|---|---|

- 路径选择：抗原入侵 → 学生选"体液线/细胞线" → 对应流程图展开；两线可对比（"体液管'液体里'的敌人，细胞管'藏进细胞'的敌人"）。
- 角色排序：拖角色卡到流程槽位；顺序错误 → 提示"××应该在××前面，因为××"（讲因果，不只说错）。
- 纠错点：流程走到"抗体"时弹出纠错卡"抗体是'抱住'抗原，不是'杀死'——结合后由吞噬细胞清除"（T11）。
- 疫苗回填：流程末尾"记忆细胞"处挂链接"还记得 b08.1.3 的疫苗吗？——疫苗就是一次'演习'，留下记忆细胞"。

### 示例

```js
  type: "immuno-flow",
  params: {
    branch: "humoral",
    roleCards: [
      { id: "r1", label: "吞噬细胞", desc: "吞噬抗原，暴露抗原信息" },
      { id: "r2", label: "B 细胞", desc: "增殖分化为浆细胞" },
```

### 触控要求

- 角色卡热区 ≥ 44px；流程槽位 ≥ 13 逻辑单位；分支切换按钮 ≥ 44px。

### 深色模式

- 抗原 `--bio-substrate`（橙）+ "抗原"文字；抗体 `--bio-product`（天蓝）+ "抗体"文字；流程线 `--bio-membrane`。

### 双编码

- 角色：颜色 + 名称 + 职责一句话；抗体/抗原结合：连线 + "结合"文字（不用"杀死"）。

### 复用已有类型

### 黄队接口（先动手后结论）

- 动手：学生把"抗体"卡放到"杀死抗原"槽 → 现象：纠错卡弹出"抗体是'抱住'，不是'杀死'" →

- 动手：走到"记忆细胞" → 现象：疫苗回填链接 → 结论点题："疫苗就是一次'演习'——b08.1.3 的老朋友回来了"。

### 蓝队评审

- ✅ **可实现**：纯 DOM/SVG 流程图 + 拖拽排序，零性能风险。
- 离线预计算：无。

### 常见坑

1. **`bindNote` 不许关**："抗体结合不杀死"是本交互的核心纠错点，关了等于白做（B-F12）。

3. **两线对比别搞混**：体液线/细胞线切换时，已放的角色卡要清空（两线角色不同），切换需二次确认。
